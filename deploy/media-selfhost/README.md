# Manaratak self-hosted media package

Status: prepared for isolated deployment; **not activated externally**. This is separate from `scripts/testing/courses-media-provider-lab.mjs`. The lab's known-hash scanner is never imported here. No environment or database in the running platform is changed by these files.

## Components and contracts

- HTTPS provider: existing EAP HTTP/HMAC contracts for upload/refresh, signature verification, ClamAV scan, reconstruction, atomic clean promotion, secure delivery, bounded reads, archive/restore/reconciliation and deletion. All control calls require the canonical provider signature and durable replay-nonce reservation. Request fingerprints prevent idempotency-key substitution. Signed grants bind purpose, exact locator and short expiry; clean-delivery grants also bind SHA-256. Archived/deleted/tampered objects fail delivery even with an earlier token.
- Private ClamAV `INSTREAM`: actual byte scanning, fresh signature database required (maximum 48 hours); scanner errors, size/recursion limits and unknown replies fail closed. Signatures are updated by a separate FreshClam container. ClamD and processor have no Internet route or published port.
- Private processor: no storage volume, provider credentials or Docker socket. FFmpeg decodes/re-encodes media with `file` as the only input protocol and removes metadata; Ghostscript `pdfimage24` reconstructs PDF as raster pages with `SAFER`; UTF-8 text/VTT is validated. Outputs are type/size checked and scanned again before promotion. No shell interpolation, URL fetching, source passthrough or fixture bypass.
- Explicit limits: one operation per provider instance, one processing job, 64 MiB binary / 2 MiB text, 90-second codec budget. Busy service returns 503 for retry. Do not run multiple provider replicas against the same filesystem. Longer/larger media requires a separately designed queued processing contract. New file formats and thumbnail rendition endpoints are deliberately unsupported and fail closed; do not configure this package as the provider for unrelated EAP rendition jobs without implementing that contract.

PDF reconstruction preserves rendered pages, **not searchable text, forms, signatures, attachments or active links**. This choice removes source executable objects; approve this delivery policy before accepting production teaching PDFs. Nothing truncates page count or media duration to manufacture a successful output.

## Operator setup (not performed by this change)

1. Use a Linux Docker host with at least 8 GiB available RAM, disk quota for the data/jobs paths, encrypted storage, backups, NTP and a trusted TLS certificate. Provider should live on a dedicated media origin without application session cookies. Reserve a reverse-proxy hostname forwarding to loopback 8443; disable proxy access logs for grant paths and request bodies. Set proxy limits/timeouts consistently. Do not expose ClamD or worker ports.
2. Copy `.env.example` **outside Git**. Set audited `node:<supported>-bookworm-slim@sha256:...` and `clamav/clamav:<supported>_base@sha256:...` image references; no image/digest is invented by this package. Build and scan the resulting processor image and record FFmpeg/Ghostscript package versions before rollout. Review image and codec updates on a regular schedule.
3. Generate credentials locally with `node prepare-secrets.mjs /srv/manaratak-media-secrets`. Supply `tls_key` and full-chain `tls_certificate` as separate private files. Secrets are distinct, generated randomly, never printed and never overwritten. Provision private `storage`, `jobs`, `signatures` directories beneath `MEDIA_DATA_DIR`, owned by `MEDIA_UID:MEDIA_GID` (default 10001); restrict storage/secrets to that operator identity. Bind-mounted secrets must be readable by that UID. Keep the jobs path quota bounded (for example 1 GiB); never grant the processor access to the storage or signature volume.
4. Validate with `docker compose --env-file /private/media.env config --quiet`, then build and start **on an isolated host first**. FreshClam must download and validate signatures before ClamD becomes available; a missing database must remain unavailable. All runtime services use a read-only root filesystem, dropped capabilities, no-new-privileges and resource limits. The updater alone has external network access.
5. Inject `MANARATAK_ASSET_PROVIDER_BASE_URL`, `MANARATAK_ASSET_PROVIDER_API_KEY`, `MANARATAK_ASSET_PROVIDER_SIGNING_SECRET`, timeout 120000 and bounded response size into an **isolated API** through its secret manager. Key/signing values correspond to the private provider files. Never set an insecure-HTTP override or disable TLS validation. Use the existing authenticated `/v1/capabilities/readiness` checks; readiness must reflect real scanner/database/processor availability.
6. Run actual acceptance: clean audio/video/image/PDF/VTT upload → finalization → scan → reconstruction → rescan → clean promotion → authorized student playback/download; confirm SHA/type/size and all PDF pages/video duration. Send EICAR through the scanner path and require rejection. Test expired/tampered tokens, nonce replay after restart, wrong MIME/size/hash, scanner stop/stale database, worker timeout, idempotent retries, archive/delete revocation, restore checksum, storage-full and restart recovery. Also confirm signature updater isolation and that processing cannot reach external hosts. **Do not switch production until these pass.**
7. Retain canonical EAP records/audit as the owner of retention/deletion. Back up storage, metadata, operations and receipts together; restore and test hashes. Nonces are pruned after 3 minutes; receipts after 24 hours (longer than grant TTL); lifecycle fences persist. Review orphan quarantine files/storage capacity through an explicit approved retention procedure, never by indiscriminately deleting files still referenced by EAP. Rotate credentials in a planned maintenance window; old short-lived grants cease when grant signing changes. Rollback uses the previous provider image/config and private storage backup; do not roll back domain trust records to make unsafe files readable.

## Verified locally and remaining operational work

Before Compose validation, run `node verify-config.mjs /private/media.env` to reject mutable image references, public secrets paths and malformed origins. For the isolated engine smoke test only, set `MEDIA_INSTANCE_KIND=isolated` on that isolated provider and run `MEDIA_SELFHOST_ACCEPTANCE=ISOLATED_ONLY MEDIA_ACCEPTANCE_ORIGIN=https://127.0.0.1:8443 MEDIA_ACCEPTANCE_SECRET_DIR=/private/secrets node accept-isolated.mjs`. Use a locally trusted TLS certificate, not a TLS-verification bypass. The test checks the provider's isolated attestation **before any upload**, exercises real engine/reconstruction/archive/restore paths and removes only its own generated objects. The default provider scope is production and is refused by this test. It does not replace the codec matrix or container failure tests above.

`node --test deploy/media-selfhost/security.test.mjs` verifies control signatures, grant integrity/expiry, MIME/path restrictions and scanner TCP failure/stale-database handling. The TCP test server is explicitly a contract emulator, **not ClamAV**. Runtime syntax/config checks can run without Docker. This workstation has no Docker/ClamAV/Ghostscript service; real engine, codec, container, TLS/DNS, disk quota, update and restore acceptance are consequently **not certified here**. There are no external deployments or production writes.
