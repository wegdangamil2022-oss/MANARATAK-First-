# منارتك — نسخة التصميم والمعاينة

هذا المستودع **Manaratal-Final** مخصص لتعديل الشكل والهوية والألوان في Google AI Studio.
وهو منفصل عن المستودع الرسمي **MANARATAK_FINAL**. البيانات المعروضة أمثلة للتصميم وليست معلومات محدثة للتقديم.

## التشغيل

```sh
npm install
npm run dev
```

افتح المنفذ 3000:

- الموقع العام: `/ar` أو `/en`.
- لوحة التحكم: `/admin/dashboard`.
- يوجد رابط عائم للتبديل بين الواجهتين.

يعمل المشروع بواجهة React وVite فقط. لا يحتاج إلى API أو قاعدة بيانات أو مفاتيح بيئة.
للبناء: `npm run build`، ثم `npm run preview`.
يمكن استيراد هذا المستودع في Google AI Studio وتشغيل أمر التطوير المعتاد.

## ما تم تضمينه

- ملفات الواجهة العامة في `apps/web/src`، ومنها البطاقات وصفحات التفاصيل.
- ملفات لوحة التحكم في `apps/admin/src`، مع بيانات عرض للمنح والجامعات والتخصصات والدورات والاختبارات.
- بيانات تجريبية للواجهة العامة: المنح، الجامعات، التخصصات، الدول، الدورات، الاختبارات، المقالات، الخدمات وأدوات الطلاب.
- الأجزاء المشتركة التي تحتاجها الواجهتان فقط في `packages`.
- ملفات تشغيل المعاينة في `preview` و`vite.config.ts`.

بعض شاشات الإدارة المتخصصة تعرض حالات فارغة؛ هذه نسخة تصميم وليست نظام إدارة عاملًا.
أوامر الكتابة والاستيراد والدفع لا تنفذ عمليات حقيقية. الصور والخطوط الخارجية تحتاج إلى الإنترنت.

## تعديل التصميم وإعادة التعديلات لاحقًا

حافظ على أسماء الملفات ومساراتها. عدّل الألوان والتنسيق والمكونات داخل:

- `apps/web/src/features/public-template`: تصميم الموقع والبطاقات؛ البيانات في `data`.
- `apps/web/src/index.css` و`apps/admin/src/index.css`: الألوان والأنماط العامة.
- `apps/admin/src/pages` و`apps/admin/src/components`: صفحات ومكونات لوحة التحكم.

عند نقل التعديلات إلى الرسمي لاحقًا، راجع فرق ملفات التصميم فقط.
لا تنقل `preview` أو إعدادات المعاينة أو تغيير `BrowserRouter basename` إلى الرسمي تلقائيًا.
لا تضف معلومات اتصال أو مفاتيح سرية أو بيانات مستخدمين إلى نسخة التصميم.
