## 2. طبيعة الدكتوراه وهدفها

تهدف دكتوراه الصحافة العلمية إلى إعداد باحث أو ممارس باحث قادر على إنتاج معرفة مستقلة في الإعلام والاتصال وصناعة المعنى العام، مع تركيز على اتصال المخاطر وعدم اليقين العلمي وعلاقة الصحفيين بالعلماء والمجلات المحكمة. ويُتوقع منه تحديد فجوة حقيقية، وبناء سؤال أو مشكلة قابلة للفحص، واختيار نظرية ومنهج ينسجمان مع طبيعة المجال.

تختلف عن مستوى الماجستير في أن الطالب يقود برنامجًا بحثيًا طويل الأجل، ويطور تفسيرًا أو منهجًا أو ممارسة أو أداة جديدة، ويختبر حدودها وصلاحيتها وقابليتها للنقل. لا تشمل هوية التخصص بيانات جامعة أو مشرف أو برنامج مؤسسي محدد.

## 3. أنواع الدكتوراه الشائعة

- دكتوراه بحثية تقليدية بأطروحة.
- دكتوراه بينية تربط الاتصال بالسياسة أو الصحة أو التقنية.
- دكتوراه تعاونية مع مؤسسة إعلامية أو عامة مع استقلال أكاديمي.
- دكتوراه بالنشر أو مسار مدمج عند توفر النظام.

## 4. الخلفيات الأكاديمية المناسبة ومسارات الدخول

### تخصصات الماجستير المرتبطة

- الصحافة العلمية
- الإعلام والاتصال
- الصحافة أو العلاقات العامة

### تخصصات قريبة قد تقبل

- العلوم الاجتماعية أو السياسية
- التسويق أو الدراسات الثقافية لمسارات محددة
- مجال كمي أو تقني مناسب إذا كان موضوع الأطروحة يتطلبه

### الدخول المباشر بعد البكالوريوس عند شيوعه

- بكالوريوس متميز في الصحافة العلمية أو مجال قريب ضمن مسار دكتوراه مدمج.
- درجة مهنية أو إبداعية أولى مع ملف بحث أو ممارسة قوي.
- خلفية بينية مع مقررات استدراكية وخبرة موثقة في مجال السؤال.

### الخبرة أو الترخيص المطلوب للدكتوراه المهنية

- قد تتطلب الصيغة المهنية خبرة موثقة وملف أعمال أو ممارسة مناسبًا.
- لا تمنح الدكتوراه تلقائيًا ترخيصًا مهنيًا أو صلاحية تشغيلية منظمة.
- أي عمل مع جمهور أو عملاء أو رياضيين أو مجتمعات أو مواد حساسة يحتاج الموافقات والاختصاصات المناسبة.

## 5. مراحل برنامج الدكتوراه

1. مقررات أو حلقات متقدمة بحسب نظام البرنامج.
2. تدريب بحثي ومنهجي وبناء خطة تعلم فردية.
3. امتحان شامل أو تأهيلي عند وجوده.
4. تحديد مشكلة البحث ومراجعة الأدبيات والممارسات السابقة.
5. إعداد المقترح وخطة البيانات أو الممارسة والموافقات الأخلاقية.
6. الانتقال إلى مرحلة مرشح الدكتوراه.
7. تنفيذ البحث أو المشروع وتحليل الأدلة وتوثيق القرارات.
8. عرض النتائج أو الأعمال ونشرها عند اشتراط ذلك.
9. كتابة الأطروحة أو التفسير النقدي ومناقشته والدفاع عنه.
10. استكمال الإيداع ومتطلبات التخرج.

## 6. المعرفة والمقررات المتقدمة

### المعرفة النظرية المتقدمة

- اتصال المخاطر وعدم اليقين العلمي.
- علاقة الصحفيين بالعلماء والمجلات المحكمة.
- مكافحة التضليل العلمي والصحي.
- تصور الجمهور للأدلة والخبرة.
- نظريات الاتصال والإعلام وتكوين الرأي العام.
- اقتصاديات الإعلام والمنصات والتحولات الرقمية.
- الجمهور والثقة والمصداقية وتأثير الرسائل.

### مناهج البحث والتحليل

- تحليل المحتوى والخطاب والأطر الإعلامية.
- المسوحات والتجارب ودراسات الجمهور.
- المقابلات والإثنوغرافيا الرقمية ودراسات غرف الأخبار.
- تحليل الشبكات والمنصات والبيانات الرقمية.
- تصميم مقارن أو طولي أو مختلط عند ملاءمته للسؤال.

### الأخلاقيات والنزاهة العلمية

- حماية المشاركين والمصادر والبيانات الشخصية.
- الشفافية في جمع بيانات المنصات واستخدام الخوارزميات.
- تجنب الإضرار والتضليل والتلاعب بالجمهور.
- إدارة تضارب المصالح والاستقلال التحريري.
- توثيق القرارات والبيانات أو المواد والإصدارات بما يسمح بالتدقيق وإعادة التقييم.

- اقتصاديات الإعلام والمنصات والتحولات الرقمية

## 8. الامتحان التأهيلي أو الشامل عند وجوده

قد يختبر التقييم المعرفة المتقدمة في الصحافة العلمية، ونقد الأدبيات، وتصميم دراسة أو تحليل حالة، والدفاع عن فرضيات أو تفسيرات بديلة. وتختلف الصيغة بين اختبار تحريري أو شفهي أو دفاع عن مقترح أولي.

## 9. مقترح البحث ومرحلة الترشح

يحدد المقترح مشكلة قابلة للفحص في اتصال المخاطر وعدم اليقين العلمي، ويربطها بالأدبيات والنظرية، ويبرر اختيار البيانات أو الحالات أو المشاركين، وأدوات القياس والتحليل، وخطة الجودة والشفافية، والأخلاقيات والموارد والمخاطر والجدول الزمني.

## 10. الأطروحة والمساهمة الأصلية

قد تتمثل المساهمة الأصلية في تطوير نظرية أو نموذج أو منهج جديد يفسر اتصال المخاطر وعدم اليقين العلمي، أو إنتاج دليل تجريبي أو ممارسة موثقة تعيد صياغة فهم علاقة الصحفيين بالعلماء والمجلات المحكمة، أو تصميم أداة أو إطار تقييم يمكن اختباره ونقد حدوده ونقله إلى سياقات أخرى.

## 11. الإشراف والبيئة البحثية

- مشرف رئيس ذو خبرة في الصحافة العلمية وموضوع السؤال الدقيق.
- لجنة تضم خبرة نظرية ومنهجية وتطبيقية أو إبداعية بحسب المشروع.
- وصول مشروع إلى البيانات أو المواقع أو الاستوديوهات أو المنصات أو المشاركين المطلوبين.
- دعم تقني أو إحصائي أو إنتاجي وتوثيقي مناسب.
- خطة لإدارة الحقوق والمخاطر واستمرارية الوصول إلى الموارد.

## 12. متطلبات البحث والنشر والتدريس

- حلقات بحث وتحديثات دورية للجنة الإشراف.
- عرض نتائج أو أعمال في مؤتمر أو ندوة أو معرض أو منصة مناسبة.
- إعداد أوراق أو مخرجات محكمة وفق سياسة المؤسسة وطبيعة المجال.
- تدريس أو مساعدة تعليمية أو إشراف عملي في بعض البرامج.
- تدريب في الأخلاقيات وإدارة البيانات أو الحقوق والسلامة.
- حفظ سجل بحث أو ممارسة يوضح القرارات والتغييرات والنتائج.

## 13. المهارات البحثية والمهنية المتقدمة

- صياغة سؤال أصيل في الصحافة العلمية
- بناء إطار نظري ومنهجي قابل للدفاع
- تطبيق مناهج متقدمة على اتصال المخاطر وعدم اليقين العلمي
- تحليل أدلة أو ممارسات معقدة ونقد حدودها
- إدارة مشروع بحث طويل متعدد الأطراف
- الكتابة والنشر والعرض والدفاع العلمي
- الالتزام بالأخلاقيات والشفافية والمسؤولية

## 5. مراحل برنامج الدكتوراه

2. تدريب بحثي ومنهجي وبناء خطة تعلم فردية.
3. امتحان شامل أو تأهيلي عند وجوده.
4. تحديد مشكلة البحث ومراجعة الأدبيات والممارسات السابقة.
5. إعداد المقترح وخطة البيانات أو الممارسة والموافقات الأخلاقية.
6. الانتقال إلى مرحلة مرشح الدكتوراه.
7. تنفيذ البحث أو المشروع وتحليل الأدلة وتوثيق القرارات.
8. عرض النتائج أو الأعمال ونشرها عند اشتراط ذلك.
9. كتابة الأطروحة أو التفسير النقدي ومناقشته والدفاع عنه.
10. استكمال الإيداع ومتطلبات التخرج.

## 2. طبيعة الدكتوراه وهدفها

تهدف دكتوراه الإعلان إلى إعداد باحث أو ممارس باحث قادر على إنتاج معرفة مستقلة في الإعلام والاتصال وصناعة المعنى العام، مع تركيز على الإقناع والانتباه والذاكرة والاستهداف والإعلانات البرمجية. ويُتوقع منه تحديد فجوة حقيقية، وبناء سؤال أو مشكلة قابلة للفحص، واختيار نظرية ومنهج ينسجمان مع طبيعة المجال.

تختلف عن مستوى الماجستير في أن الطالب يقود برنامجًا بحثيًا طويل الأجل، ويطور تفسيرًا أو منهجًا أو ممارسة أو أداة جديدة، ويختبر حدودها وصلاحيتها وقابليتها للنقل. لا تشمل هوية التخصص بيانات جامعة أو مشرف أو برنامج مؤسسي محدد.

## 3. أنواع الدكتوراه الشائعة

## 2. طبيعة الدكتوراه وهدفها

تهدف دكتوراه الاتصال التسويقي إلى إعداد باحث أو ممارس باحث قادر على إنتاج معرفة مستقلة في الإعلام والاتصال وصناعة المعنى العام، مع تركيز على تكامل الرسائل عبر القنوات ورحلة العميل والعلامة التجارية. ويُتوقع منه تحديد فجوة حقيقية، وبناء سؤال أو مشكلة قابلة للفحص، واختيار نظرية ومنهج ينسجمان مع طبيعة المجال.

تختلف عن مستوى الماجستير في أن الطالب يقود برنامجًا بحثيًا طويل الأجل، ويطور تفسيرًا أو منهجًا أو ممارسة أو أداة جديدة، ويختبر حدودها وصلاحيتها وقابليتها للنقل. لا تشمل هوية التخصص بيانات جامعة أو مشرف أو برنامج مؤسسي محدد.

## 3. أنواع الدكتوراه الشائعة

- دكتوراه بحثية تقليدية بأطروحة.
- دكتوراه بينية تربط الاتصال بالسياسة أو الصحة أو التقنية.
- دكتوراه تعاونية مع مؤسسة إعلامية أو عامة مع استقلال أكاديمي.
- دكتوراه بالنشر أو مسار مدمج عند توفر النظام.

## 4. الخلفيات الأكاديمية المناسبة ومسارات الدخول

### تخصصات الماجستير المرتبطة

- الاتصال التسويقي
- الإعلام والاتصال
- الصحافة أو العلاقات العامة

### تخصصات قريبة قد تقبل

- العلوم الاجتماعية أو السياسية
- التسويق أو الدراسات الثقافية لمسارات محددة
- مجال كمي أو تقني مناسب إذا كان موضوع الأطروحة يتطلبه

### الدخول المباشر بعد البكالوريوس عند شيوعه

- بكالوريوس متميز في الاتصال التسويقي أو مجال قريب ضمن مسار دكتوراه مدمج.
- درجة مهنية أو إبداعية أولى مع ملف بحث أو ممارسة قوي.
- خلفية بينية مع مقررات استدراكية وخبرة موثقة في مجال السؤال.

### الخبرة أو الترخيص المطلوب للدكتوراه المهنية

- قد تتطلب الصيغة المهنية خبرة موثقة وملف أعمال أو ممارسة مناسبًا.
- لا تمنح الدكتوراه تلقائيًا ترخيصًا مهنيًا أو صلاحية تشغيلية منظمة.
- أي عمل مع جمهور أو عملاء أو رياضيين أو مجتمعات أو مواد حساسة يحتاج الموافقات والاختصاصات المناسبة.

## 5. مراحل برنامج الدكتوراه

1. مقررات أو حلقات متقدمة بحسب نظام البرنامج.
2. تدريب بحثي ومنهجي وبناء خطة تعلم فردية.
3. امتحان شامل أو تأهيلي عند وجوده.
4. تحديد مشكلة البحث ومراجعة الأدبيات والممارسات السابقة.
5. إعداد المقترح وخطة البيانات أو الممارسة والموافقات الأخلاقية.
6. الانتقال إلى مرحلة مرشح الدكتوراه.
7. تنفيذ البحث أو المشروع وتحليل الأدلة وتوثيق القرارات.
8. عرض النتائج أو الأعمال ونشرها عند اشتراط ذلك.
9. كتابة الأطروحة أو التفسير النقدي ومناقشته والدفاع عنه.
10. استكمال الإيداع ومتطلبات التخرج.

| طبيعة التوفر | متخصصة ومتفاوتة التوفر، وتتركز في كليات الإعلام والاتصال ومراكز بحوث المنصات والمجال العام |
| الوصف المختصر | دكتوراه تركز على إنتاج معرفة أو ممارسة أصلية في الاتصال الاستراتيجي، مع اهتمام خاص بـمواءمة الاتصال مع الأهداف المؤسسية وبناء الشرعية والثقة. |

## 2. طبيعة الدكتوراه وهدفها

تهدف دكتوراه الاتصال الاستراتيجي إلى إعداد باحث أو ممارس باحث قادر على إنتاج معرفة مستقلة في الإعلام والاتصال وصناعة المعنى العام، مع تركيز على مواءمة الاتصال مع الأهداف المؤسسية وبناء الشرعية والثقة. ويُتوقع منه تحديد فجوة حقيقية، وبناء سؤال أو مشكلة قابلة للفحص، واختيار نظرية ومنهج ينسجمان مع طبيعة المجال.

تختلف عن مستوى الماجستير في أن الطالب يقود برنامجًا بحثيًا طويل الأجل، ويطور تفسيرًا أو منهجًا أو ممارسة أو أداة جديدة، ويختبر حدودها وصلاحيتها وقابليتها للنقل. لا تشمل هوية التخصص بيانات جامعة أو مشرف أو برنامج مؤسسي محدد.

## 3. أنواع الدكتوراه الشائعة

- دكتوراه بحثية تقليدية بأطروحة.
- دكتوراه بينية تربط الاتصال بالسياسة أو الصحة أو التقنية.
- دكتوراه تعاونية مع مؤسسة إعلامية أو عامة مع استقلال أكاديمي.
- دكتوراه بالنشر أو مسار مدمج عند توفر النظام.

## 4. الخلفيات الأكاديمية المناسبة ومسارات الدخول

### تخصصات الماجستير المرتبطة

- الاتصال الاستراتيجي
- الإعلام والاتصال
- الصحافة أو العلاقات العامة

### تخصصات قريبة قد تقبل

- العلوم الاجتماعية أو السياسية
- التسويق أو الدراسات الثقافية لمسارات محددة
- مجال كمي أو تقني مناسب إذا كان موضوع الأطروحة يتطلبه

### الدخول المباشر بعد البكالوريوس عند شيوعه

- بكالوريوس متميز في الاتصال الاستراتيجي أو مجال قريب ضمن مسار دكتوراه مدمج.
- درجة مهنية أو إبداعية أولى مع ملف بحث أو ممارسة قوي.
- خلفية بينية مع مقررات استدراكية وخبرة موثقة في مجال السؤال.

### الخبرة أو الترخيص المطلوب للدكتوراه المهنية

- قد تتطلب الصيغة المهنية خبرة موثقة وملف أعمال أو ممارسة مناسبًا.
- لا تمنح الدكتوراه تلقائيًا ترخيصًا مهنيًا أو صلاحية تشغيلية منظمة.
- أي عمل مع جمهور أو عملاء أو رياضيين أو مجتمعات أو مواد حساسة يحتاج الموافقات والاختصاصات المناسبة.

## 5. مراحل برنامج الدكتوراه

1. مقررات أو حلقات متقدمة بحسب نظام البرنامج.
2. تدريب بحثي ومنهجي وبناء خطة تعلم فردية.
3. امتحان شامل أو تأهيلي عند وجوده.
4. تحديد مشكلة البحث ومراجعة الأدبيات والممارسات السابقة.
5. إعداد المقترح وخطة البيانات أو الممارسة والموافقات الأخلاقية.
6. الانتقال إلى مرحلة مرشح الدكتوراه.
7. تنفيذ البحث أو المشروع وتحليل الأدلة وتوثيق القرارات.
8. عرض النتائج أو الأعمال ونشرها عند اشتراط ذلك.
9. كتابة الأطروحة أو التفسير النقدي ومناقشته والدفاع عنه.
10. استكمال الإيداع ومتطلبات التخرج.

- الجمهور والثقة والمصداقية وتأثير الرسائل.

### مناهج البحث والتحليل

- المسوحات والتجارب ودراسات الجمهور.
- المقابلات والإثنوغرافيا الرقمية ودراسات غرف الأخبار.
- تحليل الشبكات والمنصات والبيانات الرقمية.
- تصميم مقارن أو طولي أو مختلط عند ملاءمته للسؤال.

### الأخلاقيات والنزاهة العلمية

- الشفافية في جمع بيانات المنصات واستخدام الخوارزميات.
- تجنب الإضرار والتضليل والتلاعب بالجمهور.
- إدارة تضارب المصالح والاستقلال التحريري.
- توثيق القرارات والبيانات أو المواد والإصدارات بما يسمح بالتدقيق وإعادة التقييم.

## 8. الامتحان التأهيلي أو الشامل عند وجوده

قد يختبر التقييم المعرفة المتقدمة في الاتصال الاستراتيجي، ونقد الأدبيات، وتصميم دراسة أو تحليل حالة، والدفاع عن فرضيات أو تفسيرات بديلة. وتختلف الصيغة بين اختبار تحريري أو شفهي أو دفاع عن مقترح أولي.

## 9. مقترح البحث ومرحلة الترشح

يحدد المقترح مشكلة قابلة للفحص في مواءمة الاتصال مع الأهداف المؤسسية، ويربطها بالأدبيات والنظرية، ويبرر اختيار البيانات أو الحالات أو المشاركين، وأدوات القياس والتحليل، وخطة الجودة والشفافية، والأخلاقيات والموارد والمخاطر والجدول الزمني.

## 10. الأطروحة والمساهمة الأصلية

قد تتمثل المساهمة الأصلية في تطوير نظرية أو نموذج أو منهج جديد يفسر مواءمة الاتصال مع الأهداف المؤسسية، أو إنتاج دليل تجريبي أو ممارسة موثقة تعيد صياغة فهم بناء الشرعية والثقة، أو تصميم أداة أو إطار تقييم يمكن اختباره ونقد حدوده ونقله إلى سياقات أخرى.

## 11. الإشراف والبيئة البحثية

- مشرف رئيس ذو خبرة في الاتصال الاستراتيجي وموضوع السؤال الدقيق.
- لجنة تضم خبرة نظرية ومنهجية وتطبيقية أو إبداعية بحسب المشروع.
- وصول مشروع إلى البيانات أو المواقع أو الاستوديوهات أو المنصات أو المشاركين المطلوبين.
- دعم تقني أو إحصائي أو إنتاجي وتوثيقي مناسب.
- خطة لإدارة الحقوق والمخاطر واستمرارية الوصول إلى الموارد.

## 12. متطلبات البحث والنشر والتدريس

- حلقات بحث وتحديثات دورية للجنة الإشراف.
- عرض نتائج أو أعمال في مؤتمر أو ندوة أو معرض أو منصة مناسبة.
- إعداد أوراق أو مخرجات محكمة وفق سياسة المؤسسة وطبيعة المجال.
- تدريس أو مساعدة تعليمية أو إشراف عملي في بعض البرامج.
- تدريب في الأخلاقيات وإدارة البيانات أو الحقوق والسلامة.
- حفظ سجل بحث أو ممارسة يوضح القرارات والتغييرات والنتائج.

- تجنب الإضرار والتضليل والتلاعب بالجمهور.
- إدارة تضارب المصالح والاستقلال التحريري.
- توثيق القرارات والبيانات أو المواد والإصدارات بما يسمح بالتدقيق وإعادة التقييم.

## 7. مجالات البحث والتخصصات الدقيقة

- الهوية والسمعة المؤسسية
- اتصال القيادة والموظفين
- تقارير الاستدامة والمسؤولية

- نظريات الاتصال والإعلام وتكوين الرأي العام
- اقتصاديات الإعلام والمنصات والتحولات الرقمية

## 8. الامتحان التأهيلي أو الشامل عند وجوده

قد يختبر التقييم المعرفة المتقدمة في الاتصال المؤسسي، ونقد الأدبيات، وتصميم دراسة أو تحليل حالة، والدفاع عن فرضيات أو تفسيرات بديلة. وتختلف الصيغة بين اختبار تحريري أو شفهي أو دفاع عن مقترح أولي.

## 9. مقترح البحث ومرحلة الترشح

يحدد المقترح مشكلة قابلة للفحص في الهوية والسمعة المؤسسية، ويربطها بالأدبيات والنظرية، ويبرر اختيار البيانات أو الحالات أو المشاركين، وأدوات القياس والتحليل، وخطة الجودة والشفافية، والأخلاقيات والموارد والمخاطر والجدول الزمني.

## 10. الأطروحة والمساهمة الأصلية

قد تتمثل المساهمة الأصلية في تطوير نظرية أو نموذج أو منهج جديد يفسر الهوية والسمعة المؤسسية، أو إنتاج دليل تجريبي أو ممارسة موثقة تعيد صياغة فهم اتصال القيادة والموظفين، أو تصميم أداة أو إطار تقييم يمكن اختباره ونقد حدوده ونقله إلى سياقات أخرى.

## 11. الإشراف والبيئة البحثية

- وصول مشروع إلى البيانات أو المواقع أو الاستوديوهات أو المنصات أو المشاركين المطلوبين.

- خطة لإدارة الحقوق والمخاطر واستمرارية الوصول إلى الموارد.

- إعداد أوراق أو مخرجات محكمة وفق سياسة المؤسسة وطبيعة المجال.

- حفظ سجل بحث أو ممارسة يوضح القرارات والتغييرات والنتائج.

## 2. طبيعة الدكتوراه وهدفها

تهدف دكتوراه الاتصال السياسي إلى إعداد باحث أو ممارس باحث قادر على إنتاج معرفة مستقلة في الإعلام والاتصال وصناعة المعنى العام، مع تركيز على الحملات والخطاب الانتخابي والإعلام والديمقراطية والاستقطاب. ويُتوقع منه تحديد فجوة حقيقية، وبناء سؤال أو مشكلة قابلة للفحص، واختيار نظرية ومنهج ينسجمان مع طبيعة المجال.

تختلف عن مستوى الماجستير في أن الطالب يقود برنامجًا بحثيًا طويل الأجل، ويطور تفسيرًا أو منهجًا أو ممارسة أو أداة جديدة، ويختبر حدودها وصلاحيتها وقابليتها للنقل. لا تشمل هوية التخصص بيانات جامعة أو مشرف أو برنامج مؤسسي محدد.

## 3. أنواع الدكتوراه الشائعة

- دكتوراه بحثية تقليدية بأطروحة.
- دكتوراه بينية تربط الاتصال بالسياسة أو الصحة أو التقنية.
- دكتوراه تعاونية مع مؤسسة إعلامية أو عامة مع استقلال أكاديمي.
- دكتوراه بالنشر أو مسار مدمج عند توفر النظام.

## 4. الخلفيات الأكاديمية المناسبة ومسارات الدخول

### تخصصات الماجستير المرتبطة

- الاتصال السياسي
- الإعلام والاتصال
- الصحافة أو العلاقات العامة

### تخصصات قريبة قد تقبل

- العلوم الاجتماعية أو السياسية
- التسويق أو الدراسات الثقافية لمسارات محددة
- مجال كمي أو تقني مناسب إذا كان موضوع الأطروحة يتطلبه

### الدخول المباشر بعد البكالوريوس عند شيوعه

- بكالوريوس متميز في الاتصال السياسي أو مجال قريب ضمن مسار دكتوراه مدمج.
- درجة مهنية أو إبداعية أولى مع ملف بحث أو ممارسة قوي.
- خلفية بينية مع مقررات استدراكية وخبرة موثقة في مجال السؤال.

### الخبرة أو الترخيص المطلوب للدكتوراه المهنية

- قد تتطلب الصيغة المهنية خبرة موثقة وملف أعمال أو ممارسة مناسبًا.
- لا تمنح الدكتوراه تلقائيًا ترخيصًا مهنيًا أو صلاحية تشغيلية منظمة.
- أي عمل مع جمهور أو عملاء أو رياضيين أو مجتمعات أو مواد حساسة يحتاج الموافقات والاختصاصات المناسبة.

## 5. مراحل برنامج الدكتوراه

1. مقررات أو حلقات متقدمة بحسب نظام البرنامج.
2. تدريب بحثي ومنهجي وبناء خطة تعلم فردية.
3. امتحان شامل أو تأهيلي عند وجوده.
4. تحديد مشكلة البحث ومراجعة الأدبيات والممارسات السابقة.
5. إعداد المقترح وخطة البيانات أو الممارسة والموافقات الأخلاقية.
6. الانتقال إلى مرحلة مرشح الدكتوراه.
7. تنفيذ البحث أو المشروع وتحليل الأدلة وتوثيق القرارات.
8. عرض النتائج أو الأعمال ونشرها عند اشتراط ذلك.
9. كتابة الأطروحة أو التفسير النقدي ومناقشته والدفاع عنه.
10. استكمال الإيداع ومتطلبات التخرج.

## 2. طبيعة الدكتوراه وهدفها

تهدف دكتوراه الاتصال الصحي إلى إعداد باحث أو ممارس باحث قادر على إنتاج معرفة مستقلة في الإعلام والاتصال وصناعة المعنى العام، مع تركيز على التواصل بين الممارس والمريض وحملات الصحة العامة. ويُتوقع منه تحديد فجوة حقيقية، وبناء سؤال أو مشكلة قابلة للفحص، واختيار نظرية ومنهج ينسجمان مع طبيعة المجال.

تختلف عن مستوى الماجستير في أن الطالب يقود برنامجًا بحثيًا طويل الأجل، ويطور تفسيرًا أو منهجًا أو ممارسة أو أداة جديدة، ويختبر حدودها وصلاحيتها وقابليتها للنقل. لا تشمل هوية التخصص بيانات جامعة أو مشرف أو برنامج مؤسسي محدد.

## 3. أنواع الدكتوراه الشائعة

- دكتوراه بحثية تقليدية بأطروحة.
- دكتوراه بينية تربط الاتصال بالسياسة أو الصحة أو التقنية.
- دكتوراه تعاونية مع مؤسسة إعلامية أو عامة مع استقلال أكاديمي.
- دكتوراه بالنشر أو مسار مدمج عند توفر النظام.

## 4. الخلفيات الأكاديمية المناسبة ومسارات الدخول

### تخصصات الماجستير المرتبطة

- الاتصال الصحي
- الإعلام والاتصال
- الصحافة أو العلاقات العامة

### تخصصات قريبة قد تقبل

- العلوم الاجتماعية أو السياسية
- التسويق أو الدراسات الثقافية لمسارات محددة
- مجال كمي أو تقني مناسب إذا كان موضوع الأطروحة يتطلبه

### الدخول المباشر بعد البكالوريوس عند شيوعه

- بكالوريوس متميز في الاتصال الصحي أو مجال قريب ضمن مسار دكتوراه مدمج.
- درجة مهنية أو إبداعية أولى مع ملف بحث أو ممارسة قوي.
- خلفية بينية مع مقررات استدراكية وخبرة موثقة في مجال السؤال.

### الخبرة أو الترخيص المطلوب للدكتوراه المهنية

- قد تتطلب الصيغة المهنية خبرة موثقة وملف أعمال أو ممارسة مناسبًا.
- لا تمنح الدكتوراه تلقائيًا ترخيصًا مهنيًا أو صلاحية تشغيلية منظمة.
- أي عمل مع جمهور أو عملاء أو رياضيين أو مجتمعات أو مواد حساسة يحتاج الموافقات والاختصاصات المناسبة.

## 5. مراحل برنامج الدكتوراه

1. مقررات أو حلقات متقدمة بحسب نظام البرنامج.
2. تدريب بحثي ومنهجي وبناء خطة تعلم فردية.
3. امتحان شامل أو تأهيلي عند وجوده.
4. تحديد مشكلة البحث ومراجعة الأدبيات والممارسات السابقة.
5. إعداد المقترح وخطة البيانات أو الممارسة والموافقات الأخلاقية.
6. الانتقال إلى مرحلة مرشح الدكتوراه.
7. تنفيذ البحث أو المشروع وتحليل الأدلة وتوثيق القرارات.
8. عرض النتائج أو الأعمال ونشرها عند اشتراط ذلك.
9. كتابة الأطروحة أو التفسير النقدي ومناقشته والدفاع عنه.
10. استكمال الإيداع ومتطلبات التخرج.

## 9. مقترح البحث ومرحلة الترشح

## 10. الأطروحة والمساهمة الأصلية

قد تتمثل المساهمة الأصلية في تطوير نظرية أو نموذج أو منهج جديد يفسر التواصل بين الممارس والمريض، أو إنتاج دليل تجريبي أو ممارسة موثقة تعيد صياغة فهم حملات الصحة العامة، أو تصميم أداة أو إطار تقييم يمكن اختباره ونقد حدوده ونقله إلى سياقات أخرى.

## 11. الإشراف والبيئة البحثية

- دعم تقني أو إحصائي أو إنتاجي وتوثيقي مناسب.
- خطة لإدارة الحقوق والمخاطر واستمرارية الوصول إلى الموارد.

## 12. متطلبات البحث والنشر والتدريس

- حلقات بحث وتحديثات دورية للجنة الإشراف.
- عرض نتائج أو أعمال في مؤتمر أو ندوة أو معرض أو منصة مناسبة.
- إعداد أوراق أو مخرجات محكمة وفق سياسة المؤسسة وطبيعة المجال.
- تدريس أو مساعدة تعليمية أو إشراف عملي في بعض البرامج.
- تدريب في الأخلاقيات وإدارة البيانات أو الحقوق والسلامة.
- حفظ سجل بحث أو ممارسة يوضح القرارات والتغييرات والنتائج.

- لا تمنح الدكتوراه تلقائيًا ترخيصًا مهنيًا أو صلاحية تشغيلية منظمة.

## 5. مراحل برنامج الدكتوراه

4. تحديد مشكلة البحث ومراجعة الأدبيات والممارسات السابقة.

6. الانتقال إلى مرحلة مرشح الدكتوراه.
7. تنفيذ البحث أو المشروع وتحليل الأدلة وتوثيق القرارات.
8. عرض النتائج أو الأعمال ونشرها عند اشتراط ذلك.
9. كتابة الأطروحة أو التفسير النقدي ومناقشته والدفاع عنه.

## 2. طبيعة الدكتوراه وهدفها

تهدف دكتوراه الإعلام الجديد إلى إعداد باحث أو ممارس باحث قادر على إنتاج معرفة مستقلة في الإعلام والاتصال وصناعة المعنى العام، مع تركيز على تحولات الوسائط والتقارب وثقافة المشاركة والمبدعين. ويُتوقع منه تحديد فجوة حقيقية، وبناء سؤال أو مشكلة قابلة للفحص، واختيار نظرية ومنهج ينسجمان مع طبيعة المجال.

تختلف عن مستوى الماجستير في أن الطالب يقود برنامجًا بحثيًا طويل الأجل، ويطور تفسيرًا أو منهجًا أو ممارسة أو أداة جديدة، ويختبر حدودها وصلاحيتها وقابليتها للنقل. لا تشمل هوية التخصص بيانات جامعة أو مشرف أو برنامج مؤسسي محدد.

- دكتوراه تعاونية مع مؤسسة إعلامية أو عامة مع استقلال أكاديمي.

- تدريس أو مساعدة تعليمية أو إشراف عملي في بعض البرامج.
- تدريب في الأخلاقيات وإدارة البيانات أو الحقوق والسلامة.
- حفظ سجل بحث أو ممارسة يوضح القرارات والتغييرات والنتائج.

## 13. المهارات البحثية والمهنية المتقدمة

- صياغة سؤال أصيل في الإعلام الجديد
- بناء إطار نظري ومنهجي قابل للدفاع
- تطبيق مناهج متقدمة على تحولات الوسائط والتقارب
- تحليل أدلة أو ممارسات معقدة ونقد حدودها
- إدارة مشروع بحث طويل متعدد الأطراف
- الكتابة والنشر والعرض والدفاع العلمي
- الالتزام بالأخلاقيات والشفافية والمسؤولية

## 14. مجالات العمل بعد الدكتوراه

- الجامعات ومراكز بحوث الإعلام
- المؤسسات الإعلامية وغرف الأخبار
- الهيئات التنظيمية والسياسات العامة
- وكالات الاتصال والعلاقات العامة
- مختبرات المنصات والبيانات الرقمية

## 15. أهم الوظائف المرتبطة

| الوظيفة | مدى مناسبة الدكتوراه | الملاحظة |
|---|---|---|
| باحث إعلام واتصال | مناسبة جدًا | يرتبط المجال الدقيق بموضوع الأطروحة ومنهجها. |
| عضو هيئة أكاديمية | مناسبة | التعيين تنافسي ويتطلب نشرًا وتدريسًا. |
| خبير استراتيجية أو سياسات اتصال | مناسبة مع خبرة | تتطلب فهمًا مؤسسيًا وقدرة على تحويل الأدلة إلى قرارات. |
| ممارس إعلامي مستقل | ليست شرطًا كافيًا | الخبرة المهنية والملف العملي يظلان مهمين. |

## 16. ما بعد الدكتوراه والمسارات اللاحقة

- زمالة ما بعد الدكتوراه في الإعلام أو الاتصال.
- مسار أكاديمي وبحوث الجمهور والمنصات.
- مختبرات السياسات الإعلامية والبيانات.
- البحث والتطوير داخل المؤسسات الإعلامية.
- الاستشارات وقياس الأثر الاتصالي.

## 17. الدكتوراه المشابهة والفروق

| التخصص أو الدرجة المشابهة | الفرق المختصر |
|---|---|
| دكتوراه الإعلام أو الاتصال | أوسع من التخصص الحالي وتضم نظريات ووسائط متعددة. |
| دكتوراه الصحافة أو الاتصال الاستراتيجي | تختلف بحسب تركيز السؤال على الممارسة التحريرية أو الإدارة والتأثير. |
| دكتوراه الدراسات الرقمية أو الثقافية | أكثر بينية في المنصات والثقافة والسلطة. |

## 18. التنبيه الأكاديمي والمهني

> **الدكتوراه لا تضمن منصبًا تحريرياً أو إداريًا، ولا تبرر جمع بيانات الجمهور أو المصادر دون أساس أخلاقي وقانوني. يجب الفصل بين البحث المستقل والعمل الدعائي أو المؤسسي المدفوع.**
