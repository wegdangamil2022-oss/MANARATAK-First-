## 2. طبيعة الدكتوراه وهدفها

تهدف دكتوراه التاريخ العام إلى إعداد باحث قادر على إنتاج معرفة مستقلة في التاريخ في المتاحف والمواقع، وربطها بالذاكرة العامة والسياسة والتاريخ الشفهي والمجتمعي. ويُتوقع منه تحديد فجوة حقيقية، وصياغة سؤال قابل للفحص، وبناء حجة أو تصميم بحث يميز بين الوصف والتفسير والسببية أو الحكم المعياري بحسب طبيعة المجال.

تختلف عن مستوى الماجستير في أن الطالب يقود برنامجًا بحثيًا طويل الأجل، ويطور نظرية أو منهجًا أو دليلًا أو أداة جديدة، ويختبر حدود الصلاحية والتعميم. لا تشمل هوية التخصص بيانات جامعة أو مشرف أو برنامج مؤسسي بعينه.

## 3. أنواع الدكتوراه الشائعة

- دكتوراه بحثية تقليدية قائمة على أطروحة أصلية.
- دكتوراه بينية عند اتصال السؤال بتخصص آخر ومنهج واضح للدمج.
- دكتوراه تعاونية مع مؤسسة عامة أو ثقافية أو مهنية مع استقلال أكاديمي واضح.
- دكتوراه بالنشر أو مسار مدمج عند توفر النظام المؤسسي.

اسم الدرجة لا ينشئ تخصصًا مستقلًا؛ فقد يطرح التاريخ العام ضمن PhD / DPhil وفق النظام والهدف الأكاديمي أو المهني.

## 4. الخلفيات الأكاديمية المناسبة ومسارات الدخول

### تخصصات الماجستير المرتبطة

- MAS-0810 — المسار المرجعي المرتبط في دليل الماجستير
- التاريخ أو أحد فروعه
- الآثار أو الدراسات الإقليمية
- العلوم السياسية أو الاجتماع التاريخي
- اللغات والآداب للوصول إلى المصادر
- الإنسانيات الرقمية لمسار حاسوبي تاريخي

### تخصصات قريبة قد تقبل

- تخصص قريب يدعم سؤال الأطروحة ومنهجها مع استيفاء المتطلبات الاستدراكية.
- خلفية بينية تجمع المجال الأساسي مع الإحصاء أو الحوسبة أو التاريخ أو القانون أو الصحة أو الاقتصاد بحسب موضوع البحث.
- خبرة مهنية موثقة عندما تكون الدكتوراه مهنية أو قائمة على الممارسة.

### الدخول المباشر بعد البكالوريوس عند شيوعه

- بكالوريوس متميز في مجال مرتبط ضمن نظام يسمح بالدخول المباشر أو المسار المدمج.
- خبرة بحثية موثقة وكتابة أكاديمية قوية وكفاية في المناهج المطلوبة.
- مقررات استدراكية عندما تختلف الخلفية عن جوهر التخصص.

### الخبرة أو الترخيص المطلوب للدكتوراه المهنية

- قد تتطلب الصيغة المهنية خبرة عملية وملف ممارسة أو مسؤولية مناسبة.
- الوصول إلى أفراد أو مؤسسات أو قضايا أو بيانات حساسة يحتاج موافقات وصلاحيات منفصلة.
- أي ممارسة مهنية منظمة أو وصول إلى بيانات حساسة يخضع لاعتماد أو تصريح مستقل.

## 5. مراحل برنامج الدكتوراه

1. مقررات أو حلقات متقدمة وخطة تعلم فردية.
2. تدريب منهجي في البحث الأرشيفي ونقد المصادر الأولية والمقارنة التاريخية والتحليل السياقي.
3. امتحان شامل أو تأهيلي عند وجوده.
4. مراجعة نقدية للأدبيات وتحديد الفجوة.
5. إعداد المقترح وخطة البيانات أو المصادر والأخلاقيات.
6. الانتقال إلى مرحلة مرشح الدكتوراه بعد موافقة اللجنة.
7. تنفيذ البحث باستخدام التاريخ الشفهي مع بروتوكولات أخلاقية والتحليل الكمي أو المكاني للسجلات عند الملاءمة عند الملاءمة.
8. اختبارات تحقق أو متانة أو مقارنة وتفسير بدائل النتائج.
9. كتابة الأطروحة ومناقشتها والدفاع عنها.
10. الإيداع واستكمال متطلبات النزاهة والبيانات والتخرج.

### المعرفة النظرية المتقدمة

- التحقيب والاستمرارية والتغير.
- السببية التاريخية والفاعلية والبنى.
- الذاكرة والهوية والسرديات العامة.
- تاريخ المؤسسات والمجتمعات والأفكار.

### مناهج البحث والتحليل

- البحث الأرشيفي ونقد المصادر الأولية.
- المقارنة التاريخية والتحليل السياقي.
- التاريخ الشفهي مع بروتوكولات أخلاقية.
- التحليل الكمي أو المكاني للسجلات عند الملاءمة.
- الإنسانيات الرقمية وبناء قواعد المصادر.

### الأخلاقيات والنزاهة العلمية

- الحصول على الموافقات الأخلاقية قبل جمع بيانات الأفراد أو المؤسسات أو المجتمعات.
- حماية الخصوصية والسرية والملكية الفكرية والمواد الحساسة.
- الإفصاح عن التمويل وتضارب المصالح المهنية أو السياسية أو المالية.
- توثيق المصادر والتحويلات والأدوات والشفرة أو بروتوكولات التحليل.
- عدم تضخيم النتائج أو إخفاء عدم اليقين أو استخدام البحث للإضرار بالمشاركين.

- التاريخ الشفهي والمجتمعي
- الإعلام والمنتجات الرقمية التاريخية

- المقارنة بين السياقات والتحولات المعاصرة

## 8. الامتحان التأهيلي أو الشامل عند وجوده

قد يختبر الامتحان المعرفة المتقدمة في التاريخ في المتاحف والمواقع والذاكرة العامة والسياسة، والقدرة على تحليل مادة أو بيانات أو حالة مرتبطة بالتاريخ العام والدفاع عن منهج يستخدم البحث الأرشيفي ونقد المصادر الأولية والمقارنة التاريخية والتحليل السياقي. كما قد يتطلب نقد أدبيات متعارضة، وتبرير وحدة التحليل، وبيان كيفية التحقق من الادعاءات والبدائل التفسيرية.

قد يكون تحريريًا أو شفهيًا أو دفاعًا عن مقترح أولي، وتختلف صيغته وتبعات النجاح أو الإخفاق بين الجامعات والأنظمة.

## 9. مقترح البحث ومرحلة الترشح

يحدد المقترح مشكلة أصلية في التاريخ في المتاحف والمواقع أو الذاكرة العامة والسياسة، ويعرض سؤال البحث أو الفرضيات أو الأطروحة، ويبرر استخدام البحث الأرشيفي ونقد المصادر الأولية والمقارنة التاريخية والتحليل السياقي. كما يحدد الحدث أو الفترة أو المؤسسة أو الجماعة أو مجموعة المصادر، والسياق أو الفترة أو المجتمع أو المؤسسة، ويشرح معايير الاختيار والنطاق وحدود الاستدلال.

يجب أن يتضمن خطة للبيانات أو المصادر، والجودة، والأخلاقيات، والمخاطر، والموارد، والجدول الزمني، ومعايير مسبقة للتحقق أو المقارنة، وخطة بديلة إذا تعذر الوصول إلى مادة أو مؤسسة أو عينة أساسية.

## 10. الأطروحة والمساهمة الأصلية

قد تتمثل المساهمة الأصلية في تفسير تاريخي جديد أو اكتشاف مصادر أو قاعدة بيانات أو إعادة بناء موثقة يضيف معرفة قابلة للتحقق في التاريخ العام، بما يطور فهم التاريخ في المتاحف والمواقع أو يقدم تفسيرًا أو أداة أو ممارسة قابلة للتقييم في التاريخ الشفهي والمجتمعي.

يمكن أن تكون الأطروحة تقليدية أو قائمة على أوراق منشورة أو مشروعًا مهنيًا موثقًا، لكن يجب أن تكون وحدة المساهمة واضحة، وأن يفصل الباحث بين ما أثبته وما استنتجه وما اقترحه معياريًا أو تطبيقيًا.

## 11. الإشراف والبيئة البحثية

- وصول قانوني ومستقر إلى الأرشيفات والمصادر.
- إشراف في الفترة والجغرافيا والمنهج.
- دعم لغوي أو باليوغرافي عند الحاجة.
- خطة لحفظ النسخ والبيانات الوصفية وحقوق الاستخدام.
- لجنة إشراف تجمع خبرة موضوعية ومنهجية مستقلة.
- خطة لإدارة الوصول والتخزين الآمن واستمرارية البيانات أو المصادر.

لا تحفظ أسماء المشرفين أو المؤسسات داخل هوية التخصص؛ فهي بيانات برامج جامعية في Phase 11.

## 12. متطلبات البحث والنشر والتدريس

- حلقات بحث وتحديثات دورية للجنة الإشراف.
- توثيق المنهج والبيانات أو النصوص أو الحالات وإجراءات التحليل.
- اختبارات جودة ومتانة أو مقارنة مستقلة تتناسب مع المجال.
- إعداد أوراق أو أدوات أو تقارير قابلة للتحكيم وفق سياسة المؤسسة.
- تدريس أو مساعدة تعليمية أو تدريب مهني في بعض البرامج.

لا توجد أعداد عالمية موحدة للمنشورات أو المؤتمرات أو ساعات التدريس.

## 13. المهارات البحثية والمهنية المتقدمة

- صياغة سؤال بحث أصيل في التاريخ العام.
- نقد الأدلة والنظريات في التاريخ في المتاحف والمواقع.
- تطبيق البحث الأرشيفي ونقد المصادر الأولية والمقارنة التاريخية والتحليل السياقي بصورة مستقلة.
- إدارة بيانات أو نصوص أو وثائق أو حالات معقدة وضبط جودتها.
- تقييم التحيز وعدم اليقين وحدود التعميم أو النقل بين السياقات.
- الكتابة والنشر والعرض والدفاع العلمي.
- قيادة تعاون متعدد التخصصات وإدارة مشروع طويل الأجل.

## 14. مجالات العمل بعد الدكتوراه

- الجامعات ومراكز البحوث التاريخية
- الأرشيفات والمكتبات الوطنية
- المتاحف ومؤسسات الذاكرة
- مراكز السياسات والدراسات الإقليمية
- مشروعات التاريخ العام والرقمي

## 16. ما بعد الدكتوراه والمسارات اللاحقة

- زمالة ما بعد الدكتوراه في التاريخ العام أو مجال قريب.
- مسار أكاديمي في البحث والتدريس والإشراف.
- البحث والاستشارات في مؤسسة عامة أو ثقافية أو اجتماعية أو خاصة أو دولية.
- قيادة برامج بحث أو سياسات أو تطوير بعد اكتساب الخبرة.
- ممارسة مهنية متقدمة عند استيفاء الترخيص أو الاعتماد المستقل.

## 18. التنبيه الأكاديمي والمهني

> **الاستنتاج التاريخي يعتمد على نوعية المصادر وحدود بقائها وتمثيلها، ولا يجوز تحويل الغياب الأرشيفي إلى دليل قاطع. يجب تمييز المصدر الأولي عن التأويل، وتوثيق التحيزات والفراغات. جودة الإشراف والبيئة والبيانات أو المصادر أهم من اسم الدرجة وحده، والدكتوراه لا تضمن وظيفة أكاديمية.**

## 2. طبيعة الدكتوراه وهدفها

تهدف دكتوراه علم الاجتماع إلى إعداد باحث قادر على إنتاج معرفة مستقلة في النظرية الاجتماعية والمؤسسات، وربطها باللامساواة والطبقة والجندر والأسرة والعمل والتعليم. ويُتوقع منه تحديد فجوة حقيقية، وصياغة سؤال قابل للفحص، وبناء حجة أو تصميم بحث يميز بين الوصف والتفسير والسببية أو الحكم المعياري بحسب طبيعة المجال.

تختلف عن مستوى الماجستير في أن الطالب يقود برنامجًا بحثيًا طويل الأجل، ويطور نظرية أو منهجًا أو دليلًا أو أداة جديدة، ويختبر حدود الصلاحية والتعميم. لا تشمل هوية التخصص بيانات جامعة أو مشرف أو برنامج مؤسسي بعينه.

## 3. أنواع الدكتوراه الشائعة

- دكتوراه بحثية تقليدية قائمة على أطروحة أصلية.
- دكتوراه بينية عند اتصال السؤال بتخصص آخر ومنهج واضح للدمج.
- دكتوراه تعاونية مع مؤسسة عامة أو ثقافية أو مهنية مع استقلال أكاديمي واضح.
- دكتوراه بالنشر أو مسار مدمج عند توفر النظام المؤسسي.

اسم الدرجة لا ينشئ تخصصًا مستقلًا؛ فقد يطرح علم الاجتماع ضمن PhD / DPhil وفق النظام والهدف الأكاديمي أو المهني.

## 8. الامتحان التأهيلي أو الشامل عند وجوده

قد يختبر الامتحان المعرفة المتقدمة في النظرية الاجتماعية والمؤسسات واللامساواة والطبقة والجندر، والقدرة على تحليل مادة أو بيانات أو حالة مرتبطة بـعلم الاجتماع والدفاع عن منهج يستخدم المسوح والتحليل الإحصائي والسببي والمقابلات والإثنوغرافيا ودراسة الحالة. كما قد يتطلب نقد أدبيات متعارضة، وتبرير وحدة التحليل، وبيان كيفية التحقق من الادعاءات والبدائل التفسيرية.

قد يكون تحريريًا أو شفهيًا أو دفاعًا عن مقترح أولي، وتختلف صيغته وتبعات النجاح أو الإخفاق بين الجامعات والأنظمة.

## 9. مقترح البحث ومرحلة الترشح

يحدد المقترح مشكلة أصلية في النظرية الاجتماعية والمؤسسات أو اللامساواة والطبقة والجندر، ويعرض سؤال البحث أو الفرضيات أو الأطروحة، ويبرر استخدام المسوح والتحليل الإحصائي والسببي والمقابلات والإثنوغرافيا ودراسة الحالة. كما يحدد الفرد أو الجماعة أو الشبكة أو المؤسسة أو المجتمع، والسياق أو الفترة أو المجتمع أو المؤسسة، ويشرح معايير الاختيار والنطاق وحدود الاستدلال.

يجب أن يتضمن خطة للبيانات أو المصادر، والجودة، والأخلاقيات، والمخاطر، والموارد، والجدول الزمني، ومعايير مسبقة للتحقق أو المقارنة، وخطة بديلة إذا تعذر الوصول إلى مادة أو مؤسسة أو عينة أساسية.

## 10. الأطروحة والمساهمة الأصلية

قد تتمثل المساهمة الأصلية في تفسير اجتماعي أو نظرية متوسطة المدى أو أداة قياس أو دليل سببي جديد يضيف معرفة قابلة للتحقق في علم الاجتماع، بما يطور فهم النظرية الاجتماعية والمؤسسات أو يقدم تفسيرًا أو أداة أو ممارسة قابلة للتقييم في الأسرة والعمل والتعليم.

يمكن أن تكون الأطروحة تقليدية أو قائمة على أوراق منشورة أو مشروعًا مهنيًا موثقًا، لكن يجب أن تكون وحدة المساهمة واضحة، وأن يفصل الباحث بين ما أثبته وما استنتجه وما اقترحه معياريًا أو تطبيقيًا.

## 11. الإشراف والبيئة البحثية

- خطة للشفافية وقابلية إعادة التحليل عند الإمكان.
- لجنة إشراف تجمع خبرة موضوعية ومنهجية مستقلة.
- خطة لإدارة الوصول والتخزين الآمن واستمرارية البيانات أو المصادر.

لا تحفظ أسماء المشرفين أو المؤسسات داخل هوية التخصص؛ فهي بيانات برامج جامعية في Phase 11.

## 2. طبيعة الدكتوراه وهدفها

تهدف دكتوراه الخدمة الاجتماعية إلى إعداد باحث قادر على إنتاج معرفة مستقلة في فاعلية تدخلات الخدمة الاجتماعية، وربطها بـتنظيم خدمات الحماية والرعاية والعمل المجتمعي والتمكين. ويُتوقع منه تحديد فجوة حقيقية، وصياغة سؤال قابل للفحص، وبناء حجة أو تصميم بحث يميز بين الوصف والتفسير والسببية أو الحكم المعياري بحسب طبيعة المجال.

تختلف عن مستوى الماجستير في أن الطالب يقود برنامجًا بحثيًا طويل الأجل، ويطور نظرية أو منهجًا أو دليلًا أو أداة جديدة، ويختبر حدود الصلاحية والتعميم. لا تشمل هوية التخصص بيانات جامعة أو مشرف أو برنامج مؤسسي بعينه.

## 3. أنواع الدكتوراه الشائعة

- دكتوراه بحثية تقليدية قائمة على أطروحة أصلية.
- دكتوراه مهنية أو قائمة على الممارسة عند توفرها، مع مكون بحثي أصيل قابل للفحص.
- دكتوراه تعاونية مع مؤسسة عامة أو ثقافية أو مهنية مع استقلال أكاديمي واضح.
- دكتوراه بالنشر أو مسار مدمج عند توفر النظام المؤسسي.

اسم الدرجة لا ينشئ تخصصًا مستقلًا؛ فقد يطرح الخدمة الاجتماعية ضمن PhD / DSW / DPhil وفق طبيعة البرنامج وفق النظام والهدف الأكاديمي أو المهني.

## 8. الامتحان التأهيلي أو الشامل عند وجوده

قد يختبر الامتحان المعرفة المتقدمة في فاعلية تدخلات الخدمة الاجتماعية وتنظيم خدمات الحماية والرعاية، والقدرة على تحليل مادة أو بيانات أو حالة مرتبطة بالخدمة الاجتماعية والدفاع عن منهج يستخدم بحوث التدخل والتقييم والتنفيذ والبحث التشاركي القائم على المجتمع. كما قد يتطلب نقد أدبيات متعارضة، وتبرير وحدة التحليل، وبيان كيفية التحقق من الادعاءات والبدائل التفسيرية.

قد يكون تحريريًا أو شفهيًا أو دفاعًا عن مقترح أولي، وتختلف صيغته وتبعات النجاح أو الإخفاق بين الجامعات والأنظمة.

## 9. مقترح البحث ومرحلة الترشح

يحدد المقترح مشكلة أصلية في فاعلية تدخلات الخدمة الاجتماعية أو تنظيم خدمات الحماية والرعاية، ويعرض سؤال البحث أو الفرضيات أو الأطروحة، ويبرر استخدام بحوث التدخل والتقييم والتنفيذ والبحث التشاركي القائم على المجتمع. كما يحدد المستفيد أو الأسرة أو الممارس أو الخدمة أو البرنامج أو السياسة، والسياق أو الفترة أو المجتمع أو المؤسسة، ويشرح معايير الاختيار والنطاق وحدود الاستدلال.

يجب أن يتضمن خطة للبيانات أو المصادر، والجودة، والأخلاقيات، والمخاطر، والموارد، والجدول الزمني، ومعايير مسبقة للتحقق أو المقارنة، وخطة بديلة إذا تعذر الوصول إلى مادة أو مؤسسة أو عينة أساسية.

## 10. الأطروحة والمساهمة الأصلية

قد تتمثل المساهمة الأصلية في تدخل أو نموذج ممارسة أو تنفيذ أو سياسة محسنة بدليل أصيل يضيف معرفة قابلة للتحقق في الخدمة الاجتماعية، بما يطور فهم فاعلية تدخلات الخدمة الاجتماعية أو يقدم تفسيرًا أو أداة أو ممارسة قابلة للتقييم في العمل المجتمعي والتمكين.

يمكن أن تكون الأطروحة تقليدية أو قائمة على أوراق منشورة أو مشروعًا مهنيًا موثقًا، لكن يجب أن تكون وحدة المساهمة واضحة، وأن يفصل الباحث بين ما أثبته وما استنتجه وما اقترحه معياريًا أو تطبيقيًا.

## 11. الإشراف والبيئة البحثية

- شراكات أخلاقية مع مؤسسات الخدمة والمجتمعات.
- إشراف يجمع البحث والممارسة والسياسة.
- آليات إحالة وحماية عند ظهور مخاطر.
- خطة لمنع تضارب دور الباحث والممارس.
- لجنة إشراف تجمع خبرة موضوعية ومنهجية مستقلة.
- خطة لإدارة الوصول والتخزين الآمن واستمرارية البيانات أو المصادر.

لا تحفظ أسماء المشرفين أو المؤسسات داخل هوية التخصص؛ فهي بيانات برامج جامعية في Phase 11.

## 12. متطلبات البحث والنشر والتدريس

- توثيق المنهج والبيانات أو النصوص أو الحالات وإجراءات التحليل.

لا توجد أعداد عالمية موحدة للمنشورات أو المؤتمرات أو ساعات التدريس.

## 2. طبيعة الدكتوراه وهدفها

تهدف دكتوراه علم النفس إلى إعداد باحث قادر على إنتاج معرفة مستقلة في الإدراك والانفعال والدافعية، وربطها بالشخصية والفروق الفردية والنمو والعلاقات الاجتماعية. ويُتوقع منه تحديد فجوة حقيقية، وصياغة سؤال قابل للفحص، وبناء حجة أو تصميم بحث يميز بين الوصف والتفسير والسببية أو الحكم المعياري بحسب طبيعة المجال.

تختلف عن مستوى الماجستير في أن الطالب يقود برنامجًا بحثيًا طويل الأجل، ويطور نظرية أو منهجًا أو دليلًا أو أداة جديدة، ويختبر حدود الصلاحية والتعميم. لا تشمل هوية التخصص بيانات جامعة أو مشرف أو برنامج مؤسسي بعينه.

## 3. أنواع الدكتوراه الشائعة

- دكتوراه بحثية تقليدية قائمة على أطروحة أصلية.
- دكتوراه بينية عند اتصال السؤال بتخصص آخر ومنهج واضح للدمج.
- دكتوراه تعاونية مع مؤسسة عامة أو ثقافية أو مهنية مع استقلال أكاديمي واضح.
- دكتوراه بالنشر أو مسار مدمج عند توفر النظام المؤسسي.

اسم الدرجة لا ينشئ تخصصًا مستقلًا؛ فقد يطرح علم النفس ضمن PhD / DPhil وفق النظام والهدف الأكاديمي أو المهني.

## 5. مراحل برنامج الدكتوراه

1. مقررات أو حلقات متقدمة وخطة تعلم فردية.

5. إعداد المقترح وخطة البيانات أو المصادر والأخلاقيات.
6. الانتقال إلى مرحلة مرشح الدكتوراه بعد موافقة اللجنة.
7. تنفيذ البحث باستخدام الدراسات الطولية واللحظية والملاحظة والمقابلات السريرية البحثية عند التصريح عند الملاءمة.
8. اختبارات تحقق أو متانة أو مقارنة وتفسير بدائل النتائج.
9. كتابة الأطروحة ومناقشتها والدفاع عنها.
10. الإيداع واستكمال متطلبات النزاهة والبيانات والتخرج.

## 6. المعرفة والمقررات المتقدمة

### المعرفة النظرية المتقدمة

### مناهج البحث والتحليل

- التجارب السلوكية والمعرفية.
- القياس النفسي والنمذجة الكامنة.
- الدراسات الطولية واللحظية.
- الملاحظة والمقابلات السريرية البحثية عند التصريح.
- التحليل العصبي أو الفسيولوجي أو الحاسوبي عند الملاءمة.

### الأخلاقيات والنزاهة العلمية

- الحصول على الموافقات الأخلاقية قبل جمع بيانات الأفراد أو المؤسسات أو المجتمعات.

- الإفصاح عن التمويل وتضارب المصالح المهنية أو السياسية أو المالية.

## 8. الامتحان التأهيلي أو الشامل عند وجوده

قد يختبر الامتحان المعرفة المتقدمة في الإدراك والانفعال والدافعية والشخصية والفروق الفردية، والقدرة على تحليل مادة أو بيانات أو حالة مرتبطة بـعلم النفس والدفاع عن منهج يستخدم التجارب السلوكية والمعرفية والقياس النفسي والنمذجة الكامنة. كما قد يتطلب نقد أدبيات متعارضة، وتبرير وحدة التحليل، وبيان كيفية التحقق من الادعاءات والبدائل التفسيرية.

قد يكون تحريريًا أو شفهيًا أو دفاعًا عن مقترح أولي، وتختلف صيغته وتبعات النجاح أو الإخفاق بين الجامعات والأنظمة.

## 9. مقترح البحث ومرحلة الترشح

يحدد المقترح مشكلة أصلية في الإدراك والانفعال والدافعية أو الشخصية والفروق الفردية، ويعرض سؤال البحث أو الفرضيات أو الأطروحة، ويبرر استخدام التجارب السلوكية والمعرفية والقياس النفسي والنمذجة الكامنة. كما يحدد المشارك أو المهمة أو السلوك أو الأداة أو التدخل أو السياق، والسياق أو الفترة أو المجتمع أو المؤسسة، ويشرح معايير الاختيار والنطاق وحدود الاستدلال.

يجب أن يتضمن خطة للبيانات أو المصادر، والجودة، والأخلاقيات، والمخاطر، والموارد، والجدول الزمني، ومعايير مسبقة للتحقق أو المقارنة، وخطة بديلة إذا تعذر الوصول إلى مادة أو مؤسسة أو عينة أساسية.

## 10. الأطروحة والمساهمة الأصلية

قد تتمثل المساهمة الأصلية في نظرية أو مقياس أو نموذج آلي أو تدخل أو دليل تجريبي أصيل يضيف معرفة قابلة للتحقق في علم النفس، بما يطور فهم الإدراك والانفعال والدافعية أو يقدم تفسيرًا أو أداة أو ممارسة قابلة للتقييم في النمو والعلاقات الاجتماعية.

يمكن أن تكون الأطروحة تقليدية أو قائمة على أوراق منشورة أو مشروعًا مهنيًا موثقًا، لكن يجب أن تكون وحدة المساهمة واضحة، وأن يفصل الباحث بين ما أثبته وما استنتجه وما اقترحه معياريًا أو تطبيقيًا.

## 11. الإشراف والبيئة البحثية

- مختبر أو ميدان مناسب للسؤال.
- إشراف نظري ومنهجي وسريري عند الحاجة.
- أدوات مقننة وبيانات عالية الحماية.
- خطة لإدارة المخاطر والإحالة والموافقة.
- لجنة إشراف تجمع خبرة موضوعية ومنهجية مستقلة.
- خطة لإدارة الوصول والتخزين الآمن واستمرارية البيانات أو المصادر.

لا تحفظ أسماء المشرفين أو المؤسسات داخل هوية التخصص؛ فهي بيانات برامج جامعية في Phase 11.

## 12. متطلبات البحث والنشر والتدريس

- توثيق المنهج والبيانات أو النصوص أو الحالات وإجراءات التحليل.

لا توجد أعداد عالمية موحدة للمنشورات أو المؤتمرات أو ساعات التدريس.

## 13. المهارات البحثية والمهنية المتقدمة

## 2. طبيعة الدكتوراه وهدفها

تهدف دكتوراه علم النفس السريري إلى إعداد باحث قادر على إنتاج معرفة مستقلة في آليات الاضطرابات النفسية، وربطها بالتقييم والقياس السريري وتطوير وتقييم التدخلات. ويُتوقع منه تحديد فجوة حقيقية، وصياغة سؤال قابل للفحص، وبناء حجة أو تصميم بحث يميز بين الوصف والتفسير والسببية أو الحكم المعياري بحسب طبيعة المجال.

تختلف عن مستوى الماجستير في أن الطالب يقود برنامجًا بحثيًا طويل الأجل، ويطور نظرية أو منهجًا أو دليلًا أو أداة جديدة، ويختبر حدود الصلاحية والتعميم. لا تشمل هوية التخصص بيانات جامعة أو مشرف أو برنامج مؤسسي بعينه.

## 3. أنواع الدكتوراه الشائعة

- دكتوراه بحثية تقليدية قائمة على أطروحة أصلية.
- دكتوراه مهنية أو قائمة على الممارسة عند توفرها، مع مكون بحثي أصيل قابل للفحص.
- دكتوراه تعاونية مع مؤسسة عامة أو ثقافية أو مهنية مع استقلال أكاديمي واضح.
- دكتوراه بالنشر أو مسار مدمج عند توفر النظام المؤسسي.

اسم الدرجة لا ينشئ تخصصًا مستقلًا؛ فقد يطرح علم النفس السريري ضمن PhD / DPhil / PsyD وفق طبيعة البرنامج وفق النظام والهدف الأكاديمي أو المهني.

## 8. الامتحان التأهيلي أو الشامل عند وجوده

قد يختبر الامتحان المعرفة المتقدمة في آليات الاضطرابات النفسية والتقييم والقياس السريري، والقدرة على تحليل مادة أو بيانات أو حالة مرتبطة بـعلم النفس السريري والدفاع عن منهج يستخدم التجارب السلوكية والمعرفية والقياس النفسي والنمذجة الكامنة. كما قد يتطلب نقد أدبيات متعارضة، وتبرير وحدة التحليل، وبيان كيفية التحقق من الادعاءات والبدائل التفسيرية.

قد يكون تحريريًا أو شفهيًا أو دفاعًا عن مقترح أولي، وتختلف صيغته وتبعات النجاح أو الإخفاق بين الجامعات والأنظمة.

## 9. مقترح البحث ومرحلة الترشح

يحدد المقترح مشكلة أصلية في آليات الاضطرابات النفسية أو التقييم والقياس السريري، ويعرض سؤال البحث أو الفرضيات أو الأطروحة، ويبرر استخدام التجارب السلوكية والمعرفية والقياس النفسي والنمذجة الكامنة. كما يحدد المشارك أو المهمة أو السلوك أو الأداة أو التدخل أو السياق، والسياق أو الفترة أو المجتمع أو المؤسسة، ويشرح معايير الاختيار والنطاق وحدود الاستدلال.

يجب أن يتضمن خطة للبيانات أو المصادر، والجودة، والأخلاقيات، والمخاطر، والموارد، والجدول الزمني، ومعايير مسبقة للتحقق أو المقارنة، وخطة بديلة إذا تعذر الوصول إلى مادة أو مؤسسة أو عينة أساسية.

## 10. الأطروحة والمساهمة الأصلية

قد تتمثل المساهمة الأصلية في نظرية أو مقياس أو نموذج آلي أو تدخل أو دليل تجريبي أصيل يضيف معرفة قابلة للتحقق في علم النفس السريري، بما يطور فهم آليات الاضطرابات النفسية أو يقدم تفسيرًا أو أداة أو ممارسة قابلة للتقييم في تطوير وتقييم التدخلات.

يمكن أن تكون الأطروحة تقليدية أو قائمة على أوراق منشورة أو مشروعًا مهنيًا موثقًا، لكن يجب أن تكون وحدة المساهمة واضحة، وأن يفصل الباحث بين ما أثبته وما استنتجه وما اقترحه معياريًا أو تطبيقيًا.

## 11. الإشراف والبيئة البحثية

- مختبر أو ميدان مناسب للسؤال.
- إشراف نظري ومنهجي وسريري عند الحاجة.
- أدوات مقننة وبيانات عالية الحماية.
- خطة لإدارة المخاطر والإحالة والموافقة.
- لجنة إشراف تجمع خبرة موضوعية ومنهجية مستقلة.
- خطة لإدارة الوصول والتخزين الآمن واستمرارية البيانات أو المصادر.

لا تحفظ أسماء المشرفين أو المؤسسات داخل هوية التخصص؛ فهي بيانات برامج جامعية في Phase 11.

## 12. متطلبات البحث والنشر والتدريس

- حلقات بحث وتحديثات دورية للجنة الإشراف.
- توثيق المنهج والبيانات أو النصوص أو الحالات وإجراءات التحليل.
- اختبارات جودة ومتانة أو مقارنة مستقلة تتناسب مع المجال.
- إعداد أوراق أو أدوات أو تقارير قابلة للتحكيم وفق سياسة المؤسسة.
- تدريس أو مساعدة تعليمية أو تدريب مهني في بعض البرامج.

لا توجد أعداد عالمية موحدة للمنشورات أو المؤتمرات أو ساعات التدريس.

## 13. المهارات البحثية والمهنية المتقدمة

- صياغة سؤال بحث أصيل في علم النفس السريري.
- نقد الأدلة والنظريات في آليات الاضطرابات النفسية.
- تطبيق التجارب السلوكية والمعرفية والقياس النفسي والنمذجة الكامنة بصورة مستقلة.
- إدارة بيانات أو نصوص أو وثائق أو حالات معقدة وضبط جودتها.
- تقييم التحيز وعدم اليقين وحدود التعميم أو النقل بين السياقات.
- الكتابة والنشر والعرض والدفاع العلمي.
- قيادة تعاون متعدد التخصصات وإدارة مشروع طويل الأجل.

## 14. مجالات العمل بعد الدكتوراه

- الجامعات ومراكز علم النفس
- المستشفيات ومراكز الصحة البحثية
- المؤسسات التعليمية والمجتمعية
- المنظمات ومراكز العمل والسلوك
- مختبرات الإدراك والأعصاب والسلوك

تعتمد ملاءمة المسار على موضوع الأطروحة والمنهج والخبرة وأي اعتماد مهني مستقل.

## 16. ما بعد الدكتوراه والمسارات اللاحقة

- زمالة ما بعد الدكتوراه في علم النفس السريري أو مجال قريب.

- البحث والاستشارات في مؤسسة عامة أو ثقافية أو اجتماعية أو خاصة أو دولية.
- قيادة برامج بحث أو سياسات أو تطوير بعد اكتساب الخبرة.
- ممارسة مهنية متقدمة عند استيفاء الترخيص أو الاعتماد المستقل.

## 18. التنبيه الأكاديمي والمهني

> **الدكتوراه البحثية لا تمنح حق التشخيص أو العلاج النفسي تلقائيًا. استخدام الاختبارات أو التدخلات السريرية يحتاج تدريبًا واعتمادًا وترخيصًا محليًا، مع حماية صارمة للبيانات النفسية. جودة الإشراف والبيئة والبيانات أو المصادر أهم من اسم الدرجة وحده، والدكتوراه لا تضمن وظيفة أكاديمية.**

## 2. طبيعة الدكتوراه وهدفها

تهدف دكتوراه علم النفس الإرشادي إلى إعداد باحث قادر على إنتاج معرفة مستقلة في العلاقة العلاجية وعمليات التغيير، وربطها بالنمو المهني والهوية والوقاية والمرونة والرفاه. ويُتوقع منه تحديد فجوة حقيقية، وصياغة سؤال قابل للفحص، وبناء حجة أو تصميم بحث يميز بين الوصف والتفسير والسببية أو الحكم المعياري بحسب طبيعة المجال.

تختلف عن مستوى الماجستير في أن الطالب يقود برنامجًا بحثيًا طويل الأجل، ويطور نظرية أو منهجًا أو دليلًا أو أداة جديدة، ويختبر حدود الصلاحية والتعميم. لا تشمل هوية التخصص بيانات جامعة أو مشرف أو برنامج مؤسسي بعينه.

## 3. أنواع الدكتوراه الشائعة

- دكتوراه بحثية تقليدية قائمة على أطروحة أصلية.
- دكتوراه مهنية أو قائمة على الممارسة عند توفرها، مع مكون بحثي أصيل قابل للفحص.
- دكتوراه تعاونية مع مؤسسة عامة أو ثقافية أو مهنية مع استقلال أكاديمي واضح.
- دكتوراه بالنشر أو مسار مدمج عند توفر النظام المؤسسي.

اسم الدرجة لا ينشئ تخصصًا مستقلًا؛ فقد يطرح علم النفس الإرشادي ضمن PhD / DPhil / PsyD وفق طبيعة البرنامج وفق النظام والهدف الأكاديمي أو المهني.

## 4. الخلفيات الأكاديمية المناسبة ومسارات الدخول

### تخصصات الماجستير المرتبطة

- MAS-0815 — المسار المرجعي المرتبط في دليل الماجستير
- علم النفس أو أحد فروعه
- العلوم السلوكية أو المعرفية
- الصحة العامة أو الأعصاب لمسارات صحية
- الإدارة لمسار صناعي وتنظيمي

### تخصصات قريبة قد تقبل

- تخصص قريب يدعم سؤال الأطروحة ومنهجها مع استيفاء المتطلبات الاستدراكية.
- خلفية بينية تجمع المجال الأساسي مع الإحصاء أو الحوسبة أو التاريخ أو القانون أو الصحة أو الاقتصاد بحسب موضوع البحث.
- خبرة مهنية موثقة عندما تكون الدكتوراه مهنية أو قائمة على الممارسة.

### الدخول المباشر بعد البكالوريوس عند شيوعه

- بكالوريوس متميز في مجال مرتبط ضمن نظام يسمح بالدخول المباشر أو المسار المدمج.
- خبرة بحثية موثقة وكتابة أكاديمية قوية وكفاية في المناهج المطلوبة.
- مقررات استدراكية عندما تختلف الخلفية عن جوهر التخصص.

### الخبرة أو الترخيص المطلوب للدكتوراه المهنية

- قد تتطلب الصيغة المهنية خبرة عملية وملف ممارسة أو مسؤولية مناسبة.
- الوصول إلى أفراد أو مؤسسات أو قضايا أو بيانات حساسة يحتاج موافقات وصلاحيات منفصلة.
- أي تقييم أو تدخل أو ممارسة نفسية سريرية تحتاج اعتمادًا وترخيصًا منفصلين عن الدرجة البحثية.

## 5. مراحل برنامج الدكتوراه

1. مقررات أو حلقات متقدمة وخطة تعلم فردية.
2. تدريب منهجي في التجارب السلوكية والمعرفية والقياس النفسي والنمذجة الكامنة.
3. امتحان شامل أو تأهيلي عند وجوده.
4. مراجعة نقدية للأدبيات وتحديد الفجوة.
5. إعداد المقترح وخطة البيانات أو المصادر والأخلاقيات.
6. الانتقال إلى مرحلة مرشح الدكتوراه بعد موافقة اللجنة.
7. تنفيذ البحث باستخدام الدراسات الطولية واللحظية والملاحظة والمقابلات السريرية البحثية عند التصريح عند الملاءمة.
8. اختبارات تحقق أو متانة أو مقارنة وتفسير بدائل النتائج.
9. كتابة الأطروحة ومناقشتها والدفاع عنها.
10. الإيداع واستكمال متطلبات النزاهة والبيانات والتخرج.

## 6. المعرفة والمقررات المتقدمة

### المعرفة النظرية المتقدمة

- النمو والشخصية والعلاقات الاجتماعية.
- البيولوجيا العصبية للسلوك.
- السياق الثقافي والتنظيمي والصحي.

### مناهج البحث والتحليل

- التجارب السلوكية والمعرفية.
- القياس النفسي والنمذجة الكامنة.
- الدراسات الطولية واللحظية.
- الملاحظة والمقابلات السريرية البحثية عند التصريح.
- التحليل العصبي أو الفسيولوجي أو الحاسوبي عند الملاءمة.

### الأخلاقيات والنزاهة العلمية

- الحصول على الموافقات الأخلاقية قبل جمع بيانات الأفراد أو المؤسسات أو المجتمعات.
- حماية الخصوصية والسرية والملكية الفكرية والمواد الحساسة.
- الإفصاح عن التمويل وتضارب المصالح المهنية أو السياسية أو المالية.
- توثيق المصادر والتحويلات والأدوات والشفرة أو بروتوكولات التحليل.
- عدم تضخيم النتائج أو إخفاء عدم اليقين أو استخدام البحث للإضرار بالمشاركين.

## 7. مجالات البحث والتخصصات الدقيقة

- العلاقة العلاجية وعمليات التغيير
- النمو المهني والهوية
- الوقاية والمرونة والرفاه
- الاستشارة متعددة الثقافات
- تقييم خدمات الإرشاد
- المقارنة بين السياقات والتحولات المعاصرة

تُحفظ هذه المجالات كعلاقات أو تركيزات بحثية، ولا تتحول تلقائيًا إلى تخصصات مستقلة دون مراجعة Academic Taxonomy.

## 8. الامتحان التأهيلي أو الشامل عند وجوده

قد يختبر الامتحان المعرفة المتقدمة في العلاقة العلاجية وعمليات التغيير والنمو المهني والهوية، والقدرة على تحليل مادة أو بيانات أو حالة مرتبطة بـعلم النفس الإرشادي والدفاع عن منهج يستخدم التجارب السلوكية والمعرفية والقياس النفسي والنمذجة الكامنة. كما قد يتطلب نقد أدبيات متعارضة، وتبرير وحدة التحليل، وبيان كيفية التحقق من الادعاءات والبدائل التفسيرية.

قد يكون تحريريًا أو شفهيًا أو دفاعًا عن مقترح أولي، وتختلف صيغته وتبعات النجاح أو الإخفاق بين الجامعات والأنظمة.

## 9. مقترح البحث ومرحلة الترشح

يحدد المقترح مشكلة أصلية في العلاقة العلاجية وعمليات التغيير أو النمو المهني والهوية، ويعرض سؤال البحث أو الفرضيات أو الأطروحة، ويبرر استخدام التجارب السلوكية والمعرفية والقياس النفسي والنمذجة الكامنة. كما يحدد المشارك أو المهمة أو السلوك أو الأداة أو التدخل أو السياق، والسياق أو الفترة أو المجتمع أو المؤسسة، ويشرح معايير الاختيار والنطاق وحدود الاستدلال.

يجب أن يتضمن خطة للبيانات أو المصادر، والجودة، والأخلاقيات، والمخاطر، والموارد، والجدول الزمني، ومعايير مسبقة للتحقق أو المقارنة، وخطة بديلة إذا تعذر الوصول إلى مادة أو مؤسسة أو عينة أساسية.

## 10. الأطروحة والمساهمة الأصلية

قد تتمثل المساهمة الأصلية في نظرية أو مقياس أو نموذج آلي أو تدخل أو دليل تجريبي أصيل يضيف معرفة قابلة للتحقق في علم النفس الإرشادي، بما يطور فهم العلاقة العلاجية وعمليات التغيير أو يقدم تفسيرًا أو أداة أو ممارسة قابلة للتقييم في الوقاية والمرونة والرفاه.

يمكن أن تكون الأطروحة تقليدية أو قائمة على أوراق منشورة أو مشروعًا مهنيًا موثقًا، لكن يجب أن تكون وحدة المساهمة واضحة، وأن يفصل الباحث بين ما أثبته وما استنتجه وما اقترحه معياريًا أو تطبيقيًا.

## 11. الإشراف والبيئة البحثية

- مختبر أو ميدان مناسب للسؤال.
- إشراف نظري ومنهجي وسريري عند الحاجة.
- أدوات مقننة وبيانات عالية الحماية.
- خطة لإدارة المخاطر والإحالة والموافقة.
- لجنة إشراف تجمع خبرة موضوعية ومنهجية مستقلة.
- خطة لإدارة الوصول والتخزين الآمن واستمرارية البيانات أو المصادر.

لا تحفظ أسماء المشرفين أو المؤسسات داخل هوية التخصص؛ فهي بيانات برامج جامعية في Phase 11.

## 12. متطلبات البحث والنشر والتدريس

- حلقات بحث وتحديثات دورية للجنة الإشراف.
- توثيق المنهج والبيانات أو النصوص أو الحالات وإجراءات التحليل.
- اختبارات جودة ومتانة أو مقارنة مستقلة تتناسب مع المجال.
- إعداد أوراق أو أدوات أو تقارير قابلة للتحكيم وفق سياسة المؤسسة.
- تدريس أو مساعدة تعليمية أو تدريب مهني في بعض البرامج.

لا توجد أعداد عالمية موحدة للمنشورات أو المؤتمرات أو ساعات التدريس.

## 13. المهارات البحثية والمهنية المتقدمة

- صياغة سؤال بحث أصيل في علم النفس الإرشادي.
- نقد الأدلة والنظريات في العلاقة العلاجية وعمليات التغيير.
- تطبيق التجارب السلوكية والمعرفية والقياس النفسي والنمذجة الكامنة بصورة مستقلة.
- إدارة بيانات أو نصوص أو وثائق أو حالات معقدة وضبط جودتها.
- تقييم التحيز وعدم اليقين وحدود التعميم أو النقل بين السياقات.
- الكتابة والنشر والعرض والدفاع العلمي.
- قيادة تعاون متعدد التخصصات وإدارة مشروع طويل الأجل.

## 14. مجالات العمل بعد الدكتوراه

- الجامعات ومراكز علم النفس
- المستشفيات ومراكز الصحة البحثية
- المؤسسات التعليمية والمجتمعية
- المنظمات ومراكز العمل والسلوك
- مختبرات الإدراك والأعصاب والسلوك

تعتمد ملاءمة المسار على موضوع الأطروحة والمنهج والخبرة وأي اعتماد مهني مستقل.

## 16. ما بعد الدكتوراه والمسارات اللاحقة

- قيادة برامج بحث أو سياسات أو تطوير بعد اكتساب الخبرة.
- ممارسة مهنية متقدمة عند استيفاء الترخيص أو الاعتماد المستقل.

## 2. طبيعة الدكتوراه وهدفها

تهدف دكتوراه علم النفس الصناعي والتنظيمي إلى إعداد باحث قادر على إنتاج معرفة مستقلة في الاختيار والقياس في العمل، وربطها بالدافعية والأداء والرفاه والقيادة والفرق والثقافة التنظيمية. ويُتوقع منه تحديد فجوة حقيقية، وصياغة سؤال قابل للفحص، وبناء حجة أو تصميم بحث يميز بين الوصف والتفسير والسببية أو الحكم المعياري بحسب طبيعة المجال.

تختلف عن مستوى الماجستير في أن الطالب يقود برنامجًا بحثيًا طويل الأجل، ويطور نظرية أو منهجًا أو دليلًا أو أداة جديدة، ويختبر حدود الصلاحية والتعميم. لا تشمل هوية التخصص بيانات جامعة أو مشرف أو برنامج مؤسسي بعينه.

## 3. أنواع الدكتوراه الشائعة

- دكتوراه بحثية تقليدية قائمة على أطروحة أصلية.
- دكتوراه بينية عند اتصال السؤال بتخصص آخر ومنهج واضح للدمج.
- دكتوراه تعاونية مع مؤسسة عامة أو ثقافية أو مهنية مع استقلال أكاديمي واضح.
- دكتوراه بالنشر أو مسار مدمج عند توفر النظام المؤسسي.

اسم الدرجة لا ينشئ تخصصًا مستقلًا؛ فقد يطرح علم النفس الصناعي والتنظيمي ضمن PhD / DPhil وفق النظام والهدف الأكاديمي أو المهني.

## 5. مراحل برنامج الدكتوراه

1. مقررات أو حلقات متقدمة وخطة تعلم فردية.
2. تدريب منهجي في التجارب السلوكية والمعرفية والقياس النفسي والنمذجة الكامنة.
3. امتحان شامل أو تأهيلي عند وجوده.
4. مراجعة نقدية للأدبيات وتحديد الفجوة.
5. إعداد المقترح وخطة البيانات أو المصادر والأخلاقيات.
6. الانتقال إلى مرحلة مرشح الدكتوراه بعد موافقة اللجنة.
7. تنفيذ البحث باستخدام الدراسات الطولية واللحظية والملاحظة والمقابلات السريرية البحثية عند التصريح عند الملاءمة.
8. اختبارات تحقق أو متانة أو مقارنة وتفسير بدائل النتائج.
9. كتابة الأطروحة ومناقشتها والدفاع عنها.
10. الإيداع واستكمال متطلبات النزاهة والبيانات والتخرج.

## 8. الامتحان التأهيلي أو الشامل عند وجوده

قد يختبر الامتحان المعرفة المتقدمة في الاختيار والقياس في العمل والدافعية والأداء والرفاه، والقدرة على تحليل مادة أو بيانات أو حالة مرتبطة بـعلم النفس الصناعي والتنظيمي والدفاع عن منهج يستخدم التجارب السلوكية والمعرفية والقياس النفسي والنمذجة الكامنة. كما قد يتطلب نقد أدبيات متعارضة، وتبرير وحدة التحليل، وبيان كيفية التحقق من الادعاءات والبدائل التفسيرية.

قد يكون تحريريًا أو شفهيًا أو دفاعًا عن مقترح أولي، وتختلف صيغته وتبعات النجاح أو الإخفاق بين الجامعات والأنظمة.

## 9. مقترح البحث ومرحلة الترشح

يحدد المقترح مشكلة أصلية في الاختيار والقياس في العمل أو الدافعية والأداء والرفاه، ويعرض سؤال البحث أو الفرضيات أو الأطروحة، ويبرر استخدام التجارب السلوكية والمعرفية والقياس النفسي والنمذجة الكامنة. كما يحدد المشارك أو المهمة أو السلوك أو الأداة أو التدخل أو السياق، والسياق أو الفترة أو المجتمع أو المؤسسة، ويشرح معايير الاختيار والنطاق وحدود الاستدلال.

يجب أن يتضمن خطة للبيانات أو المصادر، والجودة، والأخلاقيات، والمخاطر، والموارد، والجدول الزمني، ومعايير مسبقة للتحقق أو المقارنة، وخطة بديلة إذا تعذر الوصول إلى مادة أو مؤسسة أو عينة أساسية.

## 10. الأطروحة والمساهمة الأصلية

قد تتمثل المساهمة الأصلية في نظرية أو مقياس أو نموذج آلي أو تدخل أو دليل تجريبي أصيل يضيف معرفة قابلة للتحقق في علم النفس الصناعي والتنظيمي، بما يطور فهم الاختيار والقياس في العمل أو يقدم تفسيرًا أو أداة أو ممارسة قابلة للتقييم في القيادة والفرق والثقافة التنظيمية.

يمكن أن تكون الأطروحة تقليدية أو قائمة على أوراق منشورة أو مشروعًا مهنيًا موثقًا، لكن يجب أن تكون وحدة المساهمة واضحة، وأن يفصل الباحث بين ما أثبته وما استنتجه وما اقترحه معياريًا أو تطبيقيًا.

## 11. الإشراف والبيئة البحثية

- مختبر أو ميدان مناسب للسؤال.
- إشراف نظري ومنهجي وسريري عند الحاجة.
- أدوات مقننة وبيانات عالية الحماية.
- خطة لإدارة المخاطر والإحالة والموافقة.
- لجنة إشراف تجمع خبرة موضوعية ومنهجية مستقلة.
- خطة لإدارة الوصول والتخزين الآمن واستمرارية البيانات أو المصادر.

لا تحفظ أسماء المشرفين أو المؤسسات داخل هوية التخصص؛ فهي بيانات برامج جامعية في Phase 11.

## 12. متطلبات البحث والنشر والتدريس

- حلقات بحث وتحديثات دورية للجنة الإشراف.
- توثيق المنهج والبيانات أو النصوص أو الحالات وإجراءات التحليل.
- اختبارات جودة ومتانة أو مقارنة مستقلة تتناسب مع المجال.
- إعداد أوراق أو أدوات أو تقارير قابلة للتحكيم وفق سياسة المؤسسة.
- تدريس أو مساعدة تعليمية أو تدريب مهني في بعض البرامج.

لا توجد أعداد عالمية موحدة للمنشورات أو المؤتمرات أو ساعات التدريس.

## 13. المهارات البحثية والمهنية المتقدمة

## 2. طبيعة الدكتوراه وهدفها

تهدف دكتوراه علم النفس الاجتماعي إلى إعداد باحث قادر على إنتاج معرفة مستقلة في الإدراك الاجتماعي والاتجاهات، وربطها بالهوية والجماعات والتحيز والتأثير والإقناع والأعراف. ويُتوقع منه تحديد فجوة حقيقية، وصياغة سؤال قابل للفحص، وبناء حجة أو تصميم بحث يميز بين الوصف والتفسير والسببية أو الحكم المعياري بحسب طبيعة المجال.

تختلف عن مستوى الماجستير في أن الطالب يقود برنامجًا بحثيًا طويل الأجل، ويطور نظرية أو منهجًا أو دليلًا أو أداة جديدة، ويختبر حدود الصلاحية والتعميم. لا تشمل هوية التخصص بيانات جامعة أو مشرف أو برنامج مؤسسي بعينه.

## 3. أنواع الدكتوراه الشائعة

- دكتوراه بحثية تقليدية قائمة على أطروحة أصلية.
- دكتوراه بينية عند اتصال السؤال بتخصص آخر ومنهج واضح للدمج.
- دكتوراه تعاونية مع مؤسسة عامة أو ثقافية أو مهنية مع استقلال أكاديمي واضح.
- دكتوراه بالنشر أو مسار مدمج عند توفر النظام المؤسسي.

اسم الدرجة لا ينشئ تخصصًا مستقلًا؛ فقد يطرح علم النفس الاجتماعي ضمن PhD / DPhil وفق النظام والهدف الأكاديمي أو المهني.

## 5. مراحل برنامج الدكتوراه

3. امتحان شامل أو تأهيلي عند وجوده.
4. مراجعة نقدية للأدبيات وتحديد الفجوة.
5. إعداد المقترح وخطة البيانات أو المصادر والأخلاقيات.
6. الانتقال إلى مرحلة مرشح الدكتوراه بعد موافقة اللجنة.
7. تنفيذ البحث باستخدام الدراسات الطولية واللحظية والملاحظة والمقابلات السريرية البحثية عند التصريح عند الملاءمة.
8. اختبارات تحقق أو متانة أو مقارنة وتفسير بدائل النتائج.
9. كتابة الأطروحة ومناقشتها والدفاع عنها.
10. الإيداع واستكمال متطلبات النزاهة والبيانات والتخرج.

## 8. الامتحان التأهيلي أو الشامل عند وجوده

قد يختبر الامتحان المعرفة المتقدمة في الإدراك الاجتماعي والاتجاهات والهوية والجماعات والتحيز، والقدرة على تحليل مادة أو بيانات أو حالة مرتبطة بـعلم النفس الاجتماعي والدفاع عن منهج يستخدم التجارب السلوكية والمعرفية والقياس النفسي والنمذجة الكامنة. كما قد يتطلب نقد أدبيات متعارضة، وتبرير وحدة التحليل، وبيان كيفية التحقق من الادعاءات والبدائل التفسيرية.

قد يكون تحريريًا أو شفهيًا أو دفاعًا عن مقترح أولي، وتختلف صيغته وتبعات النجاح أو الإخفاق بين الجامعات والأنظمة.

## 9. مقترح البحث ومرحلة الترشح

يحدد المقترح مشكلة أصلية في الإدراك الاجتماعي والاتجاهات أو الهوية والجماعات والتحيز، ويعرض سؤال البحث أو الفرضيات أو الأطروحة، ويبرر استخدام التجارب السلوكية والمعرفية والقياس النفسي والنمذجة الكامنة. كما يحدد المشارك أو المهمة أو السلوك أو الأداة أو التدخل أو السياق، والسياق أو الفترة أو المجتمع أو المؤسسة، ويشرح معايير الاختيار والنطاق وحدود الاستدلال.

يجب أن يتضمن خطة للبيانات أو المصادر، والجودة، والأخلاقيات، والمخاطر، والموارد، والجدول الزمني، ومعايير مسبقة للتحقق أو المقارنة، وخطة بديلة إذا تعذر الوصول إلى مادة أو مؤسسة أو عينة أساسية.

## 10. الأطروحة والمساهمة الأصلية

قد تتمثل المساهمة الأصلية في نظرية أو مقياس أو نموذج آلي أو تدخل أو دليل تجريبي أصيل يضيف معرفة قابلة للتحقق في علم النفس الاجتماعي، بما يطور فهم الإدراك الاجتماعي والاتجاهات أو يقدم تفسيرًا أو أداة أو ممارسة قابلة للتقييم في التأثير والإقناع والأعراف.

يمكن أن تكون الأطروحة تقليدية أو قائمة على أوراق منشورة أو مشروعًا مهنيًا موثقًا، لكن يجب أن تكون وحدة المساهمة واضحة، وأن يفصل الباحث بين ما أثبته وما استنتجه وما اقترحه معياريًا أو تطبيقيًا.

- ممارسة مهنية متقدمة عند استيفاء الترخيص أو الاعتماد المستقل.

| دكتوراه علم النفس المجتمعي | يركز على البيئة والوقاية والتمكين والتغيير المجتمعي. |

## 18. التنبيه الأكاديمي والمهني

> **الدكتوراه البحثية لا تمنح حق التشخيص أو العلاج النفسي تلقائيًا. استخدام الاختبارات أو التدخلات السريرية يحتاج تدريبًا واعتمادًا وترخيصًا محليًا، مع حماية صارمة للبيانات النفسية. جودة الإشراف والبيئة والبيانات أو المصادر أهم من اسم الدرجة وحده، والدكتوراه لا تضمن وظيفة أكاديمية.**

## 2. طبيعة الدكتوراه وهدفها

تهدف دكتوراه علم النفس المعرفي إلى إعداد باحث قادر على إنتاج معرفة مستقلة في الانتباه والإدراك، وربطها بالذاكرة والتعلم واللغة والتفكير. ويُتوقع منه تحديد فجوة حقيقية، وصياغة سؤال قابل للفحص، وبناء حجة أو تصميم بحث يميز بين الوصف والتفسير والسببية أو الحكم المعياري بحسب طبيعة المجال.

تختلف عن مستوى الماجستير في أن الطالب يقود برنامجًا بحثيًا طويل الأجل، ويطور نظرية أو منهجًا أو دليلًا أو أداة جديدة، ويختبر حدود الصلاحية والتعميم. لا تشمل هوية التخصص بيانات جامعة أو مشرف أو برنامج مؤسسي بعينه.

## 3. أنواع الدكتوراه الشائعة

- دكتوراه بحثية تقليدية قائمة على أطروحة أصلية.
- دكتوراه بينية عند اتصال السؤال بتخصص آخر ومنهج واضح للدمج.
- دكتوراه تعاونية مع مؤسسة عامة أو ثقافية أو مهنية مع استقلال أكاديمي واضح.
- دكتوراه بالنشر أو مسار مدمج عند توفر النظام المؤسسي.

اسم الدرجة لا ينشئ تخصصًا مستقلًا؛ فقد يطرح علم النفس المعرفي ضمن PhD / DPhil وفق النظام والهدف الأكاديمي أو المهني.

3. امتحان شامل أو تأهيلي عند وجوده.
4. مراجعة نقدية للأدبيات وتحديد الفجوة.
5. إعداد المقترح وخطة البيانات أو المصادر والأخلاقيات.
6. الانتقال إلى مرحلة مرشح الدكتوراه بعد موافقة اللجنة.
7. تنفيذ البحث باستخدام الدراسات الطولية واللحظية والملاحظة والمقابلات السريرية البحثية عند التصريح عند الملاءمة.
8. اختبارات تحقق أو متانة أو مقارنة وتفسير بدائل النتائج.
9. كتابة الأطروحة ومناقشتها والدفاع عنها.

## 8. الامتحان التأهيلي أو الشامل عند وجوده

قد يختبر الامتحان المعرفة المتقدمة في الانتباه والإدراك والذاكرة والتعلم، والقدرة على تحليل مادة أو بيانات أو حالة مرتبطة بـعلم النفس المعرفي والدفاع عن منهج يستخدم التجارب السلوكية والمعرفية والقياس النفسي والنمذجة الكامنة. كما قد يتطلب نقد أدبيات متعارضة، وتبرير وحدة التحليل، وبيان كيفية التحقق من الادعاءات والبدائل التفسيرية.

قد يكون تحريريًا أو شفهيًا أو دفاعًا عن مقترح أولي، وتختلف صيغته وتبعات النجاح أو الإخفاق بين الجامعات والأنظمة.

## 9. مقترح البحث ومرحلة الترشح

يحدد المقترح مشكلة أصلية في الانتباه والإدراك أو الذاكرة والتعلم، ويعرض سؤال البحث أو الفرضيات أو الأطروحة، ويبرر استخدام التجارب السلوكية والمعرفية والقياس النفسي والنمذجة الكامنة. كما يحدد المشارك أو المهمة أو السلوك أو الأداة أو التدخل أو السياق، والسياق أو الفترة أو المجتمع أو المؤسسة، ويشرح معايير الاختيار والنطاق وحدود الاستدلال.

يجب أن يتضمن خطة للبيانات أو المصادر، والجودة، والأخلاقيات، والمخاطر، والموارد، والجدول الزمني، ومعايير مسبقة للتحقق أو المقارنة، وخطة بديلة إذا تعذر الوصول إلى مادة أو مؤسسة أو عينة أساسية.

## 10. الأطروحة والمساهمة الأصلية

قد تتمثل المساهمة الأصلية في نظرية أو مقياس أو نموذج آلي أو تدخل أو دليل تجريبي أصيل يضيف معرفة قابلة للتحقق في علم النفس المعرفي، بما يطور فهم الانتباه والإدراك أو يقدم تفسيرًا أو أداة أو ممارسة قابلة للتقييم في اللغة والتفكير.

يمكن أن تكون الأطروحة تقليدية أو قائمة على أوراق منشورة أو مشروعًا مهنيًا موثقًا، لكن يجب أن تكون وحدة المساهمة واضحة، وأن يفصل الباحث بين ما أثبته وما استنتجه وما اقترحه معياريًا أو تطبيقيًا.

## 11. الإشراف والبيئة البحثية

- مختبر أو ميدان مناسب للسؤال.
- إشراف نظري ومنهجي وسريري عند الحاجة.
- أدوات مقننة وبيانات عالية الحماية.
- خطة لإدارة المخاطر والإحالة والموافقة.
- لجنة إشراف تجمع خبرة موضوعية ومنهجية مستقلة.
- خطة لإدارة الوصول والتخزين الآمن واستمرارية البيانات أو المصادر.

لا تحفظ أسماء المشرفين أو المؤسسات داخل هوية التخصص؛ فهي بيانات برامج جامعية في Phase 11.

## 12. متطلبات البحث والنشر والتدريس

- اختبارات جودة ومتانة أو مقارنة مستقلة تتناسب مع المجال.
- إعداد أوراق أو أدوات أو تقارير قابلة للتحكيم وفق سياسة المؤسسة.

لا توجد أعداد عالمية موحدة للمنشورات أو المؤتمرات أو ساعات التدريس.

## 2. طبيعة الدكتوراه وهدفها

تهدف دكتوراه علم النفس التنموي إلى إعداد باحث قادر على إنتاج معرفة مستقلة في النمو المعرفي والاجتماعي والانفعالي، وربطها بالتعلق والعلاقات الأسرية والمخاطر والمرونة عبر العمر. ويُتوقع منه تحديد فجوة حقيقية، وصياغة سؤال قابل للفحص، وبناء حجة أو تصميم بحث يميز بين الوصف والتفسير والسببية أو الحكم المعياري بحسب طبيعة المجال.

تختلف عن مستوى الماجستير في أن الطالب يقود برنامجًا بحثيًا طويل الأجل، ويطور نظرية أو منهجًا أو دليلًا أو أداة جديدة، ويختبر حدود الصلاحية والتعميم. لا تشمل هوية التخصص بيانات جامعة أو مشرف أو برنامج مؤسسي بعينه.

## 3. أنواع الدكتوراه الشائعة

- دكتوراه بحثية تقليدية قائمة على أطروحة أصلية.
- دكتوراه بينية عند اتصال السؤال بتخصص آخر ومنهج واضح للدمج.
- دكتوراه تعاونية مع مؤسسة عامة أو ثقافية أو مهنية مع استقلال أكاديمي واضح.
- دكتوراه بالنشر أو مسار مدمج عند توفر النظام المؤسسي.

اسم الدرجة لا ينشئ تخصصًا مستقلًا؛ فقد يطرح علم النفس التنموي ضمن PhD / DPhil وفق النظام والهدف الأكاديمي أو المهني.

- مقررات استدراكية عندما تختلف الخلفية عن جوهر التخصص.

### الخبرة أو الترخيص المطلوب للدكتوراه المهنية

- قد تتطلب الصيغة المهنية خبرة عملية وملف ممارسة أو مسؤولية مناسبة.
- الوصول إلى أفراد أو مؤسسات أو قضايا أو بيانات حساسة يحتاج موافقات وصلاحيات منفصلة.
- أي تقييم أو تدخل أو ممارسة نفسية سريرية تحتاج اعتمادًا وترخيصًا منفصلين عن الدرجة البحثية.

## 5. مراحل برنامج الدكتوراه

1. مقررات أو حلقات متقدمة وخطة تعلم فردية.
2. تدريب منهجي في التجارب السلوكية والمعرفية والقياس النفسي والنمذجة الكامنة.
3. امتحان شامل أو تأهيلي عند وجوده.
4. مراجعة نقدية للأدبيات وتحديد الفجوة.
5. إعداد المقترح وخطة البيانات أو المصادر والأخلاقيات.
6. الانتقال إلى مرحلة مرشح الدكتوراه بعد موافقة اللجنة.
7. تنفيذ البحث باستخدام الدراسات الطولية واللحظية والملاحظة والمقابلات السريرية البحثية عند التصريح عند الملاءمة.
8. اختبارات تحقق أو متانة أو مقارنة وتفسير بدائل النتائج.
9. كتابة الأطروحة ومناقشتها والدفاع عنها.
10. الإيداع واستكمال متطلبات النزاهة والبيانات والتخرج.

## 8. الامتحان التأهيلي أو الشامل عند وجوده

قد يختبر الامتحان المعرفة المتقدمة في النمو المعرفي والاجتماعي والانفعالي والتعلق والعلاقات الأسرية، والقدرة على تحليل مادة أو بيانات أو حالة مرتبطة بـعلم النفس التنموي والدفاع عن منهج يستخدم التجارب السلوكية والمعرفية والقياس النفسي والنمذجة الكامنة. كما قد يتطلب نقد أدبيات متعارضة، وتبرير وحدة التحليل، وبيان كيفية التحقق من الادعاءات والبدائل التفسيرية.

قد يكون تحريريًا أو شفهيًا أو دفاعًا عن مقترح أولي، وتختلف صيغته وتبعات النجاح أو الإخفاق بين الجامعات والأنظمة.

## 9. مقترح البحث ومرحلة الترشح

يحدد المقترح مشكلة أصلية في النمو المعرفي والاجتماعي والانفعالي أو التعلق والعلاقات الأسرية، ويعرض سؤال البحث أو الفرضيات أو الأطروحة، ويبرر استخدام التجارب السلوكية والمعرفية والقياس النفسي والنمذجة الكامنة. كما يحدد المشارك أو المهمة أو السلوك أو الأداة أو التدخل أو السياق، والسياق أو الفترة أو المجتمع أو المؤسسة، ويشرح معايير الاختيار والنطاق وحدود الاستدلال.

يجب أن يتضمن خطة للبيانات أو المصادر، والجودة، والأخلاقيات، والمخاطر، والموارد، والجدول الزمني، ومعايير مسبقة للتحقق أو المقارنة، وخطة بديلة إذا تعذر الوصول إلى مادة أو مؤسسة أو عينة أساسية.

## 10. الأطروحة والمساهمة الأصلية

قد تتمثل المساهمة الأصلية في نظرية أو مقياس أو نموذج آلي أو تدخل أو دليل تجريبي أصيل يضيف معرفة قابلة للتحقق في علم النفس التنموي، بما يطور فهم النمو المعرفي والاجتماعي والانفعالي أو يقدم تفسيرًا أو أداة أو ممارسة قابلة للتقييم في المخاطر والمرونة عبر العمر.

يمكن أن تكون الأطروحة تقليدية أو قائمة على أوراق منشورة أو مشروعًا مهنيًا موثقًا، لكن يجب أن تكون وحدة المساهمة واضحة، وأن يفصل الباحث بين ما أثبته وما استنتجه وما اقترحه معياريًا أو تطبيقيًا.

## 11. الإشراف والبيئة البحثية

- مختبر أو ميدان مناسب للسؤال.
- إشراف نظري ومنهجي وسريري عند الحاجة.
- أدوات مقننة وبيانات عالية الحماية.
- خطة لإدارة المخاطر والإحالة والموافقة.
- لجنة إشراف تجمع خبرة موضوعية ومنهجية مستقلة.
- خطة لإدارة الوصول والتخزين الآمن واستمرارية البيانات أو المصادر.

لا تحفظ أسماء المشرفين أو المؤسسات داخل هوية التخصص؛ فهي بيانات برامج جامعية في Phase 11.

## 12. متطلبات البحث والنشر والتدريس

- حلقات بحث وتحديثات دورية للجنة الإشراف.
- توثيق المنهج والبيانات أو النصوص أو الحالات وإجراءات التحليل.
- اختبارات جودة ومتانة أو مقارنة مستقلة تتناسب مع المجال.
- إعداد أوراق أو أدوات أو تقارير قابلة للتحكيم وفق سياسة المؤسسة.
- تدريس أو مساعدة تعليمية أو تدريب مهني في بعض البرامج.

لا توجد أعداد عالمية موحدة للمنشورات أو المؤتمرات أو ساعات التدريس.

## 13. المهارات البحثية والمهنية المتقدمة

- صياغة سؤال بحث أصيل في علم النفس التنموي.
- نقد الأدلة والنظريات في النمو المعرفي والاجتماعي والانفعالي.
- تطبيق التجارب السلوكية والمعرفية والقياس النفسي والنمذجة الكامنة بصورة مستقلة.
- إدارة بيانات أو نصوص أو وثائق أو حالات معقدة وضبط جودتها.
- تقييم التحيز وعدم اليقين وحدود التعميم أو النقل بين السياقات.
- الكتابة والنشر والعرض والدفاع العلمي.
- قيادة تعاون متعدد التخصصات وإدارة مشروع طويل الأجل.

## 16. ما بعد الدكتوراه والمسارات اللاحقة

- زمالة ما بعد الدكتوراه في علم النفس التنموي أو مجال قريب.
- مسار أكاديمي في البحث والتدريس والإشراف.
- البحث والاستشارات في مؤسسة عامة أو ثقافية أو اجتماعية أو خاصة أو دولية.
- قيادة برامج بحث أو سياسات أو تطوير بعد اكتساب الخبرة.
- ممارسة مهنية متقدمة عند استيفاء الترخيص أو الاعتماد المستقل.

## 18. التنبيه الأكاديمي والمهني

> **الدكتوراه البحثية لا تمنح حق التشخيص أو العلاج النفسي تلقائيًا. استخدام الاختبارات أو التدخلات السريرية يحتاج تدريبًا واعتمادًا وترخيصًا محليًا، مع حماية صارمة للبيانات النفسية. جودة الإشراف والبيئة والبيانات أو المصادر أهم من اسم الدرجة وحده، والدكتوراه لا تضمن وظيفة أكاديمية.**
