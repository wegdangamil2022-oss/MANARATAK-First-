## 2. طبيعة الدكتوراه وهدفها

تهدف دكتوراه الخدمات اللوجستية إلى إعداد باحث قادر على تفسير وتطوير المعرفة المتعلقة بـ تصميم شبكات النقل والتوزيع وإدارة المخازن والتدفق، واختبار علاقتها بـ لوجستيات الميل الأخير. ويُتوقع من الباحث تحديد فجوة حقيقية، وصياغة سؤال قابل للفحص، وبناء تصميم يميز بين الوصف والتفسير والسببية أو الحجة المعيارية وفق طبيعة المجال.

تختلف عن الماجستير في أن الطالب يقود برنامجًا بحثيًا مستقلًا، ويطور نظرية أو منهجًا أو دليلًا أو إطارًا جديدًا، ويبرهن حدود الصلاحية والتعميم. لا تشمل هوية التخصص بيانات جامعة أو مشرف أو جهة مهنية أو نظام وطني بعينه.

## 3. أنواع الدكتوراه الشائعة

- دكتوراه بحثية تقليدية قائمة على أطروحة أصلية.
- دكتوراه مهنية أو تطبيقية تعالج مشكلة ممارسة عند توفرها.
- دكتوراه تعاونية مع جهة عامة أو خاصة مع استقلال أكاديمي واضح.
- دكتوراه بالنشر أو مسار مدمج عند توفر النظام المؤسسي.

اسم الدرجة لا ينشئ تخصصًا مستقلًا؛ فقد يطرح المجال ضمن PhD أو DBA أو SJD/JSD أو DPA بحسب النظام.

### الدخول المباشر بعد البكالوريوس عند شيوعه

- بكالوريوس متميز في مجال مرتبط مع خبرة بحثية موثقة.
- إعداد قوي في المناهج الكمية أو النوعية أو القانونية أو التاريخية المطلوبة للمسار.
- مقررات استدراكية عندما تختلف الخلفية عن جوهر التخصص.

### الخبرة أو الترخيص المطلوب للدكتوراه المهنية

- قد تتطلب الصيغة المهنية خبرة عملية موثقة ومسؤولية إدارية أو قانونية أو سياساتية.
- الوصول إلى بيانات مؤسسات أو عملاء أو قضايا أو موظفين يحتاج موافقات وسرية وصلاحيات منفصلة.
- أي ممارسة منظمة تبقى خاضعة للترخيص المحلي ولا تمنحها الدكتوراه تلقائيًا.

## 5. مراحل برنامج الدكتوراه

1. مقررات أو حلقات متقدمة وخطة تعلم فردية.
2. تدريب منهجي في التحسين المختلط وعدد صحيح ومحاكاة الشبكات وسيناريوهات الطلب.
3. امتحان شامل أو تأهيلي عند وجوده.
4. مراجعة نقدية للأدبيات وتحديد الفجوة.
5. إعداد المقترح وخطة البيانات أو المصادر والأخلاقيات.
6. الانتقال إلى مرحلة مرشح الدكتوراه بعد موافقة اللجنة.
7. تنفيذ البحث باستخدام تحليل بيانات تتبع وتشغيل ودراسات حالة ومقابلات مع الفاعلين عند الملاءمة.
8. اختبارات التحقق والمتانة أو المقارنة القانونية والتاريخية.
9. كتابة الأطروحة ومناقشتها والدفاع عنها.
10. الإيداع واستكمال متطلبات النزاهة والبيانات والتخرج.

## 6. المعرفة والمقررات المتقدمة

### المعرفة النظرية المتقدمة

- تصميم الشبكات والعمليات وتدفق الموارد.
- المخزون والطلب ومستوى الخدمة.
- العلاقات مع الموردين والوسطاء.
- المرونة والاستدامة والمخاطر التشغيلية.
- الأدبيات والاتجاهات المعاصرة في تصميم شبكات النقل والتوزيع وإدارة المخازن والتدفق.
- نقد الافتراضات والقياس والتفسير وحدود النقل بين الأنظمة والسياقات.

### مناهج البحث والتحليل

- التحسين المختلط وعدد صحيح.
- محاكاة الشبكات وسيناريوهات الطلب.
- تحليل بيانات تتبع وتشغيل.
- دراسات حالة ومقابلات مع الفاعلين.
- مراجعات منهجية أو مقارنات معيارية وربط النتائج بأدلة مستقلة.

### الأخلاقيات والنزاهة العلمية

- الموافقات الأخلاقية قبل جمع بيانات الأفراد أو المؤسسات أو القضايا الحساسة.
- حماية الخصوصية والسرية التجارية أو القانونية أو الدبلوماسية.
- الإفصاح عن التمويل والمصالح المهنية والسياسية والمالية.
- توثيق المصادر والتحويلات والشفرة أو بروتوكول التحليل.
- عدم استخدام البحث للإضرار بالمشاركين أو التأثير غير المشروع في قرار مهني أو قضائي أو سياسي.

## 7. مجالات البحث والتخصصات الدقيقة

- تصميم شبكات النقل والتوزيع
- إدارة المخازن والتدفق
- لوجستيات الميل الأخير
- الرقمنة والرؤية عبر الشبكة
- الاستدامة وقياس الأثر
- المرونة وعدم اليقين

تُحفظ هذه المجالات كعلاقات أو تركيزات بحثية، ولا تتحول تلقائيًا إلى تخصصات مستقلة دون مراجعة Academic Taxonomy.

## 8. الامتحان التأهيلي أو الشامل عند وجوده

قد يختبر الامتحان الفهم المتقدم لـ تصميم شبكات النقل والتوزيع وإدارة المخازن والتدفق، والقدرة على نقد نظرية أو دراسة أو حكم أو سياسة أو مجموعة بيانات، وتصميم بحث يستخدم التحسين المختلط وعدد صحيح ومحاكاة الشبكات وسيناريوهات الطلب مع تبرير الوحدة التحليلية والعينة أو المصادر والتحقق.

قد يكون تحريريًا أو شفهيًا أو دفاعًا عن مقترح أولي، وتختلف صيغته وتبعات النجاح أو الإخفاق بين الجامعات والأنظمة.

## 9. مقترح البحث ومرحلة الترشح

يحدد المقترح مشكلة أصلية في تصميم شبكات النقل والتوزيع أو إدارة المخازن والتدفق، ويعرض سؤال البحث أو الفرضيات أو الأطروحة القانونية، ويبرر استخدام التحسين المختلط وعدد صحيح ومحاكاة الشبكات وسيناريوهات الطلب. كما يحدد وحدة التحليل أو المؤسسات أو الأسواق أو النصوص أو الحالات والفترة الزمنية والنطاق الجغرافي أو القانوني.

يجب أن يتضمن خطة للبيانات والمصادر والجودة والأخلاقيات والمخاطر والموارد والجدول الزمني، ومعايير مسبقة للتحقق أو المقارنة، وخطة بديلة إذا تعذر الوصول إلى بيانات أو مؤسسة أو وثيقة أساسية.

## 10. الأطروحة والمساهمة الأصلية

قد تتمثل المساهمة الأصلية في نموذج شبكة أو سياسة تشغيل أو خوارزمية قرار أو دليلًا سببيًا جديدًا في الخدمات اللوجستية، بما يطور فهم تصميم شبكات النقل والتوزيع أو يقدم تفسيرًا أو أداة أو توصية قابلة للتقييم في إدارة المخازن والتدفق.

يمكن أن تكون الأطروحة تقليدية أو قائمة على أوراق منشورة أو مشروعًا مهنيًا موثقًا، لكن يجب أن تكون وحدة المساهمة واضحة، وأن يفصل الباحث بين ما أثبته وما استنتجه وما اقترحه معياريًا أو تطبيقيًا.

## 11. الإشراف والبيئة البحثية

- وصول موثق إلى بيانات النقل والمخزون والموردين.
- برمجيات تحسين ومحاكاة وتحليل مكاني.
- شراكات مع مؤسسات لوجستية أو صناعية مع حماية السرية.
- لجنة إشراف تجمع خبرة موضوعية ومنهجية مستقلة.
- خطة لإدارة الوصول والسرية والتخزين الآمن واستمرارية البيانات أو المصادر.

لا تحفظ أسماء المشرفين أو المؤسسات داخل هوية التخصص؛ فهي بيانات برامج جامعية في Phase 11.

## 12. متطلبات البحث والنشر والتدريس

- حلقات بحث وتحديثات دورية للجنة الإشراف.
- توثيق المنهج والبيانات أو النصوص أو الحالات وإجراءات التحليل.
- اختبارات جودة ومتانة أو مقارنة مستقلة تتناسب مع المجال.
- إعداد أوراق أو أدوات أو تقارير قابلة للتحكيم وفق سياسة المؤسسة.
- تدريس أو مساعدة تعليمية أو تدريب مهني في بعض البرامج.

لا توجد أعداد عالمية موحدة للمنشورات أو المؤتمرات أو ساعات التدريس.

## 13. المهارات البحثية والمهنية المتقدمة

- صياغة سؤال بحث أصيل في الخدمات اللوجستية
- نقد الأدلة والنظريات في تصميم شبكات النقل والتوزيع
- تطبيق التحسين المختلط وعدد صحيح ومحاكاة الشبكات وسيناريوهات الطلب بصورة مستقلة
- إدارة بيانات أو وثائق أو حالات معقدة وضبط جودتها
- تقييم التحيز وعدم اليقين وحدود التعميم أو القياس القانوني
- الكتابة والنشر والعرض والدفاع العلمي
- قيادة تعاون متعدد التخصصات وإدارة مشروع طويل الأجل

## 14. مجالات العمل بعد الدكتوراه

- الجامعات وكليات الأعمال والهندسة الصناعية
- البحث والاستشارات في اللوجستيات وسلاسل الإمداد
- شركات النقل والتوزيع والتصنيع والتجارة
- الهيئات الجمركية والموانئ والتخطيط والبنية التحتية

تعتمد ملاءمة المسار على موضوع الأطروحة والمنهج والخبرة وأي اعتماد مهني مستقل.

## 16. ما بعد الدكتوراه والمسارات اللاحقة

- زمالة ما بعد الدكتوراه في الخدمات اللوجستية أو مجال قريب.
- مسار أكاديمي في البحث والتدريس والإشراف.
- البحث والاستشارات في مؤسسة عامة أو خاصة أو دولية.
- قيادة برامج بحث أو سياسات أو تحول بعد اكتساب الخبرة.
- ريادة أعمال معرفية أو ممارسة مهنية عند استيفاء الترخيص.

> **الدكتوراه لا تعوض الخبرة التشغيلية ولا تمنح صلاحية تنظيمية أو جمركية. يجب توثيق افتراضات التكلفة والطلب وعدم تعميم نموذج شبكة واحدة على جميع القطاعات. جودة الإشراف والبيانات أو المصادر واستقلال البحث أهم من اسم البرنامج وحده.**

| الوصف المختصر | دكتوراه تنتج معرفة أصلية في المشتريات والتوريد، مع تركيز محتمل على استراتيجية التوريد واختيار المورد والعقود والعلاقات مع الموردين وربطهما بـ المشتريات المستدامة والرقمية. |

## 2. طبيعة الدكتوراه وهدفها

تهدف دكتوراه المشتريات والتوريد إلى إعداد باحث قادر على تفسير وتطوير المعرفة المتعلقة بـ استراتيجية التوريد واختيار المورد والعقود والعلاقات مع الموردين، واختبار علاقتها بـ المشتريات المستدامة والرقمية. ويُتوقع من الباحث تحديد فجوة حقيقية، وصياغة سؤال قابل للفحص، وبناء تصميم يميز بين الوصف والتفسير والسببية أو الحجة المعيارية وفق طبيعة المجال.

تختلف عن الماجستير في أن الطالب يقود برنامجًا بحثيًا مستقلًا، ويطور نظرية أو منهجًا أو دليلًا أو إطارًا جديدًا، ويبرهن حدود الصلاحية والتعميم. لا تشمل هوية التخصص بيانات جامعة أو مشرف أو جهة مهنية أو نظام وطني بعينه.

## 3. أنواع الدكتوراه الشائعة

- دكتوراه بحثية تقليدية قائمة على أطروحة أصلية.
- دكتوراه مهنية أو تطبيقية تعالج مشكلة ممارسة عند توفرها.
- دكتوراه تعاونية مع جهة عامة أو خاصة مع استقلال أكاديمي واضح.
- دكتوراه بالنشر أو مسار مدمج عند توفر النظام المؤسسي.

اسم الدرجة لا ينشئ تخصصًا مستقلًا؛ فقد يطرح المجال ضمن PhD أو DBA أو SJD/JSD أو DPA بحسب النظام.

## 5. مراحل برنامج الدكتوراه

1. مقررات أو حلقات متقدمة وخطة تعلم فردية.
2. تدريب منهجي في التحسين المختلط وعدد صحيح ومحاكاة الشبكات وسيناريوهات الطلب.
3. امتحان شامل أو تأهيلي عند وجوده.
4. مراجعة نقدية للأدبيات وتحديد الفجوة.
5. إعداد المقترح وخطة البيانات أو المصادر والأخلاقيات.
6. الانتقال إلى مرحلة مرشح الدكتوراه بعد موافقة اللجنة.
7. تنفيذ البحث باستخدام تحليل بيانات تتبع وتشغيل ودراسات حالة ومقابلات مع الفاعلين عند الملاءمة.
8. اختبارات التحقق والمتانة أو المقارنة القانونية والتاريخية.
9. كتابة الأطروحة ومناقشتها والدفاع عنها.
10. الإيداع واستكمال متطلبات النزاهة والبيانات والتخرج.

## 6. المعرفة والمقررات المتقدمة

### المعرفة النظرية المتقدمة

- تصميم الشبكات والعمليات وتدفق الموارد.
- المخزون والطلب ومستوى الخدمة.
- العلاقات مع الموردين والوسطاء.
- المرونة والاستدامة والمخاطر التشغيلية.
- الأدبيات والاتجاهات المعاصرة في استراتيجية التوريد واختيار المورد والعقود والعلاقات مع الموردين.
- نقد الافتراضات والقياس والتفسير وحدود النقل بين الأنظمة والسياقات.

### مناهج البحث والتحليل

- التحسين المختلط وعدد صحيح.
- محاكاة الشبكات وسيناريوهات الطلب.
- تحليل بيانات تتبع وتشغيل.
- دراسات حالة ومقابلات مع الفاعلين.
- مراجعات منهجية أو مقارنات معيارية وربط النتائج بأدلة مستقلة.

### الأخلاقيات والنزاهة العلمية

- الموافقات الأخلاقية قبل جمع بيانات الأفراد أو المؤسسات أو القضايا الحساسة.
- حماية الخصوصية والسرية التجارية أو القانونية أو الدبلوماسية.
- الإفصاح عن التمويل والمصالح المهنية والسياسية والمالية.
- توثيق المصادر والتحويلات والشفرة أو بروتوكول التحليل.
- عدم استخدام البحث للإضرار بالمشاركين أو التأثير غير المشروع في قرار مهني أو قضائي أو سياسي.

## 7. مجالات البحث والتخصصات الدقيقة

- استراتيجية التوريد واختيار المورد
- العقود والعلاقات مع الموردين
- المشتريات المستدامة والرقمية
- الرقمنة والرؤية عبر الشبكة
- الاستدامة وقياس الأثر
- المرونة وعدم اليقين

تُحفظ هذه المجالات كعلاقات أو تركيزات بحثية، ولا تتحول تلقائيًا إلى تخصصات مستقلة دون مراجعة Academic Taxonomy.

## 8. الامتحان التأهيلي أو الشامل عند وجوده

قد يختبر الامتحان الفهم المتقدم لـ استراتيجية التوريد واختيار المورد والعقود والعلاقات مع الموردين، والقدرة على نقد نظرية أو دراسة أو حكم أو سياسة أو مجموعة بيانات، وتصميم بحث يستخدم التحسين المختلط وعدد صحيح ومحاكاة الشبكات وسيناريوهات الطلب مع تبرير الوحدة التحليلية والعينة أو المصادر والتحقق.

قد يكون تحريريًا أو شفهيًا أو دفاعًا عن مقترح أولي، وتختلف صيغته وتبعات النجاح أو الإخفاق بين الجامعات والأنظمة.

## 9. مقترح البحث ومرحلة الترشح

يحدد المقترح مشكلة أصلية في استراتيجية التوريد واختيار المورد أو العقود والعلاقات مع الموردين، ويعرض سؤال البحث أو الفرضيات أو الأطروحة القانونية، ويبرر استخدام التحسين المختلط وعدد صحيح ومحاكاة الشبكات وسيناريوهات الطلب. كما يحدد وحدة التحليل أو المؤسسات أو الأسواق أو النصوص أو الحالات والفترة الزمنية والنطاق الجغرافي أو القانوني.

يجب أن يتضمن خطة للبيانات والمصادر والجودة والأخلاقيات والمخاطر والموارد والجدول الزمني، ومعايير مسبقة للتحقق أو المقارنة، وخطة بديلة إذا تعذر الوصول إلى بيانات أو مؤسسة أو وثيقة أساسية.

## 10. الأطروحة والمساهمة الأصلية

قد تتمثل المساهمة الأصلية في نموذج شبكة أو سياسة تشغيل أو خوارزمية قرار أو دليلًا سببيًا جديدًا في المشتريات والتوريد، بما يطور فهم استراتيجية التوريد واختيار المورد أو يقدم تفسيرًا أو أداة أو توصية قابلة للتقييم في العقود والعلاقات مع الموردين.

يمكن أن تكون الأطروحة تقليدية أو قائمة على أوراق منشورة أو مشروعًا مهنيًا موثقًا، لكن يجب أن تكون وحدة المساهمة واضحة، وأن يفصل الباحث بين ما أثبته وما استنتجه وما اقترحه معياريًا أو تطبيقيًا.

## 11. الإشراف والبيئة البحثية

- وصول موثق إلى بيانات النقل والمخزون والموردين.
- برمجيات تحسين ومحاكاة وتحليل مكاني.
- شراكات مع مؤسسات لوجستية أو صناعية مع حماية السرية.
- لجنة إشراف تجمع خبرة موضوعية ومنهجية مستقلة.
- خطة لإدارة الوصول والسرية والتخزين الآمن واستمرارية البيانات أو المصادر.

لا تحفظ أسماء المشرفين أو المؤسسات داخل هوية التخصص؛ فهي بيانات برامج جامعية في Phase 11.

## 12. متطلبات البحث والنشر والتدريس

- حلقات بحث وتحديثات دورية للجنة الإشراف.
- توثيق المنهج والبيانات أو النصوص أو الحالات وإجراءات التحليل.
- اختبارات جودة ومتانة أو مقارنة مستقلة تتناسب مع المجال.
- إعداد أوراق أو أدوات أو تقارير قابلة للتحكيم وفق سياسة المؤسسة.
- تدريس أو مساعدة تعليمية أو تدريب مهني في بعض البرامج.

لا توجد أعداد عالمية موحدة للمنشورات أو المؤتمرات أو ساعات التدريس.

## 13. المهارات البحثية والمهنية المتقدمة

- صياغة سؤال بحث أصيل في المشتريات والتوريد
- نقد الأدلة والنظريات في استراتيجية التوريد واختيار المورد

- الكتابة والنشر والعرض والدفاع العلمي

## 2. طبيعة الدكتوراه وهدفها

تهدف دكتوراه إدارة الموارد البشرية إلى إعداد باحث قادر على تفسير وتطوير المعرفة المتعلقة بـ الاختيار والتطوير والاحتفاظ وأنظمة الأداء والمكافآت، واختبار علاقتها بـ التحول الرقمي ومستقبل العمل. ويُتوقع من الباحث تحديد فجوة حقيقية، وصياغة سؤال قابل للفحص، وبناء تصميم يميز بين الوصف والتفسير والسببية أو الحجة المعيارية وفق طبيعة المجال.

تختلف عن الماجستير في أن الطالب يقود برنامجًا بحثيًا مستقلًا، ويطور نظرية أو منهجًا أو دليلًا أو إطارًا جديدًا، ويبرهن حدود الصلاحية والتعميم. لا تشمل هوية التخصص بيانات جامعة أو مشرف أو جهة مهنية أو نظام وطني بعينه.

## 3. أنواع الدكتوراه الشائعة

- دكتوراه بحثية تقليدية قائمة على أطروحة أصلية.
- دكتوراه مهنية أو تطبيقية تعالج مشكلة ممارسة عند توفرها.
- دكتوراه تعاونية مع جهة عامة أو خاصة مع استقلال أكاديمي واضح.
- دكتوراه بالنشر أو مسار مدمج عند توفر النظام المؤسسي.

اسم الدرجة لا ينشئ تخصصًا مستقلًا؛ فقد يطرح المجال ضمن PhD أو DBA أو SJD/JSD أو DPA بحسب النظام.

### الدخول المباشر بعد البكالوريوس عند شيوعه

- بكالوريوس متميز في مجال مرتبط مع خبرة بحثية موثقة.
- إعداد قوي في المناهج الكمية أو النوعية أو القانونية أو التاريخية المطلوبة للمسار.
- مقررات استدراكية عندما تختلف الخلفية عن جوهر التخصص.

### الخبرة أو الترخيص المطلوب للدكتوراه المهنية

- قد تتطلب الصيغة المهنية خبرة عملية موثقة ومسؤولية إدارية أو قانونية أو سياساتية.
- الوصول إلى بيانات مؤسسات أو عملاء أو قضايا أو موظفين يحتاج موافقات وسرية وصلاحيات منفصلة.
- أي ممارسة منظمة تبقى خاضعة للترخيص المحلي ولا تمنحها الدكتوراه تلقائيًا.

## 5. مراحل برنامج الدكتوراه

1. مقررات أو حلقات متقدمة وخطة تعلم فردية.
2. تدريب منهجي في المسوح والنمذجة متعددة المستويات والتجارب الميدانية وشبه التجريبية.
3. امتحان شامل أو تأهيلي عند وجوده.
4. مراجعة نقدية للأدبيات وتحديد الفجوة.
5. إعداد المقترح وخطة البيانات أو المصادر والأخلاقيات.
6. الانتقال إلى مرحلة مرشح الدكتوراه بعد موافقة اللجنة.
7. تنفيذ البحث باستخدام المقابلات والإثنوغرافيا وتحليل الشبكات والبيانات الطولية عند الملاءمة.
8. اختبارات التحقق والمتانة أو المقارنة القانونية والتاريخية.
9. كتابة الأطروحة ومناقشتها والدفاع عنها.
10. الإيداع واستكمال متطلبات النزاهة والبيانات والتخرج.

## 6. المعرفة والمقررات المتقدمة

### المعرفة النظرية المتقدمة

- الدافعية والهوية والعلاقات في العمل.
- القيادة والسلطة والثقافة التنظيمية.
- تصميم العمل والتعلم والتغيير.
- العدالة والتنوع والرفاه والأداء.
- الأدبيات والاتجاهات المعاصرة في الاختيار والتطوير والاحتفاظ وأنظمة الأداء والمكافآت.
- نقد الافتراضات والقياس والتفسير وحدود النقل بين الأنظمة والسياقات.

### مناهج البحث والتحليل

- المسوح والنمذجة متعددة المستويات.
- التجارب الميدانية وشبه التجريبية.
- المقابلات والإثنوغرافيا.
- تحليل الشبكات والبيانات الطولية.
- مراجعات منهجية أو مقارنات معيارية وربط النتائج بأدلة مستقلة.

### الأخلاقيات والنزاهة العلمية

- الموافقات الأخلاقية قبل جمع بيانات الأفراد أو المؤسسات أو القضايا الحساسة.
- حماية الخصوصية والسرية التجارية أو القانونية أو الدبلوماسية.
- الإفصاح عن التمويل والمصالح المهنية والسياسية والمالية.
- توثيق المصادر والتحويلات والشفرة أو بروتوكول التحليل.
- عدم استخدام البحث للإضرار بالمشاركين أو التأثير غير المشروع في قرار مهني أو قضائي أو سياسي.

## 7. مجالات البحث والتخصصات الدقيقة

- الاختيار والتطوير والاحتفاظ
- أنظمة الأداء والمكافآت
- التحول الرقمي ومستقبل العمل
- التنوع والسياق المؤسسي
- التحول ومستقبل العمل
- القياس والأثر التنظيمي

## 8. الامتحان التأهيلي أو الشامل عند وجوده

قد يختبر الامتحان الفهم المتقدم لـ الاختيار والتطوير والاحتفاظ وأنظمة الأداء والمكافآت، والقدرة على نقد نظرية أو دراسة أو حكم أو سياسة أو مجموعة بيانات، وتصميم بحث يستخدم المسوح والنمذجة متعددة المستويات والتجارب الميدانية وشبه التجريبية مع تبرير الوحدة التحليلية والعينة أو المصادر والتحقق.

قد يكون تحريريًا أو شفهيًا أو دفاعًا عن مقترح أولي، وتختلف صيغته وتبعات النجاح أو الإخفاق بين الجامعات والأنظمة.

## 9. مقترح البحث ومرحلة الترشح

يحدد المقترح مشكلة أصلية في الاختيار والتطوير والاحتفاظ أو أنظمة الأداء والمكافآت، ويعرض سؤال البحث أو الفرضيات أو الأطروحة القانونية، ويبرر استخدام المسوح والنمذجة متعددة المستويات والتجارب الميدانية وشبه التجريبية. كما يحدد وحدة التحليل أو المؤسسات أو الأسواق أو النصوص أو الحالات والفترة الزمنية والنطاق الجغرافي أو القانوني.

يجب أن يتضمن خطة للبيانات والمصادر والجودة والأخلاقيات والمخاطر والموارد والجدول الزمني، ومعايير مسبقة للتحقق أو المقارنة، وخطة بديلة إذا تعذر الوصول إلى بيانات أو مؤسسة أو وثيقة أساسية.

## 10. الأطروحة والمساهمة الأصلية

قد تتمثل المساهمة الأصلية في نظرية أو مقياسًا أو آلية سلوكية أو تدخلًا تنظيميًا جديدًا في إدارة الموارد البشرية، بما يطور فهم الاختيار والتطوير والاحتفاظ أو يقدم تفسيرًا أو أداة أو توصية قابلة للتقييم في أنظمة الأداء والمكافآت.

يمكن أن تكون الأطروحة تقليدية أو قائمة على أوراق منشورة أو مشروعًا مهنيًا موثقًا، لكن يجب أن تكون وحدة المساهمة واضحة، وأن يفصل الباحث بين ما أثبته وما استنتجه وما اقترحه معياريًا أو تطبيقيًا.

## 11. الإشراف والبيئة البحثية

- وصول أخلاقي إلى مؤسسات وموظفين وفرق.
- أدوات قياس نفسية وتنظيمية موثوقة.
- إشراف يجمع النظرية والسلوك والمنهج الكمي أو النوعي.
- لجنة إشراف تجمع خبرة موضوعية ومنهجية مستقلة.
- خطة لإدارة الوصول والسرية والتخزين الآمن واستمرارية البيانات أو المصادر.

لا تحفظ أسماء المشرفين أو المؤسسات داخل هوية التخصص؛ فهي بيانات برامج جامعية في Phase 11.

## 12. متطلبات البحث والنشر والتدريس

- حلقات بحث وتحديثات دورية للجنة الإشراف.
- توثيق المنهج والبيانات أو النصوص أو الحالات وإجراءات التحليل.
- اختبارات جودة ومتانة أو مقارنة مستقلة تتناسب مع المجال.
- إعداد أوراق أو أدوات أو تقارير قابلة للتحكيم وفق سياسة المؤسسة.
- تدريس أو مساعدة تعليمية أو تدريب مهني في بعض البرامج.

لا توجد أعداد عالمية موحدة للمنشورات أو المؤتمرات أو ساعات التدريس.

## 13. المهارات البحثية والمهنية المتقدمة

- صياغة سؤال بحث أصيل في إدارة الموارد البشرية
- نقد الأدلة والنظريات في الاختيار والتطوير والاحتفاظ

## 2. طبيعة الدكتوراه وهدفها

تهدف دكتوراه السلوك التنظيمي إلى إعداد باحث قادر على تفسير وتطوير المعرفة المتعلقة بـ الدافعية والهوية في العمل والفرق والشبكات الاجتماعية، واختبار علاقتها بـ العدالة والرفاه والسلوكيات السلبية. ويُتوقع من الباحث تحديد فجوة حقيقية، وصياغة سؤال قابل للفحص، وبناء تصميم يميز بين الوصف والتفسير والسببية أو الحجة المعيارية وفق طبيعة المجال.

تختلف عن الماجستير في أن الطالب يقود برنامجًا بحثيًا مستقلًا، ويطور نظرية أو منهجًا أو دليلًا أو إطارًا جديدًا، ويبرهن حدود الصلاحية والتعميم. لا تشمل هوية التخصص بيانات جامعة أو مشرف أو جهة مهنية أو نظام وطني بعينه.

## 3. أنواع الدكتوراه الشائعة

- دكتوراه بحثية تقليدية قائمة على أطروحة أصلية.
- دكتوراه مهنية أو تطبيقية تعالج مشكلة ممارسة عند توفرها.
- دكتوراه تعاونية مع جهة عامة أو خاصة مع استقلال أكاديمي واضح.
- دكتوراه بالنشر أو مسار مدمج عند توفر النظام المؤسسي.

اسم الدرجة لا ينشئ تخصصًا مستقلًا؛ فقد يطرح المجال ضمن PhD أو DBA أو SJD/JSD أو DPA بحسب النظام.

- الإفصاح عن التمويل والمصالح المهنية والسياسية والمالية.
- توثيق المصادر والتحويلات والشفرة أو بروتوكول التحليل.
- عدم استخدام البحث للإضرار بالمشاركين أو التأثير غير المشروع في قرار مهني أو قضائي أو سياسي.

## 7. مجالات البحث والتخصصات الدقيقة

- الدافعية والهوية في العمل
- الفرق والشبكات الاجتماعية
- العدالة والرفاه والسلوكيات السلبية
- التنوع والسياق المؤسسي
- التحول ومستقبل العمل
- القياس والأثر التنظيمي

تُحفظ هذه المجالات كعلاقات أو تركيزات بحثية، ولا تتحول تلقائيًا إلى تخصصات مستقلة دون مراجعة Academic Taxonomy.

## 8. الامتحان التأهيلي أو الشامل عند وجوده

قد يختبر الامتحان الفهم المتقدم لـ الدافعية والهوية في العمل والفرق والشبكات الاجتماعية، والقدرة على نقد نظرية أو دراسة أو حكم أو سياسة أو مجموعة بيانات، وتصميم بحث يستخدم المسوح والنمذجة متعددة المستويات والتجارب الميدانية وشبه التجريبية مع تبرير الوحدة التحليلية والعينة أو المصادر والتحقق.

قد يكون تحريريًا أو شفهيًا أو دفاعًا عن مقترح أولي، وتختلف صيغته وتبعات النجاح أو الإخفاق بين الجامعات والأنظمة.

## 9. مقترح البحث ومرحلة الترشح

يحدد المقترح مشكلة أصلية في الدافعية والهوية في العمل أو الفرق والشبكات الاجتماعية، ويعرض سؤال البحث أو الفرضيات أو الأطروحة القانونية، ويبرر استخدام المسوح والنمذجة متعددة المستويات والتجارب الميدانية وشبه التجريبية. كما يحدد وحدة التحليل أو المؤسسات أو الأسواق أو النصوص أو الحالات والفترة الزمنية والنطاق الجغرافي أو القانوني.

يجب أن يتضمن خطة للبيانات والمصادر والجودة والأخلاقيات والمخاطر والموارد والجدول الزمني، ومعايير مسبقة للتحقق أو المقارنة، وخطة بديلة إذا تعذر الوصول إلى بيانات أو مؤسسة أو وثيقة أساسية.

## 10. الأطروحة والمساهمة الأصلية

قد تتمثل المساهمة الأصلية في نظرية أو مقياسًا أو آلية سلوكية أو تدخلًا تنظيميًا جديدًا في السلوك التنظيمي، بما يطور فهم الدافعية والهوية في العمل أو يقدم تفسيرًا أو أداة أو توصية قابلة للتقييم في الفرق والشبكات الاجتماعية.

يمكن أن تكون الأطروحة تقليدية أو قائمة على أوراق منشورة أو مشروعًا مهنيًا موثقًا، لكن يجب أن تكون وحدة المساهمة واضحة، وأن يفصل الباحث بين ما أثبته وما استنتجه وما اقترحه معياريًا أو تطبيقيًا.

## 11. الإشراف والبيئة البحثية

- وصول أخلاقي إلى مؤسسات وموظفين وفرق.
- أدوات قياس نفسية وتنظيمية موثوقة.
- إشراف يجمع النظرية والسلوك والمنهج الكمي أو النوعي.
- لجنة إشراف تجمع خبرة موضوعية ومنهجية مستقلة.
- خطة لإدارة الوصول والسرية والتخزين الآمن واستمرارية البيانات أو المصادر.

لا تحفظ أسماء المشرفين أو المؤسسات داخل هوية التخصص؛ فهي بيانات برامج جامعية في Phase 11.

## 12. متطلبات البحث والنشر والتدريس

- حلقات بحث وتحديثات دورية للجنة الإشراف.
- توثيق المنهج والبيانات أو النصوص أو الحالات وإجراءات التحليل.
- اختبارات جودة ومتانة أو مقارنة مستقلة تتناسب مع المجال.
- إعداد أوراق أو أدوات أو تقارير قابلة للتحكيم وفق سياسة المؤسسة.
- تدريس أو مساعدة تعليمية أو تدريب مهني في بعض البرامج.

لا توجد أعداد عالمية موحدة للمنشورات أو المؤتمرات أو ساعات التدريس.

## 13. المهارات البحثية والمهنية المتقدمة

- صياغة سؤال بحث أصيل في السلوك التنظيمي
- نقد الأدلة والنظريات في الدافعية والهوية في العمل

- الكتابة والنشر والعرض والدفاع العلمي
- قيادة تعاون متعدد التخصصات وإدارة مشروع طويل الأجل

## 14. مجالات العمل بعد الدكتوراه

## 2. طبيعة الدكتوراه وهدفها

تهدف دكتوراه القيادة إلى إعداد باحث قادر على تفسير وتطوير المعرفة المتعلقة بـ نظريات القيادة وتأثيرها والقيادة الأخلاقية والموزعة، واختبار علاقتها بـ تنمية القيادات والفرق العليا. ويُتوقع من الباحث تحديد فجوة حقيقية، وصياغة سؤال قابل للفحص، وبناء تصميم يميز بين الوصف والتفسير والسببية أو الحجة المعيارية وفق طبيعة المجال.

تختلف عن الماجستير في أن الطالب يقود برنامجًا بحثيًا مستقلًا، ويطور نظرية أو منهجًا أو دليلًا أو إطارًا جديدًا، ويبرهن حدود الصلاحية والتعميم. لا تشمل هوية التخصص بيانات جامعة أو مشرف أو جهة مهنية أو نظام وطني بعينه.

## 3. أنواع الدكتوراه الشائعة

- دكتوراه بحثية تقليدية قائمة على أطروحة أصلية.
- دكتوراه مهنية أو تطبيقية تعالج مشكلة ممارسة عند توفرها.
- دكتوراه تعاونية مع جهة عامة أو خاصة مع استقلال أكاديمي واضح.
- دكتوراه بالنشر أو مسار مدمج عند توفر النظام المؤسسي.

اسم الدرجة لا ينشئ تخصصًا مستقلًا؛ فقد يطرح المجال ضمن PhD أو DBA أو SJD/JSD أو DPA بحسب النظام.

## 5. مراحل برنامج الدكتوراه

1. مقررات أو حلقات متقدمة وخطة تعلم فردية.
2. تدريب منهجي في المسوح والنمذجة متعددة المستويات والتجارب الميدانية وشبه التجريبية.
3. امتحان شامل أو تأهيلي عند وجوده.
4. مراجعة نقدية للأدبيات وتحديد الفجوة.
5. إعداد المقترح وخطة البيانات أو المصادر والأخلاقيات.
6. الانتقال إلى مرحلة مرشح الدكتوراه بعد موافقة اللجنة.
7. تنفيذ البحث باستخدام المقابلات والإثنوغرافيا وتحليل الشبكات والبيانات الطولية عند الملاءمة.
8. اختبارات التحقق والمتانة أو المقارنة القانونية والتاريخية.
9. كتابة الأطروحة ومناقشتها والدفاع عنها.
10. الإيداع واستكمال متطلبات النزاهة والبيانات والتخرج.

## 9. مقترح البحث ومرحلة الترشح

## 10. الأطروحة والمساهمة الأصلية

قد تتمثل المساهمة الأصلية في نظرية أو مقياسًا أو آلية سلوكية أو تدخلًا تنظيميًا جديدًا في القيادة، بما يطور فهم نظريات القيادة وتأثيرها أو يقدم تفسيرًا أو أداة أو توصية قابلة للتقييم في القيادة الأخلاقية والموزعة.

يمكن أن تكون الأطروحة تقليدية أو قائمة على أوراق منشورة أو مشروعًا مهنيًا موثقًا، لكن يجب أن تكون وحدة المساهمة واضحة، وأن يفصل الباحث بين ما أثبته وما استنتجه وما اقترحه معياريًا أو تطبيقيًا.

## 11. الإشراف والبيئة البحثية

- وصول أخلاقي إلى مؤسسات وموظفين وفرق.
- أدوات قياس نفسية وتنظيمية موثوقة.
- إشراف يجمع النظرية والسلوك والمنهج الكمي أو النوعي.
- لجنة إشراف تجمع خبرة موضوعية ومنهجية مستقلة.
- خطة لإدارة الوصول والسرية والتخزين الآمن واستمرارية البيانات أو المصادر.

لا تحفظ أسماء المشرفين أو المؤسسات داخل هوية التخصص؛ فهي بيانات برامج جامعية في Phase 11.

## 12. متطلبات البحث والنشر والتدريس

- حلقات بحث وتحديثات دورية للجنة الإشراف.
- توثيق المنهج والبيانات أو النصوص أو الحالات وإجراءات التحليل.
- اختبارات جودة ومتانة أو مقارنة مستقلة تتناسب مع المجال.
- إعداد أوراق أو أدوات أو تقارير قابلة للتحكيم وفق سياسة المؤسسة.
- تدريس أو مساعدة تعليمية أو تدريب مهني في بعض البرامج.

لا توجد أعداد عالمية موحدة للمنشورات أو المؤتمرات أو ساعات التدريس.

## 13. المهارات البحثية والمهنية المتقدمة

- صياغة سؤال بحث أصيل في القيادة
- نقد الأدلة والنظريات في نظريات القيادة وتأثيرها

## 2. طبيعة الدكتوراه وهدفها

تهدف دكتوراه ريادة الأعمال إلى إعداد باحث قادر على تفسير وتطوير المعرفة المتعلقة بـ اكتشاف الفرص وتكوين المشروعات والتمويل والنمو والفشل، واختبار علاقتها بـ ريادة الأعمال الاجتماعية والمؤسسية. ويُتوقع من الباحث تحديد فجوة حقيقية، وصياغة سؤال قابل للفحص، وبناء تصميم يميز بين الوصف والتفسير والسببية أو الحجة المعيارية وفق طبيعة المجال.

تختلف عن الماجستير في أن الطالب يقود برنامجًا بحثيًا مستقلًا، ويطور نظرية أو منهجًا أو دليلًا أو إطارًا جديدًا، ويبرهن حدود الصلاحية والتعميم. لا تشمل هوية التخصص بيانات جامعة أو مشرف أو جهة مهنية أو نظام وطني بعينه.

## 3. أنواع الدكتوراه الشائعة

- دكتوراه بحثية تقليدية قائمة على أطروحة أصلية.
- دكتوراه مهنية أو تطبيقية تعالج مشكلة ممارسة عند توفرها.
- دكتوراه تعاونية مع جهة عامة أو خاصة مع استقلال أكاديمي واضح.
- دكتوراه بالنشر أو مسار مدمج عند توفر النظام المؤسسي.

اسم الدرجة لا ينشئ تخصصًا مستقلًا؛ فقد يطرح المجال ضمن PhD أو DBA أو SJD/JSD أو DPA بحسب النظام.

## 5. مراحل برنامج الدكتوراه

3. امتحان شامل أو تأهيلي عند وجوده.
4. مراجعة نقدية للأدبيات وتحديد الفجوة.
5. إعداد المقترح وخطة البيانات أو المصادر والأخلاقيات.
6. الانتقال إلى مرحلة مرشح الدكتوراه بعد موافقة اللجنة.
7. تنفيذ البحث باستخدام تحليل شبكات النظم البيئية وتجارب تصميمية وميدانية عند الملاءمة.
8. اختبارات التحقق والمتانة أو المقارنة القانونية والتاريخية.
9. كتابة الأطروحة ومناقشتها والدفاع عنها.
10. الإيداع واستكمال متطلبات النزاهة والبيانات والتخرج.

## 2. طبيعة الدكتوراه وهدفها

تهدف دكتوراه الابتكار وإدارة التقنية إلى إعداد باحث قادر على تفسير وتطوير المعرفة المتعلقة بـ محافظ التقنية والبحث والتطوير ونقل التقنية والقدرات، واختبار علاقتها بـ النظم البيئية والابتكار المفتوح. ويُتوقع من الباحث تحديد فجوة حقيقية، وصياغة سؤال قابل للفحص، وبناء تصميم يميز بين الوصف والتفسير والسببية أو الحجة المعيارية وفق طبيعة المجال.

تختلف عن الماجستير في أن الطالب يقود برنامجًا بحثيًا مستقلًا، ويطور نظرية أو منهجًا أو دليلًا أو إطارًا جديدًا، ويبرهن حدود الصلاحية والتعميم. لا تشمل هوية التخصص بيانات جامعة أو مشرف أو جهة مهنية أو نظام وطني بعينه.

## 3. أنواع الدكتوراه الشائعة

- دكتوراه بحثية تقليدية قائمة على أطروحة أصلية.
- دكتوراه مهنية أو تطبيقية تعالج مشكلة ممارسة عند توفرها.
- دكتوراه تعاونية مع جهة عامة أو خاصة مع استقلال أكاديمي واضح.
- دكتوراه بالنشر أو مسار مدمج عند توفر النظام المؤسسي.

اسم الدرجة لا ينشئ تخصصًا مستقلًا؛ فقد يطرح المجال ضمن PhD أو DBA أو SJD/JSD أو DPA بحسب النظام.

3. امتحان شامل أو تأهيلي عند وجوده.
4. مراجعة نقدية للأدبيات وتحديد الفجوة.
5. إعداد المقترح وخطة البيانات أو المصادر والأخلاقيات.
6. الانتقال إلى مرحلة مرشح الدكتوراه بعد موافقة اللجنة.
7. تنفيذ البحث باستخدام تحليل شبكات النظم البيئية وتجارب تصميمية وميدانية عند الملاءمة.
8. اختبارات التحقق والمتانة أو المقارنة القانونية والتاريخية.
9. كتابة الأطروحة ومناقشتها والدفاع عنها.
10. الإيداع واستكمال متطلبات النزاهة والبيانات والتخرج.

قد يكون تحريريًا أو شفهيًا أو دفاعًا عن مقترح أولي، وتختلف صيغته وتبعات النجاح أو الإخفاق بين الجامعات والأنظمة.

## 9. مقترح البحث ومرحلة الترشح

يحدد المقترح مشكلة أصلية في محافظ التقنية والبحث والتطوير أو نقل التقنية والقدرات، ويعرض سؤال البحث أو الفرضيات أو الأطروحة القانونية، ويبرر استخدام بيانات شركات وبراءات ومنتجات ودراسات طولية وحالات مقارنة. كما يحدد وحدة التحليل أو المؤسسات أو الأسواق أو النصوص أو الحالات والفترة الزمنية والنطاق الجغرافي أو القانوني.

يجب أن يتضمن خطة للبيانات والمصادر والجودة والأخلاقيات والمخاطر والموارد والجدول الزمني، ومعايير مسبقة للتحقق أو المقارنة، وخطة بديلة إذا تعذر الوصول إلى بيانات أو مؤسسة أو وثيقة أساسية.

## 10. الأطروحة والمساهمة الأصلية

قد تتمثل المساهمة الأصلية في إطارًا أو آلية أو نموذجًا يفسر نشوء الابتكار وانتشاره وإدارته في الابتكار وإدارة التقنية، بما يطور فهم محافظ التقنية والبحث والتطوير أو يقدم تفسيرًا أو أداة أو توصية قابلة للتقييم في نقل التقنية والقدرات.

يمكن أن تكون الأطروحة تقليدية أو قائمة على أوراق منشورة أو مشروعًا مهنيًا موثقًا، لكن يجب أن تكون وحدة المساهمة واضحة، وأن يفصل الباحث بين ما أثبته وما استنتجه وما اقترحه معياريًا أو تطبيقيًا.

## 2. طبيعة الدكتوراه وهدفها

تهدف دكتوراه إدارة الأعمال الرقمية إلى إعداد باحث قادر على تفسير وتطوير المعرفة المتعلقة بـ نماذج الأعمال الرقمية والمنصات والقدرات الرقمية والحوكمة، واختبار علاقتها بـ القيمة من البيانات والذكاء الاصطناعي. ويُتوقع من الباحث تحديد فجوة حقيقية، وصياغة سؤال قابل للفحص، وبناء تصميم يميز بين الوصف والتفسير والسببية أو الحجة المعيارية وفق طبيعة المجال.

تختلف عن الماجستير في أن الطالب يقود برنامجًا بحثيًا مستقلًا، ويطور نظرية أو منهجًا أو دليلًا أو إطارًا جديدًا، ويبرهن حدود الصلاحية والتعميم. لا تشمل هوية التخصص بيانات جامعة أو مشرف أو جهة مهنية أو نظام وطني بعينه.

## 3. أنواع الدكتوراه الشائعة

- دكتوراه بحثية تقليدية قائمة على أطروحة أصلية.
- دكتوراه مهنية أو تطبيقية تعالج مشكلة ممارسة عند توفرها.
- دكتوراه تعاونية مع جهة عامة أو خاصة مع استقلال أكاديمي واضح.
- دكتوراه بالنشر أو مسار مدمج عند توفر النظام المؤسسي.

اسم الدرجة لا ينشئ تخصصًا مستقلًا؛ فقد يطرح المجال ضمن PhD أو DBA أو SJD/JSD أو DPA بحسب النظام.

## 5. مراحل برنامج الدكتوراه

1. مقررات أو حلقات متقدمة وخطة تعلم فردية.
2. تدريب منهجي في تجارب منصات وسجلات رقمية واقتصاد قياسي سببي.
3. امتحان شامل أو تأهيلي عند وجوده.
4. مراجعة نقدية للأدبيات وتحديد الفجوة.
5. إعداد المقترح وخطة البيانات أو المصادر والأخلاقيات.
6. الانتقال إلى مرحلة مرشح الدكتوراه بعد موافقة اللجنة.
7. تنفيذ البحث باستخدام تحليل شبكات ونصوص وسلوك ودراسات تحول وحوكمة رقمية عند الملاءمة.
8. اختبارات التحقق والمتانة أو المقارنة القانونية والتاريخية.
9. كتابة الأطروحة ومناقشتها والدفاع عنها.
10. الإيداع واستكمال متطلبات النزاهة والبيانات والتخرج.

## 6. المعرفة والمقررات المتقدمة

### المعرفة النظرية المتقدمة

- المنصات والأسواق الرقمية وتأثيرات الشبكة.
- التحول الرقمي والقدرات التنظيمية.
- البيانات والذكاء الاصطناعي في القرار.
- الثقة والخصوصية والتجربة الرقمية.
- الأدبيات والاتجاهات المعاصرة في نماذج الأعمال الرقمية والمنصات والقدرات الرقمية والحوكمة.
- نقد الافتراضات والقياس والتفسير وحدود النقل بين الأنظمة والسياقات.

### مناهج البحث والتحليل

- تجارب منصات وسجلات رقمية.
- اقتصاد قياسي سببي.
- تحليل شبكات ونصوص وسلوك.
- دراسات تحول وحوكمة رقمية.
- مراجعات منهجية أو مقارنات معيارية وربط النتائج بأدلة مستقلة.

### الأخلاقيات والنزاهة العلمية

- الموافقات الأخلاقية قبل جمع بيانات الأفراد أو المؤسسات أو القضايا الحساسة.
- حماية الخصوصية والسرية التجارية أو القانونية أو الدبلوماسية.
- الإفصاح عن التمويل والمصالح المهنية والسياسية والمالية.
- توثيق المصادر والتحويلات والشفرة أو بروتوكول التحليل.
- عدم استخدام البحث للإضرار بالمشاركين أو التأثير غير المشروع في قرار مهني أو قضائي أو سياسي.

## 7. مجالات البحث والتخصصات الدقيقة

- نماذج الأعمال الرقمية والمنصات
- القدرات الرقمية والحوكمة
- القيمة من البيانات والذكاء الاصطناعي
- حوكمة المنصات والبيانات
- الأمن والثقة والخصوصية
- قياس القيمة والتحول

تُحفظ هذه المجالات كعلاقات أو تركيزات بحثية، ولا تتحول تلقائيًا إلى تخصصات مستقلة دون مراجعة Academic Taxonomy.

## 8. الامتحان التأهيلي أو الشامل عند وجوده

قد يختبر الامتحان الفهم المتقدم لـ نماذج الأعمال الرقمية والمنصات والقدرات الرقمية والحوكمة، والقدرة على نقد نظرية أو دراسة أو حكم أو سياسة أو مجموعة بيانات، وتصميم بحث يستخدم تجارب منصات وسجلات رقمية واقتصاد قياسي سببي مع تبرير الوحدة التحليلية والعينة أو المصادر والتحقق.

قد يكون تحريريًا أو شفهيًا أو دفاعًا عن مقترح أولي، وتختلف صيغته وتبعات النجاح أو الإخفاق بين الجامعات والأنظمة.

## 9. مقترح البحث ومرحلة الترشح

يحدد المقترح مشكلة أصلية في نماذج الأعمال الرقمية والمنصات أو القدرات الرقمية والحوكمة، ويعرض سؤال البحث أو الفرضيات أو الأطروحة القانونية، ويبرر استخدام تجارب منصات وسجلات رقمية واقتصاد قياسي سببي. كما يحدد وحدة التحليل أو المؤسسات أو الأسواق أو النصوص أو الحالات والفترة الزمنية والنطاق الجغرافي أو القانوني.

يجب أن يتضمن خطة للبيانات والمصادر والجودة والأخلاقيات والمخاطر والموارد والجدول الزمني، ومعايير مسبقة للتحقق أو المقارنة، وخطة بديلة إذا تعذر الوصول إلى بيانات أو مؤسسة أو وثيقة أساسية.

## 10. الأطروحة والمساهمة الأصلية

قد تتمثل المساهمة الأصلية في نموذجًا أو خوارزمية قرار أو إطار حوكمة أو دليلًا سببيًا عن الأعمال الرقمية في إدارة الأعمال الرقمية، بما يطور فهم نماذج الأعمال الرقمية والمنصات أو يقدم تفسيرًا أو أداة أو توصية قابلة للتقييم في القدرات الرقمية والحوكمة.

يمكن أن تكون الأطروحة تقليدية أو قائمة على أوراق منشورة أو مشروعًا مهنيًا موثقًا، لكن يجب أن تكون وحدة المساهمة واضحة، وأن يفصل الباحث بين ما أثبته وما استنتجه وما اقترحه معياريًا أو تطبيقيًا.

## 11. الإشراف والبيئة البحثية

- وصول قانوني إلى بيانات منصات ومعاملات ومستخدمين.
- بنية حوسبة وتحليل بيانات مع ضوابط خصوصية.
- شراكات مع مؤسسات رقمية دون تبعية بحثية.
- لجنة إشراف تجمع خبرة موضوعية ومنهجية مستقلة.
- خطة لإدارة الوصول والسرية والتخزين الآمن واستمرارية البيانات أو المصادر.

لا تحفظ أسماء المشرفين أو المؤسسات داخل هوية التخصص؛ فهي بيانات برامج جامعية في Phase 11.

## 12. متطلبات البحث والنشر والتدريس

- حلقات بحث وتحديثات دورية للجنة الإشراف.
- توثيق المنهج والبيانات أو النصوص أو الحالات وإجراءات التحليل.
- اختبارات جودة ومتانة أو مقارنة مستقلة تتناسب مع المجال.
- إعداد أوراق أو أدوات أو تقارير قابلة للتحكيم وفق سياسة المؤسسة.
- تدريس أو مساعدة تعليمية أو تدريب مهني في بعض البرامج.

لا توجد أعداد عالمية موحدة للمنشورات أو المؤتمرات أو ساعات التدريس.

## 13. المهارات البحثية والمهنية المتقدمة

- صياغة سؤال بحث أصيل في إدارة الأعمال الرقمية
- نقد الأدلة والنظريات في نماذج الأعمال الرقمية والمنصات
- تطبيق تجارب منصات وسجلات رقمية واقتصاد قياسي سببي بصورة مستقلة
- إدارة بيانات أو وثائق أو حالات معقدة وضبط جودتها
- تقييم التحيز وعدم اليقين وحدود التعميم أو القياس القانوني
- الكتابة والنشر والعرض والدفاع العلمي
- قيادة تعاون متعدد التخصصات وإدارة مشروع طويل الأجل

## 14. مجالات العمل بعد الدكتوراه

- الجامعات ومراكز الاقتصاد والأعمال الرقمية
- شركات المنصات والتجارة الإلكترونية والتقنية
- التحول الرقمي وتحليلات الأعمال والاستشارات
- الهيئات التنظيمية للبيانات والمنافسة والأسواق

تعتمد ملاءمة المسار على موضوع الأطروحة والمنهج والخبرة وأي اعتماد مهني مستقل.

## 16. ما بعد الدكتوراه والمسارات اللاحقة

- مسار أكاديمي في البحث والتدريس والإشراف.
- البحث والاستشارات في مؤسسة عامة أو خاصة أو دولية.
- قيادة برامج بحث أو سياسات أو تحول بعد اكتساب الخبرة.
- ريادة أعمال معرفية أو ممارسة مهنية عند استيفاء الترخيص.

## 2. طبيعة الدكتوراه وهدفها

تهدف دكتوراه التجارة الإلكترونية إلى إعداد باحث قادر على تفسير وتطوير المعرفة المتعلقة بـ تصميم الأسواق والمتاجر الرقمية والثقة والدفع والتحويل، واختبار علاقتها بـ اللوجستيات العابرة للقنوات. ويُتوقع من الباحث تحديد فجوة حقيقية، وصياغة سؤال قابل للفحص، وبناء تصميم يميز بين الوصف والتفسير والسببية أو الحجة المعيارية وفق طبيعة المجال.

تختلف عن الماجستير في أن الطالب يقود برنامجًا بحثيًا مستقلًا، ويطور نظرية أو منهجًا أو دليلًا أو إطارًا جديدًا، ويبرهن حدود الصلاحية والتعميم. لا تشمل هوية التخصص بيانات جامعة أو مشرف أو جهة مهنية أو نظام وطني بعينه.

## 3. أنواع الدكتوراه الشائعة

- دكتوراه بحثية تقليدية قائمة على أطروحة أصلية.

- نقد الافتراضات والقياس والتفسير وحدود النقل بين الأنظمة والسياقات.

### مناهج البحث والتحليل

- تجارب مخبرية وميدانية ورقمية.
- نماذج اختيار ومسوح.
- تحليل معاملات ونقرات ونصوص.
- مقابلات وإثنوغرافيا مستهلك.
- مراجعات منهجية أو مقارنات معيارية وربط النتائج بأدلة مستقلة.

### الأخلاقيات والنزاهة العلمية

- الموافقات الأخلاقية قبل جمع بيانات الأفراد أو المؤسسات أو القضايا الحساسة.
- حماية الخصوصية والسرية التجارية أو القانونية أو الدبلوماسية.
- الإفصاح عن التمويل والمصالح المهنية والسياسية والمالية.
- توثيق المصادر والتحويلات والشفرة أو بروتوكول التحليل.
- عدم استخدام البحث للإضرار بالمشاركين أو التأثير غير المشروع في قرار مهني أو قضائي أو سياسي.

## 7. مجالات البحث والتخصصات الدقيقة

- استراتيجية السوق والقيمة
- سلوك المستهلك
- القنوات والتسعير والاتصال
- الأخلاقيات وحماية المستهلك
- التقنية والذكاء الاصطناعي
- القياس والسببية طويلة الأجل

تُحفظ هذه المجالات كعلاقات أو تركيزات بحثية، ولا تتحول تلقائيًا إلى تخصصات مستقلة دون مراجعة Academic Taxonomy.

## 8. الامتحان التأهيلي أو الشامل عند وجوده

قد يختبر الامتحان الفهم المتقدم لـ استراتيجية السوق والقيمة وسلوك المستهلك، والقدرة على نقد نظرية أو دراسة أو حكم أو سياسة أو مجموعة بيانات، وتصميم بحث يستخدم تجارب مخبرية وميدانية ورقمية ونماذج اختيار ومسوح مع تبرير الوحدة التحليلية والعينة أو المصادر والتحقق.

قد يكون تحريريًا أو شفهيًا أو دفاعًا عن مقترح أولي، وتختلف صيغته وتبعات النجاح أو الإخفاق بين الجامعات والأنظمة.

## 9. مقترح البحث ومرحلة الترشح

يحدد المقترح مشكلة أصلية في استراتيجية السوق والقيمة أو سلوك المستهلك، ويعرض سؤال البحث أو الفرضيات أو الأطروحة القانونية، ويبرر استخدام تجارب مخبرية وميدانية ورقمية ونماذج اختيار ومسوح. كما يحدد وحدة التحليل أو المؤسسات أو الأسواق أو النصوص أو الحالات والفترة الزمنية والنطاق الجغرافي أو القانوني.

يجب أن يتضمن خطة للبيانات والمصادر والجودة والأخلاقيات والمخاطر والموارد والجدول الزمني، ومعايير مسبقة للتحقق أو المقارنة، وخطة بديلة إذا تعذر الوصول إلى بيانات أو مؤسسة أو وثيقة أساسية.

## 10. الأطروحة والمساهمة الأصلية

قد تتمثل المساهمة الأصلية في نظرية أو مقياسًا أو تجربة أو نموذجًا يفسر سلوك السوق والمستهلك في التسويق، بما يطور فهم استراتيجية السوق والقيمة أو يقدم تفسيرًا أو أداة أو توصية قابلة للتقييم في سلوك المستهلك.

يمكن أن تكون الأطروحة تقليدية أو قائمة على أوراق منشورة أو مشروعًا مهنيًا موثقًا، لكن يجب أن تكون وحدة المساهمة واضحة، وأن يفصل الباحث بين ما أثبته وما استنتجه وما اقترحه معياريًا أو تطبيقيًا.

## 11. الإشراف والبيئة البحثية

- مختبر سلوك أو منصات تجارب وتسويق.
- بيانات عملاء وأسواق مع إخفاء الهوية.
- إشراف يجمع النظرية السلوكية والتحليل الكمي أو النوعي.
- لجنة إشراف تجمع خبرة موضوعية ومنهجية مستقلة.
- خطة لإدارة الوصول والسرية والتخزين الآمن واستمرارية البيانات أو المصادر.

لا تحفظ أسماء المشرفين أو المؤسسات داخل هوية التخصص؛ فهي بيانات برامج جامعية في Phase 11.

## 12. متطلبات البحث والنشر والتدريس

- حلقات بحث وتحديثات دورية للجنة الإشراف.
- توثيق المنهج والبيانات أو النصوص أو الحالات وإجراءات التحليل.
- اختبارات جودة ومتانة أو مقارنة مستقلة تتناسب مع المجال.
- إعداد أوراق أو أدوات أو تقارير قابلة للتحكيم وفق سياسة المؤسسة.
- تدريس أو مساعدة تعليمية أو تدريب مهني في بعض البرامج.

لا توجد أعداد عالمية موحدة للمنشورات أو المؤتمرات أو ساعات التدريس.

## 13. المهارات البحثية والمهنية المتقدمة

- صياغة سؤال بحث أصيل في التسويق
- نقد الأدلة والنظريات في استراتيجية السوق والقيمة
- تطبيق تجارب مخبرية وميدانية ورقمية ونماذج اختيار ومسوح بصورة مستقلة
- إدارة بيانات أو وثائق أو حالات معقدة وضبط جودتها
- تقييم التحيز وعدم اليقين وحدود التعميم أو القياس القانوني
- الكتابة والنشر والعرض والدفاع العلمي
- قيادة تعاون متعدد التخصصات وإدارة مشروع طويل الأجل

## 14. مجالات العمل بعد الدكتوراه

- الجامعات وكليات الأعمال
- البحث التسويقي وتجربة العميل والعلامات
- التحليلات والإعلان والتجزئة والمبيعات
- الاستشارات وحماية المستهلك والسياسات السوقية

تعتمد ملاءمة المسار على موضوع الأطروحة والمنهج والخبرة وأي اعتماد مهني مستقل.

## 15. أهم الوظائف المرتبطة

| الوظيفة | مدى مناسبة الدكتوراه | الملاحظة |
|---|---|---|
| باحث متخصص في التسويق | مناسبة جدًا | تتحدد الهوية الدقيقة بموضوع الأطروحة والمساهمة. |
| باحث تسويق أو خبير سلوك مستهلك | مناسبة | يحتاج الدور إلى خبرة تطبيقية وتواصل مع الجهات المستفيدة. |
| عضو هيئة أكاديمية | مناسبة | التعيين تنافسي ويتطلب إنتاجًا بحثيًا مستقلًا. |
| ممارس أو خبير معتمد في نشاط منظم | غير كافية وحدها | قد يتطلب ترخيصًا أو اعتمادًا أو خبرة منفصلة. |

## 16. ما بعد الدكتوراه والمسارات اللاحقة

- زمالة ما بعد الدكتوراه في التسويق أو مجال قريب.
- مسار أكاديمي في البحث والتدريس والإشراف.
- البحث والاستشارات في مؤسسة عامة أو خاصة أو دولية.
- قيادة برامج بحث أو سياسات أو تحول بعد اكتساب الخبرة.
- ريادة أعمال معرفية أو ممارسة مهنية عند استيفاء الترخيص.

## 17. الدكتوراه المشابهة والفروق

| التسويق الرقمي | يتقاطع مع التسويق في بعض الأسئلة أو الأدوات، لكنه يختلف في مركز المساهمة الأصلية وحدود المجال. |
| إدارة الأعمال الرقمية | يتقاطع مع التسويق في بعض الأسئلة أو الأدوات، لكنه يختلف في مركز المساهمة الأصلية وحدود المجال. |
