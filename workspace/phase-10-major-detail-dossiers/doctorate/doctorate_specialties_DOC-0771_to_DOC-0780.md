## 2. طبيعة الدكتوراه وهدفها

تهدف دكتوراه التاريخ القديم إلى إعداد باحث قادر على إنتاج معرفة مستقلة في الدول والمجتمعات القديمة، وربطها بالنقوش والبرديات والعملات والاقتصاد والتجارة القديمة. ويُتوقع منه تحديد فجوة حقيقية، وصياغة سؤال قابل للفحص، وبناء حجة أو تصميم بحث يميز بين الوصف والتفسير والسببية أو الحكم المعياري بحسب طبيعة المجال.

تختلف عن مستوى الماجستير في أن الطالب يقود برنامجًا بحثيًا طويل الأجل، ويطور نظرية أو منهجًا أو دليلًا أو أداة جديدة، ويختبر حدود الصلاحية والتعميم. لا تشمل هوية التخصص بيانات جامعة أو مشرف أو برنامج مؤسسي بعينه.

## 3. أنواع الدكتوراه الشائعة

- دكتوراه بحثية تقليدية قائمة على أطروحة أصلية.
- دكتوراه بينية عند اتصال السؤال بتخصص آخر ومنهج واضح للدمج.
- دكتوراه تعاونية مع مؤسسة عامة أو ثقافية أو مهنية مع استقلال أكاديمي واضح.
- دكتوراه بالنشر أو مسار مدمج عند توفر النظام المؤسسي.

اسم الدرجة لا ينشئ تخصصًا مستقلًا؛ فقد يطرح التاريخ القديم ضمن PhD / DPhil وفق النظام والهدف الأكاديمي أو المهني.

### الخبرة أو الترخيص المطلوب للدكتوراه المهنية

- قد تتطلب الصيغة المهنية خبرة عملية وملف ممارسة أو مسؤولية مناسبة.
- الوصول إلى أفراد أو مؤسسات أو قضايا أو بيانات حساسة يحتاج موافقات وصلاحيات منفصلة.
- أي ممارسة مهنية منظمة أو وصول إلى بيانات حساسة يخضع لاعتماد أو تصريح مستقل.

## 5. مراحل برنامج الدكتوراه

1. مقررات أو حلقات متقدمة وخطة تعلم فردية.
2. تدريب منهجي في البحث الأرشيفي ونقد المصادر الأولية والمقارنة التاريخية والتحليل السياقي.
3. امتحان شامل أو تأهيلي عند وجوده.
4. مراجعة نقدية للأدبيات وتحديد الفجوة.
5. إعداد المقترح وخطة البيانات أو المصادر والأخلاقيات.
6. الانتقال إلى مرحلة مرشح الدكتوراه بعد موافقة اللجنة.
7. تنفيذ البحث باستخدام التاريخ الشفهي مع بروتوكولات أخلاقية والتحليل الكمي أو المكاني للسجلات عند الملاءمة عند الملاءمة.
8. اختبارات تحقق أو متانة أو مقارنة وتفسير بدائل النتائج.
9. كتابة الأطروحة ومناقشتها والدفاع عنها.
10. الإيداع واستكمال متطلبات النزاهة والبيانات والتخرج.

- الذاكرة والهوية والسرديات العامة.
- تاريخ المؤسسات والمجتمعات والأفكار.

### مناهج البحث والتحليل

- البحث الأرشيفي ونقد المصادر الأولية.
- المقارنة التاريخية والتحليل السياقي.
- التاريخ الشفهي مع بروتوكولات أخلاقية.
- التحليل الكمي أو المكاني للسجلات عند الملاءمة.
- الإنسانيات الرقمية وبناء قواعد المصادر.

### الأخلاقيات والنزاهة العلمية

- الحصول على الموافقات الأخلاقية قبل جمع بيانات الأفراد أو المؤسسات أو المجتمعات.
- حماية الخصوصية والسرية والملكية الفكرية والمواد الحساسة.
- الإفصاح عن التمويل وتضارب المصالح المهنية أو السياسية أو المالية.
- توثيق المصادر والتحويلات والأدوات والشفرة أو بروتوكولات التحليل.
- عدم تضخيم النتائج أو إخفاء عدم اليقين أو استخدام البحث للإضرار بالمشاركين.

## 7. مجالات البحث والتخصصات الدقيقة

- الدول والمجتمعات القديمة
- النقوش والبرديات والعملات
- الاقتصاد والتجارة القديمة
- الدين والسلطة في العصور القديمة
- التاريخ المتوسطي والشرق الأدنى المقارن
- المقارنة بين السياقات والتحولات المعاصرة

تُحفظ هذه المجالات كعلاقات أو تركيزات بحثية، ولا تتحول تلقائيًا إلى تخصصات مستقلة دون مراجعة Academic Taxonomy.

## 8. الامتحان التأهيلي أو الشامل عند وجوده

قد يختبر الامتحان المعرفة المتقدمة في الدول والمجتمعات القديمة والنقوش والبرديات والعملات، والقدرة على تحليل مادة أو بيانات أو حالة مرتبطة بالتاريخ القديم والدفاع عن منهج يستخدم البحث الأرشيفي ونقد المصادر الأولية والمقارنة التاريخية والتحليل السياقي. كما قد يتطلب نقد أدبيات متعارضة، وتبرير وحدة التحليل، وبيان كيفية التحقق من الادعاءات والبدائل التفسيرية.

قد يكون تحريريًا أو شفهيًا أو دفاعًا عن مقترح أولي، وتختلف صيغته وتبعات النجاح أو الإخفاق بين الجامعات والأنظمة.

## 9. مقترح البحث ومرحلة الترشح

يحدد المقترح مشكلة أصلية في الدول والمجتمعات القديمة أو النقوش والبرديات والعملات، ويعرض سؤال البحث أو الفرضيات أو الأطروحة، ويبرر استخدام البحث الأرشيفي ونقد المصادر الأولية والمقارنة التاريخية والتحليل السياقي. كما يحدد الحدث أو الفترة أو المؤسسة أو الجماعة أو مجموعة المصادر، والسياق أو الفترة أو المجتمع أو المؤسسة، ويشرح معايير الاختيار والنطاق وحدود الاستدلال.

يجب أن يتضمن خطة للبيانات أو المصادر، والجودة، والأخلاقيات، والمخاطر، والموارد، والجدول الزمني، ومعايير مسبقة للتحقق أو المقارنة، وخطة بديلة إذا تعذر الوصول إلى مادة أو مؤسسة أو عينة أساسية.

## 10. الأطروحة والمساهمة الأصلية

قد تتمثل المساهمة الأصلية في تفسير تاريخي جديد أو اكتشاف مصادر أو قاعدة بيانات أو إعادة بناء موثقة يضيف معرفة قابلة للتحقق في التاريخ القديم، بما يطور فهم الدول والمجتمعات القديمة أو يقدم تفسيرًا أو أداة أو ممارسة قابلة للتقييم في الاقتصاد والتجارة القديمة.

يمكن أن تكون الأطروحة تقليدية أو قائمة على أوراق منشورة أو مشروعًا مهنيًا موثقًا، لكن يجب أن تكون وحدة المساهمة واضحة، وأن يفصل الباحث بين ما أثبته وما استنتجه وما اقترحه معياريًا أو تطبيقيًا.

## 11. الإشراف والبيئة البحثية

- وصول قانوني ومستقر إلى الأرشيفات والمصادر.
- إشراف في الفترة والجغرافيا والمنهج.
- دعم لغوي أو باليوغرافي عند الحاجة.
- خطة لحفظ النسخ والبيانات الوصفية وحقوق الاستخدام.
- لجنة إشراف تجمع خبرة موضوعية ومنهجية مستقلة.
- خطة لإدارة الوصول والتخزين الآمن واستمرارية البيانات أو المصادر.

لا تحفظ أسماء المشرفين أو المؤسسات داخل هوية التخصص؛ فهي بيانات برامج جامعية في Phase 11.

## 12. متطلبات البحث والنشر والتدريس

- حلقات بحث وتحديثات دورية للجنة الإشراف.
- توثيق المنهج والبيانات أو النصوص أو الحالات وإجراءات التحليل.
- اختبارات جودة ومتانة أو مقارنة مستقلة تتناسب مع المجال.
- إعداد أوراق أو أدوات أو تقارير قابلة للتحكيم وفق سياسة المؤسسة.
- تدريس أو مساعدة تعليمية أو تدريب مهني في بعض البرامج.

لا توجد أعداد عالمية موحدة للمنشورات أو المؤتمرات أو ساعات التدريس.

## 13. المهارات البحثية والمهنية المتقدمة

- صياغة سؤال بحث أصيل في التاريخ القديم.
- نقد الأدلة والنظريات في الدول والمجتمعات القديمة.
- تطبيق البحث الأرشيفي ونقد المصادر الأولية والمقارنة التاريخية والتحليل السياقي بصورة مستقلة.
- إدارة بيانات أو نصوص أو وثائق أو حالات معقدة وضبط جودتها.
- تقييم التحيز وعدم اليقين وحدود التعميم أو النقل بين السياقات.
- الكتابة والنشر والعرض والدفاع العلمي.
- قيادة تعاون متعدد التخصصات وإدارة مشروع طويل الأجل.

## 14. مجالات العمل بعد الدكتوراه

- الجامعات ومراكز البحوث التاريخية
- الأرشيفات والمكتبات الوطنية

## 16. ما بعد الدكتوراه والمسارات اللاحقة

- زمالة ما بعد الدكتوراه في التاريخ القديم أو مجال قريب.
- مسار أكاديمي في البحث والتدريس والإشراف.
- البحث والاستشارات في مؤسسة عامة أو ثقافية أو اجتماعية أو خاصة أو دولية.
- قيادة برامج بحث أو سياسات أو تطوير بعد اكتساب الخبرة.
- ممارسة مهنية متقدمة عند استيفاء الترخيص أو الاعتماد المستقل.

## 18. التنبيه الأكاديمي والمهني

> **الاستنتاج التاريخي يعتمد على نوعية المصادر وحدود بقائها وتمثيلها، ولا يجوز تحويل الغياب الأرشيفي إلى دليل قاطع. يجب تمييز المصدر الأولي عن التأويل، وتوثيق التحيزات والفراغات. جودة الإشراف والبيئة والبيانات أو المصادر أهم من اسم الدرجة وحده، والدكتوراه لا تضمن وظيفة أكاديمية.**

## 2. طبيعة الدكتوراه وهدفها

تهدف دكتوراه التاريخ الحديث والمعاصر إلى إعداد باحث قادر على إنتاج معرفة مستقلة في نشوء الدول والمؤسسات الحديثة، وربطها بالاستعمار والتحرر وما بعد الاستعمار والحروب والحركات الاجتماعية. ويُتوقع منه تحديد فجوة حقيقية، وصياغة سؤال قابل للفحص، وبناء حجة أو تصميم بحث يميز بين الوصف والتفسير والسببية أو الحكم المعياري بحسب طبيعة المجال.

تختلف عن مستوى الماجستير في أن الطالب يقود برنامجًا بحثيًا طويل الأجل، ويطور نظرية أو منهجًا أو دليلًا أو أداة جديدة، ويختبر حدود الصلاحية والتعميم. لا تشمل هوية التخصص بيانات جامعة أو مشرف أو برنامج مؤسسي بعينه.

## 3. أنواع الدكتوراه الشائعة

- دكتوراه بحثية تقليدية قائمة على أطروحة أصلية.
- دكتوراه بينية عند اتصال السؤال بتخصص آخر ومنهج واضح للدمج.
- دكتوراه تعاونية مع مؤسسة عامة أو ثقافية أو مهنية مع استقلال أكاديمي واضح.
- دكتوراه بالنشر أو مسار مدمج عند توفر النظام المؤسسي.

اسم الدرجة لا ينشئ تخصصًا مستقلًا؛ فقد يطرح التاريخ الحديث والمعاصر ضمن PhD / DPhil وفق النظام والهدف الأكاديمي أو المهني.

## 8. الامتحان التأهيلي أو الشامل عند وجوده

قد يختبر الامتحان المعرفة المتقدمة في نشوء الدول والمؤسسات الحديثة والاستعمار والتحرر وما بعد الاستعمار، والقدرة على تحليل مادة أو بيانات أو حالة مرتبطة بالتاريخ الحديث والمعاصر والدفاع عن منهج يستخدم البحث الأرشيفي ونقد المصادر الأولية والمقارنة التاريخية والتحليل السياقي. كما قد يتطلب نقد أدبيات متعارضة، وتبرير وحدة التحليل، وبيان كيفية التحقق من الادعاءات والبدائل التفسيرية.

قد يكون تحريريًا أو شفهيًا أو دفاعًا عن مقترح أولي، وتختلف صيغته وتبعات النجاح أو الإخفاق بين الجامعات والأنظمة.

## 9. مقترح البحث ومرحلة الترشح

يحدد المقترح مشكلة أصلية في نشوء الدول والمؤسسات الحديثة أو الاستعمار والتحرر وما بعد الاستعمار، ويعرض سؤال البحث أو الفرضيات أو الأطروحة، ويبرر استخدام البحث الأرشيفي ونقد المصادر الأولية والمقارنة التاريخية والتحليل السياقي. كما يحدد الحدث أو الفترة أو المؤسسة أو الجماعة أو مجموعة المصادر، والسياق أو الفترة أو المجتمع أو المؤسسة، ويشرح معايير الاختيار والنطاق وحدود الاستدلال.

يجب أن يتضمن خطة للبيانات أو المصادر، والجودة، والأخلاقيات، والمخاطر، والموارد، والجدول الزمني، ومعايير مسبقة للتحقق أو المقارنة، وخطة بديلة إذا تعذر الوصول إلى مادة أو مؤسسة أو عينة أساسية.

## 10. الأطروحة والمساهمة الأصلية

قد تتمثل المساهمة الأصلية في تفسير تاريخي جديد أو اكتشاف مصادر أو قاعدة بيانات أو إعادة بناء موثقة يضيف معرفة قابلة للتحقق في التاريخ الحديث والمعاصر، بما يطور فهم نشوء الدول والمؤسسات الحديثة أو يقدم تفسيرًا أو أداة أو ممارسة قابلة للتقييم في الحروب والحركات الاجتماعية.

يمكن أن تكون الأطروحة تقليدية أو قائمة على أوراق منشورة أو مشروعًا مهنيًا موثقًا، لكن يجب أن تكون وحدة المساهمة واضحة، وأن يفصل الباحث بين ما أثبته وما استنتجه وما اقترحه معياريًا أو تطبيقيًا.

- لجنة إشراف تجمع خبرة موضوعية ومنهجية مستقلة.
- خطة لإدارة الوصول والتخزين الآمن واستمرارية البيانات أو المصادر.

لا تحفظ أسماء المشرفين أو المؤسسات داخل هوية التخصص؛ فهي بيانات برامج جامعية في Phase 11.

## 2. طبيعة الدكتوراه وهدفها

تهدف دكتوراه الآثار إلى إعداد باحث قادر على إنتاج معرفة مستقلة في النظريات والمفاهيم الأساسية في الآثار، وربطها بـمناهج البحث المتقدمة في الآثار والتطبيقات والسياسات المرتبطة بـ الآثار. ويُتوقع منه تحديد فجوة حقيقية، وصياغة سؤال قابل للفحص، وبناء حجة أو تصميم بحث يميز بين الوصف والتفسير والسببية أو الحكم المعياري بحسب طبيعة المجال.

تختلف عن مستوى الماجستير في أن الطالب يقود برنامجًا بحثيًا طويل الأجل، ويطور نظرية أو منهجًا أو دليلًا أو أداة جديدة، ويختبر حدود الصلاحية والتعميم. لا تشمل هوية التخصص بيانات جامعة أو مشرف أو برنامج مؤسسي بعينه.

- دكتوراه تعاونية مع مؤسسة عامة أو ثقافية أو مهنية مع استقلال أكاديمي واضح.
- دكتوراه بالنشر أو مسار مدمج عند توفر النظام المؤسسي.

3. امتحان شامل أو تأهيلي عند وجوده.
4. مراجعة نقدية للأدبيات وتحديد الفجوة.
5. إعداد المقترح وخطة البيانات أو المصادر والأخلاقيات.
6. الانتقال إلى مرحلة مرشح الدكتوراه بعد موافقة اللجنة.
7. تنفيذ البحث باستخدام الاستشعار عن بعد ونظم المعلومات الجغرافية والتحليل الأثري الحيوي أو البيئي عند الملاءمة عند الملاءمة.
8. اختبارات تحقق أو متانة أو مقارنة وتفسير بدائل النتائج.
9. كتابة الأطروحة ومناقشتها والدفاع عنها.
10. الإيداع واستكمال متطلبات النزاهة والبيانات والتخرج.

## 6. المعرفة والمقررات المتقدمة

### المعرفة النظرية المتقدمة

- النظرية الأثرية وتفسير الثقافة المادية.
- التسلسل الزمني والسياق الطبقي.
- المناظر الطبيعية والاستيطان والحركة.
- الاقتصاد القديم والتقنية والتبادل.
- أخلاقيات التراث والملكية والإعادة.

### مناهج البحث والتحليل

- المسح والتنقيب والتسجيل الطبقي عند التصريح.
- تحليل اللقى والمواد والتأريخ العلمي.
- الاستشعار عن بعد ونظم المعلومات الجغرافية.
- التحليل الأثري الحيوي أو البيئي عند الملاءمة.
- التوثيق الرقمي والنمذجة ثلاثية الأبعاد.

### الأخلاقيات والنزاهة العلمية

- الحصول على الموافقات الأخلاقية قبل جمع بيانات الأفراد أو المؤسسات أو المجتمعات.
- حماية الخصوصية والسرية والملكية الفكرية والمواد الحساسة.
- الإفصاح عن التمويل وتضارب المصالح المهنية أو السياسية أو المالية.
- توثيق المصادر والتحويلات والأدوات والشفرة أو بروتوكولات التحليل.
- عدم تضخيم النتائج أو إخفاء عدم اليقين أو استخدام البحث للإضرار بالمشاركين.

## 7. مجالات البحث والتخصصات الدقيقة

- النظريات والمفاهيم الأساسية في الآثار
- مناهج البحث المتقدمة في الآثار
- التطبيقات والسياسات المرتبطة بـ الآثار
- المقارنة بين المؤسسات أو المجتمعات أو الفترات
- البيانات والتقنيات والتحولات المعاصرة
- الأخلاقيات والإنصاف والآثار غير المقصودة

تُحفظ هذه المجالات كعلاقات أو تركيزات بحثية، ولا تتحول تلقائيًا إلى تخصصات مستقلة دون مراجعة Academic Taxonomy.

## 8. الامتحان التأهيلي أو الشامل عند وجوده

قد يختبر الامتحان المعرفة المتقدمة في النظريات والمفاهيم الأساسية في الآثار ومناهج البحث المتقدمة في الآثار، والقدرة على تحليل مادة أو بيانات أو حالة مرتبطة بالآثار والدفاع عن منهج يستخدم المسح والتنقيب والتسجيل الطبقي عند التصريح وتحليل اللقى والمواد والتأريخ العلمي. كما قد يتطلب نقد أدبيات متعارضة، وتبرير وحدة التحليل، وبيان كيفية التحقق من الادعاءات والبدائل التفسيرية.

قد يكون تحريريًا أو شفهيًا أو دفاعًا عن مقترح أولي، وتختلف صيغته وتبعات النجاح أو الإخفاق بين الجامعات والأنظمة.

## 9. مقترح البحث ومرحلة الترشح

يحدد المقترح مشكلة أصلية في النظريات والمفاهيم الأساسية في الآثار أو مناهج البحث المتقدمة في الآثار، ويعرض سؤال البحث أو الفرضيات أو الأطروحة، ويبرر استخدام المسح والتنقيب والتسجيل الطبقي عند التصريح وتحليل اللقى والمواد والتأريخ العلمي. كما يحدد الموقع أو الطبقة أو اللقية أو المادة أو المنظر الأثري، والسياق أو الفترة أو المجتمع أو المؤسسة، ويشرح معايير الاختيار والنطاق وحدود الاستدلال.

يجب أن يتضمن خطة للبيانات أو المصادر، والجودة، والأخلاقيات، والمخاطر، والموارد، والجدول الزمني، ومعايير مسبقة للتحقق أو المقارنة، وخطة بديلة إذا تعذر الوصول إلى مادة أو مؤسسة أو عينة أساسية.

## 10. الأطروحة والمساهمة الأصلية

قد تتمثل المساهمة الأصلية في اكتشاف أو تسلسل أو تفسير مادي أو منهج توثيق وتحليل جديد يضيف معرفة قابلة للتحقق في الآثار، بما يطور فهم النظريات والمفاهيم الأساسية في الآثار أو يقدم تفسيرًا أو أداة أو ممارسة قابلة للتقييم في التطبيقات والسياسات المرتبطة بـ الآثار.

يمكن أن تكون الأطروحة تقليدية أو قائمة على أوراق منشورة أو مشروعًا مهنيًا موثقًا، لكن يجب أن تكون وحدة المساهمة واضحة، وأن يفصل الباحث بين ما أثبته وما استنتجه وما اقترحه معياريًا أو تطبيقيًا.

## 11. الإشراف والبيئة البحثية

- تصاريح ميدانية وموافقات الجهة المالكة.
- مختبرات ووسائل توثيق وحفظ مناسبة.
- إشراف يجمع الفترة الأثرية والمنهج العلمي.
- خطة لإدارة اللقى والبيانات والإعادة أو الإيداع.
- لجنة إشراف تجمع خبرة موضوعية ومنهجية مستقلة.
- خطة لإدارة الوصول والتخزين الآمن واستمرارية البيانات أو المصادر.

لا تحفظ أسماء المشرفين أو المؤسسات داخل هوية التخصص؛ فهي بيانات برامج جامعية في Phase 11.

## 12. متطلبات البحث والنشر والتدريس

- حلقات بحث وتحديثات دورية للجنة الإشراف.
- توثيق المنهج والبيانات أو النصوص أو الحالات وإجراءات التحليل.
- اختبارات جودة ومتانة أو مقارنة مستقلة تتناسب مع المجال.
- إعداد أوراق أو أدوات أو تقارير قابلة للتحكيم وفق سياسة المؤسسة.
- تدريس أو مساعدة تعليمية أو تدريب مهني في بعض البرامج.

لا توجد أعداد عالمية موحدة للمنشورات أو المؤتمرات أو ساعات التدريس.

## 13. المهارات البحثية والمهنية المتقدمة

- صياغة سؤال بحث أصيل في الآثار.
- نقد الأدلة والنظريات في النظريات والمفاهيم الأساسية في الآثار.

## 2. طبيعة الدكتوراه وهدفها

تهدف دكتوراه الآثار الكلاسيكية إلى إعداد باحث قادر على إنتاج معرفة مستقلة في آثار اليونان وروما وعالم المتوسط، وربطها بالعمارة والفن والمدينة الكلاسيكية والفخار والعملات والنقوش. ويُتوقع منه تحديد فجوة حقيقية، وصياغة سؤال قابل للفحص، وبناء حجة أو تصميم بحث يميز بين الوصف والتفسير والسببية أو الحكم المعياري بحسب طبيعة المجال.

تختلف عن مستوى الماجستير في أن الطالب يقود برنامجًا بحثيًا طويل الأجل، ويطور نظرية أو منهجًا أو دليلًا أو أداة جديدة، ويختبر حدود الصلاحية والتعميم. لا تشمل هوية التخصص بيانات جامعة أو مشرف أو برنامج مؤسسي بعينه.

## 3. أنواع الدكتوراه الشائعة

- دكتوراه بحثية تقليدية قائمة على أطروحة أصلية.
- دكتوراه بينية عند اتصال السؤال بتخصص آخر ومنهج واضح للدمج.
- دكتوراه تعاونية مع مؤسسة عامة أو ثقافية أو مهنية مع استقلال أكاديمي واضح.
- دكتوراه بالنشر أو مسار مدمج عند توفر النظام المؤسسي.

اسم الدرجة لا ينشئ تخصصًا مستقلًا؛ فقد يطرح الآثار الكلاسيكية ضمن PhD / DPhil وفق النظام والهدف الأكاديمي أو المهني.

- عدم تضخيم النتائج أو إخفاء عدم اليقين أو استخدام البحث للإضرار بالمشاركين.

## 7. مجالات البحث والتخصصات الدقيقة

## 8. الامتحان التأهيلي أو الشامل عند وجوده

قد يختبر الامتحان المعرفة المتقدمة في آثار اليونان وروما وعالم المتوسط والعمارة والفن والمدينة الكلاسيكية، والقدرة على تحليل مادة أو بيانات أو حالة مرتبطة بالآثار الكلاسيكية والدفاع عن منهج يستخدم المسح والتنقيب والتسجيل الطبقي عند التصريح وتحليل اللقى والمواد والتأريخ العلمي. كما قد يتطلب نقد أدبيات متعارضة، وتبرير وحدة التحليل، وبيان كيفية التحقق من الادعاءات والبدائل التفسيرية.

قد يكون تحريريًا أو شفهيًا أو دفاعًا عن مقترح أولي، وتختلف صيغته وتبعات النجاح أو الإخفاق بين الجامعات والأنظمة.

## 9. مقترح البحث ومرحلة الترشح

يحدد المقترح مشكلة أصلية في آثار اليونان وروما وعالم المتوسط أو العمارة والفن والمدينة الكلاسيكية، ويعرض سؤال البحث أو الفرضيات أو الأطروحة، ويبرر استخدام المسح والتنقيب والتسجيل الطبقي عند التصريح وتحليل اللقى والمواد والتأريخ العلمي. كما يحدد الموقع أو الطبقة أو اللقية أو المادة أو المنظر الأثري، والسياق أو الفترة أو المجتمع أو المؤسسة، ويشرح معايير الاختيار والنطاق وحدود الاستدلال.

يجب أن يتضمن خطة للبيانات أو المصادر، والجودة، والأخلاقيات، والمخاطر، والموارد، والجدول الزمني، ومعايير مسبقة للتحقق أو المقارنة، وخطة بديلة إذا تعذر الوصول إلى مادة أو مؤسسة أو عينة أساسية.

## 10. الأطروحة والمساهمة الأصلية

يمكن أن تكون الأطروحة تقليدية أو قائمة على أوراق منشورة أو مشروعًا مهنيًا موثقًا، لكن يجب أن تكون وحدة المساهمة واضحة، وأن يفصل الباحث بين ما أثبته وما استنتجه وما اقترحه معياريًا أو تطبيقيًا.

## 2. طبيعة الدكتوراه وهدفها

تهدف دكتوراه الآثار الإسلامية إلى إعداد باحث قادر على إنتاج معرفة مستقلة في المواقع والمدن الإسلامية، وربطها بالعمارة والمواد والحرف والتجارة وشبكات التبادل. ويُتوقع منه تحديد فجوة حقيقية، وصياغة سؤال قابل للفحص، وبناء حجة أو تصميم بحث يميز بين الوصف والتفسير والسببية أو الحكم المعياري بحسب طبيعة المجال.

تختلف عن مستوى الماجستير في أن الطالب يقود برنامجًا بحثيًا طويل الأجل، ويطور نظرية أو منهجًا أو دليلًا أو أداة جديدة، ويختبر حدود الصلاحية والتعميم. لا تشمل هوية التخصص بيانات جامعة أو مشرف أو برنامج مؤسسي بعينه.

## 3. أنواع الدكتوراه الشائعة

- دكتوراه بحثية تقليدية قائمة على أطروحة أصلية.
- دكتوراه بينية عند اتصال السؤال بتخصص آخر ومنهج واضح للدمج.
- دكتوراه تعاونية مع مؤسسة عامة أو ثقافية أو مهنية مع استقلال أكاديمي واضح.
- دكتوراه بالنشر أو مسار مدمج عند توفر النظام المؤسسي.

اسم الدرجة لا ينشئ تخصصًا مستقلًا؛ فقد يطرح الآثار الإسلامية ضمن PhD / DPhil وفق النظام والهدف الأكاديمي أو المهني.

يجب أن يتضمن خطة للبيانات أو المصادر، والجودة، والأخلاقيات، والمخاطر، والموارد، والجدول الزمني، ومعايير مسبقة للتحقق أو المقارنة، وخطة بديلة إذا تعذر الوصول إلى مادة أو مؤسسة أو عينة أساسية.

## 10. الأطروحة والمساهمة الأصلية

قد تتمثل المساهمة الأصلية في اكتشاف أو تسلسل أو تفسير مادي أو منهج توثيق وتحليل جديد يضيف معرفة قابلة للتحقق في الآثار الإسلامية، بما يطور فهم المواقع والمدن الإسلامية أو يقدم تفسيرًا أو أداة أو ممارسة قابلة للتقييم في التجارة وشبكات التبادل.

يمكن أن تكون الأطروحة تقليدية أو قائمة على أوراق منشورة أو مشروعًا مهنيًا موثقًا، لكن يجب أن تكون وحدة المساهمة واضحة، وأن يفصل الباحث بين ما أثبته وما استنتجه وما اقترحه معياريًا أو تطبيقيًا.

## 11. الإشراف والبيئة البحثية

- خطة لإدارة اللقى والبيانات والإعادة أو الإيداع.
- لجنة إشراف تجمع خبرة موضوعية ومنهجية مستقلة.
- خطة لإدارة الوصول والتخزين الآمن واستمرارية البيانات أو المصادر.

لا تحفظ أسماء المشرفين أو المؤسسات داخل هوية التخصص؛ فهي بيانات برامج جامعية في Phase 11.

## 12. متطلبات البحث والنشر والتدريس

لا توجد أعداد عالمية موحدة للمنشورات أو المؤتمرات أو ساعات التدريس.

## 2. طبيعة الدكتوراه وهدفها

تهدف دكتوراه علم المصريات إلى إعداد باحث قادر على إنتاج معرفة مستقلة في اللغة والكتابة المصرية القديمة، وربطها بالتاريخ والدين والمجتمع المصري القديم والآثار والعمارة الجنائزية والمدنية. ويُتوقع منه تحديد فجوة حقيقية، وصياغة سؤال قابل للفحص، وبناء حجة أو تصميم بحث يميز بين الوصف والتفسير والسببية أو الحكم المعياري بحسب طبيعة المجال.

تختلف عن مستوى الماجستير في أن الطالب يقود برنامجًا بحثيًا طويل الأجل، ويطور نظرية أو منهجًا أو دليلًا أو أداة جديدة، ويختبر حدود الصلاحية والتعميم. لا تشمل هوية التخصص بيانات جامعة أو مشرف أو برنامج مؤسسي بعينه.

## 3. أنواع الدكتوراه الشائعة

- دكتوراه بحثية تقليدية قائمة على أطروحة أصلية.
- دكتوراه بينية عند اتصال السؤال بتخصص آخر ومنهج واضح للدمج.
- دكتوراه تعاونية مع مؤسسة عامة أو ثقافية أو مهنية مع استقلال أكاديمي واضح.
- دكتوراه بالنشر أو مسار مدمج عند توفر النظام المؤسسي.

اسم الدرجة لا ينشئ تخصصًا مستقلًا؛ فقد يطرح علم المصريات ضمن PhD / DPhil وفق النظام والهدف الأكاديمي أو المهني.

- خطة لإدارة الوصول والتخزين الآمن واستمرارية البيانات أو المصادر.

## 12. متطلبات البحث والنشر والتدريس

- حلقات بحث وتحديثات دورية للجنة الإشراف.
- توثيق المنهج والبيانات أو النصوص أو الحالات وإجراءات التحليل.
- اختبارات جودة ومتانة أو مقارنة مستقلة تتناسب مع المجال.
- إعداد أوراق أو أدوات أو تقارير قابلة للتحكيم وفق سياسة المؤسسة.
- تدريس أو مساعدة تعليمية أو تدريب مهني في بعض البرامج.

لا توجد أعداد عالمية موحدة للمنشورات أو المؤتمرات أو ساعات التدريس.

## 13. المهارات البحثية والمهنية المتقدمة

- صياغة سؤال بحث أصيل في علم المصريات.
- نقد الأدلة والنظريات في اللغة والكتابة المصرية القديمة.
- تطبيق المسح والتنقيب والتسجيل الطبقي عند التصريح وتحليل اللقى والمواد والتأريخ العلمي بصورة مستقلة.
- إدارة بيانات أو نصوص أو وثائق أو حالات معقدة وضبط جودتها.
- تقييم التحيز وعدم اليقين وحدود التعميم أو النقل بين السياقات.
- الكتابة والنشر والعرض والدفاع العلمي.
- قيادة تعاون متعدد التخصصات وإدارة مشروع طويل الأجل.

## 14. مجالات العمل بعد الدكتوراه

- الجامعات ومراكز الآثار
- هيئات الآثار والتراث
- المتاحف والمختبرات التحليلية
- مشروعات الحفظ وإدارة المواقع
- شركات الاستشارات الأثرية المرخصة

تعتمد ملاءمة المسار على موضوع الأطروحة والمنهج والخبرة وأي اعتماد مهني مستقل.

## 2. طبيعة الدكتوراه وهدفها

تهدف دكتوراه إدارة التراث الثقافي إلى إعداد باحث قادر على إنتاج معرفة مستقلة في حوكمة المواقع والمجموعات التراثية، وربطها بالتخطيط والحفظ وإدارة المخاطر والمشاركة المجتمعية وحقوق أصحاب التراث. ويُتوقع منه تحديد فجوة حقيقية، وصياغة سؤال قابل للفحص، وبناء حجة أو تصميم بحث يميز بين الوصف والتفسير والسببية أو الحكم المعياري بحسب طبيعة المجال.

تختلف عن مستوى الماجستير في أن الطالب يقود برنامجًا بحثيًا طويل الأجل، ويطور نظرية أو منهجًا أو دليلًا أو أداة جديدة، ويختبر حدود الصلاحية والتعميم. لا تشمل هوية التخصص بيانات جامعة أو مشرف أو برنامج مؤسسي بعينه.

## 3. أنواع الدكتوراه الشائعة

- دكتوراه بحثية تقليدية قائمة على أطروحة أصلية.
- دكتوراه مهنية أو قائمة على الممارسة عند توفرها، مع مكون بحثي أصيل قابل للفحص.
- دكتوراه تعاونية مع مؤسسة عامة أو ثقافية أو مهنية مع استقلال أكاديمي واضح.
- دكتوراه بالنشر أو مسار مدمج عند توفر النظام المؤسسي.

اسم الدرجة لا ينشئ تخصصًا مستقلًا؛ فقد يطرح إدارة التراث الثقافي ضمن PhD / DPhil وفق النظام والهدف الأكاديمي أو المهني.

- قد تتطلب الصيغة المهنية خبرة عملية وملف ممارسة أو مسؤولية مناسبة.

- العمل الميداني أو الحفظ أو التعامل مع المجموعات يخضع للتصاريح والأنظمة الوطنية.

## 5. مراحل برنامج الدكتوراه

1. مقررات أو حلقات متقدمة وخطة تعلم فردية.
2. تدريب منهجي في تحليل السياسات والمؤسسات والحالات وبحوث الزوار وتجربة الجمهور.
3. امتحان شامل أو تأهيلي عند وجوده.
4. مراجعة نقدية للأدبيات وتحديد الفجوة.
5. إعداد المقترح وخطة البيانات أو المصادر والأخلاقيات.
6. الانتقال إلى مرحلة مرشح الدكتوراه بعد موافقة اللجنة.
7. تنفيذ البحث باستخدام التقييم المادي والبيئي للمجموعات والتوثيق والفهرسة والمقابلات عند الملاءمة.
8. اختبارات تحقق أو متانة أو مقارنة وتفسير بدائل النتائج.
9. كتابة الأطروحة ومناقشتها والدفاع عنها.
10. الإيداع واستكمال متطلبات النزاهة والبيانات والتخرج.

### مناهج البحث والتحليل

- تحليل السياسات والمؤسسات والحالات.
- بحوث الزوار وتجربة الجمهور.
- التقييم المادي والبيئي للمجموعات.
- التوثيق والفهرسة والمقابلات.
- البحث التشاركي وتصميم التدخلات.

### الأخلاقيات والنزاهة العلمية

- الحصول على الموافقات الأخلاقية قبل جمع بيانات الأفراد أو المؤسسات أو المجتمعات.
- حماية الخصوصية والسرية والملكية الفكرية والمواد الحساسة.
- الإفصاح عن التمويل وتضارب المصالح المهنية أو السياسية أو المالية.
- توثيق المصادر والتحويلات والأدوات والشفرة أو بروتوكولات التحليل.
- عدم تضخيم النتائج أو إخفاء عدم اليقين أو استخدام البحث للإضرار بالمشاركين.

## 7. مجالات البحث والتخصصات الدقيقة

- حوكمة المواقع والمجموعات التراثية
- التخطيط والحفظ وإدارة المخاطر
- المشاركة المجتمعية وحقوق أصحاب التراث
- السياحة الثقافية والاستدامة
- التراث في الأزمات والنزاعات
- المقارنة بين السياقات والتحولات المعاصرة

تُحفظ هذه المجالات كعلاقات أو تركيزات بحثية، ولا تتحول تلقائيًا إلى تخصصات مستقلة دون مراجعة Academic Taxonomy.

## 8. الامتحان التأهيلي أو الشامل عند وجوده

قد يختبر الامتحان المعرفة المتقدمة في حوكمة المواقع والمجموعات التراثية والتخطيط والحفظ وإدارة المخاطر، والقدرة على تحليل مادة أو بيانات أو حالة مرتبطة بـإدارة التراث الثقافي والدفاع عن منهج يستخدم تحليل السياسات والمؤسسات والحالات وبحوث الزوار وتجربة الجمهور. كما قد يتطلب نقد أدبيات متعارضة، وتبرير وحدة التحليل، وبيان كيفية التحقق من الادعاءات والبدائل التفسيرية.

قد يكون تحريريًا أو شفهيًا أو دفاعًا عن مقترح أولي، وتختلف صيغته وتبعات النجاح أو الإخفاق بين الجامعات والأنظمة.

## 9. مقترح البحث ومرحلة الترشح

يحدد المقترح مشكلة أصلية في حوكمة المواقع والمجموعات التراثية أو التخطيط والحفظ وإدارة المخاطر، ويعرض سؤال البحث أو الفرضيات أو الأطروحة، ويبرر استخدام تحليل السياسات والمؤسسات والحالات وبحوث الزوار وتجربة الجمهور. كما يحدد الموقع أو المجموعة أو المؤسسة أو الجمهور أو المجتمع صاحب التراث، والسياق أو الفترة أو المجتمع أو المؤسسة، ويشرح معايير الاختيار والنطاق وحدود الاستدلال.

يجب أن يتضمن خطة للبيانات أو المصادر، والجودة، والأخلاقيات، والمخاطر، والموارد، والجدول الزمني، ومعايير مسبقة للتحقق أو المقارنة، وخطة بديلة إذا تعذر الوصول إلى مادة أو مؤسسة أو عينة أساسية.

## 10. الأطروحة والمساهمة الأصلية

قد تتمثل المساهمة الأصلية في إطار حوكمة أو نموذج حفظ أو تفسير أو تقييم مشاركة قابل للتحقق يضيف معرفة قابلة للتحقق في إدارة التراث الثقافي، بما يطور فهم حوكمة المواقع والمجموعات التراثية أو يقدم تفسيرًا أو أداة أو ممارسة قابلة للتقييم في المشاركة المجتمعية وحقوق أصحاب التراث.

يمكن أن تكون الأطروحة تقليدية أو قائمة على أوراق منشورة أو مشروعًا مهنيًا موثقًا، لكن يجب أن تكون وحدة المساهمة واضحة، وأن يفصل الباحث بين ما أثبته وما استنتجه وما اقترحه معياريًا أو تطبيقيًا.

## 2. طبيعة الدكتوراه وهدفها

تهدف دكتوراه المتاحف إلى إعداد باحث قادر على إنتاج معرفة مستقلة في سياسات الاقتناء والمجموعات، وربطها بالعرض والتفسير والسرد المتحفي ودراسات الزوار والإتاحة. ويُتوقع منه تحديد فجوة حقيقية، وصياغة سؤال قابل للفحص، وبناء حجة أو تصميم بحث يميز بين الوصف والتفسير والسببية أو الحكم المعياري بحسب طبيعة المجال.

تختلف عن مستوى الماجستير في أن الطالب يقود برنامجًا بحثيًا طويل الأجل، ويطور نظرية أو منهجًا أو دليلًا أو أداة جديدة، ويختبر حدود الصلاحية والتعميم. لا تشمل هوية التخصص بيانات جامعة أو مشرف أو برنامج مؤسسي بعينه.

## 3. أنواع الدكتوراه الشائعة

- دكتوراه بحثية تقليدية قائمة على أطروحة أصلية.
- دكتوراه مهنية أو قائمة على الممارسة عند توفرها، مع مكون بحثي أصيل قابل للفحص.
- دكتوراه تعاونية مع مؤسسة عامة أو ثقافية أو مهنية مع استقلال أكاديمي واضح.
- دكتوراه بالنشر أو مسار مدمج عند توفر النظام المؤسسي.

اسم الدرجة لا ينشئ تخصصًا مستقلًا؛ فقد يطرح المتاحف ضمن PhD / DPhil وفق النظام والهدف الأكاديمي أو المهني.

## 9. مقترح البحث ومرحلة الترشح

يحدد المقترح مشكلة أصلية في سياسات الاقتناء والمجموعات أو العرض والتفسير والسرد المتحفي، ويعرض سؤال البحث أو الفرضيات أو الأطروحة، ويبرر استخدام تحليل السياسات والمؤسسات والحالات وبحوث الزوار وتجربة الجمهور. كما يحدد الموقع أو المجموعة أو المؤسسة أو الجمهور أو المجتمع صاحب التراث، والسياق أو الفترة أو المجتمع أو المؤسسة، ويشرح معايير الاختيار والنطاق وحدود الاستدلال.

يجب أن يتضمن خطة للبيانات أو المصادر، والجودة، والأخلاقيات، والمخاطر، والموارد، والجدول الزمني، ومعايير مسبقة للتحقق أو المقارنة، وخطة بديلة إذا تعذر الوصول إلى مادة أو مؤسسة أو عينة أساسية.

## 2. طبيعة الدكتوراه وهدفها

تهدف دكتوراه الفلسفة إلى إعداد باحث قادر على إنتاج معرفة مستقلة في الميتافيزيقا ونظرية المعرفة، وربطها بالأخلاق والفلسفة السياسية وفلسفة العقل واللغة. ويُتوقع منه تحديد فجوة حقيقية، وصياغة سؤال قابل للفحص، وبناء حجة أو تصميم بحث يميز بين الوصف والتفسير والسببية أو الحكم المعياري بحسب طبيعة المجال.

تختلف عن مستوى الماجستير في أن الطالب يقود برنامجًا بحثيًا طويل الأجل، ويطور نظرية أو منهجًا أو دليلًا أو أداة جديدة، ويختبر حدود الصلاحية والتعميم. لا تشمل هوية التخصص بيانات جامعة أو مشرف أو برنامج مؤسسي بعينه.

## 3. أنواع الدكتوراه الشائعة

- دكتوراه بحثية تقليدية قائمة على أطروحة أصلية.
- دكتوراه بينية عند اتصال السؤال بتخصص آخر ومنهج واضح للدمج.
- دكتوراه تعاونية مع مؤسسة عامة أو ثقافية أو مهنية مع استقلال أكاديمي واضح.
- دكتوراه بالنشر أو مسار مدمج عند توفر النظام المؤسسي.

اسم الدرجة لا ينشئ تخصصًا مستقلًا؛ فقد يطرح الفلسفة ضمن PhD / DPhil وفق النظام والهدف الأكاديمي أو المهني.

## 4. الخلفيات الأكاديمية المناسبة ومسارات الدخول

### تخصصات الماجستير المرتبطة

- MAS-0779 — المسار المرجعي المرتبط في دليل الماجستير
- الفلسفة أو الأخلاق أو المنطق
- تاريخ الأفكار أو الدراسات الكلاسيكية
- القانون أو السياسة لمسارات معيارية
- العلوم أو الطب أو التقنية لفلسفة المجال
- الرياضيات أو الحوسبة للمنطق والفلسفة الصورية

### تخصصات قريبة قد تقبل

- تخصص قريب يدعم سؤال الأطروحة ومنهجها مع استيفاء المتطلبات الاستدراكية.
- خلفية بينية تجمع المجال الأساسي مع الإحصاء أو الحوسبة أو التاريخ أو القانون أو الصحة أو الاقتصاد بحسب موضوع البحث.
- خبرة مهنية موثقة عندما تكون الدكتوراه مهنية أو قائمة على الممارسة.

### الدخول المباشر بعد البكالوريوس عند شيوعه

- بكالوريوس متميز في مجال مرتبط ضمن نظام يسمح بالدخول المباشر أو المسار المدمج.
- خبرة بحثية موثقة وكتابة أكاديمية قوية وكفاية في المناهج المطلوبة.
- مقررات استدراكية عندما تختلف الخلفية عن جوهر التخصص.

### الخبرة أو الترخيص المطلوب للدكتوراه المهنية

- قد تتطلب الصيغة المهنية خبرة عملية وملف ممارسة أو مسؤولية مناسبة.
- الوصول إلى أفراد أو مؤسسات أو قضايا أو بيانات حساسة يحتاج موافقات وصلاحيات منفصلة.
- أي ممارسة مهنية منظمة أو وصول إلى بيانات حساسة يخضع لاعتماد أو تصريح مستقل.

## 5. مراحل برنامج الدكتوراه

1. مقررات أو حلقات متقدمة وخطة تعلم فردية.
2. تدريب منهجي في التحليل المفهومي وإعادة بناء الحجج والمنطق الصوري أو غير الصوري عند الملاءمة.
3. امتحان شامل أو تأهيلي عند وجوده.
4. مراجعة نقدية للأدبيات وتحديد الفجوة.
5. إعداد المقترح وخطة البيانات أو المصادر والأخلاقيات.
6. الانتقال إلى مرحلة مرشح الدكتوراه بعد موافقة اللجنة.
7. تنفيذ البحث باستخدام المقارنة التاريخية للنصوص والمواقف والتجارب الفكرية والفلسفة التجريبية عند الحاجة عند الملاءمة.
8. اختبارات تحقق أو متانة أو مقارنة وتفسير بدائل النتائج.
9. كتابة الأطروحة ومناقشتها والدفاع عنها.
10. الإيداع واستكمال متطلبات النزاهة والبيانات والتخرج.

## 6. المعرفة والمقررات المتقدمة

### المعرفة النظرية المتقدمة

- تاريخ الفلسفة والمدارس الكبرى.
- نظرية المعرفة والميتافيزيقا.
- الأخلاق والفلسفة السياسية.
- المنطق والحجاج وفلسفة اللغة.
- فلسفة العلم والتقنية والممارسة.

### مناهج البحث والتحليل

- التحليل المفهومي وإعادة بناء الحجج.
- المنطق الصوري أو غير الصوري عند الملاءمة.
- المقارنة التاريخية للنصوص والمواقف.
- التجارب الفكرية والفلسفة التجريبية عند الحاجة.
- الأخلاق التطبيقية وتحليل الحالات والسياسات.

### الأخلاقيات والنزاهة العلمية

- الحصول على الموافقات الأخلاقية قبل جمع بيانات الأفراد أو المؤسسات أو المجتمعات.
- حماية الخصوصية والسرية والملكية الفكرية والمواد الحساسة.
- الإفصاح عن التمويل وتضارب المصالح المهنية أو السياسية أو المالية.
- توثيق المصادر والتحويلات والأدوات والشفرة أو بروتوكولات التحليل.
- عدم تضخيم النتائج أو إخفاء عدم اليقين أو استخدام البحث للإضرار بالمشاركين.

## 8. الامتحان التأهيلي أو الشامل عند وجوده

قد يختبر الامتحان المعرفة المتقدمة في الميتافيزيقا ونظرية المعرفة والأخلاق والفلسفة السياسية، والقدرة على تحليل مادة أو بيانات أو حالة مرتبطة بالفلسفة والدفاع عن منهج يستخدم التحليل المفهومي وإعادة بناء الحجج والمنطق الصوري أو غير الصوري عند الملاءمة. كما قد يتطلب نقد أدبيات متعارضة، وتبرير وحدة التحليل، وبيان كيفية التحقق من الادعاءات والبدائل التفسيرية.

قد يكون تحريريًا أو شفهيًا أو دفاعًا عن مقترح أولي، وتختلف صيغته وتبعات النجاح أو الإخفاق بين الجامعات والأنظمة.

## 9. مقترح البحث ومرحلة الترشح

يحدد المقترح مشكلة أصلية في الميتافيزيقا ونظرية المعرفة أو الأخلاق والفلسفة السياسية، ويعرض سؤال البحث أو الفرضيات أو الأطروحة، ويبرر استخدام التحليل المفهومي وإعادة بناء الحجج والمنطق الصوري أو غير الصوري عند الملاءمة. كما يحدد المفهوم أو الحجة أو النص أو الممارسة أو القضية المعيارية، والسياق أو الفترة أو المجتمع أو المؤسسة، ويشرح معايير الاختيار والنطاق وحدود الاستدلال.

يجب أن يتضمن خطة للبيانات أو المصادر، والجودة، والأخلاقيات، والمخاطر، والموارد، والجدول الزمني، ومعايير مسبقة للتحقق أو المقارنة، وخطة بديلة إذا تعذر الوصول إلى مادة أو مؤسسة أو عينة أساسية.

## 10. الأطروحة والمساهمة الأصلية

قد تتمثل المساهمة الأصلية في حجة أو تمييز مفهومي أو نظرية أو تطبيق معياري أصيل يضيف معرفة قابلة للتحقق في الفلسفة، بما يطور فهم الميتافيزيقا ونظرية المعرفة أو يقدم تفسيرًا أو أداة أو ممارسة قابلة للتقييم في فلسفة العقل واللغة.

يمكن أن تكون الأطروحة تقليدية أو قائمة على أوراق منشورة أو مشروعًا مهنيًا موثقًا، لكن يجب أن تكون وحدة المساهمة واضحة، وأن يفصل الباحث بين ما أثبته وما استنتجه وما اقترحه معياريًا أو تطبيقيًا.

## 11. الإشراف والبيئة البحثية

- إشراف متخصص في التقليد أو المشكلة الفلسفية.
- وصول إلى النصوص واللغات الأصلية عند الحاجة.
- تدريب في المنطق أو المنهج البيني المناسب.
- بيئة نقدية للفحص الصارم للحجج والاعتراضات.
- لجنة إشراف تجمع خبرة موضوعية ومنهجية مستقلة.
- خطة لإدارة الوصول والتخزين الآمن واستمرارية البيانات أو المصادر.

لا تحفظ أسماء المشرفين أو المؤسسات داخل هوية التخصص؛ فهي بيانات برامج جامعية في Phase 11.

## 12. متطلبات البحث والنشر والتدريس

- حلقات بحث وتحديثات دورية للجنة الإشراف.
- توثيق المنهج والبيانات أو النصوص أو الحالات وإجراءات التحليل.
- اختبارات جودة ومتانة أو مقارنة مستقلة تتناسب مع المجال.
- إعداد أوراق أو أدوات أو تقارير قابلة للتحكيم وفق سياسة المؤسسة.
- تدريس أو مساعدة تعليمية أو تدريب مهني في بعض البرامج.

لا توجد أعداد عالمية موحدة للمنشورات أو المؤتمرات أو ساعات التدريس.

## 13. المهارات البحثية والمهنية المتقدمة

- صياغة سؤال بحث أصيل في الفلسفة.
- نقد الأدلة والنظريات في الميتافيزيقا ونظرية المعرفة.
- تطبيق التحليل المفهومي وإعادة بناء الحجج والمنطق الصوري أو غير الصوري عند الملاءمة بصورة مستقلة.
- إدارة بيانات أو نصوص أو وثائق أو حالات معقدة وضبط جودتها.
- تقييم التحيز وعدم اليقين وحدود التعميم أو النقل بين السياقات.
- الكتابة والنشر والعرض والدفاع العلمي.
- قيادة تعاون متعدد التخصصات وإدارة مشروع طويل الأجل.

## 14. مجالات العمل بعد الدكتوراه

- الجامعات ومراكز الفلسفة والأخلاق
- لجان الأخلاقيات والحوكمة
- مراكز السياسات والتقنية المسؤولة
- النشر والتحرير الفكري
- الاستشارات الأخلاقية والبحثية

تعتمد ملاءمة المسار على موضوع الأطروحة والمنهج والخبرة وأي اعتماد مهني مستقل.

## 16. ما بعد الدكتوراه والمسارات اللاحقة

- زمالة ما بعد الدكتوراه في الفلسفة أو مجال قريب.
- مسار أكاديمي في البحث والتدريس والإشراف.
- البحث والاستشارات في مؤسسة عامة أو ثقافية أو اجتماعية أو خاصة أو دولية.
- قيادة برامج بحث أو سياسات أو تطوير بعد اكتساب الخبرة.
- ممارسة مهنية متقدمة عند استيفاء الترخيص أو الاعتماد المستقل.

## 18. التنبيه الأكاديمي والمهني

> **القوة الفلسفية لا تقاس بكثرة المصطلحات، بل بوضوح السؤال وصحة الحجة ومعالجة الاعتراضات. يجب تمييز الادعاء الوصفي عن المعياري وعدم تقديم الرأي بوصفه نتيجة مثبتة. جودة الإشراف والبيئة والبيانات أو المصادر أهم من اسم الدرجة وحده، والدكتوراه لا تضمن وظيفة أكاديمية.**
