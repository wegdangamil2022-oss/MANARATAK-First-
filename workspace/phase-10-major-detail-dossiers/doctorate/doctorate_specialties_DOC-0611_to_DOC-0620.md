## 2. طبيعة الدكتوراه وهدفها

تهدف دكتوراه المحاسبة الإدارية إلى إعداد باحث قادر على تفسير وتطوير المعرفة المتعلقة بـ التكاليف والرقابة الإدارية والميزانيات والحوافز، واختبار علاقتها بـ قياس الأداء ودعم القرار. ويُتوقع من الباحث تحديد فجوة حقيقية، وصياغة سؤال قابل للفحص، وبناء تصميم يميز بين الوصف والتفسير والسببية أو الحجة المعيارية وفق طبيعة المجال.

تختلف عن الماجستير في أن الطالب يقود برنامجًا بحثيًا مستقلًا، ويطور نظرية أو منهجًا أو دليلًا أو إطارًا جديدًا، ويبرهن حدود الصلاحية والتعميم. لا تشمل هوية التخصص بيانات جامعة أو مشرف أو جهة مهنية أو نظام وطني بعينه.

## 3. أنواع الدكتوراه الشائعة

- دكتوراه بحثية تقليدية قائمة على أطروحة أصلية.
- دكتوراه مهنية أو تطبيقية تعالج مشكلة ممارسة عند توفرها.
- دكتوراه تعاونية مع جهة عامة أو خاصة مع استقلال أكاديمي واضح.
- دكتوراه بالنشر أو مسار مدمج عند توفر النظام المؤسسي.

اسم الدرجة لا ينشئ تخصصًا مستقلًا؛ فقد يطرح المجال ضمن PhD أو DBA أو SJD/JSD أو DPA بحسب النظام.

### الخبرة أو الترخيص المطلوب للدكتوراه المهنية

- قد تتطلب الصيغة المهنية خبرة عملية موثقة ومسؤولية إدارية أو قانونية أو سياساتية.
- الوصول إلى بيانات مؤسسات أو عملاء أو قضايا أو موظفين يحتاج موافقات وسرية وصلاحيات منفصلة.
- أي ممارسة منظمة تبقى خاضعة للترخيص المحلي ولا تمنحها الدكتوراه تلقائيًا.

## 5. مراحل برنامج الدكتوراه

1. مقررات أو حلقات متقدمة وخطة تعلم فردية.
2. تدريب منهجي في تحليل أرشيفي واقتصاد قياسي وتجارب سلوكية ومهنية.
3. امتحان شامل أو تأهيلي عند وجوده.
4. مراجعة نقدية للأدبيات وتحديد الفجوة.
5. إعداد المقترح وخطة البيانات أو المصادر والأخلاقيات.
6. الانتقال إلى مرحلة مرشح الدكتوراه بعد موافقة اللجنة.
7. تنفيذ البحث باستخدام دراسات حالة ووثائق وتحليل نصوص ومعاملات عند الملاءمة.
8. اختبارات التحقق والمتانة أو المقارنة القانونية والتاريخية.
9. كتابة الأطروحة ومناقشتها والدفاع عنها.
10. الإيداع واستكمال متطلبات النزاهة والبيانات والتخرج.

## 6. المعرفة والمقررات المتقدمة

### المعرفة النظرية المتقدمة

- القياس والإفصاح والمعلومات المحاسبية.
- الحوافز والعقود والحوكمة.
- التدقيق والضبط والمساءلة.
- الضرائب والقطاع العام والامتثال.
- الأدبيات والاتجاهات المعاصرة في التكاليف والرقابة الإدارية والميزانيات والحوافز.
- نقد الافتراضات والقياس والتفسير وحدود النقل بين الأنظمة والسياقات.

### مناهج البحث والتحليل

- تحليل أرشيفي واقتصاد قياسي.
- تجارب سلوكية ومهنية.
- دراسات حالة ووثائق.
- تحليل نصوص ومعاملات.
- مراجعات منهجية أو مقارنات معيارية وربط النتائج بأدلة مستقلة.

### الأخلاقيات والنزاهة العلمية

- الموافقات الأخلاقية قبل جمع بيانات الأفراد أو المؤسسات أو القضايا الحساسة.
- حماية الخصوصية والسرية التجارية أو القانونية أو الدبلوماسية.
- الإفصاح عن التمويل والمصالح المهنية والسياسية والمالية.
- توثيق المصادر والتحويلات والشفرة أو بروتوكول التحليل.
- عدم استخدام البحث للإضرار بالمشاركين أو التأثير غير المشروع في قرار مهني أو قضائي أو سياسي.

- الميزانيات والحوافز
- قياس الأداء ودعم القرار

تُحفظ هذه المجالات كعلاقات أو تركيزات بحثية، ولا تتحول تلقائيًا إلى تخصصات مستقلة دون مراجعة Academic Taxonomy.

## 8. الامتحان التأهيلي أو الشامل عند وجوده

قد يختبر الامتحان الفهم المتقدم لـ التكاليف والرقابة الإدارية والميزانيات والحوافز، والقدرة على نقد نظرية أو دراسة أو حكم أو سياسة أو مجموعة بيانات، وتصميم بحث يستخدم تحليل أرشيفي واقتصاد قياسي وتجارب سلوكية ومهنية مع تبرير الوحدة التحليلية والعينة أو المصادر والتحقق.

قد يكون تحريريًا أو شفهيًا أو دفاعًا عن مقترح أولي، وتختلف صيغته وتبعات النجاح أو الإخفاق بين الجامعات والأنظمة.

## 9. مقترح البحث ومرحلة الترشح

يحدد المقترح مشكلة أصلية في التكاليف والرقابة الإدارية أو الميزانيات والحوافز، ويعرض سؤال البحث أو الفرضيات أو الأطروحة القانونية، ويبرر استخدام تحليل أرشيفي واقتصاد قياسي وتجارب سلوكية ومهنية. كما يحدد وحدة التحليل أو المؤسسات أو الأسواق أو النصوص أو الحالات والفترة الزمنية والنطاق الجغرافي أو القانوني.

يجب أن يتضمن خطة للبيانات والمصادر والجودة والأخلاقيات والمخاطر والموارد والجدول الزمني، ومعايير مسبقة للتحقق أو المقارنة، وخطة بديلة إذا تعذر الوصول إلى بيانات أو مؤسسة أو وثيقة أساسية.

## 10. الأطروحة والمساهمة الأصلية

قد تتمثل المساهمة الأصلية في مقياسًا أو تفسيرًا أو آلية إفصاح ورقابة أو دليلًا محاسبيًا جديدًا في المحاسبة الإدارية، بما يطور فهم التكاليف والرقابة الإدارية أو يقدم تفسيرًا أو أداة أو توصية قابلة للتقييم في الميزانيات والحوافز.

يمكن أن تكون الأطروحة تقليدية أو قائمة على أوراق منشورة أو مشروعًا مهنيًا موثقًا، لكن يجب أن تكون وحدة المساهمة واضحة، وأن يفصل الباحث بين ما أثبته وما استنتجه وما اقترحه معياريًا أو تطبيقيًا.

## 11. الإشراف والبيئة البحثية

- قواعد تقارير مالية وتدقيق وضرائب موثقة.
- وصول منضبط إلى بيانات شركات أو جهات عامة.
- إشراف يجمع المحاسبة والاقتصاد والقانون والمنهج.
- لجنة إشراف تجمع خبرة موضوعية ومنهجية مستقلة.
- خطة لإدارة الوصول والسرية والتخزين الآمن واستمرارية البيانات أو المصادر.

لا تحفظ أسماء المشرفين أو المؤسسات داخل هوية التخصص؛ فهي بيانات برامج جامعية في Phase 11.

## 12. متطلبات البحث والنشر والتدريس

- حلقات بحث وتحديثات دورية للجنة الإشراف.
- توثيق المنهج والبيانات أو النصوص أو الحالات وإجراءات التحليل.
- اختبارات جودة ومتانة أو مقارنة مستقلة تتناسب مع المجال.
- إعداد أوراق أو أدوات أو تقارير قابلة للتحكيم وفق سياسة المؤسسة.
- تدريس أو مساعدة تعليمية أو تدريب مهني في بعض البرامج.

لا توجد أعداد عالمية موحدة للمنشورات أو المؤتمرات أو ساعات التدريس.

## 13. المهارات البحثية والمهنية المتقدمة

- صياغة سؤال بحث أصيل في المحاسبة الإدارية
- نقد الأدلة والنظريات في التكاليف والرقابة الإدارية
- تطبيق تحليل أرشيفي واقتصاد قياسي وتجارب سلوكية ومهنية بصورة مستقلة
- إدارة بيانات أو وثائق أو حالات معقدة وضبط جودتها
- تقييم التحيز وعدم اليقين وحدود التعميم أو القياس القانوني
- الكتابة والنشر والعرض والدفاع العلمي
- قيادة تعاون متعدد التخصصات وإدارة مشروع طويل الأجل

## 14. مجالات العمل بعد الدكتوراه

- الجامعات وكليات الأعمال والمحاسبة
- البحث والاستشارات والتدقيق والتحليل
- الهيئات الرقابية والضرائب والقطاع العام
- الحوكمة والمخاطر والامتثال والتحقيق المالي

- زمالة ما بعد الدكتوراه في المحاسبة الإدارية أو مجال قريب.

- البحث والاستشارات في مؤسسة عامة أو خاصة أو دولية.
- قيادة برامج بحث أو سياسات أو تحول بعد اكتساب الخبرة.
- ريادة أعمال معرفية أو ممارسة مهنية عند استيفاء الترخيص.

## 2. طبيعة الدكتوراه وهدفها

2. تدريب منهجي في تحليل أرشيفي واقتصاد قياسي وتجارب سلوكية ومهنية.
3. امتحان شامل أو تأهيلي عند وجوده.
4. مراجعة نقدية للأدبيات وتحديد الفجوة.
5. إعداد المقترح وخطة البيانات أو المصادر والأخلاقيات.
6. الانتقال إلى مرحلة مرشح الدكتوراه بعد موافقة اللجنة.
7. تنفيذ البحث باستخدام دراسات حالة ووثائق وتحليل نصوص ومعاملات عند الملاءمة.
8. اختبارات التحقق والمتانة أو المقارنة القانونية والتاريخية.
9. كتابة الأطروحة ومناقشتها والدفاع عنها.
10. الإيداع واستكمال متطلبات النزاهة والبيانات والتخرج.

### مناهج البحث والتحليل

## 8. الامتحان التأهيلي أو الشامل عند وجوده

قد يختبر الامتحان الفهم المتقدم لـ كشف الاحتيال والتحقيق والأدلة الرقمية والمالية، والقدرة على نقد نظرية أو دراسة أو حكم أو سياسة أو مجموعة بيانات، وتصميم بحث يستخدم تحليل أرشيفي واقتصاد قياسي وتجارب سلوكية ومهنية مع تبرير الوحدة التحليلية والعينة أو المصادر والتحقق.

قد يكون تحريريًا أو شفهيًا أو دفاعًا عن مقترح أولي، وتختلف صيغته وتبعات النجاح أو الإخفاق بين الجامعات والأنظمة.

## 9. مقترح البحث ومرحلة الترشح

يحدد المقترح مشكلة أصلية في كشف الاحتيال والتحقيق أو الأدلة الرقمية والمالية، ويعرض سؤال البحث أو الفرضيات أو الأطروحة القانونية، ويبرر استخدام تحليل أرشيفي واقتصاد قياسي وتجارب سلوكية ومهنية. كما يحدد وحدة التحليل أو المؤسسات أو الأسواق أو النصوص أو الحالات والفترة الزمنية والنطاق الجغرافي أو القانوني.

يجب أن يتضمن خطة للبيانات والمصادر والجودة والأخلاقيات والمخاطر والموارد والجدول الزمني، ومعايير مسبقة للتحقق أو المقارنة، وخطة بديلة إذا تعذر الوصول إلى بيانات أو مؤسسة أو وثيقة أساسية.

## 10. الأطروحة والمساهمة الأصلية

قد تتمثل المساهمة الأصلية في مقياسًا أو تفسيرًا أو آلية إفصاح ورقابة أو دليلًا محاسبيًا جديدًا في المحاسبة الجنائية، بما يطور فهم كشف الاحتيال والتحقيق أو يقدم تفسيرًا أو أداة أو توصية قابلة للتقييم في الأدلة الرقمية والمالية.

يمكن أن تكون الأطروحة تقليدية أو قائمة على أوراق منشورة أو مشروعًا مهنيًا موثقًا، لكن يجب أن تكون وحدة المساهمة واضحة، وأن يفصل الباحث بين ما أثبته وما استنتجه وما اقترحه معياريًا أو تطبيقيًا.

## 11. الإشراف والبيئة البحثية

- وصول منضبط إلى بيانات شركات أو جهات عامة.

- لجنة إشراف تجمع خبرة موضوعية ومنهجية مستقلة.
- خطة لإدارة الوصول والسرية والتخزين الآمن واستمرارية البيانات أو المصادر.

لا تحفظ أسماء المشرفين أو المؤسسات داخل هوية التخصص؛ فهي بيانات برامج جامعية في Phase 11.

لا توجد أعداد عالمية موحدة للمنشورات أو المؤتمرات أو ساعات التدريس.

## 2. طبيعة الدكتوراه وهدفها

تهدف دكتوراه التدقيق والمراجعة إلى إعداد باحث قادر على تفسير وتطوير المعرفة المتعلقة بـ جودة التدقيق واستقلاليته وتقدير المخاطر وأدلة المراجعة، واختبار علاقتها بـ التدقيق المستمر وتحليلات البيانات. ويُتوقع من الباحث تحديد فجوة حقيقية، وصياغة سؤال قابل للفحص، وبناء تصميم يميز بين الوصف والتفسير والسببية أو الحجة المعيارية وفق طبيعة المجال.

تختلف عن الماجستير في أن الطالب يقود برنامجًا بحثيًا مستقلًا، ويطور نظرية أو منهجًا أو دليلًا أو إطارًا جديدًا، ويبرهن حدود الصلاحية والتعميم. لا تشمل هوية التخصص بيانات جامعة أو مشرف أو جهة مهنية أو نظام وطني بعينه.

## 3. أنواع الدكتوراه الشائعة

- دكتوراه بحثية تقليدية قائمة على أطروحة أصلية.
- دكتوراه مهنية أو تطبيقية تعالج مشكلة ممارسة عند توفرها.
- دكتوراه تعاونية مع جهة عامة أو خاصة مع استقلال أكاديمي واضح.
- دكتوراه بالنشر أو مسار مدمج عند توفر النظام المؤسسي.

اسم الدرجة لا ينشئ تخصصًا مستقلًا؛ فقد يطرح المجال ضمن PhD أو DBA أو SJD/JSD أو DPA بحسب النظام.

## 8. الامتحان التأهيلي أو الشامل عند وجوده

قد يختبر الامتحان الفهم المتقدم لـ جودة التدقيق واستقلاليته وتقدير المخاطر وأدلة المراجعة، والقدرة على نقد نظرية أو دراسة أو حكم أو سياسة أو مجموعة بيانات، وتصميم بحث يستخدم تحليل أرشيفي واقتصاد قياسي وتجارب سلوكية ومهنية مع تبرير الوحدة التحليلية والعينة أو المصادر والتحقق.

قد يكون تحريريًا أو شفهيًا أو دفاعًا عن مقترح أولي، وتختلف صيغته وتبعات النجاح أو الإخفاق بين الجامعات والأنظمة.

## 9. مقترح البحث ومرحلة الترشح

يحدد المقترح مشكلة أصلية في جودة التدقيق واستقلاليته أو تقدير المخاطر وأدلة المراجعة، ويعرض سؤال البحث أو الفرضيات أو الأطروحة القانونية، ويبرر استخدام تحليل أرشيفي واقتصاد قياسي وتجارب سلوكية ومهنية. كما يحدد وحدة التحليل أو المؤسسات أو الأسواق أو النصوص أو الحالات والفترة الزمنية والنطاق الجغرافي أو القانوني.

يجب أن يتضمن خطة للبيانات والمصادر والجودة والأخلاقيات والمخاطر والموارد والجدول الزمني، ومعايير مسبقة للتحقق أو المقارنة، وخطة بديلة إذا تعذر الوصول إلى بيانات أو مؤسسة أو وثيقة أساسية.

## 10. الأطروحة والمساهمة الأصلية

قد تتمثل المساهمة الأصلية في مقياسًا أو تفسيرًا أو آلية إفصاح ورقابة أو دليلًا محاسبيًا جديدًا في التدقيق والمراجعة، بما يطور فهم جودة التدقيق واستقلاليته أو يقدم تفسيرًا أو أداة أو توصية قابلة للتقييم في تقدير المخاطر وأدلة المراجعة.

يمكن أن تكون الأطروحة تقليدية أو قائمة على أوراق منشورة أو مشروعًا مهنيًا موثقًا، لكن يجب أن تكون وحدة المساهمة واضحة، وأن يفصل الباحث بين ما أثبته وما استنتجه وما اقترحه معياريًا أو تطبيقيًا.

## 11. الإشراف والبيئة البحثية

- قواعد تقارير مالية وتدقيق وضرائب موثقة.
- وصول منضبط إلى بيانات شركات أو جهات عامة.
- إشراف يجمع المحاسبة والاقتصاد والقانون والمنهج.
- لجنة إشراف تجمع خبرة موضوعية ومنهجية مستقلة.
- خطة لإدارة الوصول والسرية والتخزين الآمن واستمرارية البيانات أو المصادر.

لا تحفظ أسماء المشرفين أو المؤسسات داخل هوية التخصص؛ فهي بيانات برامج جامعية في Phase 11.

## 12. متطلبات البحث والنشر والتدريس

- حلقات بحث وتحديثات دورية للجنة الإشراف.
- توثيق المنهج والبيانات أو النصوص أو الحالات وإجراءات التحليل.
- اختبارات جودة ومتانة أو مقارنة مستقلة تتناسب مع المجال.
- إعداد أوراق أو أدوات أو تقارير قابلة للتحكيم وفق سياسة المؤسسة.
- تدريس أو مساعدة تعليمية أو تدريب مهني في بعض البرامج.

لا توجد أعداد عالمية موحدة للمنشورات أو المؤتمرات أو ساعات التدريس.

## 13. المهارات البحثية والمهنية المتقدمة

- صياغة سؤال بحث أصيل في التدقيق والمراجعة
- نقد الأدلة والنظريات في جودة التدقيق واستقلاليته
- تطبيق تحليل أرشيفي واقتصاد قياسي وتجارب سلوكية ومهنية بصورة مستقلة

- الكتابة والنشر والعرض والدفاع العلمي
- قيادة تعاون متعدد التخصصات وإدارة مشروع طويل الأجل

## 14. مجالات العمل بعد الدكتوراه

- الحوكمة والمخاطر والامتثال والتحقيق المالي

## 2. طبيعة الدكتوراه وهدفها

تهدف دكتوراه الضرائب إلى إعداد باحث قادر على تفسير وتطوير المعرفة المتعلقة بـ تصميم النظام الضريبي والامتثال والتجنب والتهرب، واختبار علاقتها بـ الآثار التوزيعية والدولية. ويُتوقع من الباحث تحديد فجوة حقيقية، وصياغة سؤال قابل للفحص، وبناء تصميم يميز بين الوصف والتفسير والسببية أو الحجة المعيارية وفق طبيعة المجال.

تختلف عن الماجستير في أن الطالب يقود برنامجًا بحثيًا مستقلًا، ويطور نظرية أو منهجًا أو دليلًا أو إطارًا جديدًا، ويبرهن حدود الصلاحية والتعميم. لا تشمل هوية التخصص بيانات جامعة أو مشرف أو جهة مهنية أو نظام وطني بعينه.

## 3. أنواع الدكتوراه الشائعة

- دكتوراه بحثية تقليدية قائمة على أطروحة أصلية.
- دكتوراه مهنية أو تطبيقية تعالج مشكلة ممارسة عند توفرها.
- دكتوراه تعاونية مع جهة عامة أو خاصة مع استقلال أكاديمي واضح.
- دكتوراه بالنشر أو مسار مدمج عند توفر النظام المؤسسي.

اسم الدرجة لا ينشئ تخصصًا مستقلًا؛ فقد يطرح المجال ضمن PhD أو DBA أو SJD/JSD أو DPA بحسب النظام.

## 5. مراحل برنامج الدكتوراه

1. مقررات أو حلقات متقدمة وخطة تعلم فردية.
2. تدريب منهجي في تحليل أرشيفي واقتصاد قياسي وتجارب سلوكية ومهنية.
3. امتحان شامل أو تأهيلي عند وجوده.
4. مراجعة نقدية للأدبيات وتحديد الفجوة.
5. إعداد المقترح وخطة البيانات أو المصادر والأخلاقيات.
6. الانتقال إلى مرحلة مرشح الدكتوراه بعد موافقة اللجنة.
7. تنفيذ البحث باستخدام دراسات حالة ووثائق وتحليل نصوص ومعاملات عند الملاءمة.
8. اختبارات التحقق والمتانة أو المقارنة القانونية والتاريخية.
9. كتابة الأطروحة ومناقشتها والدفاع عنها.
10. الإيداع واستكمال متطلبات النزاهة والبيانات والتخرج.

## 2. طبيعة الدكتوراه وهدفها

تهدف دكتوراه التمويل إلى إعداد باحث قادر على تفسير وتطوير المعرفة المتعلقة بـ تسعير الأصول وتمويل الشركات والوساطة والأسواق، واختبار علاقتها بـ السلوك والمخاطر والتنظيم. ويُتوقع من الباحث تحديد فجوة حقيقية، وصياغة سؤال قابل للفحص، وبناء تصميم يميز بين الوصف والتفسير والسببية أو الحجة المعيارية وفق طبيعة المجال.

تختلف عن الماجستير في أن الطالب يقود برنامجًا بحثيًا مستقلًا، ويطور نظرية أو منهجًا أو دليلًا أو إطارًا جديدًا، ويبرهن حدود الصلاحية والتعميم. لا تشمل هوية التخصص بيانات جامعة أو مشرف أو جهة مهنية أو نظام وطني بعينه.

## 3. أنواع الدكتوراه الشائعة

- دكتوراه بحثية تقليدية قائمة على أطروحة أصلية.
- دكتوراه مهنية أو تطبيقية تعالج مشكلة ممارسة عند توفرها.
- دكتوراه تعاونية مع جهة عامة أو خاصة مع استقلال أكاديمي واضح.
- دكتوراه بالنشر أو مسار مدمج عند توفر النظام المؤسسي.

اسم الدرجة لا ينشئ تخصصًا مستقلًا؛ فقد يطرح المجال ضمن PhD أو DBA أو SJD/JSD أو DPA بحسب النظام.

6. الانتقال إلى مرحلة مرشح الدكتوراه بعد موافقة اللجنة.
7. تنفيذ البحث باستخدام تحليل معاملات ومحافظ وشركات واختبارات أحداث وضغط وتجارب عند الملاءمة.
8. اختبارات التحقق والمتانة أو المقارنة القانونية والتاريخية.
9. كتابة الأطروحة ومناقشتها والدفاع عنها.
10. الإيداع واستكمال متطلبات النزاهة والبيانات والتخرج.

## 9. مقترح البحث ومرحلة الترشح

## 2. طبيعة الدكتوراه وهدفها

تهدف دكتوراه التمويل والاستثمار إلى إعداد باحث قادر على تفسير وتطوير المعرفة المتعلقة بـ بناء المحافظ وتخصيص الأصول وتقييم الأوراق والاستثمارات البديلة، واختبار علاقتها بـ الأداء والمخاطر وسلوك المستثمر. ويُتوقع من الباحث تحديد فجوة حقيقية، وصياغة سؤال قابل للفحص، وبناء تصميم يميز بين الوصف والتفسير والسببية أو الحجة المعيارية وفق طبيعة المجال.

تختلف عن الماجستير في أن الطالب يقود برنامجًا بحثيًا مستقلًا، ويطور نظرية أو منهجًا أو دليلًا أو إطارًا جديدًا، ويبرهن حدود الصلاحية والتعميم. لا تشمل هوية التخصص بيانات جامعة أو مشرف أو جهة مهنية أو نظام وطني بعينه.

## 3. أنواع الدكتوراه الشائعة

- دكتوراه بحثية تقليدية قائمة على أطروحة أصلية.
- دكتوراه مهنية أو تطبيقية تعالج مشكلة ممارسة عند توفرها.
- دكتوراه تعاونية مع جهة عامة أو خاصة مع استقلال أكاديمي واضح.
- دكتوراه بالنشر أو مسار مدمج عند توفر النظام المؤسسي.

اسم الدرجة لا ينشئ تخصصًا مستقلًا؛ فقد يطرح المجال ضمن PhD أو DBA أو SJD/JSD أو DPA بحسب النظام.

3. امتحان شامل أو تأهيلي عند وجوده.
4. مراجعة نقدية للأدبيات وتحديد الفجوة.
5. إعداد المقترح وخطة البيانات أو المصادر والأخلاقيات.
6. الانتقال إلى مرحلة مرشح الدكتوراه بعد موافقة اللجنة.
7. تنفيذ البحث باستخدام تحليل معاملات ومحافظ وشركات واختبارات أحداث وضغط وتجارب عند الملاءمة.
8. اختبارات التحقق والمتانة أو المقارنة القانونية والتاريخية.
9. كتابة الأطروحة ومناقشتها والدفاع عنها.
10. الإيداع واستكمال متطلبات النزاهة والبيانات والتخرج.

## 8. الامتحان التأهيلي أو الشامل عند وجوده

قد يكون تحريريًا أو شفهيًا أو دفاعًا عن مقترح أولي، وتختلف صيغته وتبعات النجاح أو الإخفاق بين الجامعات والأنظمة.

## 9. مقترح البحث ومرحلة الترشح

يحدد المقترح مشكلة أصلية في بناء المحافظ وتخصيص الأصول أو تقييم الأوراق والاستثمارات البديلة، ويعرض سؤال البحث أو الفرضيات أو الأطروحة القانونية، ويبرر استخدام اقتصاد قياسي مالي وسلاسل زمنية ونماذج تسعير ومحاكاة. كما يحدد وحدة التحليل أو المؤسسات أو الأسواق أو النصوص أو الحالات والفترة الزمنية والنطاق الجغرافي أو القانوني.

يجب أن يتضمن خطة للبيانات والمصادر والجودة والأخلاقيات والمخاطر والموارد والجدول الزمني، ومعايير مسبقة للتحقق أو المقارنة، وخطة بديلة إذا تعذر الوصول إلى بيانات أو مؤسسة أو وثيقة أساسية.

## 10. الأطروحة والمساهمة الأصلية

قد تتمثل المساهمة الأصلية في نموذج تسعير أو قياس مخاطر أو دليلًا عن الأسواق والمؤسسات المالية في التمويل والاستثمار، بما يطور فهم بناء المحافظ وتخصيص الأصول أو يقدم تفسيرًا أو أداة أو توصية قابلة للتقييم في تقييم الأوراق والاستثمارات البديلة.

يمكن أن تكون الأطروحة تقليدية أو قائمة على أوراق منشورة أو مشروعًا مهنيًا موثقًا، لكن يجب أن تكون وحدة المساهمة واضحة، وأن يفصل الباحث بين ما أثبته وما استنتجه وما اقترحه معياريًا أو تطبيقيًا.

## 2. طبيعة الدكتوراه وهدفها

تختلف عن الماجستير في أن الطالب يقود برنامجًا بحثيًا مستقلًا، ويطور نظرية أو منهجًا أو دليلًا أو إطارًا جديدًا، ويبرهن حدود الصلاحية والتعميم. لا تشمل هوية التخصص بيانات جامعة أو مشرف أو جهة مهنية أو نظام وطني بعينه.

- إعداد قوي في المناهج الكمية أو النوعية أو القانونية أو التاريخية المطلوبة للمسار.
- مقررات استدراكية عندما تختلف الخلفية عن جوهر التخصص.

### الخبرة أو الترخيص المطلوب للدكتوراه المهنية

- قد تتطلب الصيغة المهنية خبرة عملية موثقة ومسؤولية إدارية أو قانونية أو سياساتية.
- الوصول إلى بيانات مؤسسات أو عملاء أو قضايا أو موظفين يحتاج موافقات وسرية وصلاحيات منفصلة.
- أي ممارسة منظمة تبقى خاضعة للترخيص المحلي ولا تمنحها الدكتوراه تلقائيًا.

## 5. مراحل برنامج الدكتوراه

1. مقررات أو حلقات متقدمة وخطة تعلم فردية.
2. تدريب منهجي في اقتصاد قياسي مالي وسلاسل زمنية ونماذج تسعير ومحاكاة.
3. امتحان شامل أو تأهيلي عند وجوده.
4. مراجعة نقدية للأدبيات وتحديد الفجوة.
5. إعداد المقترح وخطة البيانات أو المصادر والأخلاقيات.
6. الانتقال إلى مرحلة مرشح الدكتوراه بعد موافقة اللجنة.
7. تنفيذ البحث باستخدام تحليل معاملات ومحافظ وشركات واختبارات أحداث وضغط وتجارب عند الملاءمة.
8. اختبارات التحقق والمتانة أو المقارنة القانونية والتاريخية.
9. كتابة الأطروحة ومناقشتها والدفاع عنها.
10. الإيداع واستكمال متطلبات النزاهة والبيانات والتخرج.

## 6. المعرفة والمقررات المتقدمة

### المعرفة النظرية المتقدمة

- تسعير الأصول والمخاطر والعائد.
- تمويل الشركات والوساطة والأسواق.
- السلوك المالي والمعلومات والسيولة.
- التنظيم والابتكار والاستقرار المالي.
- الأدبيات والاتجاهات المعاصرة في العقود والمنتجات المتوافقة مع الشريعة والمخاطر والسيولة والحوكمة الشرعية.
- نقد الافتراضات والقياس والتفسير وحدود النقل بين الأنظمة والسياقات.

### مناهج البحث والتحليل

- اقتصاد قياسي مالي وسلاسل زمنية.
- نماذج تسعير ومحاكاة.
- تحليل معاملات ومحافظ وشركات.
- اختبارات أحداث وضغط وتجارب.
- مراجعات منهجية أو مقارنات معيارية وربط النتائج بأدلة مستقلة.

### الأخلاقيات والنزاهة العلمية

- الموافقات الأخلاقية قبل جمع بيانات الأفراد أو المؤسسات أو القضايا الحساسة.
- حماية الخصوصية والسرية التجارية أو القانونية أو الدبلوماسية.
- الإفصاح عن التمويل والمصالح المهنية والسياسية والمالية.
- توثيق المصادر والتحويلات والشفرة أو بروتوكول التحليل.
- عدم استخدام البحث للإضرار بالمشاركين أو التأثير غير المشروع في قرار مهني أو قضائي أو سياسي.

## 7. مجالات البحث والتخصصات الدقيقة

- العقود والمنتجات المتوافقة مع الشريعة
- المخاطر والسيولة والحوكمة الشرعية
- أسواق الصكوك والتمويل الاجتماعي
- المخاطر والتنظيم
- السلوك والمعلومات
- الابتكار والاستقرار

تُحفظ هذه المجالات كعلاقات أو تركيزات بحثية، ولا تتحول تلقائيًا إلى تخصصات مستقلة دون مراجعة Academic Taxonomy.

## 8. الامتحان التأهيلي أو الشامل عند وجوده

قد يختبر الامتحان الفهم المتقدم لـ العقود والمنتجات المتوافقة مع الشريعة والمخاطر والسيولة والحوكمة الشرعية، والقدرة على نقد نظرية أو دراسة أو حكم أو سياسة أو مجموعة بيانات، وتصميم بحث يستخدم اقتصاد قياسي مالي وسلاسل زمنية ونماذج تسعير ومحاكاة مع تبرير الوحدة التحليلية والعينة أو المصادر والتحقق.

قد يكون تحريريًا أو شفهيًا أو دفاعًا عن مقترح أولي، وتختلف صيغته وتبعات النجاح أو الإخفاق بين الجامعات والأنظمة.

## 9. مقترح البحث ومرحلة الترشح

يحدد المقترح مشكلة أصلية في العقود والمنتجات المتوافقة مع الشريعة أو المخاطر والسيولة والحوكمة الشرعية، ويعرض سؤال البحث أو الفرضيات أو الأطروحة القانونية، ويبرر استخدام اقتصاد قياسي مالي وسلاسل زمنية ونماذج تسعير ومحاكاة. كما يحدد وحدة التحليل أو المؤسسات أو الأسواق أو النصوص أو الحالات والفترة الزمنية والنطاق الجغرافي أو القانوني.

يجب أن يتضمن خطة للبيانات والمصادر والجودة والأخلاقيات والمخاطر والموارد والجدول الزمني، ومعايير مسبقة للتحقق أو المقارنة، وخطة بديلة إذا تعذر الوصول إلى بيانات أو مؤسسة أو وثيقة أساسية.

## 10. الأطروحة والمساهمة الأصلية

قد تتمثل المساهمة الأصلية في نموذج تسعير أو قياس مخاطر أو دليلًا عن الأسواق والمؤسسات المالية في التمويل الإسلامي، بما يطور فهم العقود والمنتجات المتوافقة مع الشريعة أو يقدم تفسيرًا أو أداة أو توصية قابلة للتقييم في المخاطر والسيولة والحوكمة الشرعية.

يمكن أن تكون الأطروحة تقليدية أو قائمة على أوراق منشورة أو مشروعًا مهنيًا موثقًا، لكن يجب أن تكون وحدة المساهمة واضحة، وأن يفصل الباحث بين ما أثبته وما استنتجه وما اقترحه معياريًا أو تطبيقيًا.

## 11. الإشراف والبيئة البحثية

- قواعد بيانات أسواق وشركات ومصارف موثقة.
- حوسبة كمية وأدوات محاكاة واختبار خلفي.
- إشراف يجمع التمويل والاقتصاد والإحصاء والتنظيم.
- لجنة إشراف تجمع خبرة موضوعية ومنهجية مستقلة.
- خطة لإدارة الوصول والسرية والتخزين الآمن واستمرارية البيانات أو المصادر.

لا تحفظ أسماء المشرفين أو المؤسسات داخل هوية التخصص؛ فهي بيانات برامج جامعية في Phase 11.

## 12. متطلبات البحث والنشر والتدريس

- حلقات بحث وتحديثات دورية للجنة الإشراف.
- توثيق المنهج والبيانات أو النصوص أو الحالات وإجراءات التحليل.
- اختبارات جودة ومتانة أو مقارنة مستقلة تتناسب مع المجال.
- إعداد أوراق أو أدوات أو تقارير قابلة للتحكيم وفق سياسة المؤسسة.
- تدريس أو مساعدة تعليمية أو تدريب مهني في بعض البرامج.

لا توجد أعداد عالمية موحدة للمنشورات أو المؤتمرات أو ساعات التدريس.

## 13. المهارات البحثية والمهنية المتقدمة

- صياغة سؤال بحث أصيل في التمويل الإسلامي
- نقد الأدلة والنظريات في العقود والمنتجات المتوافقة مع الشريعة
- تطبيق اقتصاد قياسي مالي وسلاسل زمنية ونماذج تسعير ومحاكاة بصورة مستقلة

- الكتابة والنشر والعرض والدفاع العلمي

## 2. طبيعة الدكتوراه وهدفها

تهدف دكتوراه المصارف والبنوك إلى إعداد باحث قادر على تفسير وتطوير المعرفة المتعلقة بـ الوساطة والائتمان والسيولة والمخاطر والرقابة المصرفية، واختبار علاقتها بـ الرقمنة والمنافسة والاستقرار. ويُتوقع من الباحث تحديد فجوة حقيقية، وصياغة سؤال قابل للفحص، وبناء تصميم يميز بين الوصف والتفسير والسببية أو الحجة المعيارية وفق طبيعة المجال.

تختلف عن الماجستير في أن الطالب يقود برنامجًا بحثيًا مستقلًا، ويطور نظرية أو منهجًا أو دليلًا أو إطارًا جديدًا، ويبرهن حدود الصلاحية والتعميم. لا تشمل هوية التخصص بيانات جامعة أو مشرف أو جهة مهنية أو نظام وطني بعينه.

## 3. أنواع الدكتوراه الشائعة

- دكتوراه بحثية تقليدية قائمة على أطروحة أصلية.
- دكتوراه مهنية أو تطبيقية تعالج مشكلة ممارسة عند توفرها.
- دكتوراه تعاونية مع جهة عامة أو خاصة مع استقلال أكاديمي واضح.
- دكتوراه بالنشر أو مسار مدمج عند توفر النظام المؤسسي.

اسم الدرجة لا ينشئ تخصصًا مستقلًا؛ فقد يطرح المجال ضمن PhD أو DBA أو SJD/JSD أو DPA بحسب النظام.

### الأخلاقيات والنزاهة العلمية

- الموافقات الأخلاقية قبل جمع بيانات الأفراد أو المؤسسات أو القضايا الحساسة.
- حماية الخصوصية والسرية التجارية أو القانونية أو الدبلوماسية.
- الإفصاح عن التمويل والمصالح المهنية والسياسية والمالية.
- توثيق المصادر والتحويلات والشفرة أو بروتوكول التحليل.
- عدم استخدام البحث للإضرار بالمشاركين أو التأثير غير المشروع في قرار مهني أو قضائي أو سياسي.

## 7. مجالات البحث والتخصصات الدقيقة

- الوساطة والائتمان والسيولة
- المخاطر والرقابة المصرفية
- الرقمنة والمنافسة والاستقرار
- المخاطر والتنظيم
- السلوك والمعلومات
- الابتكار والاستقرار

تُحفظ هذه المجالات كعلاقات أو تركيزات بحثية، ولا تتحول تلقائيًا إلى تخصصات مستقلة دون مراجعة Academic Taxonomy.

## 8. الامتحان التأهيلي أو الشامل عند وجوده

قد يختبر الامتحان الفهم المتقدم لـ الوساطة والائتمان والسيولة والمخاطر والرقابة المصرفية، والقدرة على نقد نظرية أو دراسة أو حكم أو سياسة أو مجموعة بيانات، وتصميم بحث يستخدم اقتصاد قياسي مالي وسلاسل زمنية ونماذج تسعير ومحاكاة مع تبرير الوحدة التحليلية والعينة أو المصادر والتحقق.

قد يكون تحريريًا أو شفهيًا أو دفاعًا عن مقترح أولي، وتختلف صيغته وتبعات النجاح أو الإخفاق بين الجامعات والأنظمة.

## 9. مقترح البحث ومرحلة الترشح

يحدد المقترح مشكلة أصلية في الوساطة والائتمان والسيولة أو المخاطر والرقابة المصرفية، ويعرض سؤال البحث أو الفرضيات أو الأطروحة القانونية، ويبرر استخدام اقتصاد قياسي مالي وسلاسل زمنية ونماذج تسعير ومحاكاة. كما يحدد وحدة التحليل أو المؤسسات أو الأسواق أو النصوص أو الحالات والفترة الزمنية والنطاق الجغرافي أو القانوني.

يجب أن يتضمن خطة للبيانات والمصادر والجودة والأخلاقيات والمخاطر والموارد والجدول الزمني، ومعايير مسبقة للتحقق أو المقارنة، وخطة بديلة إذا تعذر الوصول إلى بيانات أو مؤسسة أو وثيقة أساسية.

## 10. الأطروحة والمساهمة الأصلية

قد تتمثل المساهمة الأصلية في نموذج تسعير أو قياس مخاطر أو دليلًا عن الأسواق والمؤسسات المالية في المصارف والبنوك، بما يطور فهم الوساطة والائتمان والسيولة أو يقدم تفسيرًا أو أداة أو توصية قابلة للتقييم في المخاطر والرقابة المصرفية.

يمكن أن تكون الأطروحة تقليدية أو قائمة على أوراق منشورة أو مشروعًا مهنيًا موثقًا، لكن يجب أن تكون وحدة المساهمة واضحة، وأن يفصل الباحث بين ما أثبته وما استنتجه وما اقترحه معياريًا أو تطبيقيًا.

## 11. الإشراف والبيئة البحثية

- قواعد بيانات أسواق وشركات ومصارف موثقة.
- حوسبة كمية وأدوات محاكاة واختبار خلفي.
- إشراف يجمع التمويل والاقتصاد والإحصاء والتنظيم.
- لجنة إشراف تجمع خبرة موضوعية ومنهجية مستقلة.
- خطة لإدارة الوصول والسرية والتخزين الآمن واستمرارية البيانات أو المصادر.

لا تحفظ أسماء المشرفين أو المؤسسات داخل هوية التخصص؛ فهي بيانات برامج جامعية في Phase 11.

## 12. متطلبات البحث والنشر والتدريس

- حلقات بحث وتحديثات دورية للجنة الإشراف.
- توثيق المنهج والبيانات أو النصوص أو الحالات وإجراءات التحليل.
- اختبارات جودة ومتانة أو مقارنة مستقلة تتناسب مع المجال.
- إعداد أوراق أو أدوات أو تقارير قابلة للتحكيم وفق سياسة المؤسسة.
- تدريس أو مساعدة تعليمية أو تدريب مهني في بعض البرامج.

لا توجد أعداد عالمية موحدة للمنشورات أو المؤتمرات أو ساعات التدريس.

## 13. المهارات البحثية والمهنية المتقدمة

- صياغة سؤال بحث أصيل في المصارف والبنوك
- نقد الأدلة والنظريات في الوساطة والائتمان والسيولة
- تطبيق اقتصاد قياسي مالي وسلاسل زمنية ونماذج تسعير ومحاكاة بصورة مستقلة
- إدارة بيانات أو وثائق أو حالات معقدة وضبط جودتها
- تقييم التحيز وعدم اليقين وحدود التعميم أو القياس القانوني
- الكتابة والنشر والعرض والدفاع العلمي
- قيادة تعاون متعدد التخصصات وإدارة مشروع طويل الأجل

## 14. مجالات العمل بعد الدكتوراه

- الجامعات ومراكز التمويل والاقتصاد
- المصارف والأسواق وإدارة الأصول والمخاطر
- البنوك المركزية والهيئات التنظيمية
- التقنية المالية والاستشارات والتحليل

تعتمد ملاءمة المسار على موضوع الأطروحة والمنهج والخبرة وأي اعتماد مهني مستقل.

## 15. أهم الوظائف المرتبطة

| الوظيفة | مدى مناسبة الدكتوراه | الملاحظة |
|---|---|---|
| باحث متخصص في المصارف والبنوك | مناسبة جدًا | تتحدد الهوية الدقيقة بموضوع الأطروحة والمساهمة. |
| باحث تمويل أو محلل كمي متقدم | مناسبة | يحتاج الدور إلى خبرة تطبيقية وتواصل مع الجهات المستفيدة. |
| عضو هيئة أكاديمية | مناسبة | التعيين تنافسي ويتطلب إنتاجًا بحثيًا مستقلًا. |
| ممارس أو خبير معتمد في نشاط منظم | غير كافية وحدها | قد يتطلب ترخيصًا أو اعتمادًا أو خبرة منفصلة. |

## 16. ما بعد الدكتوراه والمسارات اللاحقة

- زمالة ما بعد الدكتوراه في المصارف والبنوك أو مجال قريب.
- مسار أكاديمي في البحث والتدريس والإشراف.
- البحث والاستشارات في مؤسسة عامة أو خاصة أو دولية.
- قيادة برامج بحث أو سياسات أو تحول بعد اكتساب الخبرة.
- ريادة أعمال معرفية أو ممارسة مهنية عند استيفاء الترخيص.

## 17. الدكتوراه المشابهة والفروق

| التخصص أو الدرجة المشابهة | الفرق المختصر |
|---|---|
| التمويل الإسلامي | يتقاطع مع المصارف والبنوك في بعض الأسئلة أو الأدوات، لكنه يختلف في مركز المساهمة الأصلية وحدود المجال. |
| المصارف الإسلامية | يتقاطع مع المصارف والبنوك في بعض الأسئلة أو الأدوات، لكنه يختلف في مركز المساهمة الأصلية وحدود المجال. |
| التمويل الدولي | يتقاطع مع المصارف والبنوك في بعض الأسئلة أو الأدوات، لكنه يختلف في مركز المساهمة الأصلية وحدود المجال. |

## 18. التنبيه الأكاديمي والمهني

> **الدكتوراه لا تمنح ترخيصًا استثماريًا أو مصرفيًا، ولا تضمن عوائد. يجب تجنب التحيز المستقبلي والإفراط في الملاءمة والإفصاح عن تضارب المصالح والمخاطر. جودة الإشراف والبيانات أو المصادر واستقلال البحث أهم من اسم البرنامج وحده.**
