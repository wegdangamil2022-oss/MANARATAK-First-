## 2. طبيعة الدكتوراه وهدفها

تهدف دكتوراه القانون الخاص إلى إعداد باحث قادر على تفسير وتطوير المعرفة المتعلقة بـ العقود والملكية والمسؤولية واستقلال الإرادة وحماية الطرف الضعيف، واختبار علاقتها بـ تنازع المصالح والحقوق الخاصة. ويُتوقع من الباحث تحديد فجوة حقيقية، وصياغة سؤال قابل للفحص، وبناء تصميم يميز بين الوصف والتفسير والسببية أو الحجة المعيارية وفق طبيعة المجال.

تختلف عن الماجستير في أن الطالب يقود برنامجًا بحثيًا مستقلًا، ويطور نظرية أو منهجًا أو دليلًا أو إطارًا جديدًا، ويبرهن حدود الصلاحية والتعميم. لا تشمل هوية التخصص بيانات جامعة أو مشرف أو جهة مهنية أو نظام وطني بعينه.

## 3. أنواع الدكتوراه الشائعة

- دكتوراه بحثية تقليدية قائمة على أطروحة أصلية.
- دكتوراه مهنية أو تطبيقية تعالج مشكلة ممارسة عند توفرها.
- دكتوراه تعاونية مع جهة عامة أو خاصة مع استقلال أكاديمي واضح.
- دكتوراه بالنشر أو مسار مدمج عند توفر النظام المؤسسي.

اسم الدرجة لا ينشئ تخصصًا مستقلًا؛ فقد يطرح المجال ضمن PhD أو DBA أو SJD/JSD أو DPA بحسب النظام.

### الدخول المباشر بعد البكالوريوس عند شيوعه

- بكالوريوس متميز في مجال مرتبط مع خبرة بحثية موثقة.
- إعداد قوي في المناهج الكمية أو النوعية أو القانونية أو التاريخية المطلوبة للمسار.
- مقررات استدراكية عندما تختلف الخلفية عن جوهر التخصص.

### الخبرة أو الترخيص المطلوب للدكتوراه المهنية

- قد تتطلب الصيغة المهنية خبرة عملية موثقة ومسؤولية إدارية أو قانونية أو سياساتية.
- الوصول إلى بيانات مؤسسات أو عملاء أو قضايا أو موظفين يحتاج موافقات وسرية وصلاحيات منفصلة.
- أي ممارسة منظمة تبقى خاضعة للترخيص المحلي ولا تمنحها الدكتوراه تلقائيًا.

## 5. مراحل برنامج الدكتوراه

1. مقررات أو حلقات متقدمة وخطة تعلم فردية.
2. تدريب منهجي في تحليل فقهي للنصوص والأحكام وقانون مقارن وتاريخ قانوني.
3. امتحان شامل أو تأهيلي عند وجوده.
4. مراجعة نقدية للأدبيات وتحديد الفجوة.
5. إعداد المقترح وخطة البيانات أو المصادر والأخلاقيات.
6. الانتقال إلى مرحلة مرشح الدكتوراه بعد موافقة اللجنة.
7. تنفيذ البحث باستخدام بحث قانوني تجريبي وتحليل مؤسسات وسياسات ومقابلات عند الملاءمة.
8. اختبارات التحقق والمتانة أو المقارنة القانونية والتاريخية.
9. كتابة الأطروحة ومناقشتها والدفاع عنها.
10. الإيداع واستكمال متطلبات النزاهة والبيانات والتخرج.

## 6. المعرفة والمقررات المتقدمة

### المعرفة النظرية المتقدمة

- مصادر القانون وتفسير النصوص والمبادئ.
- الحقوق والالتزامات والسلطة والمساءلة.
- المؤسسات والإجراءات والإنفاذ.
- التفاعل بين القانون والمجتمع والاقتصاد والتقنية.
- الأدبيات والاتجاهات المعاصرة في العقود والملكية والمسؤولية واستقلال الإرادة وحماية الطرف الضعيف.
- نقد الافتراضات والقياس والتفسير وحدود النقل بين الأنظمة والسياقات.

### مناهج البحث والتحليل

- تحليل فقهي للنصوص والأحكام.
- قانون مقارن وتاريخ قانوني.
- بحث قانوني تجريبي.
- تحليل مؤسسات وسياسات ومقابلات.
- مراجعات منهجية أو مقارنات معيارية وربط النتائج بأدلة مستقلة.

### الأخلاقيات والنزاهة العلمية

- الموافقات الأخلاقية قبل جمع بيانات الأفراد أو المؤسسات أو القضايا الحساسة.
- حماية الخصوصية والسرية التجارية أو القانونية أو الدبلوماسية.
- الإفصاح عن التمويل والمصالح المهنية والسياسية والمالية.
- توثيق المصادر والتحويلات والشفرة أو بروتوكول التحليل.
- عدم استخدام البحث للإضرار بالمشاركين أو التأثير غير المشروع في قرار مهني أو قضائي أو سياسي.

## 7. مجالات البحث والتخصصات الدقيقة

- العقود والملكية والمسؤولية
- استقلال الإرادة وحماية الطرف الضعيف
- تنازع المصالح والحقوق الخاصة
- المقارنة والتطور التاريخي
- الإنفاذ والوصول إلى العدالة
- التقنية والحقوق والسياسات

تُحفظ هذه المجالات كعلاقات أو تركيزات بحثية، ولا تتحول تلقائيًا إلى تخصصات مستقلة دون مراجعة Academic Taxonomy.

## 8. الامتحان التأهيلي أو الشامل عند وجوده

قد يختبر الامتحان الفهم المتقدم لـ العقود والملكية والمسؤولية واستقلال الإرادة وحماية الطرف الضعيف، والقدرة على نقد نظرية أو دراسة أو حكم أو سياسة أو مجموعة بيانات، وتصميم بحث يستخدم تحليل فقهي للنصوص والأحكام وقانون مقارن وتاريخ قانوني مع تبرير الوحدة التحليلية والعينة أو المصادر والتحقق.

قد يكون تحريريًا أو شفهيًا أو دفاعًا عن مقترح أولي، وتختلف صيغته وتبعات النجاح أو الإخفاق بين الجامعات والأنظمة.

## 9. مقترح البحث ومرحلة الترشح

يحدد المقترح مشكلة أصلية في العقود والملكية والمسؤولية أو استقلال الإرادة وحماية الطرف الضعيف، ويعرض سؤال البحث أو الفرضيات أو الأطروحة القانونية، ويبرر استخدام تحليل فقهي للنصوص والأحكام وقانون مقارن وتاريخ قانوني. كما يحدد وحدة التحليل أو المؤسسات أو الأسواق أو النصوص أو الحالات والفترة الزمنية والنطاق الجغرافي أو القانوني.

يجب أن يتضمن خطة للبيانات والمصادر والجودة والأخلاقيات والمخاطر والموارد والجدول الزمني، ومعايير مسبقة للتحقق أو المقارنة، وخطة بديلة إذا تعذر الوصول إلى بيانات أو مؤسسة أو وثيقة أساسية.

## 10. الأطروحة والمساهمة الأصلية

قد تتمثل المساهمة الأصلية في تفسيرًا قانونيًا أصيلًا أو إطارًا مقارنًا أو اقتراحًا تشريعيًا مدعومًا بالأدلة في القانون الخاص، بما يطور فهم العقود والملكية والمسؤولية أو يقدم تفسيرًا أو أداة أو توصية قابلة للتقييم في استقلال الإرادة وحماية الطرف الضعيف.

يمكن أن تكون الأطروحة تقليدية أو قائمة على أوراق منشورة أو مشروعًا مهنيًا موثقًا، لكن يجب أن تكون وحدة المساهمة واضحة، وأن يفصل الباحث بين ما أثبته وما استنتجه وما اقترحه معياريًا أو تطبيقيًا.

## 11. الإشراف والبيئة البحثية

- قواعد تشريعات وأحكام ومعاهدات موثقة.
- وصول قانوني إلى وثائق أو مقابلات حساسة.
- إشراف يراعي النظام القانوني والمنهج المقارن أو التجريبي.
- لجنة إشراف تجمع خبرة موضوعية ومنهجية مستقلة.
- خطة لإدارة الوصول والسرية والتخزين الآمن واستمرارية البيانات أو المصادر.

لا تحفظ أسماء المشرفين أو المؤسسات داخل هوية التخصص؛ فهي بيانات برامج جامعية في Phase 11.

## 12. متطلبات البحث والنشر والتدريس

- حلقات بحث وتحديثات دورية للجنة الإشراف.
- توثيق المنهج والبيانات أو النصوص أو الحالات وإجراءات التحليل.
- اختبارات جودة ومتانة أو مقارنة مستقلة تتناسب مع المجال.
- إعداد أوراق أو أدوات أو تقارير قابلة للتحكيم وفق سياسة المؤسسة.
- تدريس أو مساعدة تعليمية أو تدريب مهني في بعض البرامج.

لا توجد أعداد عالمية موحدة للمنشورات أو المؤتمرات أو ساعات التدريس.

## 13. المهارات البحثية والمهنية المتقدمة

- صياغة سؤال بحث أصيل في القانون الخاص
- نقد الأدلة والنظريات في العقود والملكية والمسؤولية
- تطبيق تحليل فقهي للنصوص والأحكام وقانون مقارن وتاريخ قانوني بصورة مستقلة
- إدارة بيانات أو وثائق أو حالات معقدة وضبط جودتها
- تقييم التحيز وعدم اليقين وحدود التعميم أو القياس القانوني
- الكتابة والنشر والعرض والدفاع العلمي
- قيادة تعاون متعدد التخصصات وإدارة مشروع طويل الأجل

## 14. مجالات العمل بعد الدكتوراه

- الجامعات وكليات القانون
- مراكز الدراسات والتشريع والسياسات
- المنظمات الدولية والهيئات التنظيمية
- الاستشارات القانونية والبحث والتحكيم وفق الترخيص

تعتمد ملاءمة المسار على موضوع الأطروحة والمنهج والخبرة وأي اعتماد مهني مستقل.

## 16. ما بعد الدكتوراه والمسارات اللاحقة

- زمالة ما بعد الدكتوراه في القانون الخاص أو مجال قريب.
- مسار أكاديمي في البحث والتدريس والإشراف.
- البحث والاستشارات في مؤسسة عامة أو خاصة أو دولية.
- قيادة برامج بحث أو سياسات أو تحول بعد اكتساب الخبرة.
- ريادة أعمال معرفية أو ممارسة مهنية عند استيفاء الترخيص.

## 18. التنبيه الأكاديمي والمهني

> **الدكتوراه البحثية لا تمنح حق مزاولة المحاماة أو القضاء أو الإفتاء القانوني. يجب تحديد النظام القانوني والزمن والنطاق وعدم تقديم المحتوى الأكاديمي كاستشارة قانونية. جودة الإشراف والبيانات أو المصادر واستقلال البحث أهم من اسم البرنامج وحده.**

## 2. طبيعة الدكتوراه وهدفها

تهدف دكتوراه القانون التجاري إلى إعداد باحث قادر على تفسير وتطوير المعرفة المتعلقة بـ المعاملات والتجار والعقود والشركات والإفلاس والأوراق، واختبار علاقتها بـ التجارة الرقمية والدولية. ويُتوقع من الباحث تحديد فجوة حقيقية، وصياغة سؤال قابل للفحص، وبناء تصميم يميز بين الوصف والتفسير والسببية أو الحجة المعيارية وفق طبيعة المجال.

تختلف عن الماجستير في أن الطالب يقود برنامجًا بحثيًا مستقلًا، ويطور نظرية أو منهجًا أو دليلًا أو إطارًا جديدًا، ويبرهن حدود الصلاحية والتعميم. لا تشمل هوية التخصص بيانات جامعة أو مشرف أو جهة مهنية أو نظام وطني بعينه.

- قد تتطلب الصيغة المهنية خبرة عملية موثقة ومسؤولية إدارية أو قانونية أو سياساتية.
- الوصول إلى بيانات مؤسسات أو عملاء أو قضايا أو موظفين يحتاج موافقات وسرية وصلاحيات منفصلة.
- أي ممارسة منظمة تبقى خاضعة للترخيص المحلي ولا تمنحها الدكتوراه تلقائيًا.

## 5. مراحل برنامج الدكتوراه

1. مقررات أو حلقات متقدمة وخطة تعلم فردية.
2. تدريب منهجي في تحليل فقهي للنصوص والأحكام وقانون مقارن وتاريخ قانوني.
3. امتحان شامل أو تأهيلي عند وجوده.
4. مراجعة نقدية للأدبيات وتحديد الفجوة.
5. إعداد المقترح وخطة البيانات أو المصادر والأخلاقيات.
6. الانتقال إلى مرحلة مرشح الدكتوراه بعد موافقة اللجنة.
7. تنفيذ البحث باستخدام بحث قانوني تجريبي وتحليل مؤسسات وسياسات ومقابلات عند الملاءمة.
8. اختبارات التحقق والمتانة أو المقارنة القانونية والتاريخية.
9. كتابة الأطروحة ومناقشتها والدفاع عنها.
10. الإيداع واستكمال متطلبات النزاهة والبيانات والتخرج.

- نقد الافتراضات والقياس والتفسير وحدود النقل بين الأنظمة والسياقات.

### مناهج البحث والتحليل

## 8. الامتحان التأهيلي أو الشامل عند وجوده

قد يختبر الامتحان الفهم المتقدم لـ مصادر القانون الدولي ومسؤولية الدول والمعاهدات والمنظمات والاختصاص، والقدرة على نقد نظرية أو دراسة أو حكم أو سياسة أو مجموعة بيانات، وتصميم بحث يستخدم تحليل فقهي للنصوص والأحكام وقانون مقارن وتاريخ قانوني مع تبرير الوحدة التحليلية والعينة أو المصادر والتحقق.

قد يكون تحريريًا أو شفهيًا أو دفاعًا عن مقترح أولي، وتختلف صيغته وتبعات النجاح أو الإخفاق بين الجامعات والأنظمة.

## 9. مقترح البحث ومرحلة الترشح

يحدد المقترح مشكلة أصلية في مصادر القانون الدولي ومسؤولية الدول أو المعاهدات والمنظمات والاختصاص، ويعرض سؤال البحث أو الفرضيات أو الأطروحة القانونية، ويبرر استخدام تحليل فقهي للنصوص والأحكام وقانون مقارن وتاريخ قانوني. كما يحدد وحدة التحليل أو المؤسسات أو الأسواق أو النصوص أو الحالات والفترة الزمنية والنطاق الجغرافي أو القانوني.

يجب أن يتضمن خطة للبيانات والمصادر والجودة والأخلاقيات والمخاطر والموارد والجدول الزمني، ومعايير مسبقة للتحقق أو المقارنة، وخطة بديلة إذا تعذر الوصول إلى بيانات أو مؤسسة أو وثيقة أساسية.

## 10. الأطروحة والمساهمة الأصلية

قد تتمثل المساهمة الأصلية في تفسيرًا قانونيًا أصيلًا أو إطارًا مقارنًا أو اقتراحًا تشريعيًا مدعومًا بالأدلة في القانون الدولي، بما يطور فهم مصادر القانون الدولي ومسؤولية الدول أو يقدم تفسيرًا أو أداة أو توصية قابلة للتقييم في المعاهدات والمنظمات والاختصاص.

يمكن أن تكون الأطروحة تقليدية أو قائمة على أوراق منشورة أو مشروعًا مهنيًا موثقًا، لكن يجب أن تكون وحدة المساهمة واضحة، وأن يفصل الباحث بين ما أثبته وما استنتجه وما اقترحه معياريًا أو تطبيقيًا.

## 11. الإشراف والبيئة البحثية

- قواعد تشريعات وأحكام ومعاهدات موثقة.
- وصول قانوني إلى وثائق أو مقابلات حساسة.
- إشراف يراعي النظام القانوني والمنهج المقارن أو التجريبي.
- لجنة إشراف تجمع خبرة موضوعية ومنهجية مستقلة.
- خطة لإدارة الوصول والسرية والتخزين الآمن واستمرارية البيانات أو المصادر.

لا تحفظ أسماء المشرفين أو المؤسسات داخل هوية التخصص؛ فهي بيانات برامج جامعية في Phase 11.

## 12. متطلبات البحث والنشر والتدريس

- حلقات بحث وتحديثات دورية للجنة الإشراف.
- توثيق المنهج والبيانات أو النصوص أو الحالات وإجراءات التحليل.
- اختبارات جودة ومتانة أو مقارنة مستقلة تتناسب مع المجال.
- إعداد أوراق أو أدوات أو تقارير قابلة للتحكيم وفق سياسة المؤسسة.
- تدريس أو مساعدة تعليمية أو تدريب مهني في بعض البرامج.

لا توجد أعداد عالمية موحدة للمنشورات أو المؤتمرات أو ساعات التدريس.

## 13. المهارات البحثية والمهنية المتقدمة

- صياغة سؤال بحث أصيل في القانون الدولي
- نقد الأدلة والنظريات في مصادر القانون الدولي ومسؤولية الدول

## 2. طبيعة الدكتوراه وهدفها

تهدف دكتوراه القانون الدولي الإنساني إلى إعداد باحث قادر على تفسير وتطوير المعرفة المتعلقة بـ قواعد النزاعات المسلحة وحماية المدنيين والمقاتلين، واختبار علاقتها بـ المساءلة والأسلحة والاحتلال. ويُتوقع من الباحث تحديد فجوة حقيقية، وصياغة سؤال قابل للفحص، وبناء تصميم يميز بين الوصف والتفسير والسببية أو الحجة المعيارية وفق طبيعة المجال.

تختلف عن الماجستير في أن الطالب يقود برنامجًا بحثيًا مستقلًا، ويطور نظرية أو منهجًا أو دليلًا أو إطارًا جديدًا، ويبرهن حدود الصلاحية والتعميم. لا تشمل هوية التخصص بيانات جامعة أو مشرف أو جهة مهنية أو نظام وطني بعينه.

## 3. أنواع الدكتوراه الشائعة

- دكتوراه بحثية تقليدية قائمة على أطروحة أصلية.
- دكتوراه مهنية أو تطبيقية تعالج مشكلة ممارسة عند توفرها.
- دكتوراه تعاونية مع جهة عامة أو خاصة مع استقلال أكاديمي واضح.
- دكتوراه بالنشر أو مسار مدمج عند توفر النظام المؤسسي.

اسم الدرجة لا ينشئ تخصصًا مستقلًا؛ فقد يطرح المجال ضمن PhD أو DBA أو SJD/JSD أو DPA بحسب النظام.

- عدم استخدام البحث للإضرار بالمشاركين أو التأثير غير المشروع في قرار مهني أو قضائي أو سياسي.

## 7. مجالات البحث والتخصصات الدقيقة

## 8. الامتحان التأهيلي أو الشامل عند وجوده

قد يختبر الامتحان الفهم المتقدم لـ قواعد النزاعات المسلحة وحماية المدنيين والمقاتلين، والقدرة على نقد نظرية أو دراسة أو حكم أو سياسة أو مجموعة بيانات، وتصميم بحث يستخدم تحليل فقهي للنصوص والأحكام وقانون مقارن وتاريخ قانوني مع تبرير الوحدة التحليلية والعينة أو المصادر والتحقق.

قد يكون تحريريًا أو شفهيًا أو دفاعًا عن مقترح أولي، وتختلف صيغته وتبعات النجاح أو الإخفاق بين الجامعات والأنظمة.

## 9. مقترح البحث ومرحلة الترشح

يحدد المقترح مشكلة أصلية في قواعد النزاعات المسلحة أو حماية المدنيين والمقاتلين، ويعرض سؤال البحث أو الفرضيات أو الأطروحة القانونية، ويبرر استخدام تحليل فقهي للنصوص والأحكام وقانون مقارن وتاريخ قانوني. كما يحدد وحدة التحليل أو المؤسسات أو الأسواق أو النصوص أو الحالات والفترة الزمنية والنطاق الجغرافي أو القانوني.

يمكن أن تكون الأطروحة تقليدية أو قائمة على أوراق منشورة أو مشروعًا مهنيًا موثقًا، لكن يجب أن تكون وحدة المساهمة واضحة، وأن يفصل الباحث بين ما أثبته وما استنتجه وما اقترحه معياريًا أو تطبيقيًا.

لا توجد أعداد عالمية موحدة للمنشورات أو المؤتمرات أو ساعات التدريس.

## 2. طبيعة الدكتوراه وهدفها

تهدف دكتوراه القانون الجنائي إلى إعداد باحث قادر على تفسير وتطوير المعرفة المتعلقة بـ التجريم والمسؤولية والعقوبة والإجراءات والأدلة الجنائية، واختبار علاقتها بـ السياسة الجنائية وحقوق المتهم والضحية. ويُتوقع من الباحث تحديد فجوة حقيقية، وصياغة سؤال قابل للفحص، وبناء تصميم يميز بين الوصف والتفسير والسببية أو الحجة المعيارية وفق طبيعة المجال.

تختلف عن الماجستير في أن الطالب يقود برنامجًا بحثيًا مستقلًا، ويطور نظرية أو منهجًا أو دليلًا أو إطارًا جديدًا، ويبرهن حدود الصلاحية والتعميم. لا تشمل هوية التخصص بيانات جامعة أو مشرف أو جهة مهنية أو نظام وطني بعينه.

## 3. أنواع الدكتوراه الشائعة

- دكتوراه بحثية تقليدية قائمة على أطروحة أصلية.
- دكتوراه مهنية أو تطبيقية تعالج مشكلة ممارسة عند توفرها.
- دكتوراه تعاونية مع جهة عامة أو خاصة مع استقلال أكاديمي واضح.
- دكتوراه بالنشر أو مسار مدمج عند توفر النظام المؤسسي.

اسم الدرجة لا ينشئ تخصصًا مستقلًا؛ فقد يطرح المجال ضمن PhD أو DBA أو SJD/JSD أو DPA بحسب النظام.

## 10. الأطروحة والمساهمة الأصلية

يمكن أن تكون الأطروحة تقليدية أو قائمة على أوراق منشورة أو مشروعًا مهنيًا موثقًا، لكن يجب أن تكون وحدة المساهمة واضحة، وأن يفصل الباحث بين ما أثبته وما استنتجه وما اقترحه معياريًا أو تطبيقيًا.

## 11. الإشراف والبيئة البحثية

- قواعد تشريعات وأحكام ومعاهدات موثقة.
- وصول قانوني إلى وثائق أو مقابلات حساسة.
- إشراف يراعي النظام القانوني والمنهج المقارن أو التجريبي.
- لجنة إشراف تجمع خبرة موضوعية ومنهجية مستقلة.
- خطة لإدارة الوصول والسرية والتخزين الآمن واستمرارية البيانات أو المصادر.

لا تحفظ أسماء المشرفين أو المؤسسات داخل هوية التخصص؛ فهي بيانات برامج جامعية في Phase 11.

## 12. متطلبات البحث والنشر والتدريس

- حلقات بحث وتحديثات دورية للجنة الإشراف.
- توثيق المنهج والبيانات أو النصوص أو الحالات وإجراءات التحليل.
- اختبارات جودة ومتانة أو مقارنة مستقلة تتناسب مع المجال.
- إعداد أوراق أو أدوات أو تقارير قابلة للتحكيم وفق سياسة المؤسسة.
- تدريس أو مساعدة تعليمية أو تدريب مهني في بعض البرامج.

لا توجد أعداد عالمية موحدة للمنشورات أو المؤتمرات أو ساعات التدريس.

## 13. المهارات البحثية والمهنية المتقدمة

- صياغة سؤال بحث أصيل في القانون الجنائي

## 2. طبيعة الدكتوراه وهدفها

تهدف دكتوراه القانون الدستوري إلى إعداد باحث قادر على تفسير وتطوير المعرفة المتعلقة بـ تصميم الدساتير وفصل السلطات والحقوق والحريات والرقابة، واختبار علاقتها بـ الانتقال الدستوري والفيدرالية. ويُتوقع من الباحث تحديد فجوة حقيقية، وصياغة سؤال قابل للفحص، وبناء تصميم يميز بين الوصف والتفسير والسببية أو الحجة المعيارية وفق طبيعة المجال.

تختلف عن الماجستير في أن الطالب يقود برنامجًا بحثيًا مستقلًا، ويطور نظرية أو منهجًا أو دليلًا أو إطارًا جديدًا، ويبرهن حدود الصلاحية والتعميم. لا تشمل هوية التخصص بيانات جامعة أو مشرف أو جهة مهنية أو نظام وطني بعينه.

## 3. أنواع الدكتوراه الشائعة

- دكتوراه بحثية تقليدية قائمة على أطروحة أصلية.
- دكتوراه مهنية أو تطبيقية تعالج مشكلة ممارسة عند توفرها.
- دكتوراه تعاونية مع جهة عامة أو خاصة مع استقلال أكاديمي واضح.
- دكتوراه بالنشر أو مسار مدمج عند توفر النظام المؤسسي.

اسم الدرجة لا ينشئ تخصصًا مستقلًا؛ فقد يطرح المجال ضمن PhD أو DBA أو SJD/JSD أو DPA بحسب النظام.

### الخبرة أو الترخيص المطلوب للدكتوراه المهنية

- قد تتطلب الصيغة المهنية خبرة عملية موثقة ومسؤولية إدارية أو قانونية أو سياساتية.
- الوصول إلى بيانات مؤسسات أو عملاء أو قضايا أو موظفين يحتاج موافقات وسرية وصلاحيات منفصلة.
- أي ممارسة منظمة تبقى خاضعة للترخيص المحلي ولا تمنحها الدكتوراه تلقائيًا.

## 5. مراحل برنامج الدكتوراه

1. مقررات أو حلقات متقدمة وخطة تعلم فردية.
2. تدريب منهجي في تحليل فقهي للنصوص والأحكام وقانون مقارن وتاريخ قانوني.
3. امتحان شامل أو تأهيلي عند وجوده.
4. مراجعة نقدية للأدبيات وتحديد الفجوة.
5. إعداد المقترح وخطة البيانات أو المصادر والأخلاقيات.
6. الانتقال إلى مرحلة مرشح الدكتوراه بعد موافقة اللجنة.
7. تنفيذ البحث باستخدام بحث قانوني تجريبي وتحليل مؤسسات وسياسات ومقابلات عند الملاءمة.
8. اختبارات التحقق والمتانة أو المقارنة القانونية والتاريخية.
9. كتابة الأطروحة ومناقشتها والدفاع عنها.
10. الإيداع واستكمال متطلبات النزاهة والبيانات والتخرج.

قد يكون تحريريًا أو شفهيًا أو دفاعًا عن مقترح أولي، وتختلف صيغته وتبعات النجاح أو الإخفاق بين الجامعات والأنظمة.

## 9. مقترح البحث ومرحلة الترشح

## 2. طبيعة الدكتوراه وهدفها

تهدف دكتوراه القانون الإداري إلى إعداد باحث قادر على تفسير وتطوير المعرفة المتعلقة بـ القرار الإداري والضبط والمرافق والعقود العامة، واختبار علاقتها بـ القضاء الإداري والمساءلة. ويُتوقع من الباحث تحديد فجوة حقيقية، وصياغة سؤال قابل للفحص، وبناء تصميم يميز بين الوصف والتفسير والسببية أو الحجة المعيارية وفق طبيعة المجال.

تختلف عن الماجستير في أن الطالب يقود برنامجًا بحثيًا مستقلًا، ويطور نظرية أو منهجًا أو دليلًا أو إطارًا جديدًا، ويبرهن حدود الصلاحية والتعميم. لا تشمل هوية التخصص بيانات جامعة أو مشرف أو جهة مهنية أو نظام وطني بعينه.

## 3. أنواع الدكتوراه الشائعة

- دكتوراه بحثية تقليدية قائمة على أطروحة أصلية.
- دكتوراه مهنية أو تطبيقية تعالج مشكلة ممارسة عند توفرها.
- دكتوراه تعاونية مع جهة عامة أو خاصة مع استقلال أكاديمي واضح.
- دكتوراه بالنشر أو مسار مدمج عند توفر النظام المؤسسي.

اسم الدرجة لا ينشئ تخصصًا مستقلًا؛ فقد يطرح المجال ضمن PhD أو DBA أو SJD/JSD أو DPA بحسب النظام.

## 2. طبيعة الدكتوراه وهدفها

تهدف دكتوراه القانون المدني إلى إعداد باحث قادر على تفسير وتطوير المعرفة المتعلقة بـ الالتزامات والعقود والتعويض والملكية والحقوق العينية، واختبار علاقتها بـ الأحوال والمعاملات المدنية. ويُتوقع من الباحث تحديد فجوة حقيقية، وصياغة سؤال قابل للفحص، وبناء تصميم يميز بين الوصف والتفسير والسببية أو الحجة المعيارية وفق طبيعة المجال.

تختلف عن الماجستير في أن الطالب يقود برنامجًا بحثيًا مستقلًا، ويطور نظرية أو منهجًا أو دليلًا أو إطارًا جديدًا، ويبرهن حدود الصلاحية والتعميم. لا تشمل هوية التخصص بيانات جامعة أو مشرف أو جهة مهنية أو نظام وطني بعينه.

## 3. أنواع الدكتوراه الشائعة

- دكتوراه بحثية تقليدية قائمة على أطروحة أصلية.
- دكتوراه مهنية أو تطبيقية تعالج مشكلة ممارسة عند توفرها.
- دكتوراه تعاونية مع جهة عامة أو خاصة مع استقلال أكاديمي واضح.
- دكتوراه بالنشر أو مسار مدمج عند توفر النظام المؤسسي.

اسم الدرجة لا ينشئ تخصصًا مستقلًا؛ فقد يطرح المجال ضمن PhD أو DBA أو SJD/JSD أو DPA بحسب النظام.

## 5. مراحل برنامج الدكتوراه

1. مقررات أو حلقات متقدمة وخطة تعلم فردية.
2. تدريب منهجي في تحليل فقهي للنصوص والأحكام وقانون مقارن وتاريخ قانوني.
3. امتحان شامل أو تأهيلي عند وجوده.
4. مراجعة نقدية للأدبيات وتحديد الفجوة.
5. إعداد المقترح وخطة البيانات أو المصادر والأخلاقيات.
6. الانتقال إلى مرحلة مرشح الدكتوراه بعد موافقة اللجنة.
7. تنفيذ البحث باستخدام بحث قانوني تجريبي وتحليل مؤسسات وسياسات ومقابلات عند الملاءمة.
8. اختبارات التحقق والمتانة أو المقارنة القانونية والتاريخية.
9. كتابة الأطروحة ومناقشتها والدفاع عنها.
10. الإيداع واستكمال متطلبات النزاهة والبيانات والتخرج.

- نقد الافتراضات والقياس والتفسير وحدود النقل بين الأنظمة والسياقات.

### مناهج البحث والتحليل

- تحليل فقهي للنصوص والأحكام.

- عدم استخدام البحث للإضرار بالمشاركين أو التأثير غير المشروع في قرار مهني أو قضائي أو سياسي.

## 8. الامتحان التأهيلي أو الشامل عند وجوده

قد يختبر الامتحان الفهم المتقدم لـ الالتزامات والعقود والتعويض والملكية والحقوق العينية، والقدرة على نقد نظرية أو دراسة أو حكم أو سياسة أو مجموعة بيانات، وتصميم بحث يستخدم تحليل فقهي للنصوص والأحكام وقانون مقارن وتاريخ قانوني مع تبرير الوحدة التحليلية والعينة أو المصادر والتحقق.

قد يكون تحريريًا أو شفهيًا أو دفاعًا عن مقترح أولي، وتختلف صيغته وتبعات النجاح أو الإخفاق بين الجامعات والأنظمة.

## 9. مقترح البحث ومرحلة الترشح

يحدد المقترح مشكلة أصلية في الالتزامات والعقود والتعويض أو الملكية والحقوق العينية، ويعرض سؤال البحث أو الفرضيات أو الأطروحة القانونية، ويبرر استخدام تحليل فقهي للنصوص والأحكام وقانون مقارن وتاريخ قانوني. كما يحدد وحدة التحليل أو المؤسسات أو الأسواق أو النصوص أو الحالات والفترة الزمنية والنطاق الجغرافي أو القانوني.

يجب أن يتضمن خطة للبيانات والمصادر والجودة والأخلاقيات والمخاطر والموارد والجدول الزمني، ومعايير مسبقة للتحقق أو المقارنة، وخطة بديلة إذا تعذر الوصول إلى بيانات أو مؤسسة أو وثيقة أساسية.

## 10. الأطروحة والمساهمة الأصلية

قد تتمثل المساهمة الأصلية في تفسيرًا قانونيًا أصيلًا أو إطارًا مقارنًا أو اقتراحًا تشريعيًا مدعومًا بالأدلة في القانون المدني، بما يطور فهم الالتزامات والعقود والتعويض أو يقدم تفسيرًا أو أداة أو توصية قابلة للتقييم في الملكية والحقوق العينية.

يمكن أن تكون الأطروحة تقليدية أو قائمة على أوراق منشورة أو مشروعًا مهنيًا موثقًا، لكن يجب أن تكون وحدة المساهمة واضحة، وأن يفصل الباحث بين ما أثبته وما استنتجه وما اقترحه معياريًا أو تطبيقيًا.

## 11. الإشراف والبيئة البحثية

- قواعد تشريعات وأحكام ومعاهدات موثقة.
- وصول قانوني إلى وثائق أو مقابلات حساسة.
- إشراف يراعي النظام القانوني والمنهج المقارن أو التجريبي.
- لجنة إشراف تجمع خبرة موضوعية ومنهجية مستقلة.
- خطة لإدارة الوصول والسرية والتخزين الآمن واستمرارية البيانات أو المصادر.

لا تحفظ أسماء المشرفين أو المؤسسات داخل هوية التخصص؛ فهي بيانات برامج جامعية في Phase 11.

## 12. متطلبات البحث والنشر والتدريس

- حلقات بحث وتحديثات دورية للجنة الإشراف.
- توثيق المنهج والبيانات أو النصوص أو الحالات وإجراءات التحليل.
- اختبارات جودة ومتانة أو مقارنة مستقلة تتناسب مع المجال.
- إعداد أوراق أو أدوات أو تقارير قابلة للتحكيم وفق سياسة المؤسسة.
- تدريس أو مساعدة تعليمية أو تدريب مهني في بعض البرامج.

لا توجد أعداد عالمية موحدة للمنشورات أو المؤتمرات أو ساعات التدريس.

## 13. المهارات البحثية والمهنية المتقدمة

- صياغة سؤال بحث أصيل في القانون المدني
- نقد الأدلة والنظريات في الالتزامات والعقود والتعويض
- تطبيق تحليل فقهي للنصوص والأحكام وقانون مقارن وتاريخ قانوني بصورة مستقلة
- إدارة بيانات أو وثائق أو حالات معقدة وضبط جودتها
- تقييم التحيز وعدم اليقين وحدود التعميم أو القياس القانوني
- الكتابة والنشر والعرض والدفاع العلمي
- قيادة تعاون متعدد التخصصات وإدارة مشروع طويل الأجل

## 2. طبيعة الدكتوراه وهدفها

تهدف دكتوراه القانون البحري إلى إعداد باحث قادر على تفسير وتطوير المعرفة المتعلقة بـ السفن والنقل البحري والتأمين والحوادث والمسؤولية، واختبار علاقتها بـ الموانئ والبيئة والحدود البحرية. ويُتوقع من الباحث تحديد فجوة حقيقية، وصياغة سؤال قابل للفحص، وبناء تصميم يميز بين الوصف والتفسير والسببية أو الحجة المعيارية وفق طبيعة المجال.

تختلف عن الماجستير في أن الطالب يقود برنامجًا بحثيًا مستقلًا، ويطور نظرية أو منهجًا أو دليلًا أو إطارًا جديدًا، ويبرهن حدود الصلاحية والتعميم. لا تشمل هوية التخصص بيانات جامعة أو مشرف أو جهة مهنية أو نظام وطني بعينه.

- المؤسسات والإجراءات والإنفاذ.
- التفاعل بين القانون والمجتمع والاقتصاد والتقنية.
- الأدبيات والاتجاهات المعاصرة في السفن والنقل البحري والتأمين والحوادث والمسؤولية.
- نقد الافتراضات والقياس والتفسير وحدود النقل بين الأنظمة والسياقات.

### مناهج البحث والتحليل

- تحليل فقهي للنصوص والأحكام.
- قانون مقارن وتاريخ قانوني.
- بحث قانوني تجريبي.
- تحليل مؤسسات وسياسات ومقابلات.
- مراجعات منهجية أو مقارنات معيارية وربط النتائج بأدلة مستقلة.

### الأخلاقيات والنزاهة العلمية

- الموافقات الأخلاقية قبل جمع بيانات الأفراد أو المؤسسات أو القضايا الحساسة.
- حماية الخصوصية والسرية التجارية أو القانونية أو الدبلوماسية.
- الإفصاح عن التمويل والمصالح المهنية والسياسية والمالية.
- توثيق المصادر والتحويلات والشفرة أو بروتوكول التحليل.
- عدم استخدام البحث للإضرار بالمشاركين أو التأثير غير المشروع في قرار مهني أو قضائي أو سياسي.

## 7. مجالات البحث والتخصصات الدقيقة

- السفن والنقل البحري
- التأمين والحوادث والمسؤولية
- الموانئ والبيئة والحدود البحرية
- المقارنة والتطور التاريخي
- الإنفاذ والوصول إلى العدالة
- التقنية والحقوق والسياسات

تُحفظ هذه المجالات كعلاقات أو تركيزات بحثية، ولا تتحول تلقائيًا إلى تخصصات مستقلة دون مراجعة Academic Taxonomy.

## 8. الامتحان التأهيلي أو الشامل عند وجوده

قد يختبر الامتحان الفهم المتقدم لـ السفن والنقل البحري والتأمين والحوادث والمسؤولية، والقدرة على نقد نظرية أو دراسة أو حكم أو سياسة أو مجموعة بيانات، وتصميم بحث يستخدم تحليل فقهي للنصوص والأحكام وقانون مقارن وتاريخ قانوني مع تبرير الوحدة التحليلية والعينة أو المصادر والتحقق.

قد يكون تحريريًا أو شفهيًا أو دفاعًا عن مقترح أولي، وتختلف صيغته وتبعات النجاح أو الإخفاق بين الجامعات والأنظمة.

## 9. مقترح البحث ومرحلة الترشح

يحدد المقترح مشكلة أصلية في السفن والنقل البحري أو التأمين والحوادث والمسؤولية، ويعرض سؤال البحث أو الفرضيات أو الأطروحة القانونية، ويبرر استخدام تحليل فقهي للنصوص والأحكام وقانون مقارن وتاريخ قانوني. كما يحدد وحدة التحليل أو المؤسسات أو الأسواق أو النصوص أو الحالات والفترة الزمنية والنطاق الجغرافي أو القانوني.

يجب أن يتضمن خطة للبيانات والمصادر والجودة والأخلاقيات والمخاطر والموارد والجدول الزمني، ومعايير مسبقة للتحقق أو المقارنة، وخطة بديلة إذا تعذر الوصول إلى بيانات أو مؤسسة أو وثيقة أساسية.

## 10. الأطروحة والمساهمة الأصلية

قد تتمثل المساهمة الأصلية في تفسيرًا قانونيًا أصيلًا أو إطارًا مقارنًا أو اقتراحًا تشريعيًا مدعومًا بالأدلة في القانون البحري، بما يطور فهم السفن والنقل البحري أو يقدم تفسيرًا أو أداة أو توصية قابلة للتقييم في التأمين والحوادث والمسؤولية.

يمكن أن تكون الأطروحة تقليدية أو قائمة على أوراق منشورة أو مشروعًا مهنيًا موثقًا، لكن يجب أن تكون وحدة المساهمة واضحة، وأن يفصل الباحث بين ما أثبته وما استنتجه وما اقترحه معياريًا أو تطبيقيًا.

## 11. الإشراف والبيئة البحثية

- قواعد تشريعات وأحكام ومعاهدات موثقة.
- وصول قانوني إلى وثائق أو مقابلات حساسة.
- إشراف يراعي النظام القانوني والمنهج المقارن أو التجريبي.
- لجنة إشراف تجمع خبرة موضوعية ومنهجية مستقلة.
- خطة لإدارة الوصول والسرية والتخزين الآمن واستمرارية البيانات أو المصادر.

لا تحفظ أسماء المشرفين أو المؤسسات داخل هوية التخصص؛ فهي بيانات برامج جامعية في Phase 11.

## 12. متطلبات البحث والنشر والتدريس

- حلقات بحث وتحديثات دورية للجنة الإشراف.
- توثيق المنهج والبيانات أو النصوص أو الحالات وإجراءات التحليل.
- اختبارات جودة ومتانة أو مقارنة مستقلة تتناسب مع المجال.
- إعداد أوراق أو أدوات أو تقارير قابلة للتحكيم وفق سياسة المؤسسة.
- تدريس أو مساعدة تعليمية أو تدريب مهني في بعض البرامج.

لا توجد أعداد عالمية موحدة للمنشورات أو المؤتمرات أو ساعات التدريس.

## 13. المهارات البحثية والمهنية المتقدمة

- صياغة سؤال بحث أصيل في القانون البحري
- نقد الأدلة والنظريات في السفن والنقل البحري
- تطبيق تحليل فقهي للنصوص والأحكام وقانون مقارن وتاريخ قانوني بصورة مستقلة
- إدارة بيانات أو وثائق أو حالات معقدة وضبط جودتها
- تقييم التحيز وعدم اليقين وحدود التعميم أو القياس القانوني
- الكتابة والنشر والعرض والدفاع العلمي
- قيادة تعاون متعدد التخصصات وإدارة مشروع طويل الأجل

## 14. مجالات العمل بعد الدكتوراه

- الجامعات وكليات القانون
- مراكز الدراسات والتشريع والسياسات
- المنظمات الدولية والهيئات التنظيمية
- الاستشارات القانونية والبحث والتحكيم وفق الترخيص

تعتمد ملاءمة المسار على موضوع الأطروحة والمنهج والخبرة وأي اعتماد مهني مستقل.

## 15. أهم الوظائف المرتبطة

| الوظيفة | مدى مناسبة الدكتوراه | الملاحظة |
|---|---|---|
| باحث متخصص في القانون البحري | مناسبة جدًا | تتحدد الهوية الدقيقة بموضوع الأطروحة والمساهمة. |
| باحث قانوني أو خبير تشريعات وسياسات | مناسبة | يحتاج الدور إلى خبرة تطبيقية وتواصل مع الجهات المستفيدة. |
| عضو هيئة أكاديمية | مناسبة | التعيين تنافسي ويتطلب إنتاجًا بحثيًا مستقلًا. |
| ممارس أو خبير معتمد في نشاط منظم | غير كافية وحدها | قد يتطلب ترخيصًا أو اعتمادًا أو خبرة منفصلة. |

## 16. ما بعد الدكتوراه والمسارات اللاحقة

- زمالة ما بعد الدكتوراه في القانون البحري أو مجال قريب.
- مسار أكاديمي في البحث والتدريس والإشراف.
- البحث والاستشارات في مؤسسة عامة أو خاصة أو دولية.
- قيادة برامج بحث أو سياسات أو تحول بعد اكتساب الخبرة.
- ريادة أعمال معرفية أو ممارسة مهنية عند استيفاء الترخيص.

## 18. التنبيه الأكاديمي والمهني

> **الدكتوراه البحثية لا تمنح حق مزاولة المحاماة أو القضاء أو الإفتاء القانوني. يجب تحديد النظام القانوني والزمن والنطاق وعدم تقديم المحتوى الأكاديمي كاستشارة قانونية. جودة الإشراف والبيانات أو المصادر واستقلال البحث أهم من اسم البرنامج وحده.**
