# 351. تصميم تجربة المستخدم — User Experience Design

## 1. معلومات تخصص الماجستير الأساسية

| الحقل | التفاصيل |
|---|---|
| الرمز المرجعي | `MAS-0351` |
| الاسم بالعربية | تصميم تجربة المستخدم |
| الاسم بالإنجليزية | User Experience Design |
| التخصص الأساسي المرتبط | تصميم وتقييم تجارب رقمية فعالة وسهلة الاستخدام ومتماسكة عبر المنتجات والخدمات |
| المجال الأكاديمي | كلية الحوسبة وتقنية المعلومات |

| أنواع البرنامج | ماجستير علوم في تصميم تجربة المستخدم، أو مقررات ورسالة، أو مشروع تطبيقي |
| أنماط الدراسة العامة | حضوري أو هجين؛ وتحتاج بعض المسارات إلى مختبرات أو بنية حوسبة متقدمة |
| طبيعة التوفر | بحثي/تطبيقي؛ ويختلف عمق البحث والتطبيق بين المؤسسات |
| الوصف المختصر | برنامج متقدم يركز على تصميم وتقييم تجارب رقمية فعالة وسهلة الاستخدام ومتماسكة عبر المنتجات والخدمات. |

## 2. نبذة عن تخصص الماجستير

يركز ماجستير تصميم تجربة المستخدم على تصميم وتقييم تجارب رقمية فعالة وسهلة الاستخدام ومتماسكة عبر المنتجات والخدمات، وينقل الطالب من المعرفة العامة إلى مستوى أعمق من التحليل والتصميم والتجريب والتطبيق. كما يهتم بجودة البيانات، وقياس النتائج، والتوثيق، والأمن، والمسؤولية المهنية والأخلاقية.

تختلف هوية البرنامج بحسب المؤسسة؛ فقد يكون بحثيًا أو مهنيًا أو تطبيقيًا. ولا تعني درجة الماجستير وحدها الحصول على صلاحيات قانونية أو سريرية أو وصول غير مقيد إلى الأنظمة والبيانات.

- مقررات ورسالة

يركز ماجستير معمارية المؤسسات الرقمية على تصميم البنية المتكاملة للأعمال والبيانات والتطبيقات والتقنية في المؤسسات الرقمية، وينقل الطالب من المعرفة العامة إلى مستوى أعمق من التحليل والتصميم والتجريب والتطبيق. كما يهتم بجودة البيانات، وقياس النتائج، والتوثيق، والأمن، والمسؤولية المهنية والأخلاقية.

- الألعاب والواقع الممتد
- الاستشارات التقنية
- البحث والتعليم

## 11. أهم الوظائف المرتبطة

| الوظيفة | مدى مناسبة الماجستير | الملاحظة المهنية |
|---|---|---|
| أخصائي أو مهندس هندسة المنصات وعمليات التطوير | مناسب | يتطلب مهارات تقنية مرتبطة بالمسار |
| مطوّر أو مهندس أنظمة | مناسب | يركز على البناء والاختبار والنشر |
| محلل أو مسؤول تشغيل | مناسب | يتطلب فهمًا للبيانات والموثوقية |
| باحث حوسبة | مناسب | قد تفضل الدكتوراه للمسار الأكاديمي |

## 12. المسارات الأكاديمية والمهنية اللاحقة

### الدكتوراه المرتبطة

- هندسة المنصات وعمليات التطوير
- علوم الحاسوب
- هندسة البرمجيات والأنظمة
- الأمن السيبراني
- الحوسبة المتقدمة

### الزمالات أو الاعتمادات المهنية المرتبطة

- اعتمادات سحابية أو شبكات أو قواعد بيانات بحسب المسار
- شهادات أمن معلومات عند الصلة
- إدارة المشاريع وDevOps
- زمالات بحثية أو مهنية

## 13. التخصصات المشابهة والفروق

| التخصص المشابه | الفرق المختصر |
|---|---|
| علوم الحاسوب | المظلة الأوسع للخوارزميات والأنظمة والنظرية |
| هندسة البرمجيات | تركز على دورة حياة البرمجيات وجودتها ومعماريتها |
| تقنية المعلومات | تركز على تشغيل وإدارة الخدمات والبنية التقنية |

## 14. العلاقة بتخصصات البكالوريوس

| نوع العلاقة | تخصصات البكالوريوس |
|---|---|
| مرتبطة مباشرة | علوم الحاسوب, تقنية المعلومات, هندسة البرمجيات, هندسة الحاسوب أو نظم المعلومات |
| مقبولة غالبًا | الرياضيات, علوم البيانات, الهندسة الكهربائية, إدارة الأعمال التقنية بحسب التخصص |
| قد تحتاج مقررات استدراكية | الخلفيات الكمية التي تحتاج برمجة وهياكل بيانات, الخلفيات التطبيقية التي تحتاج خوارزميات ونظم حاسوبية |

## 15. التنبيه الأكاديمي والمهني
