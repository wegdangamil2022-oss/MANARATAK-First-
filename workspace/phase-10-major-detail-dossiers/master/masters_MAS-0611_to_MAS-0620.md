# 611. المحاسبة الإدارية — Management Accounting

## 1. معلومات تخصص الماجستير الأساسية

| الحقل | التفاصيل |
|---|---|
| الرمز المرجعي | `MAS-0611` |
| الاسم بالعربية | المحاسبة الإدارية |
| الاسم بالإنجليزية | Management Accounting |
| التخصص الأساسي المرتبط | استخدام معلومات التكلفة والأداء والميزانيات لدعم التخطيط والرقابة والقرار الداخلي |
| المجال الأكاديمي | كلية الاقتصاد والمحاسبة والتمويل |
| مستوى الدرجة | ماجستير — Master |
| أسماء الدرجات الشائعة | MSc / MA / MFin / MAcc |
| المدة الشائعة | سنة إلى سنتين غالبًا، وقد يمتد المسار البحثي أو المهني بحسب المشروع والرسالة |
| أنواع البرنامج | ماجستير مهني أو علوم في المحاسبة الإدارية، أو مقررات ورسالة، أو مشروع تطبيقي |
| أنماط الدراسة العامة | حضوري أو هجين بحسب طبيعة التدريب والمشروع والبيانات المستخدمة |
| طبيعة التوفر | بحثي/مهني؛ ويختلف عمق البحث والتطبيق بين المؤسسات |
| الوصف المختصر | برنامج متقدم يركز على استخدام معلومات التكلفة والأداء والميزانيات لدعم التخطيط والرقابة والقرار الداخلي. |

## 2. نبذة عن تخصص الماجستير

يركز ماجستير المحاسبة الإدارية على استخدام معلومات التكلفة والأداء والميزانيات لدعم التخطيط والرقابة والقرار الداخلي، وينقل الطالب من المعرفة العامة إلى مستوى أعمق من التحليل والتخطيط واتخاذ القرار أو البحث والتطبيق. ويهتم بقياس النتائج، وإدارة المخاطر، واستخدام البيانات، والعمل مع أصحاب المصلحة.

تختلف هوية البرنامج بحسب المؤسسة؛ فقد يكون مهنيًا أو تنفيذيًا أو بحثيًا أو تطبيقيًا. ولا تعني الدرجة وحدها الحصول على ترخيص أو منصب أو صلاحية مهنية مستقلة.

## 3. أنواع البرنامج الشائعة

## 1. معلومات تخصص الماجستير الأساسية

| الحقل | التفاصيل |
|---|---|
| الرمز المرجعي | `MAS-0613` |
| الاسم بالعربية | المحاسبة الجنائية |
| الاسم بالإنجليزية | Forensic Accounting |
| التخصص الأساسي المرتبط | استخدام المحاسبة والتحقيق وتحليل البيانات لكشف الاحتيال والنزاعات والأدلة المالية |
| المجال الأكاديمي | كلية الاقتصاد والمحاسبة والتمويل |
| مستوى الدرجة | ماجستير — Master |
| أسماء الدرجات الشائعة | MSc / MA / MFin / MAcc |
| المدة الشائعة | سنة إلى سنتين غالبًا، وقد يمتد المسار البحثي أو المهني بحسب المشروع والرسالة |
| أنواع البرنامج | ماجستير مهني أو علوم في المحاسبة الجنائية، أو مقررات ورسالة، أو مشروع تطبيقي |
| أنماط الدراسة العامة | حضوري أو هجين بحسب طبيعة التدريب والمشروع والبيانات المستخدمة |
| طبيعة التوفر | بحثي/مهني؛ ويختلف عمق البحث والتطبيق بين المؤسسات |
| الوصف المختصر | برنامج متقدم يركز على استخدام المحاسبة والتحقيق وتحليل البيانات لكشف الاحتيال والنزاعات والأدلة المالية. |

## 2. نبذة عن تخصص الماجستير

يركز ماجستير المحاسبة الجنائية على استخدام المحاسبة والتحقيق وتحليل البيانات لكشف الاحتيال والنزاعات والأدلة المالية، وينقل الطالب من المعرفة العامة إلى مستوى أعمق من التحليل والتخطيط واتخاذ القرار أو البحث والتطبيق. ويهتم بقياس النتائج، وإدارة المخاطر، واستخدام البيانات، والعمل مع أصحاب المصلحة.

تختلف هوية البرنامج بحسب المؤسسة؛ فقد يكون مهنيًا أو تنفيذيًا أو بحثيًا أو تطبيقيًا. ولا تعني الدرجة وحدها الحصول على ترخيص أو منصب أو صلاحية مهنية مستقلة.

## 3. أنواع البرنامج الشائعة

## 2. نبذة عن تخصص الماجستير

يركز ماجستير الضرائب على تحليل وتصميم والامتثال للضرائب على الأفراد والشركات والمعاملات الدولية، وينقل الطالب من المعرفة العامة إلى مستوى أعمق من التحليل والتخطيط واتخاذ القرار أو البحث والتطبيق. ويهتم بقياس النتائج، وإدارة المخاطر، واستخدام البيانات، والعمل مع أصحاب المصلحة.

## 2. نبذة عن تخصص الماجستير

يركز ماجستير المصارف والبنوك على إدارة المؤسسات المصرفية والائتمان والسيولة والمخاطر والعمليات والتنظيم، وينقل الطالب من المعرفة العامة إلى مستوى أعمق من التحليل والتخطيط واتخاذ القرار أو البحث والتطبيق. ويهتم بقياس النتائج، وإدارة المخاطر، واستخدام البيانات، والعمل مع أصحاب المصلحة.

تختلف هوية البرنامج بحسب المؤسسة؛ فقد يكون مهنيًا أو تنفيذيًا أو بحثيًا أو تطبيقيًا. ولا تعني الدرجة وحدها الحصول على ترخيص أو منصب أو صلاحية مهنية مستقلة.
