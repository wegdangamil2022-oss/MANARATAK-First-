# 331. الحوسبة الموزعة — Distributed Computing

## 1. معلومات تخصص الماجستير الأساسية

| الحقل | التفاصيل |
|---|---|
| الرمز المرجعي | `MAS-0331` |
| الاسم بالعربية | الحوسبة الموزعة |
| الاسم بالإنجليزية | Distributed Computing |
| التخصص الأساسي المرتبط | تصميم وتحليل الأنظمة التي تعمل عبر عقد متعددة وتحقق الاتساق والتوافر وتحمل الأعطال |
| المجال الأكاديمي | كلية الحوسبة وتقنية المعلومات |

| أنواع البرنامج | ماجستير علوم في الحوسبة الموزعة، أو مقررات ورسالة، أو مشروع تطبيقي/تصميمي |
| أنماط الدراسة العامة | حضوري غالبًا للمختبر أو الاستوديو أو المشروع؛ وقد تتوفر مقررات نظرية وحاسوبية هجينًا |

## 2. نبذة عن تخصص الماجستير

يركز ماجستير الحوسبة الموزعة على تصميم وتحليل الأنظمة التي تعمل عبر عقد متعددة وتحقق الاتساق والتوافر وتحمل الأعطال، وينقل الطالب من المعرفة العامة إلى مستوى أعمق من التحليل والتصميم أو البرمجة أو البحث والتطبيق. ويجمع عادةً بين أدوات المجال، ودراسة السوابق أو الأنظمة، وإدارة المشروع، والتحقق من النتائج، والمسؤولية المهنية.

تختلف هوية البرنامج الفعلية بحسب المؤسسة؛ فقد يكون بحثيًا أو مهنيًا أو تصميميًا أو تطبيقيًا. ولا تعني درجة الماجستير وحدها الحصول على ترخيص أو صلاحية مهنية مستقلة، لأن ذلك يعتمد على المؤهل الأولي والتدريب والاعتماد والأنظمة المحلية.

### الجانب العملي أو التطبيقي

قد يشمل بناء نظام أو تطبيق أو خوارزمية، وإجراء اختبارات أداء وأمان مرتبطة بـتصميم ونمذجة وتنفيذ وتحليل نظم قواعد البيانات العلائقية وغير العلائقية والموزعة. ويجب استخدام البيانات والأنظمة ضمن تفويض قانوني وأخلاقي واضح.
