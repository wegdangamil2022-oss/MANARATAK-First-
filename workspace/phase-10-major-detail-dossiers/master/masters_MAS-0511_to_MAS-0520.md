# 511. البساتين — Horticulture

## 1. معلومات تخصص الماجستير الأساسية

| الحقل | التفاصيل |
|---|---|
| الرمز المرجعي | `MAS-0511` |
| الاسم بالعربية | البساتين |
| الاسم بالإنجليزية | Horticulture |
| التخصص الأساسي المرتبط | إنتاج وإدارة وتحسين محاصيل البساتين والإكثار والجودة وما بعد الحصاد |

| أنواع البرنامج | ماجستير بحثي أو تطبيقي في البساتين، أو مقررات ورسالة، أو مشروع بحثي/تطبيقي |
| أنماط الدراسة العامة | حضوري غالبًا للمختبر أو العمل الميداني؛ وقد تتوفر مكونات حاسوبية ونظرية هجينًا |

## 2. نبذة عن تخصص الماجستير

يركز ماجستير البساتين على إنتاج وإدارة وتحسين محاصيل البساتين والإكثار والجودة وما بعد الحصاد، وينقل الطالب من المعرفة العامة إلى مستوى أعمق من صياغة المشكلات أو الفرضيات، وتصميم الدراسة أو النموذج، وتحليل البيانات، وتفسير النتائج ضمن حدود الأدلة.

تختلف هوية البرنامج بحسب المؤسسة؛ فقد يكون بحثيًا أو تطبيقيًا أو ميدانيًا أو حاسوبيًا. ولا تعني درجة الماجستير وحدها الحصول على ترخيص مهني أو سريري أو تنظيمي مستقل.

## 3. أنواع البرنامج الشائعة

- مقررات ورسالة
- مشروع بحثي أو مهني
- مسار مختبري أو حاسوبي أو ميداني بحسب التخصص

### الجانب العملي أو التطبيقي
