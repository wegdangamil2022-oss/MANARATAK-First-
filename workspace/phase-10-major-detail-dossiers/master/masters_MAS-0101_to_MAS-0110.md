# 101. تمريض الصحة العامة — Public Health Nursing

## 1. معلومات تخصص الماجستير الأساسية

| الحقل | التفاصيل |
|---|---|
| الرمز المرجعي | `MAS-0101` |
| الاسم بالعربية | تمريض الصحة العامة |
| الاسم بالإنجليزية | Public Health Nursing |
| التخصص الأساسي المرتبط | تطبيق علوم التمريض والصحة العامة لحماية صحة السكان والوقاية والاستجابة للاحتياجات المجتمعية |
| المجال الأكاديمي | كلية التمريض والقبالة |
| مستوى الدرجة | ماجستير — Master |
| أسماء الدرجات الشائعة | MSc Nursing / MSN / MN |
| المدة الشائعة | سنة إلى سنتين غالبًا، وقد تمتد البرامج السريرية أو البحثية بحسب التدريب والرسالة |
| أنواع البرنامج | ماجستير تمريض الصحة العامة، أو مقررات ورسالة، أو مسار بحثي/تطبيقي بحسب المؤسسة |
| أنماط الدراسة العامة | حضوري غالبًا للمكونات السريرية أو المخبرية؛ وقد تتوفر المقررات النظرية هجينًا |
| طبيعة التوفر | تخصص مجتمعي/سكاني يجمع التمريض والوبائيات والبرامج الصحية، وقد يطرح حضوريًا أو هجينًا |
| الوصف المختصر | برنامج متقدم يركز على تطبيق علوم التمريض والصحة العامة لحماية صحة السكان والوقاية والاستجابة للاحتياجات المجتمعية. |

## 2. نبذة عن تخصص الماجستير

يركز ماجستير تمريض الصحة العامة على تطبيق علوم التمريض والصحة العامة لحماية صحة السكان والوقاية والاستجابة للاحتياجات المجتمعية، وينقل الطالب من المعرفة العامة في مرحلة البكالوريوس إلى مستوى أعمق من التحليل والممارسة المنظمة أو البحث. ويهتم بقراءة الأدلة، وتقييم النتائج، وضبط الجودة، والتواصل مع الفرق ذات الصلة.

تختلف هوية البرنامج الفعلية بحسب المؤسسة؛ فقد يكون سريريًا أو مهنيًا أو بحثيًا أو مختلطًا. ولا يفترض أن اسم الماجستير وحده يمنح ترخيصًا أو صلاحية مستقلة، لأن ذلك يتوقف على المؤهل الأولي، والتدريب العملي، والاعتماد، واللوائح المهنية.

## 11. أهم الوظائف المرتبطة

| الوظيفة | مدى مناسبة الماجستير | الملاحظة المهنية |
|---|---|---|
| أخصائي علوم تصوير طبي | مناسب بحسب الخلفية والترخيص | قد يكون بحثيًا أو تقنيًا أو سريريًا. |
| أخصائي جودة وجرعات | مناسب مع التدريب | يعمل مع الفيزياء الطبية والحماية. |
| باحث معالجة صور | مناسب | يفيد البرمجة والتحليل. |
| إصدار تقرير تشخيصي مستقل | غير كافٍ وحده | غالبًا يتطلب طبيب أشعة مرخصًا. |

## 13. التخصصات المشابهة والفروق

| التخصص المشابه | الفرق المختصر |
|---|---|
| تقنية الأشعة | تركز على تشغيل الأجهزة وإنتاج الصور سريريًا. |
| الفيزياء الطبية | تركز على الجرعات والأجهزة والسلامة بصورة أعمق. |
| معالجة الصور الطبية | أكثر حوسبة وخوارزميات وقد لا تشمل الممارسة السريرية. |

## 14. العلاقة بتخصصات البكالوريوس

| نوع العلاقة | تخصصات البكالوريوس |
|---|---|
| مرتبطة مباشرة | الأشعة والتصوير الطبي, تقنية الأشعة, الفيزياء الطبية, الهندسة الطبية الحيوية |
| مقبولة غالبًا | علوم الحاسب, الطب, تقنية الطب النووي, الموجات فوق الصوتية |
| قد تحتاج مقررات استدراكية | الخلفيات التقنية قد تحتاج تشريحًا وفيزيولوجيا وسلامة سريرية, الخلفيات الصحية قد تحتاج رياضيات وبرمجة ومعالجة صور |
