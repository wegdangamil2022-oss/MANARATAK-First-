# 971. العمارة البحرية — Naval Architecture

## 1. معلومات تخصص الماجستير الأساسية

| الحقل | التفاصيل |
|---|---|
| الرمز المرجعي | `MAS-0971` |
| الاسم بالعربية | العمارة البحرية |
| الاسم بالإنجليزية | Naval Architecture |
| التخصص الأساسي المرتبط | تصميم وتحليل هياكل السفن وثباتها ودفعها |
| المجال الأكاديمي | كلية الطيران والبحرية والنقل |
| مستوى الدرجة | ماجستير — Master |
| أسماء الدرجات الشائعة | MSc / MA / MAv |
| المدة الشائعة | سنة إلى سنتين غالبًا، وقد يمتد المسار البحثي أو المهني أو التقني بحسب المشروع والرسالة |
| أنواع البرنامج | ماجستير علوم أو إدارة تقنية في العمارة البحرية، أو مقررات ورسالة، أو مشروع تطبيقي |
| أنماط الدراسة العامة | حضوري أو هجين بحسب طبيعة المختبر أو المحاكاة أو التدريب أو البحث |
| طبيعة التوفر | مهني/تقني/بحثي؛ ويختلف عمق البحث والتطبيق بين المؤسسات |
| الوصف المختصر | برنامج متقدم يركز على تصميم وتحليل هياكل السفن وثباتها ودفعها. |

## 2. نبذة عن تخصص الماجستير

يركز ماجستير العمارة البحرية على تصميم وتحليل هياكل السفن وثباتها ودفعها، وينقل الطالب من المعرفة العامة إلى مستوى أعمق من التحليل والتخطيط والتطبيق أو البحث. كما يهتم بإدارة المخاطر والجودة، واستخدام الأدلة والبيانات، والتوثيق، والمسؤولية المهنية والأخلاقية.

تختلف هوية البرنامج بحسب المؤسسة؛ فقد يكون بحثيًا أو مهنيًا أو تقنيًا أو تطبيقيًا. ولا تعني درجة الماجستير وحدها الحصول على ترخيص أو رتبة أو صلاحية تشغيلية أو دينية أو مهنية مستقلة.

- مقررات ورسالة

| الحقل | التفاصيل |
|---|---|
| الرمز المرجعي | `MAS-0973` |
| الاسم بالعربية | إدارة النقل |
| الاسم بالإنجليزية | Transportation Management |
| التخصص الأساسي المرتبط | إدارة عمليات وشبكات ومؤسسات النقل |
| المجال الأكاديمي | كلية الطيران والبحرية والنقل |
| مستوى الدرجة | ماجستير — Master |
| أسماء الدرجات الشائعة | MSc / MA / MAv |
| المدة الشائعة | سنة إلى سنتين غالبًا، وقد يمتد المسار البحثي أو المهني أو التقني بحسب المشروع والرسالة |
| أنواع البرنامج | ماجستير علوم أو إدارة تقنية في إدارة النقل، أو مقررات ورسالة، أو مشروع تطبيقي |
| أنماط الدراسة العامة | حضوري أو هجين بحسب طبيعة المختبر أو المحاكاة أو التدريب أو البحث |
| طبيعة التوفر | مهني/تقني/بحثي؛ ويختلف عمق البحث والتطبيق بين المؤسسات |
| الوصف المختصر | برنامج متقدم يركز على إدارة عمليات وشبكات ومؤسسات النقل. |

## 2. نبذة عن تخصص الماجستير

يركز ماجستير إدارة النقل على إدارة عمليات وشبكات ومؤسسات النقل، وينقل الطالب من المعرفة العامة إلى مستوى أعمق من التحليل والتخطيط والتطبيق أو البحث. كما يهتم بإدارة المخاطر والجودة، واستخدام الأدلة والبيانات، والتوثيق، والمسؤولية المهنية والأخلاقية.

تختلف هوية البرنامج بحسب المؤسسة؛ فقد يكون بحثيًا أو مهنيًا أو تقنيًا أو تطبيقيًا. ولا تعني درجة الماجستير وحدها الحصول على ترخيص أو رتبة أو صلاحية تشغيلية أو دينية أو مهنية مستقلة.

## 3. أنواع البرنامج الشائعة

- ماجستير علوم أو إدارة تقنية في إدارة النقل
- ماجستير مهني أو بحثي
- مقررات ومشروع عمليات/هندسة
- مقررات ورسالة

# 980. أنظمة النقل الذكية — Intelligent Transportation Systems

## 1. معلومات تخصص الماجستير الأساسية

| الحقل | التفاصيل |
|---|---|
| الرمز المرجعي | `MAS-0980` |
| الاسم بالعربية | أنظمة النقل الذكية |
| الاسم بالإنجليزية | Intelligent Transportation Systems |
| التخصص الأساسي المرتبط | دمج الاستشعار والاتصالات والبيانات في النقل |
| المجال الأكاديمي | كلية الطيران والبحرية والنقل |
| مستوى الدرجة | ماجستير — Master |
| أسماء الدرجات الشائعة | MSc / MA / MAv |
| المدة الشائعة | سنة إلى سنتين غالبًا، وقد يمتد المسار البحثي أو المهني أو التقني بحسب المشروع والرسالة |
| أنواع البرنامج | ماجستير علوم أو إدارة تقنية في أنظمة النقل الذكية، أو مقررات ورسالة، أو مشروع تطبيقي |
| أنماط الدراسة العامة | حضوري أو هجين بحسب طبيعة المختبر أو المحاكاة أو التدريب أو البحث |
| طبيعة التوفر | مهني/تقني/بحثي؛ ويختلف عمق البحث والتطبيق بين المؤسسات |
| الوصف المختصر | برنامج متقدم يركز على دمج الاستشعار والاتصالات والبيانات في النقل. |

## 2. نبذة عن تخصص الماجستير

يركز ماجستير أنظمة النقل الذكية على دمج الاستشعار والاتصالات والبيانات في النقل، وينقل الطالب من المعرفة العامة إلى مستوى أعمق من التحليل والتخطيط والتطبيق أو البحث. كما يهتم بإدارة المخاطر والجودة، واستخدام الأدلة والبيانات، والتوثيق، والمسؤولية المهنية والأخلاقية.

تختلف هوية البرنامج بحسب المؤسسة؛ فقد يكون بحثيًا أو مهنيًا أو تقنيًا أو تطبيقيًا. ولا تعني درجة الماجستير وحدها الحصول على ترخيص أو رتبة أو صلاحية تشغيلية أو دينية أو مهنية مستقلة.
