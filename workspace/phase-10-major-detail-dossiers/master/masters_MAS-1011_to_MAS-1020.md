# 1011. الأمن الإنساني — Human Security

## 1. معلومات تخصص الماجستير الأساسية

| الحقل | التفاصيل |
|---|---|
| الرمز المرجعي | `MAS-1011` |
| الاسم بالعربية | الأمن الإنساني |
| الاسم بالإنجليزية | Human Security |
| التخصص الأساسي المرتبط | دراسة أمن الأفراد والمجتمعات من الخوف والحاجة |
| المجال الأكاديمي | كلية الأمن والعدالة والحماية المدنية |

| أسماء الدرجات الشائعة | MSc / MA |
| المدة الشائعة | سنة إلى سنتين غالبًا، وقد يمتد المسار البحثي أو المهني أو التقني بحسب المشروع والرسالة |
| أنواع البرنامج | ماجستير علوم أو آداب في الأمن الإنساني، أو مقررات ورسالة، أو مشروع تطبيقي |
| أنماط الدراسة العامة | حضوري أو هجين بحسب طبيعة المختبر أو المحاكاة أو التدريب أو البحث |
| طبيعة التوفر | مهني/بحثي؛ ويختلف عمق البحث والتطبيق بين المؤسسات |
| الوصف المختصر | برنامج متقدم يركز على دراسة أمن الأفراد والمجتمعات من الخوف والحاجة. |

## 2. نبذة عن تخصص الماجستير

يركز ماجستير الأمن الإنساني على دراسة أمن الأفراد والمجتمعات من الخوف والحاجة، وينقل الطالب من المعرفة العامة إلى مستوى أعمق من التحليل والتخطيط والتطبيق أو البحث. كما يهتم بإدارة المخاطر والجودة، واستخدام الأدلة والبيانات، والتوثيق، والمسؤولية المهنية والأخلاقية.

تختلف هوية البرنامج بحسب المؤسسة؛ فقد يكون بحثيًا أو مهنيًا أو تقنيًا أو تطبيقيًا. ولا تعني درجة الماجستير وحدها الحصول على ترخيص أو رتبة أو صلاحية تشغيلية أو دينية أو مهنية مستقلة.

## 3. أنواع البرنامج الشائعة

- ماجستير علوم أو آداب في الأمن الإنساني
- ماجستير مهني أو بحثي
- مقررات ومشروع سياسات/عمليات
- مقررات ورسالة
