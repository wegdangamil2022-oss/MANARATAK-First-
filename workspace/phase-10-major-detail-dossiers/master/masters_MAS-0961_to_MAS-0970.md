# 961. علوم الطيران — Aviation Science

## 1. معلومات تخصص الماجستير الأساسية

| الحقل | التفاصيل |
|---|---|
| الرمز المرجعي | `MAS-0961` |
| الاسم بالعربية | علوم الطيران |
| الاسم بالإنجليزية | Aviation Science |
| التخصص الأساسي المرتبط | دراسة أنظمة الطيران وعملياته وتقنياته وسلامته |
| المجال الأكاديمي | كلية الطيران والبحرية والنقل |
| مستوى الدرجة | ماجستير — Master |
| أسماء الدرجات الشائعة | MSc / MA / MAv |
| المدة الشائعة | سنة إلى سنتين غالبًا، وقد يمتد المسار البحثي أو المهني أو التقني بحسب المشروع والرسالة |
| أنواع البرنامج | ماجستير علوم أو إدارة تقنية في علوم الطيران، أو مقررات ورسالة، أو مشروع تطبيقي |
| أنماط الدراسة العامة | حضوري أو هجين بحسب طبيعة المختبر أو المحاكاة أو التدريب أو البحث |
| طبيعة التوفر | مهني/تقني/بحثي؛ ويختلف عمق البحث والتطبيق بين المؤسسات |
| الوصف المختصر | برنامج متقدم يركز على دراسة أنظمة الطيران وعملياته وتقنياته وسلامته. |

## 2. نبذة عن تخصص الماجستير

يركز ماجستير علوم الطيران على دراسة أنظمة الطيران وعملياته وتقنياته وسلامته، وينقل الطالب من المعرفة العامة إلى مستوى أعمق من التحليل والتخطيط والتطبيق أو البحث. كما يهتم بإدارة المخاطر والجودة، واستخدام الأدلة والبيانات، والتوثيق، والمسؤولية المهنية والأخلاقية.

تختلف هوية البرنامج بحسب المؤسسة؛ فقد يكون بحثيًا أو مهنيًا أو تقنيًا أو تطبيقيًا. ولا تعني درجة الماجستير وحدها الحصول على ترخيص أو رتبة أو صلاحية تشغيلية أو دينية أو مهنية مستقلة.

## 2. نبذة عن تخصص الماجستير

يركز ماجستير إدارة الشحن البحري على إدارة شركات الشحن والأساطيل والعقود والأسواق، وينقل الطالب من المعرفة العامة إلى مستوى أعمق من التحليل والتخطيط والتطبيق أو البحث. كما يهتم بإدارة المخاطر والجودة، واستخدام الأدلة والبيانات، والتوثيق، والمسؤولية المهنية والأخلاقية.

تختلف هوية البرنامج بحسب المؤسسة؛ فقد يكون بحثيًا أو مهنيًا أو تقنيًا أو تطبيقيًا. ولا تعني درجة الماجستير وحدها الحصول على ترخيص أو رتبة أو صلاحية تشغيلية أو دينية أو مهنية مستقلة.
