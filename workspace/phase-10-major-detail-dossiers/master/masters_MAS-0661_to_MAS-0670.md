# 661. السياسة العامة — Public Policy

## 1. معلومات تخصص الماجستير الأساسية

| الحقل | التفاصيل |

| التخصص الأساسي المرتبط | دراسة السياسة العامة وتحليل الفاعلين والمؤسسات والقوى والقرارات والبيئات الوطنية والدولية المرتبطة به |

| أنواع البرنامج | ماجستير آداب أو علوم في السياسة العامة، أو مقررات ورسالة، أو مشروع تطبيقي |

## 2. نبذة عن تخصص الماجستير

يركز ماجستير السياسة العامة على دراسة السياسة العامة وتحليل الفاعلين والمؤسسات والقوى والقرارات والبيئات الوطنية والدولية المرتبطة به، وينقل الطالب من المعرفة العامة إلى مستوى أعمق من التحليل والتخطيط والتطبيق أو البحث. ويهتم باستخدام الأدلة، والتوثيق، وقياس النتائج، والمسؤولية المهنية والأخلاقية.

تختلف هوية البرنامج بحسب المؤسسة؛ فقد يكون مهنيًا أو بحثيًا أو تطبيقيًا. ولا تعني درجة الماجستير وحدها الحصول على ترخيص أو منصب أو صلاحية مهنية مستقلة.

## 3. أنواع البرنامج الشائعة

- مقررات ورسالة
- مشروع سياسات أو تحليل استراتيجي

## 1. معلومات تخصص الماجستير الأساسية

| المجال الأكاديمي | كلية القانون والعلوم السياسية والإدارة العامة |

## 2. نبذة عن تخصص الماجستير

يركز ماجستير الإدارة المحلية على تطوير المعرفة والممارسة في الإدارة المحلية وتحسين الحوكمة والخدمات والأداء المؤسسي العام، وينقل الطالب من المعرفة العامة إلى مستوى أعمق من التحليل والتخطيط والتطبيق أو البحث. ويهتم باستخدام الأدلة، والتوثيق، وقياس النتائج، والمسؤولية المهنية والأخلاقية.

تختلف هوية البرنامج بحسب المؤسسة؛ فقد يكون مهنيًا أو بحثيًا أو تطبيقيًا. ولا تعني درجة الماجستير وحدها الحصول على ترخيص أو منصب أو صلاحية مهنية مستقلة.

## 3. أنواع البرنامج الشائعة

- ماجستير مهني أو بحثي في الإدارة المحلية

- مقررات ورسالة

# 670. القانون المصرفي والمالي — Banking and Finance Law

## 1. معلومات تخصص الماجستير الأساسية

| الحقل | التفاصيل |
|---|---|
| الرمز المرجعي | `MAS-0670` |
| الاسم بالعربية | القانون المصرفي والمالي |
| الاسم بالإنجليزية | Banking and Finance Law |
| التخصص الأساسي المرتبط | التعمق في قواعد القانون المصرفي والمالي وتحليل تشريعاته وأحكامه وتطبيقاته ومشكلاته المعاصرة |
| المجال الأكاديمي | كلية القانون والعلوم السياسية والإدارة العامة |
| مستوى الدرجة | ماجستير — Master |
| أسماء الدرجات الشائعة | LLM / MA / MPA / MPP |

| أنواع البرنامج | ماجستير قانون — LLM في القانون المصرفي والمالي، أو مقررات ورسالة، أو مشروع تطبيقي |
| أنماط الدراسة العامة | حضوري أو هجين بحسب طبيعة التدريب والمشروع والبحث |

## 2. نبذة عن تخصص الماجستير

يركز ماجستير القانون المصرفي والمالي على التعمق في قواعد القانون المصرفي والمالي وتحليل تشريعاته وأحكامه وتطبيقاته ومشكلاته المعاصرة، وينقل الطالب من المعرفة العامة إلى مستوى أعمق من التحليل والتخطيط والتطبيق أو البحث. ويهتم باستخدام الأدلة، والتوثيق، وقياس النتائج، والمسؤولية المهنية والأخلاقية.

تختلف هوية البرنامج بحسب المؤسسة؛ فقد يكون مهنيًا أو بحثيًا أو تطبيقيًا. ولا تعني درجة الماجستير وحدها الحصول على ترخيص أو منصب أو صلاحية مهنية مستقلة.
