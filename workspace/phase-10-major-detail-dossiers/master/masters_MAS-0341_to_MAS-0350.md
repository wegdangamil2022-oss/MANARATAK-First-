# 341. هندسة البيانات — Data Engineering

## 1. معلومات تخصص الماجستير الأساسية

| الحقل | التفاصيل |
|---|---|
| الرمز المرجعي | `MAS-0341` |
| الاسم بالعربية | هندسة البيانات |
| الاسم بالإنجليزية | Data Engineering |
| التخصص الأساسي المرتبط | تصميم وبناء وتشغيل منصات وخطوط بيانات موثوقة وقابلة للتوسع لدعم التحليلات والذكاء الاصطناعي |

## 2. نبذة عن تخصص الماجستير

يركز ماجستير هندسة البيانات على تصميم وبناء وتشغيل منصات وخطوط بيانات موثوقة وقابلة للتوسع لدعم التحليلات والذكاء الاصطناعي، وينقل الطالب من المعرفة العامة إلى مستوى أعمق من التحليل والتصميم والتجريب والتطبيق. كما يهتم بجودة البيانات، وقياس النتائج، والتوثيق، والأمن، والمسؤولية المهنية والأخلاقية.

تختلف هوية البرنامج بحسب المؤسسة؛ فقد يكون بحثيًا أو مهنيًا أو تطبيقيًا. ولا تعني درجة الماجستير وحدها الحصول على صلاحيات قانونية أو سريرية أو وصول غير مقيد إلى الأنظمة والبيانات.

|---|---|---|
| أخصائي أو مهندس التفاعل بين الإنسان والحاسوب | مناسب | يتطلب مهارات تقنية مرتبطة بالمسار |
| مطوّر أو مهندس أنظمة | مناسب | يركز على البناء والاختبار والنشر |
| محلل أو مسؤول تشغيل | مناسب | يتطلب فهمًا للبيانات والموثوقية |
| باحث حوسبة | مناسب | قد تفضل الدكتوراه للمسار الأكاديمي |

## 12. المسارات الأكاديمية والمهنية اللاحقة

### الدكتوراه المرتبطة

- التفاعل بين الإنسان والحاسوب
- علوم الحاسوب
- هندسة البرمجيات والأنظمة
- الأمن السيبراني
- الحوسبة المتقدمة

### الزمالات أو الاعتمادات المهنية المرتبطة

- اعتمادات سحابية أو شبكات أو قواعد بيانات بحسب المسار
- شهادات أمن معلومات عند الصلة
- إدارة المشاريع وDevOps
- زمالات بحثية أو مهنية

## 13. التخصصات المشابهة والفروق

| التخصص المشابه | الفرق المختصر |
|---|---|
| علوم الحاسوب | المظلة الأوسع للخوارزميات والأنظمة والنظرية |
| هندسة البرمجيات | تركز على دورة حياة البرمجيات وجودتها ومعماريتها |
| تقنية المعلومات | تركز على تشغيل وإدارة الخدمات والبنية التقنية |

## 14. العلاقة بتخصصات البكالوريوس

| نوع العلاقة | تخصصات البكالوريوس |
|---|---|
| مرتبطة مباشرة | علوم الحاسوب, تقنية المعلومات, هندسة البرمجيات, هندسة الحاسوب أو نظم المعلومات |
| مقبولة غالبًا | الرياضيات, علوم البيانات, الهندسة الكهربائية, إدارة الأعمال التقنية بحسب التخصص |
| قد تحتاج مقررات استدراكية | الخلفيات الكمية التي تحتاج برمجة وهياكل بيانات, الخلفيات التطبيقية التي تحتاج خوارزميات ونظم حاسوبية |

## 15. التنبيه الأكاديمي والمهني

> **يجب الالتزام بأمن المعلومات والخصوصية وحقوق المستخدمين والترخيص البرمجي. لا تمنح الدرجة صلاحية الوصول إلى الأنظمة أو البيانات دون تفويض.**
