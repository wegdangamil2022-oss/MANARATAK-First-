# 631. تمويل التنمية — Development Finance

## 1. معلومات تخصص الماجستير الأساسية

| الحقل | التفاصيل |
|---|---|
| الرمز المرجعي | `MAS-0631` |
| الاسم بالعربية | تمويل التنمية |
| الاسم بالإنجليزية | Development Finance |
| التخصص الأساسي المرتبط | تمويل مشروعات وبرامج التنمية والبنية والقطاع الخاص ذات الأثر الاقتصادي والاجتماعي |
| المجال الأكاديمي | كلية الاقتصاد والمحاسبة والتمويل |
| مستوى الدرجة | ماجستير — Master |
| أسماء الدرجات الشائعة | MSc / MA / MFin / MAcc |
| المدة الشائعة | سنة إلى سنتين غالبًا، وقد يمتد المسار البحثي أو المهني بحسب المشروع والرسالة |
| أنواع البرنامج | ماجستير علوم أو تمويل في تمويل التنمية، أو مقررات ورسالة، أو مشروع تطبيقي |
| أنماط الدراسة العامة | حضوري أو هجين بحسب طبيعة التدريب والمشروع والبيانات المستخدمة |
| طبيعة التوفر | بحثي/مهني؛ ويختلف عمق البحث والتطبيق بين المؤسسات |
| الوصف المختصر | برنامج متقدم يركز على تمويل مشروعات وبرامج التنمية والبنية والقطاع الخاص ذات الأثر الاقتصادي والاجتماعي. |

## 2. نبذة عن تخصص الماجستير

يركز ماجستير تمويل التنمية على تمويل مشروعات وبرامج التنمية والبنية والقطاع الخاص ذات الأثر الاقتصادي والاجتماعي، وينقل الطالب من المعرفة العامة إلى مستوى أعمق من التحليل والتخطيط واتخاذ القرار أو البحث والتطبيق. ويهتم بقياس النتائج، وإدارة المخاطر، واستخدام البيانات، والعمل مع أصحاب المصلحة.

تختلف هوية البرنامج بحسب المؤسسة؛ فقد يكون مهنيًا أو تنفيذيًا أو بحثيًا أو تطبيقيًا. ولا تعني الدرجة وحدها الحصول على ترخيص أو منصب أو صلاحية مهنية مستقلة.

- مقررات ورسالة

## 2. نبذة عن تخصص الماجستير

يركز ماجستير الاقتصاد البيئي على تحليل التلوث والموارد والمناخ والتنوع باستخدام أدوات الاقتصاد والسياسات، وينقل الطالب من المعرفة العامة إلى مستوى أعمق من التحليل والتخطيط واتخاذ القرار أو البحث والتطبيق. ويهتم بقياس النتائج، وإدارة المخاطر، واستخدام البيانات، والعمل مع أصحاب المصلحة.

تختلف هوية البرنامج بحسب المؤسسة؛ فقد يكون مهنيًا أو تنفيذيًا أو بحثيًا أو تطبيقيًا. ولا تعني الدرجة وحدها الحصول على ترخيص أو منصب أو صلاحية مهنية مستقلة.

## 1. معلومات تخصص الماجستير الأساسية

## 2. نبذة عن تخصص الماجستير

يركز ماجستير التحليل الجنائي المالي على التحقيق في الاحتيال وغسل الأموال والتلاعب وتتبع الأموال وبناء الأدلة المالية، وينقل الطالب من المعرفة العامة إلى مستوى أعمق من التحليل والتخطيط واتخاذ القرار أو البحث والتطبيق. ويهتم بقياس النتائج، وإدارة المخاطر، واستخدام البيانات، والعمل مع أصحاب المصلحة.

تختلف هوية البرنامج بحسب المؤسسة؛ فقد يكون مهنيًا أو تنفيذيًا أو بحثيًا أو تطبيقيًا. ولا تعني الدرجة وحدها الحصول على ترخيص أو منصب أو صلاحية مهنية مستقلة.
