# 981. إدارة النقل الجوي الدولي — International Air Transport Management

## 1. معلومات تخصص الماجستير الأساسية

| الحقل | التفاصيل |
|---|---|
| الرمز المرجعي | `MAS-0981` |
| الاسم بالعربية | إدارة النقل الجوي الدولي |
| الاسم بالإنجليزية | International Air Transport Management |
| التخصص الأساسي المرتبط | إدارة أسواق وشبكات وتنظيم النقل الجوي دوليًا |
| المجال الأكاديمي | كلية الطيران والبحرية والنقل |
| مستوى الدرجة | ماجستير — Master |
| أسماء الدرجات الشائعة | MSc / MA / MAv |
| المدة الشائعة | سنة إلى سنتين غالبًا، وقد يمتد المسار البحثي أو المهني أو التقني بحسب المشروع والرسالة |
| أنواع البرنامج | ماجستير علوم أو إدارة تقنية في إدارة النقل الجوي الدولي، أو مقررات ورسالة، أو مشروع تطبيقي |
| أنماط الدراسة العامة | حضوري أو هجين بحسب طبيعة المختبر أو المحاكاة أو التدريب أو البحث |
| طبيعة التوفر | مهني/تقني/بحثي؛ ويختلف عمق البحث والتطبيق بين المؤسسات |
| الوصف المختصر | برنامج متقدم يركز على إدارة أسواق وشبكات وتنظيم النقل الجوي دوليًا. |

## 2. نبذة عن تخصص الماجستير

يركز ماجستير إدارة النقل الجوي الدولي على إدارة أسواق وشبكات وتنظيم النقل الجوي دوليًا، وينقل الطالب من المعرفة العامة إلى مستوى أعمق من التحليل والتخطيط والتطبيق أو البحث. كما يهتم بإدارة المخاطر والجودة، واستخدام الأدلة والبيانات، والتوثيق، والمسؤولية المهنية والأخلاقية.

تختلف هوية البرنامج بحسب المؤسسة؛ فقد يكون بحثيًا أو مهنيًا أو تقنيًا أو تطبيقيًا. ولا تعني درجة الماجستير وحدها الحصول على ترخيص أو رتبة أو صلاحية تشغيلية أو دينية أو مهنية مستقلة.

## 3. أنواع البرنامج الشائعة

- ماجستير علوم أو إدارة تقنية في إدارة النقل الجوي الدولي
- ماجستير مهني أو بحثي

- مقررات ورسالة

## 2. نبذة عن تخصص الماجستير

يركز ماجستير علوم الشرطة على دراسة الشرطة ووظائفها وأساليبها وتنظيمها، وينقل الطالب من المعرفة العامة إلى مستوى أعمق من التحليل والتخطيط والتطبيق أو البحث. كما يهتم بإدارة المخاطر والجودة، واستخدام الأدلة والبيانات، والتوثيق، والمسؤولية المهنية والأخلاقية.

تختلف هوية البرنامج بحسب المؤسسة؛ فقد يكون بحثيًا أو مهنيًا أو تقنيًا أو تطبيقيًا. ولا تعني درجة الماجستير وحدها الحصول على ترخيص أو رتبة أو صلاحية تشغيلية أو دينية أو مهنية مستقلة.
