# 681. قانون الضرائب — Tax Law

## 1. معلومات تخصص الماجستير الأساسية

| الحقل | التفاصيل |
|---|---|
| الرمز المرجعي | `MAS-0681` |
| الاسم بالعربية | قانون الضرائب |
| الاسم بالإنجليزية | Tax Law |
| التخصص الأساسي المرتبط | التعمق في قواعد قانون الضرائب وتحليل تشريعاته وأحكامه وتطبيقاته ومشكلاته المعاصرة |
| المجال الأكاديمي | كلية القانون والعلوم السياسية والإدارة العامة |
| مستوى الدرجة | ماجستير — Master |
| أسماء الدرجات الشائعة | LLM / MA / MPA / MPP |
| المدة الشائعة | سنة إلى سنتين غالبًا، وقد يمتد المسار البحثي أو المهني بحسب المشروع والرسالة |
| أنواع البرنامج | ماجستير قانون — LLM في قانون الضرائب، أو مقررات ورسالة، أو مشروع تطبيقي |
| أنماط الدراسة العامة | حضوري أو هجين بحسب طبيعة التدريب والمشروع والبحث |
| طبيعة التوفر | مهني/بحثي؛ ويختلف عمق البحث والتطبيق بين المؤسسات |
| الوصف المختصر | برنامج متقدم يركز على التعمق في قواعد قانون الضرائب وتحليل تشريعاته وأحكامه وتطبيقاته ومشكلاته المعاصرة. |

## 2. نبذة عن تخصص الماجستير

يركز ماجستير قانون الضرائب على التعمق في قواعد قانون الضرائب وتحليل تشريعاته وأحكامه وتطبيقاته ومشكلاته المعاصرة، وينقل الطالب من المعرفة العامة إلى مستوى أعمق من التحليل والتخطيط والتطبيق أو البحث. ويهتم باستخدام الأدلة، والتوثيق، وقياس النتائج، والمسؤولية المهنية والأخلاقية.

تختلف هوية البرنامج بحسب المؤسسة؛ فقد يكون مهنيًا أو بحثيًا أو تطبيقيًا. ولا تعني درجة الماجستير وحدها الحصول على ترخيص أو منصب أو صلاحية مهنية مستقلة.

يركز ماجستير التربية الخاصة على تطوير المعرفة والممارسة التربوية في التربية الخاصة وتحسين التعلم والمناهج والتقويم والبيئات التعليمية، وينقل الطالب من المعرفة العامة إلى مستوى أعمق من التحليل والتخطيط والتطبيق أو البحث. ويهتم باستخدام الأدلة، والتوثيق، وقياس النتائج، والمسؤولية المهنية والأخلاقية.

تختلف هوية البرنامج بحسب المؤسسة؛ فقد يكون مهنيًا أو بحثيًا أو تطبيقيًا. ولا تعني درجة الماجستير وحدها الحصول على ترخيص أو منصب أو صلاحية مهنية مستقلة.
