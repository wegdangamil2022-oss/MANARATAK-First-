# 991. التحقيق الجنائي — Criminal Investigation

## 1. معلومات تخصص الماجستير الأساسية

| الحقل | التفاصيل |
|---|---|
| الرمز المرجعي | `MAS-0991` |
| الاسم بالعربية | التحقيق الجنائي |
| الاسم بالإنجليزية | Criminal Investigation |
| التخصص الأساسي المرتبط | إدارة التحقيقات والمقابلات وتحليل الوقائع والأدلة |

| المدة الشائعة | سنة إلى سنتين غالبًا، وقد يمتد المسار البحثي أو المهني أو التقني بحسب المشروع والرسالة |
| أنواع البرنامج | ماجستير علوم أو آداب في التحقيق الجنائي، أو مقررات ورسالة، أو مشروع تطبيقي |
| أنماط الدراسة العامة | حضوري أو هجين بحسب طبيعة المختبر أو المحاكاة أو التدريب أو البحث |

## 2. نبذة عن تخصص الماجستير

يركز ماجستير التحقيق الجنائي على إدارة التحقيقات والمقابلات وتحليل الوقائع والأدلة، وينقل الطالب من المعرفة العامة إلى مستوى أعمق من التحليل والتخطيط والتطبيق أو البحث. كما يهتم بإدارة المخاطر والجودة، واستخدام الأدلة والبيانات، والتوثيق، والمسؤولية المهنية والأخلاقية.

تختلف هوية البرنامج بحسب المؤسسة؛ فقد يكون بحثيًا أو مهنيًا أو تقنيًا أو تطبيقيًا. ولا تعني درجة الماجستير وحدها الحصول على ترخيص أو رتبة أو صلاحية تشغيلية أو دينية أو مهنية مستقلة.

## 3. أنواع البرنامج الشائعة

- ماجستير مهني أو بحثي

- مقررات ورسالة

## 2. نبذة عن تخصص الماجستير

# 1000. السلامة ومكافحة الحرائق — Fire Safety

## 1. معلومات تخصص الماجستير الأساسية

| الحقل | التفاصيل |
|---|---|
| الرمز المرجعي | `MAS-1000` |
| الاسم بالعربية | السلامة ومكافحة الحرائق |
| الاسم بالإنجليزية | Fire Safety |
| التخصص الأساسي المرتبط | تطوير نظم الوقاية والحماية ومكافحة الحرائق |
| المجال الأكاديمي | كلية الأمن والعدالة والحماية المدنية |
| مستوى الدرجة | ماجستير — Master |
| أسماء الدرجات الشائعة | MSc / MA |
| المدة الشائعة | سنة إلى سنتين غالبًا، وقد يمتد المسار البحثي أو المهني أو التقني بحسب المشروع والرسالة |
| أنواع البرنامج | ماجستير علوم أو آداب في السلامة ومكافحة الحرائق، أو مقررات ورسالة، أو مشروع تطبيقي |
| أنماط الدراسة العامة | حضوري أو هجين بحسب طبيعة المختبر أو المحاكاة أو التدريب أو البحث |
| طبيعة التوفر | مهني/بحثي؛ ويختلف عمق البحث والتطبيق بين المؤسسات |
| الوصف المختصر | برنامج متقدم يركز على تطوير نظم الوقاية والحماية ومكافحة الحرائق. |

## 2. نبذة عن تخصص الماجستير

يركز ماجستير السلامة ومكافحة الحرائق على تطوير نظم الوقاية والحماية ومكافحة الحرائق، وينقل الطالب من المعرفة العامة إلى مستوى أعمق من التحليل والتخطيط والتطبيق أو البحث. كما يهتم بإدارة المخاطر والجودة، واستخدام الأدلة والبيانات، والتوثيق، والمسؤولية المهنية والأخلاقية.

تختلف هوية البرنامج بحسب المؤسسة؛ فقد يكون بحثيًا أو مهنيًا أو تقنيًا أو تطبيقيًا. ولا تعني درجة الماجستير وحدها الحصول على ترخيص أو رتبة أو صلاحية تشغيلية أو دينية أو مهنية مستقلة.

## 3. أنواع البرنامج الشائعة

- ماجستير علوم أو آداب في السلامة ومكافحة الحرائق
- ماجستير مهني أو بحثي

- مقررات ورسالة
