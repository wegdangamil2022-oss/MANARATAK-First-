# 641. القانون الخاص — Private Law

## 1. معلومات تخصص الماجستير الأساسية

| الحقل | التفاصيل |
|---|---|
| الرمز المرجعي | `MAS-0641` |
| الاسم بالعربية | القانون الخاص |
| الاسم بالإنجليزية | Private Law |
| التخصص الأساسي المرتبط | التعمق في قواعد القانون الخاص وتحليل تشريعاته وأحكامه وتطبيقاته ومشكلاته المعاصرة |
| المجال الأكاديمي | كلية القانون والعلوم السياسية والإدارة العامة |
| مستوى الدرجة | ماجستير — Master |
| أسماء الدرجات الشائعة | LLM / MA / MPA / MPP |
| المدة الشائعة | سنة إلى سنتين غالبًا، وقد يمتد المسار البحثي أو المهني بحسب المشروع والرسالة |
| أنواع البرنامج | ماجستير قانون — LLM في القانون الخاص، أو مقررات ورسالة، أو مشروع تطبيقي |
| أنماط الدراسة العامة | حضوري أو هجين بحسب طبيعة التدريب والمشروع والبحث |
| طبيعة التوفر | مهني/بحثي؛ ويختلف عمق البحث والتطبيق بين المؤسسات |
| الوصف المختصر | برنامج متقدم يركز على التعمق في قواعد القانون الخاص وتحليل تشريعاته وأحكامه وتطبيقاته ومشكلاته المعاصرة. |

## 2. نبذة عن تخصص الماجستير

يركز ماجستير القانون الخاص على التعمق في قواعد القانون الخاص وتحليل تشريعاته وأحكامه وتطبيقاته ومشكلاته المعاصرة، وينقل الطالب من المعرفة العامة إلى مستوى أعمق من التحليل والتخطيط والتطبيق أو البحث. ويهتم باستخدام الأدلة، والتوثيق، وقياس النتائج، والمسؤولية المهنية والأخلاقية.

تختلف هوية البرنامج بحسب المؤسسة؛ فقد يكون مهنيًا أو بحثيًا أو تطبيقيًا. ولا تعني درجة الماجستير وحدها الحصول على ترخيص أو منصب أو صلاحية مهنية مستقلة.

## 2. نبذة عن تخصص الماجستير

يركز ماجستير القانون الدولي على التعمق في قواعد القانون الدولي وتحليل تشريعاته وأحكامه وتطبيقاته ومشكلاته المعاصرة، وينقل الطالب من المعرفة العامة إلى مستوى أعمق من التحليل والتخطيط والتطبيق أو البحث. ويهتم باستخدام الأدلة، والتوثيق، وقياس النتائج، والمسؤولية المهنية والأخلاقية.

تختلف هوية البرنامج بحسب المؤسسة؛ فقد يكون مهنيًا أو بحثيًا أو تطبيقيًا. ولا تعني درجة الماجستير وحدها الحصول على ترخيص أو منصب أو صلاحية مهنية مستقلة.

# 650. القانون البحري — Maritime Law

## 1. معلومات تخصص الماجستير الأساسية

| الحقل | التفاصيل |
|---|---|
| الرمز المرجعي | `MAS-0650` |
| الاسم بالعربية | القانون البحري |
| الاسم بالإنجليزية | Maritime Law |
| التخصص الأساسي المرتبط | التعمق في قواعد القانون البحري وتحليل تشريعاته وأحكامه وتطبيقاته ومشكلاته المعاصرة |
| المجال الأكاديمي | كلية القانون والعلوم السياسية والإدارة العامة |
| مستوى الدرجة | ماجستير — Master |
| أسماء الدرجات الشائعة | LLM / MA / MPA / MPP |
| المدة الشائعة | سنة إلى سنتين غالبًا، وقد يمتد المسار البحثي أو المهني بحسب المشروع والرسالة |
| أنواع البرنامج | ماجستير قانون — LLM في القانون البحري، أو مقررات ورسالة، أو مشروع تطبيقي |
| أنماط الدراسة العامة | حضوري أو هجين بحسب طبيعة التدريب والمشروع والبحث |
| طبيعة التوفر | مهني/بحثي؛ ويختلف عمق البحث والتطبيق بين المؤسسات |
| الوصف المختصر | برنامج متقدم يركز على التعمق في قواعد القانون البحري وتحليل تشريعاته وأحكامه وتطبيقاته ومشكلاته المعاصرة. |

## 2. نبذة عن تخصص الماجستير

يركز ماجستير القانون البحري على التعمق في قواعد القانون البحري وتحليل تشريعاته وأحكامه وتطبيقاته ومشكلاته المعاصرة، وينقل الطالب من المعرفة العامة إلى مستوى أعمق من التحليل والتخطيط والتطبيق أو البحث. ويهتم باستخدام الأدلة، والتوثيق، وقياس النتائج، والمسؤولية المهنية والأخلاقية.

تختلف هوية البرنامج بحسب المؤسسة؛ فقد يكون مهنيًا أو بحثيًا أو تطبيقيًا. ولا تعني درجة الماجستير وحدها الحصول على ترخيص أو منصب أو صلاحية مهنية مستقلة.
