# 821. تحليل السلوك التطبيقي — Applied Behavior Analysis

## 1. معلومات تخصص الماجستير الأساسية

| الحقل | التفاصيل |
|---|---|
| الرمز المرجعي | `MAS-0821` |

| الاسم بالإنجليزية | Applied Behavior Analysis |
| التخصص الأساسي المرتبط | دراسة تحليل السلوك التطبيقي وقياس السلوك والعمليات النفسية أو تطبيقها ضمن حدود مهنية وأخلاقية |

## 2. نبذة عن تخصص الماجستير

يركز ماجستير تحليل السلوك التطبيقي على دراسة تحليل السلوك التطبيقي وقياس السلوك والعمليات النفسية أو تطبيقها ضمن حدود مهنية وأخلاقية، وينقل الطالب إلى مستوى متقدم من التحليل والتفسير والتطبيق أو البحث، مع الاهتمام بالتوثيق والسياق والأخلاقيات.

تختلف هوية البرنامج بحسب المؤسسة؛ وقد يكون بحثيًا أو مهنيًا أو ميدانيًا. ولا تعني الدرجة وحدها الحصول على ترخيص أو صلاحية مهنية مستقلة.

## 3. أنواع البرنامج الشائعة

- ماجستير بحثي أو مهني في تحليل السلوك التطبيقي
- مقررات ورسالة
- مقررات ومشروع تطبيقي
- مسار ميداني أو إبداعي عند انطباقه

تختلف هوية البرنامج بحسب المؤسسة؛ وقد يكون بحثيًا أو مهنيًا أو ميدانيًا. ولا تعني الدرجة وحدها الحصول على ترخيص أو صلاحية مهنية مستقلة.

## 2. نبذة عن تخصص الماجستير

يركز ماجستير الطفولة والأسرة على دراسة الطفولة والأسرة وتحليل المجتمع والمؤسسات والسكان والسياسات والتغير الاجتماعي، وينقل الطالب إلى مستوى متقدم من التحليل والتفسير والتطبيق أو البحث، مع الاهتمام بالتوثيق والسياق والأخلاقيات.

تختلف هوية البرنامج بحسب المؤسسة؛ وقد يكون بحثيًا أو مهنيًا أو ميدانيًا. ولا تعني الدرجة وحدها الحصول على ترخيص أو صلاحية مهنية مستقلة.
