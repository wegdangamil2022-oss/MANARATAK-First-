# تخصصات بكالوريوس الحوسبة وتقنية المعلومات
## الدفعة التالية (MJR-0253 إلى MJR-0262)

> **عدد التخصصات:** 10  
> **النطاق:** معلومات التخصص نفسه فقط  
> **غير مشمول:** الجامعات، الدول، لغات الدراسة، الرسوم، المنح، الدورات، شروط القبول، والرواتب  
> **الإصدار:** 1.0  
> **تاريخ الإعداد:** 04 أغسطس 2026

## ملاحظات تحريرية مهمة

1. التخصصات من MJR-0253 إلى MJR-0262 مأخوذة حرفيًا وبالترتيب من الملف المرجعي.
2. جميع تخصصات هذه الدفعة تندرج تحت كلية الحوسبة وتقنية المعلومات، وقد تطرح بعض الجامعات عددًا منها كتخصصات مستقلة، بينما تطرحها جامعات أخرى كمسارات داخل علوم الحاسوب أو تقنية المعلومات أو نظم المعلومات.
3. الأمن السيبراني يهتم بحماية الأنظمة والشبكات والتطبيقات والعمليات الرقمية من التهديدات، بينما أمن المعلومات أوسع من حيث حماية سرية المعلومات وسلامتها وتوافرها بغض النظر عن شكلها الرقمي أو الورقي أو التنظيمي.
4. الأدلة الجنائية الرقمية تركز على جمع الأدلة الرقمية وحفظها وتحليلها وتوثيقها بصورة قابلة للاستخدام في التحقيقات، ولا تعني ممارسة الاختراق أو الوصول إلى أجهزة الآخرين دون تفويض قانوني.
5. أمن الشبكات يركز على حماية البنية الشبكية وحركة البيانات وأجهزة الاتصال، وهو جزء متخصص من الأمن السيبراني وليس مرادفًا له.
6. إدارة قواعد البيانات تركز على تشغيل قواعد البيانات وتأمينها ونسخها احتياطيًا وتحسينها واستعادتها، بينما يدرس تخصص قواعد البيانات تصميم النماذج ومحركات التخزين والاستعلام والمعاملات بصورة أوسع وأعمق.
7. هندسة البيانات تركز على بناء خطوط ومنصات موثوقة لنقل البيانات وتحويلها وتخزينها وإتاحتها للتحليلات والذكاء الاصطناعي، ولا تساوي تحليل البيانات أو علم البيانات.
8. نظم المؤسسات تدرس الأنظمة المتكاملة التي تدير الموارد والعمليات والبيانات بين أقسام المؤسسة، مثل ERP وCRM وSCM، مع التركيز على المواءمة بين التقنية والعمل.
9. الحوسبة المتنقلة أوسع من تطوير تطبيقات الهاتف؛ فهي تشمل الأنظمة والشبكات والسياق والحساسات والأمان والعمل أثناء التنقل وعبر أجهزة متعددة.
10. إنترنت الأشياء يجمع الأجهزة والحساسات والاتصال والمنصات والبيانات، ويتطلب اهتمامًا خاصًا بالأمن والسلامة والطاقة والاعتمادية؛ لأن الخطأ قد يؤثر في العالم المادي وليس في البيانات فقط.

# 1. الأمن السيبراني — Cybersecurity

## 1. معلومات التخصص الأساسية

| البند | التفاصيل |
|---|---|
| الرمز المرجعي | `MJR-0253` |
| اسم التخصص بالعربية | الأمن السيبراني |
| الاسم بالإنجليزية | Cybersecurity |
| الكلية أو المجال الأكاديمي | كلية الحوسبة وتقنية المعلومات، وقد يطرح ضمن علوم الحاسوب أو تقنية المعلومات أو كلية مستقلة للأمن السيبراني |
| الدرجة الشائعة | بكالوريوس الأمن السيبراني أو بكالوريوس الحوسبة بمسار الأمن السيبراني |
| المدة الشائعة للدراسة | 4 سنوات غالبًا، وقد تكون 3 سنوات في بعض الأنظمة الجامعية |
| توفر التخصص | متزايد الانتشار كتخصص مستقل، كما يطرح بكثرة كمسار داخل علوم الحاسوب أو تقنية المعلومات |
| الوصف المختصر | دراسة حماية الأنظمة والشبكات والتطبيقات والبيانات والخدمات الرقمية من الهجمات والأخطاء وسوء الاستخدام، مع الاستعداد للكشف والاستجابة والتعافي. |

## 2. نبذة عن التخصص

يتعامل الأمن السيبراني مع المخاطر التي تهدد البيئة الرقمية للمؤسسات والأفراد والدول. يدرس الطالب كيف تعمل الأنظمة والشبكات والتطبيقات أولًا، ثم يتعلم كيف يمكن أن تتعرض للثغرات أو سوء الإعداد أو الاستغلال، وكيف تُصمم الضوابط التي تمنع الحوادث أو تقلل أثرها وتكشفها في الوقت المناسب.

التخصص لا يقتصر على الاختبار التقني، بل يجمع بين الهندسة والعمليات وإدارة المخاطر والحوكمة والقانون والأخلاقيات. لذلك يدرس الطالب أمن الشبكات والأنظمة والتطبيقات والتشفير وإدارة الهوية والمراقبة والاستجابة للحوادث، إضافة إلى السياسات والتقييم وإدارة استمرارية الأعمال. ويعد المختبر الآمن والمصرح به جزءًا أساسيًا من التدريب، لأن المهارات الهجومية لا يجوز تطبيقها على أنظمة حقيقية دون إذن مكتوب ونطاق محدد.

# 2. أمن المعلومات — Information Security

## 1. معلومات التخصص الأساسية

| البند | التفاصيل |
|---|---|
| الرمز المرجعي | `MJR-0254` |
| اسم التخصص بالعربية | أمن المعلومات |
| الاسم بالإنجليزية | Information Security |
| الكلية أو المجال الأكاديمي | كلية الحوسبة وتقنية المعلومات، وقد يطرح ضمن نظم المعلومات أو إدارة الأعمال التقنية أو الأمن السيبراني |
| الدرجة الشائعة | بكالوريوس أمن المعلومات أو بكالوريوس تقنية المعلومات بمسار أمن المعلومات |
| المدة الشائعة للدراسة | 4 سنوات غالبًا، وقد تكون 3 سنوات في بعض الأنظمة |
| توفر التخصص | يطرح كتخصص مستقل أو مسار، وقد تختلف البرامج بين التركيز التقني والتركيز الإداري والحوكمي |
| الوصف المختصر | دراسة حماية المعلومات من الوصول أو التعديل أو الإفشاء أو الفقد غير المصرح به، عبر ضوابط تقنية وإدارية ومادية طوال دورة حياة المعلومات. |

## 2. نبذة عن التخصص

ينطلق أمن المعلومات من ثلاثة أهداف رئيسية: سرية المعلومات وسلامتها وتوافرها، ثم يضيف إليها الخصوصية والأصالة والمساءلة والمرونة. يهتم التخصص بالمعلومة نفسها منذ إنشائها وجمعها وتصنيفها واستخدامها ومشاركتها وتخزينها حتى إتلافها، بصرف النظر عن وجودها في قاعدة بيانات أو ملف ورقي أو بريد إلكتروني أو خدمة سحابية.

لهذا يجمع البرنامج بين أساس تقني في الحوسبة والشبكات والتشفير، وأساس تنظيمي في السياسات والمخاطر والتدقيق واستمرارية الأعمال والامتثال والخصوصية. ويحتاج الخريج إلى فهم كيف تتكامل الضوابط التقنية مع السلوك البشري والإجراءات والعقود والموردين، لأن حماية المعلومات لا تتحقق بأداة واحدة أو جدار ناري فقط.

# 3. الأدلة الجنائية الرقمية — Digital Forensics

## 1. معلومات التخصص الأساسية

| البند | التفاصيل |
|---|---|
| الرمز المرجعي | `MJR-0255` |
| اسم التخصص بالعربية | الأدلة الجنائية الرقمية |
| الاسم بالإنجليزية | Digital Forensics |
| الكلية أو المجال الأكاديمي | كلية الحوسبة وتقنية المعلومات، وقد يطرح ضمن الأمن السيبراني أو العدالة الجنائية أو علوم الأدلة |
| الدرجة الشائعة | بكالوريوس الأدلة الجنائية الرقمية أو بكالوريوس الأمن السيبراني بمسار التحليل الجنائي الرقمي |

## 2. نبذة عن التخصص

تنشأ الأدلة الرقمية من الحواسيب والهواتف والشبكات والخدمات السحابية والتطبيقات والأجهزة الذكية. يدرس الطالب كيف تُعزل الأجهزة أو الحسابات ذات الصلة، وكيف تُنشأ نسخ جنائية موثوقة دون تغيير الأصل، وكيف تُستخرج الآثار والملفات والسجلات والتوقيتات ثم تُربط في تسلسل منطقي يجيب عن أسئلة التحقيق.

يجمع التخصص بين المعرفة التقنية والإجراءات القانونية والأخلاقية. فالنتيجة الجيدة ليست مجرد العثور على ملف، بل إثبات مصدره وسياقه وسلامته وحدود التحليل وتوثيق كل خطوة وأداة وتوقيت. كما يتعلم الطالب التمييز بين الحقائق التي تدعمها الأدلة والاستنتاجات المحتملة، وتجنب تجاوز التفويض أو كشف بيانات لا علاقة لها بالقضية.

# 4. أمن الشبكات — Network Security

## 1. معلومات التخصص الأساسية

| البند | التفاصيل |
|---|---|

| اسم التخصص بالعربية | أمن الشبكات |

## 2. نبذة عن التخصص

يشمل التخصص حماية شبكات المؤسسات ومراكز البيانات والسحابة والشبكات اللاسلكية والاتصال عن بعد. ولا يكفي تركيب جدار ناري؛ إذ يحتاج المهندس إلى فهم هندسة الشبكة وتدفقات العمل والهوية والسجلات والاعتمادية، وتصميم الضوابط بحيث لا تتحول الحماية إلى نقطة فشل أو عائق غير ضروري للخدمة.

| تطوير تطبيقات الهاتف | يركز على بناء التطبيقات، بينما تشمل الحوسبة المتنقلة الشبكات والسياق والأنظمة والطاقة والأجهزة. |
| الحوسبة المتنقلة السحابية | مجال فرعي يركز على توزيع العمل بين الجهاز والسحابة والطرف. |
| إنترنت الأشياء | يركز على الأشياء والحساسات والاتصال الآلي، وقد لا يكون المستخدم المتنقل هو المركز. |
| الاتصالات اللاسلكية | تركز على القنوات والشبكات والبروتوكولات أكثر من التطبيقات وتجربة المستخدم. |

## 10. التنبيه المهني عند الحاجة

> **الموقع والكاميرا والميكروفون وجهات الاتصال ومعرّفات الجهاز بيانات وصلاحيات شديدة الحساسية. يجب طلب الحد الأدنى منها عند الحاجة، وشرح الغرض، وتأمين التخزين والنقل، وعدم تتبع المستخدم أو جمع بياناته في الخلفية دون موافقة وأساس واضحين.**

# 10. إنترنت الأشياء — Internet of Things

## 1. معلومات التخصص الأساسية

| البند | التفاصيل |
|---|---|
| الرمز المرجعي | `MJR-0262` |
| اسم التخصص بالعربية | إنترنت الأشياء |
| الاسم بالإنجليزية | Internet of Things |
| الكلية أو المجال الأكاديمي | كلية الحوسبة وتقنية المعلومات، وقد يطرح ضمن هندسة الحاسوب أو الإلكترونيات أو الاتصالات أو الذكاء الاصطناعي |
| الدرجة الشائعة | بكالوريوس إنترنت الأشياء أو بكالوريوس الحوسبة/الهندسة بمسار إنترنت الأشياء |
| المدة الشائعة للدراسة | 4 سنوات غالبًا، وقد تمتد إلى 5 سنوات عندما تطرح كدرجة هندسية |
| توفر التخصص | متزايد الانتشار كتخصص مستقل أو مسار متعدد التخصصات يجمع العتاد والبرمجيات والاتصال والبيانات |
| الوصف المختصر | دراسة تصميم وربط وتشغيل وتأمين أجهزة وحساسات قادرة على جمع بيانات من العالم المادي وتبادلها ومعالجتها واتخاذ إجراءات عبر الشبكات والمنصات الطرفية والسحابية. |

## 2. نبذة عن التخصص

يتكون نظام إنترنت الأشياء من أكثر من جهاز متصل؛ فهو منظومة تضم حساسًا أو مشغلًا، ومتحكمًا أو منصة مضمنة، واتصالًا محليًا أو واسع النطاق، وبوابة أو حوسبة طرفية، وخدمة سحابية، وبيانات وتطبيقًا للمستخدم أو نظامًا آليًا. يدرس الطالب كيف تتكامل هذه الطبقات تحت قيود الطاقة والحجم والتكلفة والاتصال والأمان.

تتنوع التطبيقات من المنازل والمباني والمدن إلى الصناعة والزراعة والصحة والنقل والبيئة. وبسبب اتصال النظام بالعالم المادي، فإن التصميم يحتاج إلى السلامة والاعتمادية والتحديث الآمن وإدارة دورة حياة الجهاز، لا إلى سرعة إرسال البيانات فقط. كما يتعلم الطالب أن الأجهزة محدودة الموارد قد تبقى سنوات في الميدان، مما يجعل الهوية والتشفير والتحديث والمراقبة عناصر أساسية منذ التصميم.

- شبكات الحاسوب والاتصالات

### المواد الأساسية والجانب العملي

- معماريات إنترنت الأشياء وطبقاتها
- الحساسات والمشغلات وواجهات الأجهزة
- المتحكمات والبرمجة المضمنة
- بروتوكولات الاتصال قصيرة وبعيدة المدى
- بروتوكولات الرسائل وإدارة الأجهزة
- البوابات والحوسبة الطرفية
- المنصات السحابية وتخزين البيانات

- مشروع منظومة إنترنت أشياء متكاملة

يبني الطالب نموذجًا يبدأ بحساس أو جهاز، ثم يبرمج المتحكم، ويختار الاتصال، ويرسل البيانات إلى بوابة أو سحابة، ويعرضها أو يستخدمها لتشغيل مشغل. ويختبر فقد الاتصال والطاقة والتأخير والتكرار والتحديث والأمن، ويوثق الهوية والمفاتيح وإجراءات النشر والصيانة.
