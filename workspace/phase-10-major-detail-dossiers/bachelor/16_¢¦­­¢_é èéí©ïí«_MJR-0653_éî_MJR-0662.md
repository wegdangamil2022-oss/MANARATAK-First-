# تخصصات بكالوريوس الاتصال المؤسسي والإعلام والإنتاج والنشر
## الدفعة التالية (MJR-0653 إلى MJR-0662)

> **عدد التخصصات:** 10  
> **النطاق:** معلومات التخصص نفسه فقط  
> **غير مشمول:** الجامعات، الدول، لغات الدراسة، الرسوم، المنح، الدورات، شروط القبول، والرواتب  
> **الإصدار:** 1.0  
> **تاريخ الإعداد:** 05 أغسطس 2026

## ملاحظات تحريرية مهمة

1. أسماء التخصصات ورموزها وترتيبها من MJR-0653 إلى MJR-0662 مأخوذة حرفيًا من ملف تخصصات البكالوريوس المرجعي، بينما الشرح تحرير تعريفي عام وفق القالب المعتمد.
2. الاتصال المؤسسي يدير هوية المؤسسة ورسائلها الداخلية والخارجية، بينما الاتصال السياسي يركز على السلطة والحملات والرأي العام.
3. الاتصال الصحي مجال غير سريري ولا يمنح صلاحية التشخيص أو العلاج.
4. الإعلام الرقمي يركز على إنتاج وإدارة المحتوى عبر المنصات، بينما الإعلام الجديد يهتم أيضًا بالتحولات التفاعلية والشبكية والناشئة.
5. الإنتاج الإذاعي والتلفزيوني يشمل البرامج والبث، بينما الإنتاج السينمائي يركز على دورة صناعة الفيلم.
6. كتابة السيناريو تركز على النص والبنية والشخصيات، ولا تساوي الإخراج أو الإنتاج.
7. التصوير الصحفي يخضع لمعايير التحقق وعدم التلاعب والسياق والكرامة.
8. النشر يشمل التحرير والحقوق والتصميم والإنتاج والتسويق والتوزيع، وليس الكتابة وحدها.
9. العمل في مواقع التصوير والبث يتطلب إدارة السلامة والتصاريح وحقوق الاستخدام.
10. جميع التخصصات تتطلب احترام الخصوصية والملكية الفكرية والشفافية وعدم التضليل أو استغلال الفئات الحساسة.

# 1. الاتصال المؤسسي — Corporate Communication

## 1. معلومات التخصص الأساسية

| العنصر | المعلومات |
|---|---|
| الرمز المرجعي | `MJR-0653` |
| الاسم بالعربية | الاتصال المؤسسي |
| الاسم بالإنجليزية | Corporate Communication |
| الكلية أو المجال الأكاديمي | كلية الإعلام والاتصال أو إدارة الأعمال |
| الدرجة الشائعة | بكالوريوس الاتصال المؤسسي |
| المدة الشائعة للدراسة | 4 سنوات غالبًا، وقد تكون 3 سنوات في بعض الأنظمة |
| طبيعة توفر التخصص | يطرح كتخصص مستقل أو مسار داخل العلاقات العامة والاتصال الاستراتيجي |
| الوصف المختصر | إدارة هوية المؤسسة ورسائلها وعلاقاتها واتصالاتها الداخلية والخارجية بصورة متكاملة. |

## 2. نبذة عن التخصص

يركز الاتصال المؤسسي على كيفية تعريف المؤسسة بنفسها والتواصل مع الموظفين والعملاء والإعلام والمستثمرين والحكومة والمجتمع. يشمل الهوية والسمعة والاتصال الداخلي وعلاقات المستثمرين والأزمات والمسؤولية والاستدامة.

يختلف عن الاتصال التسويقي الذي يركز على العملاء والسوق، إذ يتعامل الاتصال المؤسسي مع المؤسسة ككل ومع جماهير متعددة ومصالح قد تكون متعارضة.

يختلف تنظيم البرنامج بين الجامعات؛ فقد يطرح كتخصص مستقل أو مسار داخل برنامج أوسع، وتختلف نسبة التدريب العملي والاستوديوهات والمشروعات بحسب طبيعة الجامعة. لذلك يجب مراجعة الخطة الدراسية الفعلية وعدم الاعتماد على اسم التخصص وحده.

# 3. الاتصال الصحي — Health Communication

## 1. معلومات التخصص الأساسية

| العنصر | المعلومات |
|---|---|
| الرمز المرجعي | `MJR-0655` |
| الاسم بالعربية | الاتصال الصحي |
| الاسم بالإنجليزية | Health Communication |
| الكلية أو المجال الأكاديمي | كلية الإعلام والاتصال أو الصحة العامة |
| الدرجة الشائعة | بكالوريوس الاتصال الصحي |
| المدة الشائعة للدراسة | 4 سنوات غالبًا، وقد تكون 3 سنوات في بعض الأنظمة |
| طبيعة توفر التخصص | يطرح كتخصص متعدد التخصصات أو مسار داخل الاتصال والصحة العامة |
| الوصف المختصر | تصميم وتقييم التواصل الصحي بين الأفراد والمؤسسات والجمهور لدعم الفهم والوقاية والقرارات المستنيرة. |

## 2. نبذة عن التخصص

يجمع الاتصال الصحي بين علوم الاتصال والصحة العامة، ويدرس كيفية شرح المعلومات الصحية، وتصميم حملات الوقاية، وتحسين تواصل المرضى ومقدمي الرعاية، وإدارة الاتصال أثناء الأوبئة والأزمات.

لا يمنح التخصص صلاحية التشخيص أو العلاج، لكنه يهيئ للعمل في التوعية والبحث وتصميم الرسائل ومحو الأمية الصحية وتجربة المريض، بالتعاون مع المختصين الصحيين.

يختلف تنظيم البرنامج بين الجامعات؛ فقد يطرح كتخصص مستقل أو مسار داخل برنامج أوسع، وتختلف نسبة التدريب العملي والاستوديوهات والمشروعات بحسب طبيعة الجامعة. لذلك يجب مراجعة الخطة الدراسية الفعلية وعدم الاعتماد على اسم التخصص وحده.

> **لا يجوز فبركة المشاهد أو تعديل الصورة بما يغير معناها، ويجب احترام الخصوصية والكرامة والموافقات وسلامة المصور والأشخاص، وتجنب نشر صور صادمة بلا مصلحة عامة واضحة.**

# 10. النشر — Publishing

## 1. معلومات التخصص الأساسية

| العنصر | المعلومات |
|---|---|
| الرمز المرجعي | `MJR-0662` |
| الاسم بالعربية | النشر |
| الاسم بالإنجليزية | Publishing |
| الكلية أو المجال الأكاديمي | كلية الإعلام والاتصال أو الآداب وإدارة الأعمال |
| الدرجة الشائعة | بكالوريوس النشر |
| المدة الشائعة للدراسة | 4 سنوات غالبًا، وقد تكون 3 سنوات في بعض الأنظمة |
| طبيعة توفر التخصص | يطرح كتخصص مستقل أو مسار داخل الإعلام واللغة وإدارة الصناعات الإبداعية |
| الوصف المختصر | إدارة دورة حياة الكتب والمجلات والمحتوى من اختيار النص والتحرير والتصميم إلى الإنتاج والتسويق والتوزيع. |

## 2. نبذة عن التخصص

يدرس تخصص النشر كيفية تحويل المخطوط أو الفكرة إلى منتج منشور ورقي أو رقمي. يشمل اكتساب الحقوق والتحرير والمراجعة والتصميم والإنتاج والطباعة والبيانات الوصفية والتسويق والتوزيع والمبيعات والنشر الإلكتروني.

يجمع المجال بين الحس التحريري والإدارة والتقنية والقانون، ويختلف عن الكتابة التي تنتج النص، وعن إدارة المحتوى التي تنظم محتوى مؤسسات ومنصات متنوعة.

يختلف تنظيم البرنامج بين الجامعات؛ فقد يطرح كتخصص مستقل أو مسار داخل برنامج أوسع، وتختلف نسبة التدريب العملي والاستوديوهات والمشروعات بحسب طبيعة الجامعة. لذلك يجب مراجعة الخطة الدراسية الفعلية وعدم الاعتماد على اسم التخصص وحده.

## 7. أهم الوظائف المرتبطة بالتخصص

## 9. التخصصات المشابهة

| التخصص المشابه | الفرق المختصر |
|---|---|
| إدارة المحتوى | تنظم دورة المحتوى داخل المؤسسات والمنصات، لا الكتب فقط. |
| التحرير | وظيفة جوهرية داخل النشر لكنها لا تشمل كامل العمل التجاري والإنتاجي. |
| المكتبات والمعلومات | تركز على تنظيم المعلومات وإتاحتها وحفظها. |
| الكتابة الإبداعية | تنتج النصوص، بينما النشر يختارها ويطورها ويوصلها للسوق. |

## 10. التنبيه المهني عند الحاجة

> **يجب احترام حقوق المؤلف والعقود والإتاوات والخصوصية، وعدم نشر مواد مسروقة أو تشهيرية، وضمان دقة البيانات الوصفية والإفصاح عن النسخ المعدلة أو المولدة آليًا عند الحاجة.**
