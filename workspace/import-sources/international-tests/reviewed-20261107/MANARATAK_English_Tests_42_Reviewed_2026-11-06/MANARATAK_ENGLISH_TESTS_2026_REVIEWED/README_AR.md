# مكتبة منارتك — اختبارات اللغة الإنجليزية

هذه الحزمة تحتوي على **42 دليلًا مستقلًا، موحّدًا في 16 قسمًا** وفق التسلسل الفعلي لملف IELTS. الهدف إتاحة الملفات لواجهة تصميم واحدة دون إضافة قسم رئيسي مختلف بين الاختبارات.

- `01_Guides_42_MD/` — جميع الأدلة بصيغة Markdown.
- `02_Template_And_QA/TEMPLATE_16_SECTIONS.md` — القالب المعتمد.
- `02_Template_And_QA/MANARATAK_ENGLISH_42_MANIFEST.json` — قائمة مرتبة وبيانات تقنية لتوليد تبويبات المنصة.
- `02_Template_And_QA/QUALITY_CHECK_42.csv` — تقرير فحص مستقل لكل اختبار.
- `02_Template_And_QA/QUALITY_REPORT_AR.md` — التغييرات والقيود والتحقق.
- `02_Template_And_QA/OFFICIAL_REFERENCES_VERIFIED_2026-11-06.md` — مراجع رسمية منتقاة.

**ملحوظة:** الترتيب المعتمد هنا يخص الـ16 قسمًا داخل كل اختبار. اسم ملف كل اختبار حُفظ كما في مصدره، ويحتوي `manifest.json` على ترتيب عرض مقترح يبدأ بأشهر الاختبارات.
