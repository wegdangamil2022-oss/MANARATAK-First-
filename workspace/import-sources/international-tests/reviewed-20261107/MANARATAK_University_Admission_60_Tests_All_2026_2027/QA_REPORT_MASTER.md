| العنصر | النتيجة |
|---|---:|
| أرشيفات الدفعات الأصلية | 28 |
| ملفات Markdown الأصلية | 60 |
| ملفات JSON الأصلية | 60 |
| الاختبارات ذات الأسماء غير المكررة | 60 |
| الاختبارات بأقسام مرقمة من 1 إلى 16 دون نقص | 60 من 60 |
| ملفات JSON بعدد 16 قسمًا | 60 من 60 |

### ما الذي تم التحقق منه؟

1. فتح كل أرشيف من الدفعات الـ28 وتشغيل اختبار CRC على كامل أعضائه.
2. استخراج ملفي Markdown وJSON لكل اختبار ومطابقة أسمائهما مع ترتيب الاختبارات المتفق عليه.
3. فحص تسلسل عناوين Markdown الرئيسية من القسم 1 إلى القسم 16، والتحقق من وجود 16 قسمًا في JSON.
4. نسخ الملفات **بايتًا مقابل بايت** دون تحرير أو اختصار أو إعادة توليد المحتوى.
5. الاحتفاظ بكل أرشيف دفعة أصلي في مجلد خاص داخل الأرشيف الموحد.
6. فحص مطابقة جميع الملفات المستخرجة مع نظائرها داخل الأرشيف النهائي.

### حدود التحقق

- **لم تُعد كتابة النصوص أو توحيد مخططات JSON المختلفة**؛ جميعها النسخ الأصلية.
- لا يفيد فحص عدد الأقسام بأن عناوينها الفرعية متطابقة لفظيًا في جميع الدفعات القديمة.
- **لم تُراجع صحة كل معلومة أو صلاحية كل رابط خارجي** في هذا الفحص؛ العمل الحالي هو الجمع والحفظ والتحقق من السلامة.
