# منارتك — الأرشيف الموحد لاختبارات القبول (60 اختبارًا)

تم تجميع جميع الأدلة والملفات الأصلية الموجودة في **28 دفعة**. توجد ملفات Markdown وJSON الأصلية دون أي تعديل على محتواها، إضافة إلى نسخة كاملة من أرشيف كل دفعة.

## تنظيم المجلدات

- `01_GUIDES_MARKDOWN/` — **60 دليلًا** بصيغتها الأصلية Markdown.
- `02_GUIDES_JSON/` — **60 ملف JSON** يقابل كل دليل.
- `03_BATCH_METADATA/` — ملفات الفهارس وتقارير الجودة وملفات التحقق الأصلية حسب الدفعة.
- `04_ORIGINAL_BATCH_ZIPS/` — ملفات ZIP الأصلية الـ28 لمن يريد كل محتويات الدفعات كما صدرت.
- `INDEX_MASTER.md` — قائمة الاختبارات كاملة بالترتيب الأصلي.
- `QA_REPORT_MASTER.md` — نتائج الفحص التقني أثناء التجميع.
- `MANIFEST.json` — بيانات منظمة تفصيلية ومقاييس وبصمات SHA-256 للأدلة.
- `SHA256SUMS.txt` — بصمات الملفات المجمّعة.

**تنبيه:** فحص سلامة الملفات والأقسام لا يعادل تدقيقًا أكاديميًا مستقلًا لصحة كل معلومة في الأدلة، ولا يضمن أن تحديثات العام اللاحق قد صدرت.
