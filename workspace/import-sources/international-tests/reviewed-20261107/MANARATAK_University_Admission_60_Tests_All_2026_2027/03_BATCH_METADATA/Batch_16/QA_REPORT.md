# تقرير فحص الدفعة السادسة عشرة — منارتك

**تاريخ المراجعة:** 5 نوفمبر 2026.

### فحص البنية والملفات
- اختباران مرقمان 31 و32، ولكل دليل 16 قسمًا مرقمًا مرتبًا وفق قالب IELTS المعدل بلا قسم زائد أو مقدمة خارج الأقسام.
- الحفاظ على جميع فقرات كل قسم في JSON بصيغة `body_markdown` دون اقتطاع أو تلخيص، مع عناصر `blocks` قابلة للعرض.
- التحقق من انتظام أعمدة الجداول وترتيب العناوين ووجود الروابط الرسمية وعدم وجود عبارات داخلية للمصممين.
- استخدام بيانات 2026 لنظام وأسعار UG وPG مع تسمية السنة بوضوح؛ عدم اختراع موعد رسمي لـUG 2027.
- استخدام الجدول الرسمي المعدل بتاريخ 26 أكتوبر 2026 لمواعيد PG 2027 المبدئية بدل الجدول القديم.
- اختبار صحة JSON وأرشيف ZIP والهاش SHA-256 لكل ملف.
