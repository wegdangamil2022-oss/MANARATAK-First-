## نطاق الفحص
- **مطابقة عدد وترتيب الأقسام:** 16/16 لكل دليل؛ أسماء الأقسام تطابق ترتيب قالب IELTS المعدّل.
- **مطابقة JSON مع Markdown:** كل قسم يتضمن حقل `markdown` الأصلي كاملاً وحقل `blocks` لتنظيم العرض؛ جرى اختبار التطابق النصي آليًا.
- **فحص الجداول:** تم التحقق من تساوي عدد خلايا صفوف الجداول مع عناوينها.
- **فصل البيانات الزمنية:** تواريخ 2027 رسمية من تقويم ÖSYM المنشور 28 أكتوبر 2026؛ معلومات الرسوم وبنية الجلسات تُقدم بصفتها مرجع دورة 2026 عند عدم نشر دليل دورة 2027.
- **منع المحتوى الإداري:** لا توجد عبارات حالة اعتماد أو تعليمات برمجة داخل دليل الطالب.
- **قيد التحقق:** فحص الروابط يعني فحص عددها وبنيتها المبدئية، ولا يضمن بقاء المواقع متاحة في المستقبل، ولا يعني التحقق من كل بند في كل دليل PDF مفصّل.
- **الحقوق:** لم تُنسخ الأسئلة المحمية؛ أي أمثلة تدريبية وصفت صراحة بأنها أصلية.
