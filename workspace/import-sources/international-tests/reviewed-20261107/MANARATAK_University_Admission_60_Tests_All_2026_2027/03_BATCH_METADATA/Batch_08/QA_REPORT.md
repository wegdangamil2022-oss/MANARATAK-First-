## نطاق التحقق

- تطابق 16 قسمًا وترتيبها مع هيكل دليل IELTS.
- عدم وجود نص تمهيدي أو تعليمات إدارية خارج الأقسام الرئيسية.
- فحص الجداول وعدد الأعمدة وعدم فقدان الأقسام أثناء تحويلها إلى JSON.
- استخراج الروابط الموجودة داخل الأدلة من المواقع الحكومية المرتبطة.
- اختلاف الرسوم والمواعيد بحسب المستفيد أو الدورة يُراجع داخل منصة الحجز ولا يُقدَّم كتسعيرة عامة.
- هذا الفحص بنيوي ومراجعة مصادر أساسية، ولا يحل محل تحقق مسؤول المحتوى عند تحديث موسم الاختبارات.

## الملفات المعتمدة

- دليلا Markdown مستقلان.
- ملفا JSON منظمان بنوع البيانات والبنية وترقيم الأقسام.
- فهرس Markdown وفهرس JSON.
- التقرير الحالي.
