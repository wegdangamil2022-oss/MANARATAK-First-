## التحقق البنيوي

- كل دليل يبدأ بعنوانه مباشرة ثم «1. نظرة عامة على الاختبار»، دون قسم مقدمة إضافية.
- تطابق الأقسام الستة عشر **عددًا وتسلسلًا وعنوانًا حرفيًا** مع قائمة IELTS المعدّل المعتمدة، ولا يوجد قسم 17 أو 18.
- كل قسم لا يقل عن 800 حرف ويتضمن عنوانين فرعيين على الأقل.
- كل دليل يتجاوز 3,500 كلمة و45 عنوانًا فرعيًا و80 سطر جداول و8 روابط HTTPS مميزة.
- يحفظ JSON النص الكامل وكل كتلة Markdown دون حذف أو تنقيح، وتمت إعادة بناء النص ومقارنته حرفيًا بالأصل.
- تأكدت سلامة ZIP ومطابقة التسعة ملفات داخل الأرشيف للملفات الأصلية، مع SHA-256 للثمانية المدخلة في البصمات.
