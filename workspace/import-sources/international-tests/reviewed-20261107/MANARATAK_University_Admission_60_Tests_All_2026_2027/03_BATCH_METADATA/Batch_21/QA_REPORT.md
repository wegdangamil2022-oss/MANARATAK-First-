## شروط النجاح

- ترقيم الأقسام: 1–16 متصل بلا أقسام إضافية، وترتيب العناوين مطابق لقالب IELTS المعدّل.
- لا توجد مادة إرشادية للطالب خارج الأقسام؛ يظهر عنوان الاختبار فقط خارجها.
- JSON يحفظ نص كل قسم كاملًا في `content_markdown` ويضيف `blocks` لتسهيل عرض الجداول والعناوين والقوائم.
- فحص إعادة بناء Markdown من JSON نجح حرفيًا لكل دليل.
- جرى فحص وجود الجداول والعناوين الفرعية وروابط رسمية داخل كل دليل.
- المواعيد والرسوم 2026 موسومة مرجعية، ولا يوجد ادعاء بفتح قبول 2027.

## نقاط تحقق معلوماتية

- IPMAT Indore: فصل المسار المحلي عن SAT للمتقدم الدولي بالاستناد إلى وثيقتي IIM Indore لسنة 2026.
- JIPMAT: فصل صلاحية الدخول للاختبار عن أهلية IIM Jammu وIIM Bodh Gaya، مع تأكيد اختلاف سياسة الأجانب.
- بنية JIPMAT 2026: 33 + 33 + 34 = 100 سؤال، والحد الأعلى 400 درجة، والمدة 150 دقيقة.
- بنية IPMAT Indore 2026: ثلاثة أقسام × 40 دقيقة؛ لم يُعتمد عدد أسئلة غير مثبت في دليل قبول المعهد.

**حدود المراجعة:** تحقق بنيوي ومرجعي للمعلومات الأساسية في المصادر المعلنة؛ لا يعني ضمان استمرار جميع الشروط والروابط والرسوم لدورة 2027. يُحدَّث الدليل عند صدور نشرات العام الجديد.
