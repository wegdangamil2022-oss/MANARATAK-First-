| 40 | ATMA | برامج الدراسات العليا الإدارية في الهند | Markdown + JSON |

**القالب المعتمد:** 16 قسمًا بالترتيب نفسه الموجود في دليل IELTS المعدل.  
**تاريخ التحقق:** 5 نوفمبر 2026.  
**التصنيف:** القبول والدراسات العليا > إدارة الأعمال؛ لا يُصنّفان اختبارات لغة ولا يُعدان إثباتًا تلقائيًا لأهلية الأجانب.  
**تاريخ دورة MAT المرجعية:** ديسمبر 2026.  
**تاريخ دورة ATMA المرجعية:** أغسطس 2026؛ تفاصيل دورة 2027 غير معلنة على المصدر الرسمي وقت المراجعة.

تصلح ملفات JSON للاستيراد البرمجي؛ يحفظ كل ملف Markdown كاملًا في `full_markdown` إضافة إلى `sections` و`blocks` لعرض المحتوى في الواجهة دون نصوص إدارية داخل دليل الطالب.
