## النتائج

- الملف يتضمن 274 مؤسسة: 134 مؤكدة بحسب البحث المرفق، 135 مؤكدة جزئيًا، حالتين غير محسومتين، وثلاث مؤسسات غير نشطة/تاريخية.
- طُبق 104 ربطًا بمدن أو بلدات؛ أضيفت 66 بلدة، وعدّلت أسماء بديلة أو بيانات منطقة في 21 سجل مدينة قائم.
- صُححت منطقة Qaskeleng/Kaskelen من مدينة ألماتي `KZ-75` إلى إقليم ألماتي `KZ-19`، ومنطقة Padang Besar من Kedah `MY-02` إلى Perlis `MY-09`، مع حفظ المعرفات الأصلية. لم تكن هناك جامعة مرتبطة بهذين المعرفين قبل الدفعة.
- جميع الجامعات الـ**10,723** محفوظة: **10,553** مرتبطة بالمصدر، و**170** للمراجعة. المدن **10,676**، والمناطق **5,003**، والدول **194**.
- رُبطت العناوين المحلية الإندونيسية بالبلدة الواردة في العنوان، مثل Ketaren وDukuhwaluh وKarangklesem وUjong Tanoh Darat، مع توثيق المديرية/الناحية في نطاق القرار.

## الحالات المعلقة

بقيت النتائج الجزئية الـ135، والحالتان غير المحسومتين، والثلاث التاريخية دون ربط نشط. كذلك بقيت 30 نتيجة صنّفها الملف «مؤكد» لأن المدينة وحدها لا تحسم المنطقة أو الوضع المؤسسي أو نطاق المقر. تتضمن هذه الثلاثون جامعات كوسوفو الثماني، منطقتي إثيوبيا الحاليتين، Troms وFinnmark، Kanifing، تغيرات فيتنام، بلديات Skopje، تعارض عدن/تعز، عنوانًا قرب Taoh، ومصدر Matsusaka التاريخي لعام 2005.

كل حالة لها قرار مستقل في `row-dispositions.json` وسبب حديث في ورقة `Geography Review` بملفات المرحلة الأولى. حُفظت أسماء المدن المؤكدة لبعض الحالات المعلقة دون تعيين معرف مدينة أو منطقة تخمينية. لم تُحذف مؤسسة أو تُغيّر هويتها أو تُنقل إلى دولة بديلة. الأسماء المؤسسية المقترحة محفوظة كأدلة؛ لم تتغير تلقائيًا من بحث الموقع.

## الأدلة وحدودها

`uploaded-rows.json` يحفظ الحقول العشرين لكل سجل. `reviewed-decisions.json` يربط القرار ببصمة الملف ورقم الصف ورابط المصدر ونطاق المقر. `applied-university-changes.jsonl` و`applied-city-changes.jsonl` يحفظان قبل/بعد. تستمر سلسلة إيصالات المصدر في `geography-research-restoration/2026-10-13`، مع حفظ الأرشيف التاريخي وتقارير الدفعات السابقة.

أُعيد طلب 147 رابطًا من النتائج المؤكدة ومصادرها المساندة؛ نتائج HTTP والبصمات في `http-source-rechecks.json`. نجاح الطلب لا يعني تحقق عنوان الحرم أو جميع الحدود. بعض الروابط محجوبة أو تعذرت قراءتها؛ تبقى القرارات موثقة بصفتها بحثًا قدمه المستخدم، ولا تُسمى تحققًا حيًا مستقلًا. جميع المدن المضافة بإحداثيات فارغة وتحت `NEEDS_MANUAL_REVIEW`.

جميع الروابط المضافة تحمل `USER_RESEARCH_ADDRESS_REQUIRES_OWNER_VERIFICATION`. هذه معرفات مصدر، وليست علاقات قاعدة بيانات أو موافقة نشر. لم يحصل اتصال بقاعدة بيانات أو استيراد فعلي أو ترحيل أو نشر للتطبيق.

## التحقق والاستكمال

```bash
python scripts/verify-university-location-workbook-batch12.py
python scripts/verify-geography-research-restoration.py
python scripts/tests/verify-geography-research-restoration.test.py
npm run imports:qc:verify
```
