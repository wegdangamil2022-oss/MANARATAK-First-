# معيار ترتيب لوحة الإدارة

توجيه المالك: الوصول السريع للعمل المفيد، استخدام خط القاهرة، وضبط المقاسات والمسافات، مع الحفاظ على إصلاحات البيانات والصلاحيات.

## المقياس المعتمد لهذه الدفعة

| الاستخدام | المقاس | الملاحظات |
| --- | --- | --- |
| عنوان الصفحة | 24px | وزن 800، دون عناوين ضخمة أو تكرار الاسم |
| عنوان سجل التخصص | 20px | رأس مضغوط، الاسم العربي وتحته الإنجليزي |
| عنوان القسم | 16px | تمييز القسم عن محتواه |
| عنوان فرعي | 14px | في تفاصيل التخصص |
| النصوص والحقول والتبويبات | 13px | في تفاصيل التخصص، مع ارتفاع سطر مريح |
| الرموز والبيانات المساعدة | 12px تقريبًا | لا تستخدم للأزرار الأساسية |

خط القاهرة مطبق على نصوص مساحة الإدارة، بما فيها العناصر القديمة التي تفرض خطًا أحادي المسافة. احتفظت الأيقونات برسوم SVG. لا يُعد هذا إثباتًا لمراجعة تطبيق الواجهة العامة المنفصل.

## ترتيب الصفحة

1. عنوان السجل وهويته المختصرة وحالته الحالية، ثم الإجراءات المتاحة أعلى الصفحة.
2. اختيار ملف الدرجة عند وجوده، دون بطاقة كبيرة تسبق العنوان.
3. تبويبات أو تنقّل واضح يلتف على الشاشات الصغيرة.
4. بيانات القسم ومحرره فقط؛ دون صندوق استخدام إداري متكرر قبل كل تبويب.
5. الارتباطات وأثر التغيير والمعرّفات داخل معلومات إضافية قابلة للفتح. تبقى أخطاء التحميل والتعديلات غير المحفوظة ظاهرة.

## حدود الحماية

- لا حذف لبيانات الاستخدام أو التاريخ أو أدلة المصدر لتبسيط الواجهة.
- لا تغيير لمسارات الحفظ أو معرّفات المستوى أو مراجعة النسخ.
- إجراءات النشر مرتبطة بالصلاحية والملف المحدد والجاهزية وحفظ التعديلات، وتظل قواعد الخادم المرجع النهائي.
- لا نقل قيم الترجمة أو التصنيف من خلال التخمين.
- إبقاء حقول القرار عند إغلاق لوحة النشر وإعادة فتحها، وحماية التعديلات عند تغيير المستوى أو التبويب.

## نطاق ما تحقق

- تفاصيل التخصص: ترتيب جديد للعنوان والإجراءات والدرجات والتبويبات والمعلومات الإضافية، مع فحص السلوك بالمتصفح.
- معيار الخط وعنوان الصفحة: مشترك في مساحة الإدارة، وتحقق مباشرة في قوائم المنح والجامعات والتخصصات.
- ترتيب قوائم المنح والجامعات والتخصصات موثق في ملفاتها السابقة.
- المراجعة التفصيلية لبقية الصفحات تُنفّذ قسمًا قسمًا؛ لا يُستنتج اكتمال مراجعتها من تطبيق الخط المشترك.

## دليل الدفعة

فحص Chromium على الحزمة الفعلية ببيانات صناعية فقط، بمقاسات 1360/820/390: خط القاهرة محمّل، عنوان 24px، تبويبات 13px دون تمرير أفقي، تأكيد النشر، تعطيل النشر عند غياب الصلاحية أو الجاهزية أو وجود تعديلات، حماية تبديل المستوى والتبويب، الوصول للمعلومات الإضافية، وبقاء حقول المراجعة بعد إغلاق اللوحة. لم يتصل فحص المتصفح بقاعدة البيانات ولم ينفذ كتابة.

ثمانية معالجات تحميل/تحرير/حفظ/تبديل مستوى/نشر تطابقت نصيًا مع الحالة السابقة. نجح TypeScript وبناء الإدارة. فحص الصفحة: صفر أخطاء lint وتحذير Hook قديم واحد. بقيت تحذيرات حجم الحزمة والخطوط وقت البناء؛ تحقق تحميل القاهرة فعليًا داخل المتصفح.

الأدلة المحلية: `private/admin-major-detail-20261023/BROWSER_CHECK.json` و`HANDLER_INTEGRITY.json` وصور الصفحة. هذه الدفعة لا تُثبت قبول نشر محتوى حقيقي ولا تعيد فتح تغييرات قاعدة البيانات.

تحديث لاحق بتوجيه المالك: [العرض المضغوط للتخصصات](ADMIN_MAJOR_COMPACT_PRESENTATION_2026-10-23.md). يتقدم مقياس رأس السجل 20px وبطاقاته 15px وعناوين الفلاتر 13px وقيمها 12px على مقاسات هذه العناصر في الدفعة الأولى أعلاه. لا يتغير عنوان قوائم الإدارة العام 24px.
