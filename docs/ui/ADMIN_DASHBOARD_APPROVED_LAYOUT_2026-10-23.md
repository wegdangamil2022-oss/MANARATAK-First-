# تنظيم لوحة التحكم المعتمد

اعتمد المالك تنظيم لوحة التحكم بعد شرح محتويات الملف `MANARATAK-First--main.zip`، وطلب الحفاظ على الإصلاحات وترتيب الإضافات. الاعتماد هنا لتصميم الواجهة؛ لا يغيّر حالات قبول مراحل R أو بوابات النشر.

## ترتيب الصفحة

1. عنوان لوحة التحكم وزر تحديث المؤشرات وحالة قراءة المصادر.
2. بطاقات حجم المنصة الثماني، بالأيقونات والألوان القائمة.
3. إشارات المتابعة مع اسم القسم على كل بطاقة، وبطاقة الصحة والجاهزية.
4. دليل جميع أقسام الإدارة المتاحة للحساب، في المجموعات الست نفسها المعتمدة في القائمة الرئيسية. للحساب ذي جميع الصلاحيات يوجد 27 رابطًا؛ لوحة التحكم نفسها هي القسم الثامن والعشرون ولا يتكرر رابطها داخلها.
5. تفاصيل مؤشرات الأقسام: لوحة مستقلة قابلة للفتح لكل مجال مصرح به، مع بقاء المؤشرات ومصادرها وروابطها وأزرار إعادة القراءة.
6. النشاط الإداري المصرح، ثم تغطية القياس والنواقص المعلنة.

يُشتق الدليل مباشرة من سجل التنقل القائم، لذلك تظهر الأقسام المضافة إليه تلقائيًا بحسب صلاحيات الحساب. لا يُطلب من الخادم عدّ سجلات الأقسام التي ليس لها عقد قياس قائم.

## الضوابط والتحقق

لم تتغير عقود API أو قاعدة البيانات أو الطلبات أو مهلات القراءة أو ضوابط النشر والمال. تبقى حالات الأعداد المجهولة والقديمة ظاهرة دون تحويلها إلى أصفار. تُحجب روابط الأقسام ومجموعات المؤشرات عند سحب صلاحياتها.

نجح TypeScript واختبارا Dashboard القائمان. وُسّع فحص سحب الصلاحية ليشمل روابط الدليل وإزالة مجموعة مؤشرات المنح فورًا؛ لم تُعد المجموعات العامة. نجح ESLint دون أخطاء، مع ثلاثة تحذيرات في الصفحة والاختبار القائمين. يُسجل التحقق البصري للحزمة المحلية في دليل التسليم المنفصل بعد البناء.

## الحزمة المحلية وحدود فحص المتصفح

بُنيت حزمة الإدارة من `06b056be462d551fd85db9da8d20c8e511076a36` وتحققت مطابقة HTML الذي يقدمه العنوان المحلي لها. استُبدلت ملفات الواجهة فقط مع إبقاء ملفات الحزمة السابقة ذات الأسماء المبصومة للتبويبات المفتوحة. لم يُعد تشغيل API أو تغيير مفاتيحه أو إبطال جلسات المستخدمين؛ مصدر API الجاري ما زال `758a63cc1768924063f4c00ea291f4867d55962a`.

لم يكتمل فحص المسار الحقيقي: طلب POST لتسجيل الدخول لم يرجع استجابة خلال 90 ثانية، ثم أثبتت محاولة تشخيصية ذات تسجيل للطلبات وصول الطلب إلى عنوانه دون استجابة خلال 30 ثانية. كانت حيوية API متاحة بـHTTP 200؛ لم يثبت سبب تعطل تسجيل الدخول، ولم يُعد الفحص الحقيقي بعد المحاولة التشخيصية.

لإتمام فحص التصميم دون تغيير صلاحيات حساب فعلي أو طلب بياناته، استُخدم متصفح معزول برد جلسة اختباري وردود مصادر HTTP 503 داخل أداة الفحص فقط. نجح عرض الروابط الـ27 في ست مجموعات ومطابقتها للقائمة الرئيسية دون تكرار، وظهرت مجموعات المؤشرات الـ11 وبطاقاتها الـ53، وفُتحت تفاصيل المنح وعمل الانتقال إلى البيانات المرجعية. نجح العرض على 1360×1000 و390×844 دون تمدد أفقي أو أخطاء JavaScript؛ بقيت الأعداد مجهولة عند تعذر مصادرها. هذه نتيجة واجهة معزولة وليست إثبات دخول فعلي أو اتصال جميع مصادر البيانات.

أدلة هذه الدفعة محلية في `private/admin-dashboard-approved-20261023/`: ملف `LOCAL_ARTIFACT_INSTALL.json` لإثبات الحزمة، و`BROWSER_CHECK.json` لعائق الدخول الحقيقي، و`ISOLATED_UI_CHECK.json` لفحص التصميم المعزول. لم تحاول أداة التصميم أية كتابة محتوى.
