# دورات منارتك — استكمال الصلاحيات والإتاحة والشهادات

## 1. الصلاحيات — منفذ

تمت إضافة سياسة `COURSE_SCOPE` إلى IAM القائم، دون جدول مدربين أو ACL موازٍ. السياسة تقبل 1–100 معرف دورة UUID صريحًا، وتفشل مغلقة عند غياب السياق أو فساد الإعداد. لا يمكنها تفويض المالية أو الشهادات. جميع سياسات الدور الأخرى (الوقت/IP وفصل الواجبات) تظل نافذة.

من إدارة الصلاحيات: أنشئ سياسة «نطاق دورات محددة»، ثم دورًا يتضمن `admin:courses:workspace` و`admin:courses:read`، وإحدى قدرات `edit` أو `review` أو `publish` أو `grade` أو `learners` وفق الوظيفة. اربط السياسة بالدور وأسنده للهوية عبر مسار IAM المعتمد والتحقق الثنائي والموافقات الحالية. لا يكفي تغيير اسم الدور إلى «مدرب»، ولا تمنح واجهة الدورات أدوارًا تلقائيًا.

تفتح «الدورات المسندة» مساحة محدودة، مع صفحة خادمية بحجم 20. الأدوات المخفية غير متاحة عبر API أيضًا. المحرر المسند يحرر المنهج والتقييمات، والمراجع يعتمد الجاهزية، والناشر ينشر/يلغي النشر، والمصحح يقرأ التسليمات ويعتمد درجاتها. الاطلاع على الطلاب والتقارير قدرة مستقلة. إدارة السياسات التجارية والنسخ والأرشفة تظل للمدير العام للقسم. لا يتغير وصول المديرين الحاليين.

التحقق: 504 اختبارات وحدة/عقد ناجحة (5 اختبارات قديمة متخطاة ومعلنة)، منها 23 فحص نطاق وتوجيه قدرات جديد. TypeScript API/admin/web والبناء ناجحان. قبول متصفح فعلي بأربعة حسابات Human مستقلة/MFA وأدوار وسياسات في PostgreSQL16 المعزولة: إتاحة الدورة المسندة وإظهار أدوات كل دور، ورفض الدورة الأخرى والكتالوج العام والشهادات والطلاب والأرشفة وتحرير المحتوى من الدور غير المخول. إنشاء وحدة من المحرر الفعلي وحده نجح. أربع صور والنتائج في `evidence/courses-governance-20261026/scoped-access-verification.json`. هذه حسابات مصطنعة؛ لا تعديل لإسنادات مستخدمي الأصلية.

الملفات الرئيسية: `CourseScopePolicy.ts` و`DefaultPolicyEvaluator.ts` و`ManagePoliciesUseCase.ts`، وعقد/واجهة سياسة IAM ودليل الصلاحيات؛ `CourseAccessService.ts` و`CourseAccessGuard.ts` وتوصيل API؛ `AssignedCoursesPage.tsx` والمحرر والتوجيه والقائمة الإدارية.

## 2. المعاينات والجدولة والاستئناف

منفذة بسياسة `deliveryPolicy` داخل النسخة المحفوظة للدورة، دون جدول مراجعة/منهج موازٍ أو ترحيل إضافي. تبويب «المعاينات والجدولة» يضبط الترتيب الحر/المتسلسل، معاينة كل محاضرة، وموعد UTC صريحًا. الحفظ عبر أمر المالك مع المبرر وIf-Match والتدقيق/Outbox الحاليين؛ الدورة المنشورة غير قابلة للتحرير.

تتحقق خدمات التعلم من نسخة التحاق الطالب، وتزيل نصوص وكتل وملفات وأسئلة المحاضرات المقفلة من الاستجابة. طلب الملف المباشر أو بدء الاختبار أو حفظ التقدم/الاستئناف لا يتجاوز القفل. إنهاء محاضرة الاختبار المتسلسلة يعتمد اجتياز تقييمها المحفوظ. مواعيد الإتاحة تقارن بساعة الخادم عند القراءة؛ لا يوجد عامل جديد أو موعد مُصطنع أو ادعاء إرسال إشعارات مجدولة.

المعاينة العامة `/[locale]/courses/:slug/preview` لا تقرأ مسودة؛ تعرض فهرس النسخة المنشورة والمحتوى المصرح بمعاينته بعد إتاحته فقط. لا تعرض أسئلة/إجابات التقييم، ولا تفتح أصلًا غير تابع للمحاضرة؛ ملفاتها تمر بأذونات EAP قصيرة العمر وسياسة الحقوق الحالية، دون تحويل الأصل إلى PUBLIC. أضيف رابطها إلى تفاصيل الدورة العامة. يبقى محتوى غير المعاينة للطالب المسجل والتصريح المالي القائم.

الاستئناف محفوظ ذريًا في بيانات تسجيل الطالب ويُقرأ بين الأجهزة؛ لا يغير نسبة الإكمال ولا يمس نسخة الالتحاق أو البيانات الأخرى. يرفض التسجيل الملغى/غير النشط، والمحاضرة الأجنبية أو المقفلة، والنسخة المتغيرة. اختبار PostgreSQL فعلي أثبت ثبات سياسة النسخة القديمة بعد تعديل النسخة الحالية، وحفظ بقية بيانات التسجيل ورفض تضارب النسخ.

## 3. ربط الشهادات

منفذ ضمن نطاق الشهادات القائم. تبويب «ربط الشهادة» يعرض القالب وإصداره والجهة المعتمدة وحالتهما الفعلية. تغيير الربط يتطلب صلاحية إدارة الدورة **وصلاحية اعتماد قوالب الشهادات**؛ لا تكفي صلاحية المدرب. يتحقق CertificateUseCases من القالب/الإصدار/الجهة قبل الحفظ، وتثبت المراجع في نسخة الدورة. النسخ لا يرث الربط. عند إكمال الطالب يستخدم مستهلك CourseCompleted النسخة التي التحق بها، ويرفض الربط الملغى أو إصدار القالب المتغير بدل اختيار إصدار جديد بصمت. الدورات القديمة تحافظ على مسار القالب الافتراضي المحكوم الموجود.

أضيفت قراءة حالة الإكمال/الشهادة من CertificateReadModelService المالك، وفق هوية الطالب ومعرف الإكمال المحفوظ. تميز الواجهة «غير مستحق»، «لم تسجل شهادة صادرة»، «شهادة فعالة مع ملف/دون ملف»، والإبطال/الانتهاء، مع تحديث ورابط حساب الطالب. لا تعتبر الإكمال إصدارًا، ولا تزعم وجود مهمة تجهيز عند غياب دليل. اختبارات الإصدار تستخدم حدث الإكمال الموثق وعقد الشهادات الحالي؛ لا يوجد endpoint لإصدار شهادة من الدورة.

## 4. مزود الوسائط

قرار المالك منفذ: حزمة `deploy/media-selfhost/`، دون تفعيل خارجي. تشمل Compose، مزود HTTPS بعقد EAP الحالي، تخزينًا خاصًا، HMAC وnonces محفوظة ومنع استبدال طلبات التكرار، ClamAV/FreshClam، عامل معالجة معزولًا عن التخزين/الإنترنت والأسرار الرئيسية، FFmpeg/Ghostscript، فحصًا قبل/بعد المعالجة، وإبطال الأذونات بعد الأرشفة حتى عند الاستعادة. توليد الأسرار محليًا دون طباعتها، ومدقق إعدادات يطلب صورًا مثبتة بـdigest، واختبار تشغيل معزول يرفض نطاق الإنتاج قبل أول رفع. الوثائق تبين الحدود، إعداد TLS، النسخ الاحتياطية والرجوع والتحديث ومصفوفة قبول المحركات.

**الفجوة التشغيلية الفعلية:** الجهاز لا يملك Docker أو خدمة ClamAV/Ghostscript. لم نشغّل الحاويات أو محركات الفحص والمعالجة الإنتاجية، ولم نفعّل DNS/TLS أو نختبر استعادة التخزين على خادم فعلي. الفحوص المحلية الستة تختبر التوقيعات/الأذونات/المسارات/أنواع الملفات وبروتوكول الماسح وفشله وتقادم قاعدة التواقيع، بمحاكي TCP معلن؛ لا تثبت كشف فيروسات حقيقي. YAML وبنية العزل وsyntax جميع ملفات التشغيل فُحصت؛ `docker compose config/build` وقبول المحركات الفعلية يبقيان قبل التشغيل على خادم معزول. PDF يعاد بناؤه بصريًا ويفقد النص القابل للبحث/النماذج والتوقيعات النشطة؛ هذا موثق لاعتماد سياسة التسليم قبل الإنتاج. لا توجد خدمة خارجية مفعلة أو كتابة على قاعدة الإنتاج.
