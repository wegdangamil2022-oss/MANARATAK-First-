## المنجز

- تسعة تبويبات أفقية 5/3/2 أعمدة، Cairo، عنوان 22px ورأس نيلي/بترولي وقراءة افتراضية. احتُفظ بنماذج التحرير والعلاقات الأصلية مع ترجمة واجهتها العربية والإنجليزية.
- حفظ واحد للمحتوى مع سبب، وحفظ مستقل للعلاقات وسبب مستقل للقرارات. المسودات محفوظة عبر التبويبات، مع تحذير الإلغاء والمغادرة والرجوع في المتصفح.
- If-Match بالإصدار المحمل، ثم إعادة قراءة الحفظ. التعارض أو فشل التحقق لا يعرض نجاحًا، مع إعادة تحميل أحدث سجل. تعديل المنشور مقفل؛ إلغاء النشر متاح وفق الصلاحية.
- جاهزية النشر من فحص المالك نفسه. رابط الصفحة العامة مشروط بإثبات أن الاستعلام العام يعيد السجل نفسه. صلاحيات الخادم وبوابات المالك محفوظة.
- عدادات inReview وincomplete من COUNT مطابق للحالة، دون جمع مؤشرات متداخلة. المؤشرات القديمة محفوظة لمستهلكيها.
- عرض الصفر ووحدات المبالغ دون تحويل مفترض، وفصل رابط التقديم والمصدر وموقع الجهة. HTTP(S) صريح فقط، دون # أو بيانات دخول مضمنة. أدلة المصدر تطابق حقول عقد المالك بما فيها الثقة ووقت التوثيق.
- نواقص الصحة تنتقل إلى تبويبها، وألوان الجاهزية مشروطة بالبيانات. حوارات التأكيد تضبط التركيز وEscape واستعادته.
- لا كتابة أو ترحيلات على القاعدة الأصلية.

## نتائج التحقق

- **73/73 اختبارًا** في scholarship-admin.vitest.config.ts: عقود API، الإصدارات، العدادات، القراءة والتحرير، التبويبات، المسودات، نماذج الإنجليزية التسعة، إعادة قراءة الحفظ، النشر، الصفر، الروابط وأدلة المصدر. تشمل اختبارات سياسة الترجمة والمكون المشترك.
- **7/7 اختبارات PostgreSQL 16 معزولة ومثبتة الهوية**: استمرار الحفظ والقراءة المستقلة، التدقيق وOutbox، سباق عميلين (نجاح واحد وتعارض واحد)، العلاقات دون فقد المحتوى، العدادات مقابل SQL مستقل، الجاهزية والنشر وإلغاء النشر والأرشفة، ورفض تأليف الترجمة والتراجع الكامل حسب السياسة.
- **HTTP عبر createApiApp الفعلي** على القاعدة المعزولة: جلستان مستقلتان بمصادقة MFA وCSRF؛ PATCH متزامن يعيد 200 و409، وGET مستقل يثبت القيمة المحفوظة. الكتابة دون دخول ترفض بـ401، وأرقام HTTP تطابق SQL. لا استبدال للمصادقة ولا تشغيل عمال الخلفية. إيصال منقح: evidence/scholarships-20261025/http-acceptance.json.
- TypeScript للـadmin وAPI ناجح. ESLint للملفات المستهدفة ناجح بلا تحذيرات. بناء admin الإنتاجي ناجح مع تحذير حجم الحزمة المشتركة القائم؛ الأداء مؤجل حسب المستخدم.
- متصفح حقيقي عند 1440/1280/768/390/360px: عنوان 22px، Cairo، تسعة تبويبات بأعمدة 5/5/3/2/2 ودون تجاوز أفقي، وRTL/LTR. اختبار الرجوع أبقى المسودة والموقع حتى التأكيد؛ حوار التأكيد استقبل التركيز، وأغلقه Escape وأعاده للزر.
- صور الكمبيوتر والهاتف في مجلد الأدلة من معاينة معزولة ببيانات صناعية وبدائل للشبكة والمصادقة، وليست Neon. اختبار HTTP وقاعدة البيانات مستقل عنها. لا ندعي اختبار متصفح متصل بالقاعدة الأصلية.

## حدود تشغيلية باقية

1. تأليف ترجمة **محتوى** المنح مقفل بسياسة المشروع INFRASTRUCTURE_ONLY. ترجمة الواجهة متاحة؛ اختبار القاعدة يثبت رفض كتابة ترجمة المحتوى والتراجع، دون تجاوز السياسة. تفعيلها يحتاج اعتماد سياسة منفصلًا.
2. إصدار المنح الجديد لم يُفعّل على القاعدة الأصلية: الخادم الحالي محفوظ، وحارس التشغيل مرتبط بإيصال إصدار المراجعة السابق. لا تغيير في MFA أو حساب المدير. تعديل CSS لسجل المراجعة وحده ظاهر بعد تحديث الصفحة.
3. تحسين أداء القاعدة وفحص حساب المدير النهائي مؤجلان إلى مرحلة التشغيل حسب المستخدم، مع فحوص الوصول اليدوية المذكورة أعلاه.
