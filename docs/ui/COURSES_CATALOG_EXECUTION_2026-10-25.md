## التحقق الفعلي

- **الوحدات والعقود:** 370 ناجحًا، صفر فشل، 5 اختبارات قديمة مشروطة ببيئة قاعدة خاصة متخطاة؛ 53 ملفًا ناجحًا وملفان متخطيان. لم تُحسب المتخطاة نجاحًا.
- **PostgreSQL 16 المعزولة:** 7/7، مع حارس DB-T والتحقق من الهوية والكتالوج قبل الكتابة؛ 324 تركيبًا لحقائق الدراسة والشهادة، و10,005 سجل لترقيم ثابت وخمسة ترتيبات وإحصاءات جميع النتائج، ومطابقة شروط مركبة و37 خيارًا بصفحتين 25+12. حُذفت بيانات هذه المجموعة المملوكة للاختبار بعده.
- **API والمتصفح الحقيقي:** Edge وExpress وPostgreSQL المعزولة مع تسجيل دخول MFA فعلي؛ 46 سجل واجهة اصطناعيًا (28 خارجية و18 داخلية)، صفحات 20+20+6؛ عرض/بحث/AND/إعادة تحميل/مزود/تفاصيل وعودة وتركيز، إنشاء مسودة عربية وقراءة مستقلة، و401 للمجهول و403 لموظف لا يملك الدورات.
- **سلامة الإنشاء:** قراءة مستقلة تؤكد DRAFT داخليًا ونسخة محفوظة واحدة وسجل Audit واحد وOutbox واحد، وسبب عربي مطابق. لم تُكتب هذه البيانات على القاعدة الأصلية.
- **الأخطاء:** حقن 503 اختباري معلن ثم Retry إلى API الحقيقي؛ المؤشرات «—» عند فشل القراءة، وصفر حقيقي عند عدم وجود نتائج؛ إعادة الصفحة 9 إلى 1 في النطاق الخالي.
- **العرض:** 1440 و1024 و768 و360 و320px بالعربية، و360 و1440px بالإنجليزية؛ لا تمدد أفقي للوثيقة، تمرير جدول الهاتف داخل صندوقه، Cairo محمّل، ودعم Escape والتركيز وحماية الرجوع دون فقد المدخلات.
- **TypeScript والبناء:** `tsc -b apps/api apps/admin` وVite وesbuild ناجحة. تحذير Vite للحزمة الإدارية الكبيرة القائمة باقٍ.
- **ESLint:** صفر أخطاء و22 تحذيرًا في الملفات القائمة (منها any وتحذير effect قائم في المحرر القديم)؛ ملفات ميزة الدورات الجديدة بلا تحذيرات. لم تُعطّل القواعد.

أدلة النتائج والصور الفعلية: `evidence/courses-catalog-20261025/`. الصور تحتوي بيانات قبول اصطناعية مع شريط يصرّح بأنها قاعدة معزولة؛ ليست سجلات أصلية ولا إثباتًا لاستيراد حقيقي. سكربت القبول `scripts/testing/courses-catalog-browser-acceptance.mjs` يتطلب خادم المختبر المحلي والمصادقة القانونية، ولا يقبل عنوان إنتاج.

أوامر الوحدات: `vitest run --config config/testing/courses-admin.vitest.config.ts`. مجموعة PostgreSQL المنفصلة في `courses-admin.database.vitest.config.ts` تتطلب التفويض والهدف DB-T والتحقق من عقد المختبر، ولا تعمل على عنوان قاعدة يمرر عشوائيًا.

- اختبارات API والحالة والمستودع وPostgreSQL، وإعدادا الاختبار، وسكربت القبول والتوثيق والصور.

## المتبقي الفعلي

- إغلاق **07.A**: إضافة خارجية يدوية مدققة مع dedup ومصدر، نافذة create/read/edit-section كاملة، إجراءات تحقق/جاهزية/نشر داخل النافذة، فلاتر سلامة الرابط وأعدادها، تحديد كل نتائج الفلتر عبر snapshot ثابت، معاينة نشر جماعي وتنفيذ محدود idempotent وتقرير جزئي.
- إغلاق **07.B**: المحرر الموحد والكتل والترتيب والوسائط والنسخ وتبويبات الطلاب والتقدم والتقييمات والتقارير بحسب المواصفة. المحرر الحالي محفوظ وليس بديلًا عن هذا العمل.
- اختبار قبول بشري لقارئ الشاشة، واعتماد التشغيل على بيانات المالك بعد مراجعة الفرع. هذه الدفعة لم تُفعّل على منفذ الموقع الأصلي 3000 ولم تبدل اتصاله أو مفاتيح MFA.
- تحسين زمن القاعدة الأصلية وحجم حزمة الإدارة يبقى ضمن العمل الذي أجله المالك؛ لا تدّعي سرعة الإنتاج من نتائج المختبر.

هذه دفعة تأسيس عاملة ومختبرة، وليست إغلاقًا شاملًا للقسم 07 أو إثباتًا لإتاحة النشر الجماعي أو التشغيل المدفوع.
