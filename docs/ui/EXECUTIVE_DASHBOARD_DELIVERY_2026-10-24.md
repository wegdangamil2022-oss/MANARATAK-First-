## التفعيل على قاعدة التطوير الأصلية — الحالة الأحدث

بناءً على طلب المالك تشغيل الموقع من القاعدة الأصلية، نُفّذ الانتقال على **قاعدة Neon التطويرية المحددة مسبقًا فقط**. لا يُعد هذا إذن نشر إنتاجي أو اعتمادًا قانونيًا أو مراجعة مستقلة مختلقة. [الدليل المنقح دون أسرار أو صفوف شخصية](evidence/executive-dashboard-20261024/original-development-activation.json).

مرشح التنفيذ والتشغيل `207a76d5e1d6deab5fc7791e482b06738d56decb` يتضمن ترويسة Dashboard النيلي/البترولي، وتحديث Express/Zod وbody-parser؛ نتيجة `npm audit --omit=dev` الفعلية **صفر ثغرات**. لا تُستنتج منها سلامة مطلقة أو صفر تحذيرات تطوير.

أُنشئت نسخة كاملة خاصة للمخطط وصفوف **282 جدولًا** مع نقل رقمي لا يمرر int8/decimal عبر JavaScript Number. فشلت محاولة pg_dump الكاملة الأصلية، فحُفظ فشلها ولم تُسمّ نسخة ناجحة. نجح البديل المنطقي الكامل، ثم استُعيد في عنقود PostgreSQL 16 جديد، مع تطابق جميع بصمات الصفوف ودون تعطيل triggers. جُرّبت الترقية على النسخة المستعادة قبل الأصل؛ نجحت وبقيت جميع صفوف الأعمال السابقة مطابقة.

طُبّق الترحيل الإضافي مرة واحدة عبر بوابة الترحيل القائمة، بحساب الترحيل المحدود، مع معاملة ذرية وlock timeout. البصمة الحالية الوحيدة للمرشح: `b6f6580c2a4b48407116451757462f276b604dc53cd794e10e1330d74d0386d5`. نجح تطابق Prisma، وأُضيف صف ترحيل واحد؛ بقيت بصمات جميع صفوف الأعمال وسجلات الترحيلات التاريخية، بما فيها rollback محلول سابقًا، دون تغيير. دور الموقع لا يملك جداول أو DDL أو وصولًا إلى دفتر الترحيلات.

الخادم المحلي على `http://127.0.0.1:3000` يقدم حزم Web/Admin الفعلية وAPI الحالي على Neon الأصلي. التشغيل محدود بالدخول والقراءة أثناء مراجعة التفعيل؛ الكتابات الأخرى ترجع 423، والدفع والعمال وOutbox والإشعارات وجمع الزيارات معطلة. لم تُشغّل أحداث Outbox القديمة أو يُرسل بريد. توجد في الأصل: **حساب مؤهل واحد، و3 ملفات تخصص، و194 دولة، و168 عملة، و260 لغة؛ الجامعات والمنح صفر**. ليست هذه الأعداد هي 2004 حسابات المختبر الصناعي.

نجح تسجيل الدخول العادي للحساب الموجود دون تغيير كلمة المرور أو الصلاحيات؛ أعادت `/auth/me` وواجهات Dashboard الثلاث للحسابات والزيارات والتقديم **200**. القياسات المنفردة على الشبكة الحالية كانت قرابة 13.7 و10.2 و2.6 و16.2 ثانية على الترتيب؛ هذه حدود أداء فعلية تحتاج متابعة، وليست وعود سرعة أو قبول حمل إنتاجي. بيانات الزيارات تعرض عدم بدء القياس، ولا تتحول إلى صفر ملفق. تفعيل الجمع ومهمة الاحتفاظ ونشر خدمة تقديم فعلية تبقى خطوات إعداد منفصلة.

اجتازت **فحوص GitHub التسعة** على المرشح 207a76d5، بما فيها [Enterprise CI 40101747302](https://github.com/wegdangamil2022-oss/MANARATAK-First-/actions/runs/40101747302). اجتاز البناء وTypeScript والوحدات واستخراج الحزم والتحقق منها وLinux؛ لا تعني الحالة نجاح خطوات إضافية مشروطة لم تُشغّل. إصلاح الاختبارات التاريخية يستخدم مصدر R06 المقبول عند `e28e79883280963b9ac09675a0a0a10c08a60e15`، مع إثبات رفض المخطط الحالي من الاعتماد التاريخي، دون تخفيف guard أو تغيير اعتماد سابق.

أعيدت مجموعة الوحدات العامة محليًا مرة واحدة لتغير التبعيات المشتركة: Vitest نجح **724 ملفًا و5369 اختبارًا**، مع **3 ملفات و8 اختبارات متجاوزة سابقًا**. بقيت عشر حالات Node محلية متأثرة بصلاحية symlink ومسارات Windows؛ الفحص الشامل الفعلي على Linux نجح. اجتازت مجموعة المصدر التاريخي المركزة 112/113 أولًا؛ استُخدم junction حقيقي لحالة Windows الوحيدة وأعيدت تلك الحالة فقط فنجحت. لم تُحذف assertions أو اختبارات إلزامية.

تمت مشاهدة صفحة الدخول الخاصة بالتشغيل الأصلي في المتصفح. انقطع اتصال أداة المتصفح أثناء محاولة إكمال العرض، لذلك **لم يُثبت العرض المرئي النهائي لـDashboard بعد الدخول على القاعدة الأصلية**. أدلة العرض المتجاوب السابقة الصناعية باقية؛ نجاح API الأصلي لا يستبدل هذا الفحص. لم يُدمج الفرع في main.

كشفت متابعة الفحص العام تعارضًا مع CSP الصارم في الألوان المضمنة داخل بطاقات قديمة وعرض أشرطة الرسم الجديد. استُبدلت بفئات من لوحة ألوان ثابتة وخصائص SVG؛ لا استثناء `unsafe-inline` ولا تعطيل لفاحص الأمان. التغيير في `ReviewOverview` تقني من سطرَي تنسيق إلى فئات مكافئة بالألوان نفسها، دون تعديل ترتيب قسم المراجعة أو وظائفه. نجحت اختبارات سياسته 5/5، وفاحص W1 عدد 136/136، واختبارات العرض المتأثر للمراجعة 3/3، وبناء Admin وTypeScript. أعيد فحص المتصفح للمقاسات واللغتين والتكبير، مع التحقق من عرض الشريط ولونه فعليًا وغياب أساليب مضمنة داخل Dashboard.

## متابعة الأداء والقياس والمصادقة

[الأدلة المنقحة](evidence/executive-dashboard-20261024/runtime-performance-and-analytics.json) تخص قياسًا فعليًا على قاعدة التطوير الأصلية. حُوّلت قراءة هوية المصادقة من ثلاثة استعلامات متتابعة إلى JOIN واحد، مع mapper نفسه والتحقق نفسه من دورة الحياة، وإبقاء تعذر التخزين فشلًا مغلقًا. جُمّعت أجزاء الإحصاءات في SQL محدد المعاملات مع بقاء المعاملة RepeatableRead وحدودها؛ لا cache لصلاحيات المستخدم أو نتائج هويته بين الطلبات.

في الملاحظة المفردة عبر الاتصال المجمع: الهوية 1961→341ms مع 3→1 استعلامات، الحسابات 2415→1227ms مع 6→5 أوامر، والتقديم 5031→951ms مع 8→5 أوامر. وفي HTTP قبل تفعيل MFA: `/auth/me` نحو 1.4 ثانية، ومجاميع Dashboard الثلاثة نحو 2.3–2.5 ثانية. هذه مقارنات محدودة وليست p95 أو ضمان زمن الشبكة؛ زادت المهلات في المراجعة الحية اللاحقة ولا نعدّ الأداء كله مغلقًا منها.

أزيل حظر الكتابات المؤقت من المشغل الخاص فقط. مسارات API الأصلية ما زالت تطلب الصلاحية وCSRF وMFA والتأكيد الحديث للعمليات الحساسة وقيود المراجعة والإصدارات. أثبت الفحص أن الزائر 401 وأن الحساب دون MFA يحصل على `MFA_ENROLLMENT_REQUIRED` 403 بصيغة problem+json؛ لم يُنشأ محتوى تجريبي في الأصل لإثبات الكتابة. أُعد مفتاح تشفير MFA محلي ثابت ومحمي بـWindows DPAPI، مع رفض استبداله عند وجود اعتماد TOTP سابق. المالك أدخل كلمة المرور والمفتاح والرموز بنفسه؛ لا تخزينها في أدلة المستودع.

فعّل المالك MFA وأُثبت `MFA_LOGIN_VERIFIED` وجلسة نشطة بعد معالجة فرق ساعة الجهاز الذي كان نحو 74 ثانية أمام مصدرَي وقت مستقلين. لم تُوسّع نافذة TOTP ولم يُقبل رمز معاد أو تُعطل الحماية. قد تبقى خطوة «تأكيد العمليات الحساسة» لازمة عند التعديل؛ نجاح الدخول وحده لا يمدّد هذه النافذة.

أصبح إعداد القياس الحقيقي enabled مع نسخة الموافقة المحددة و30 يومًا للموافقة و90 يومًا للأحداث. لا تسجيل قبل قبول الزائر، ولا تاريخ افتراضي؛ في فحص 24 أكتوبر 2026 نحو 18:30 بتوقيت عدن بقيت الأحداث صفرًا ولم تنتهِ أي أحداث. أُثبتت دورة احتفاظ مكتملة عند 18:15 ومهمة دورية كل 15 دقيقة. يستخدم المشغل الخاص queue القائمة بمرشح أنواع immutable داخل SELECT FOR UPDATE SKIP LOCKED وعند تحديث المطالبة؛ النوع الوحيد `analytics.retention.sweep`. بقية عمال المال والإشعارات وOutbox تبقى متوقفة، وبصمات المهام الأخرى وOutbox لم تتغير خلال فحص التفعيل.

التحقق الإضافي: وحدات الهوية ونطاق المطالبة 9/9، PostgreSQL 16 صناعي جديد 11/11 بما فيه إثبات عدم التقاط إشعار أعلى أولوية، وفشل تخزين المصادقة 12/12، وعقد المصدر 32/32. اجتاز API TypeScript والبناء، وصفر أخطاء ESLint للملفات الستة المتأثرة، مع 39 تحذيرًا قائمة. تدقيق تبعيات التشغيل صفر. اجتازت فحوص GitHub التسعة لمرشح 422a9f51، ومنها [Enterprise 40105074440](https://github.com/wegdangamil2022-oss/MANARATAK-First-/actions/runs/40105074440). أي متابعة أحدث تحتاج نتيجتها الخاصة.
