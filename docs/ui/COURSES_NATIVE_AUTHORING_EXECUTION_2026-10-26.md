- مسار متصفح الطالب ناجح: دخول طالب فعلي، تسجيل عبر الزر، عرض النص/الجدول/الكود بأمان، تقدم 0→50 مع ثباته بعد إعادة التحميل→100، وإكمال دون ادعاء شهادة. إلغاء نشر وتعديل محتوى عبر API الإدارة الفعلية ثم إثبات بقاء نسخة الطالب الأصلية والتقدم. المجهول وغير الملتحق ومستخدم الطالب على API الإدارة مرفوضون. أربع صور للكمبيوتر والهاتف و320px، بلا أخطاء صفحة.
- دورة مسار الطالب **زُرعت منشورة داخل المختبر** لاختبار الوصول والتقدم والتاريخ. هذا لا يثبت قبول بوابة نشر دورة داخلية كاملة؛ اختبار الإدارة يثبت حظر نشر الدورة الناقصة فقط. لم يثبت هذا المسار مشاهدة الفيديو أو الانتباه.
