# عرض التخصصات المضغوط

طلب المالك تقليل الارتفاع والفراغات، وتقديم العربية، وتحسين بطاقات التخصصات وإضافة جدول، وإظهار حالة أقسام المحتوى العشرة دون المساس بالإصلاحات.

## الواجهة

- رأس السجل: عنوان عربي 20px والإنجليزي 12px تحته، اختيار الدرجة بمحاذاة الهوية، ثم إجراءات أفقية تلتف عند ضيق المساحة. يتبع الالتفاف عرض مساحة السجل، وليس عرض نافذة المتصفح وحده.
- البطاقة: الاسم العربي 15px والإنجليزي 11px، رمز المستوى، الدرجة، الكلية، المجال، حالة المراجعة والنشر، اكتمال **الهوية**، التاريخ عند توفره ورابط التفاصيل. الكلية غير المسجلة تظهر «غير محددة»؛ لا نستنتجها من اسم التخصص.
- تُقرأ بيانات الكلية والمجال من علاقات الاستجابة الفعلية: `facultyName` و`collegeContext` و`academicField` و`discipline`، مع توافق الحقول الوصفية السابقة. لا طلب لكل بطاقة، ولا ترجمة مولّدة للأسماء.
- الجدول يعرض الصفحة المفلترة نفسها، ويحافظ على معرف ملف الدرجة في رابط التفاصيل. التبديل لا يجلب بيانات جديدة ولا يصفر الفلاتر أو الترقيم.
- عناوين فلاتر المنح والجامعات والتخصصات 13px بوزن 700؛ القيم داخل الحقول 12px بوزن 500. خط القاهرة محفوظ.
- يظهر الهيكل المطلوب للمحتوى حتى عند غياب الكتل: الأقسام الفارغة في عمودين على الكمبيوتر وعمود على الهاتف، بحالة «بانتظار المحتوى». تبقى الأقسام ذات المحتوى بعرض كامل لقراءة النص وتحريره. تعذر القراءة لا يعرض نتيجة فارغة أو عداد صفر مؤكد.

## نتيجة فحص المحتوى الفعلي

فحص `manaratak_probe` داخل معاملة `READ ONLY` عند `2026-10-23T19:37:59Z`، دون أي كتابة: كل من `MJR-0237` و`MJR-0238` و`MJR-0239` لديه إصدار واحد و**صفر كتل محتوى**، سواء لكل ملف الدرجة أو للإصدار الحالي. الأسماء العربية والإنجليزية محفوظة، و`facultyName` و`collegeContext` فارغان.

تتفق النتيجة مع [تسليم استيراد الهوية](../reviews/IMPORT_MAJOR_PILOT_COMPLETION_2026-10-23.md): محتوى ملفات التفاصيل لم يستورد بعد. إظهار العناوين العشرة لا يمثل إدخال محتواها أو اعتمادها أو نشرها. لم ننشئ محتوى أو كلية أو ترجمة افتراضية، ولم نعدل القاعدة أو خطة الاستيراد.

## التحقق

- TypeScript وبناء الإدارة ناجحان.
- فحص Chromium للحزمة الفعلية ببيانات صناعية عند 1360 و1000 و820 و390 بكسل: رأس الكمبيوتر 218px، عنوان السجل 20px، البطاقات 15px/11px، عنوان الفلتر 13px وقيمته 12px، دون تجاوز أفقي للصفحة. يبقى تمرير الجدول محصورًا في حاويته.
- تحقق التبديل بطاقة/جدول دون زيادة طلبات API، وبقاء فلتر الدرجة ورابط الملف. تحقق المحتوى المحفوظ والمحتوى الفارغ وفشل القراءة على نحو منفصل.
- أعيدت فحوص تفاصيل التخصص المتأثرة: التعديلات غير المحفوظة وتبديل الملف والتبويب، صلاحية النشر والجاهزية وتأكيده، حفظ مسودة المراجعة والوصول إلى معلومات الاستخدام. لا كتابة فعلية في اختبارات المتصفح.
- ستة معالجات حفظ/تعديل/تبديل/إجراء تطابقت نصيًا مع المرجع السابق. تغير عرض حالة فشل تحميل المحتوى فقط، دون تغيير أوامر الحفظ أو شروط الخادم.

الأدلة المحلية: `private/admin-major-compact-20261023/BROWSER_CHECK.json` و`DETAIL_REGRESSION.json` و`HANDLER_INTEGRITY.json` والصور؛ نتيجة القراءة الفعلية في `private/owner-account-20261023/MAJOR_CONTENT_READONLY.json`. لا نعرض هذه الفحوص الصناعية كقبول نشر أو استيراد للمحتوى الحقيقي.
