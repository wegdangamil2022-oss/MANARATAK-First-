# استكمال قائمة المراجعة من ملف المشروع

طلب المالك مراجعة قائمة المراجعة في ملف المشروع والتأكد من وجود عناصرها. المرجع الأول `MANARATAK-First--main.zip`، مع التحقق المباشر من تطابق صفحة المراجعة المستخرجة معه. هذه الصفحة تحتوي بالفعل على التصميم المختصر الأحدث؛ استُخدمت أيضًا النسخة المحلية `MANARATAK_PUBLIC_UI_CODEX_HANDOFF_2026-09-05.zip` لتحديد عناصر العرض الأقدم المفقودة، دون إعادة عقودها الملغاة.

## مطابقة العناصر

| العنصر | الحالة في هذا التسليم |
|---|---|
| العنوان وزر التحديث | باقيان، مع عداد الاستعلامات المقروءة ووقت أحدث قراءة مصدر ناجحة |
| بيان حدود القراءة والتنقل | باقٍ، مع بيان واضح للمصادر المتعثرة بعد انتهاء التحميل |
| إشارات دورة المراجعة | ست بطاقات: المراجعة، النواقص، الجاهزية، الاستيراد، تجاوز SLA، واقتراب SLA |
| اقتراب SLA | موضع البطاقة مستعاد، والعدد غير مقاس لغياب حد إنذار معتمد؛ لا يوجد استنتاج من آخر تعديل |
| إشارات الجودة | الترجمة، تحقق المصدر، الروابط المعطلة، مراجعة الاستيراد؛ الأعداد تخص العينة المصرح بها |
| الترجمة المتخصصة | رابط إلى مساحة الترجمات عند امتلاك صلاحيتها |
| التكرارات والتعارضات والتحديثات | بطاقتان ورابط سريع إلى مركز استيراد المنح عند امتلاك صلاحيتي المنح والاستيراد؛ لا أعداد تجميعية مختلقة |
| شرح الأولوية | لوحة تصف أولوية القسم، والاقتراح الحالي للمرتفعة والمتوسطة، ومتطلبات دليل SLA |
| بطاقات المجالات | المجالات التسعة القائمة، مع عدد السجلات وتفصيل مراجعة/ناقص/جاهز وحالة التغطية وروابط أقسامها |
| البحث | بحث محلي في العنوان والمعرف والحالة والاكتمال ورموز المراجعة، داخل العينة المصرح بها فقط؛ النص لا يُضاف إلى URL |
| الفلاتر السريعة | العروض السبعة المعتمدة، بالإضافة إلى رابط التكرار/التعارض في مركز الاستيراد |
| الفلاتر التفصيلية | المجال والسبب والأولوية والمصدر وعمر الانتظار والترتيب والعرض المحفوظ؛ جميع روابط التحكم الأصلية محفوظة |
| مسح التصفية | يمسح البحث والفلاتر دون إعادة طلب مصادر البيانات |
| الأعمال المعلقة | لوحة بعنوان وعدد نتائج، مع الجدول والأوقات والإشارات والأولوية والفتح لدى القسم والمعاينة |
| الحالة والاكتمال | عرض القيم النصية المرسلة صراحة من القسم، دون استنتاجها من فلتر الطلب أو اختلاق مراجع معيّن |
| تغطية المصادر | الجدول والأخطاء وأوقات القراءة والأعداد وحدود النوافذ وأزرار استمرار القراءة محفوظة |
| صفحات العينة | السابق/التالي محفوظان داخل لوحة النتائج |
| معاينة الأدلة | الوقت والسياسة وSLA والتدقيق المحدود وتتبع الاستيراد ومقارنة المصدر وتحذيرات الرابط الخارجي محفوظة، مع تنسيق النافذة بألوان الإدارة |
| الانتقال لإتمام القرار | يظل داخل قسم السجل؛ لا تحرير أو موافقة أو رفض أو نشر من القائمة المجمعة |

## الحفاظ على الإصلاحات

أثبتت مقارنة AST بقاء روابط التحكم الاثني عشر الموجودة في الصفحة داخل ZIP، وأصبح العدد 16 بعد إضافة البحث والأزرار الجديدة. لا تعني هذه المقارنة قبولًا شاملاً لكل عملية خلفية؛ هي دليل المحافظة على ربط عناصر الواجهة. الأداة المحلية: `private/admin-review-restore-20261023/SOURCE_AUDIT.json`.

لم تتغير مصادر المراجعة أو صلاحياتها أو Loader أو API أو Prisma أو migrations. تغيّر إسقاط الواجهة فقط لإظهار حقلي الحالة والاكتمال النصيين إن توفرا؛ لا تُنسخ بيانات المراجعين أو معلوماتهم الخاصة. الأعداد تتبع العينة، والقيمة غير المتاحة لا تتحول إلى صفر، ووقت المراجعة مستقل عن وقت التعديل والاستيراد.

## التحقق المركّز

نجحت اختبارات الواجهة الستة: فحصان للأعداد والفلاتر، وفحصان لمسح أدلة الجلسة والتدقيق عند 401، وفحص البحث المحلي ومسحه دون طلبات جديدة، وفحص عدم استنتاج الحالة أو البحث في معلومات المراجع الخاصة. فشل الفحص الجديد أولًا لأن الأداة حاولت تسلسل بنية React دائرية؛ صُحح بفحص عقدة النص مباشرة وأعيد وحده. أُعيدت المجموعة ذاتها بعد إضافة حقلي الحالة والاكتمال إلى الإسقاط المتأثر، دون إعادة مجموعات المراحل العامة.

نجح TypeScript وبناء حزمة الإدارة، ونجح ESLint دون أخطاء، مع ثمانية تحذيرات في الصفحة والاختبارات القائمة. لا تعني هذه النتائج أن عائق الاستجابة في تسجيل الدخول الفعلي، المسجل في تسليم لوحة التحكم، قد عولج.
