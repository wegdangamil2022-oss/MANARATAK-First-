# ضبط البطاقات والفلاتر وصفحات المراجعة — 2026-10-24

## المشكلة المثبتة بالصور

كانت بطاقات تفاصيل مؤشرات لوحة التحكم تستخدم أربعة أعمدة وفق عرض نافذة المتصفح،
حتى عندما تصبح المساحة الداخلية ضيقة. كما كان عنوان المؤشر ينافس العدد ضمن عمودين
دون حجز مساحة مناسبة للكلمات. وكانت قائمة المراجعة تعرض 40 سجلًا، مع تكرار العرض
المحفوظ في الأزرار والقائمة، وتسميات مختلفة اللون، وزر متابعة المصادر أسفل النتائج.

## التغيير

- شبكة المؤشرات تتبع المساحة المتاحة، بحد مناسب لعرض البطاقة، وتعرض العنوان والأيقونة
  والعدد أفقيًا. في تجربة عرض 820 بكسل: عمودان، وعند 390 بكسل: عمود واحد.
- عنوان مختصر للعرض، مع الاحتفاظ بتعريف العدد الكامل داخل تفاصيل المصدر. رتبت
  القراءة والنطاق والتواريخ في حقول؛ مسار API ومعاملاته داخل تفاصيل تقنية مستقلة.
- فلاتر المراجعة ستة بلا تكرار «العرض» الذي يوجد بالفعل في الأزرار السريعة. تسميات
  موحدة اللون والحجم، وأيقونات مناسبة تتنوع بين النيلي والفيروزي والذهبي. القاهرة
  لكل عناصر الصفحة، مع تسمية 14px وقيمة 13px وحالة تحميل 13px.
- عشرة سجلات لكل صفحة، وأزرار السابق/التالي أعلى النتائج وأسفلها. رقم الصفحة ونطاق
  السجلات معزولان اتجاهيًا ليظهرا صحيحين في العربية. البحث والتصفية يعيدان الصفحة
  الأولى، ويضبط رقم الصفحة إذا تقلصت النتائج.
- «تحميل المزيد» أعلى جدول النتائج، ويستدعي نفس متابعة المصادر المصرح بها. لم يتغير
  حجم طلبات API أو سقف النافذة؛ عشر سجلات تخص العرض فقط، وليس إجمالي القاعدة.
- زر «تحقق المصدر» يطلب مصادر التحقق الفعلية مثل عروض الترجمة والجاهزية، بدل
  الاكتفاء بتصفية عينة سير المراجعة التي قد لا تحتوي دليل تحقق المصدر.
- أعيد ترتيب مربعات حالات المراجعة والجودة والمجالات والمراجعات المتخصصة. بيانات
  الأولوية والمصادر والمراجعين والمواعيد المفقودة تبقى مجهولة، ولا تستبدل بأصفار.
- لم تتغير الصلاحيات أو عقود الاعتماد والنشر أو API أو المخطط أو الترحيلات.

## التحقق

- 12 اختبار مراجعة و3 اختبارات صلاحيات وقراءات لوحة تحكم ناجحة. الحالة الجديدة
  تثبت التنقل 10 ثم 10 ثم 3 من 23 سجلًا، والعودة والبحث دون إعادة طلب API.
  واختبار آخر يثبت جلب قراءتَي تحقق المنح عند اختيار زر تحقق المصدر.
- فحص أنواع الإدارة ناجح؛ ESLint بلا أخطاء، مع تحذيرات الخطافات السبعة السابقة.
- تحقق متصفح باستجابات صناعية معلنة على خادم المعاينة: 1360 و1000 و820 و390 بكسل،
  بلا تجاوز أفقي للصفحة أو أخطاء JavaScript. بطاقات تفاصيل الجامعات 157px ارتفاعًا
  والعناوين في سطر واحد في هذه العينات. جرى فتح بيانات المصدر والاستعلام، والفلاتر،
  والسابق/التالي، وتحميل المصدر التالي، والبحث ومسحه، ومعاينة الأدلة وإغلاقها.
- جدول النتائج يسمح بالتمرير الأفقي على الهاتف للحفاظ على قراءة الأعمدة؛ لا يعيد
  ضغط الكلمات إلى أعمدة ضيقة. لم تعَد مجموعات API أو قاعدة البيانات غير المتأثرة.

التحقق الصناعي يثبت العرض والتفاعل، ولا يُسجل كدليل على اتصال القاعدة الفعلية.
يسجل تحقق الحزمة الفعلية والبيانات المحلية في دليل التشغيل المرافق بعد تثبيتها.
