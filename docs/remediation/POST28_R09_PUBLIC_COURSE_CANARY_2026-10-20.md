# R09 — القراءة العامة للدورات ومطابقتها بالمالك

المرشح المصحح `819216eba0d09afb3048235e310e2854ef54779d`، والتشغيل الفعلي `39348319130`. الحالة النهائية `PUBLIC_OWNER_CANARY_VERIFIED`؛ نجح التشغيل المبني على Linux وجميع check runs الثلاثة والعشرين. تبقى أدلة مسار الطالب على `ce0690c` محفوظة في [تسليم الدفعة السابقة](POST28_R09_LEARNER_JOURNEY_2026-10-20.md)، ولا تُنسب إلى مصدر أحدث. أعيدت حالات تعقيم CMS الأربع تلقائيًا في CI على المصدر الجديد ونجحت أيضًا، دون ادعاء إعادة مسار الطالب.

## الإصلاح الوظيفي

كان اختيار native/imported في `PublishedCatalogDiscovery` يضيف `accessType=FREE`، وهي ليست من قيم CourseAccessType التي يقبلها API. وكان خيار الإتاحة «مجانية» يرسل القيمة غير المقبولة نفسها. أُزيل الافتراض من مرشحي المصدر: native/imported يختاران originType الصحيح، ويظل paid يطلب PAID. واستُبدلت قيمة الإتاحة المجهولة بخيارات FREE_STUDY وFREE_CERTIFICATE وFREE_STUDY_AND_CERTIFICATE بأسماء واضحة. لم تتغير قواعد نشر المالك أو الصلاحيات أو بوابات الدفع والتسجيل؛ الاختيارات تعكس الأنواع القائمة في العقد ولا تمنح أهلية شهادة أو إعفاء ماليًا جديدًا.

أثبتت اختبارات الطلبات الموجهة فشل حالتي native/imported قبل التصحيح، وبقاء paid ناجحًا، ثم نجاح الحالات الثلاث. وأثبت اختبار الإتاحة غياب الاختيارات canonical قبل إصلاحها ثم نجاح الحالات الأربع ذات الصلة. [RED/GREEN وحدودها](../reviews/evidence/post28/819216eba0d09afb3048235e310e2854ef54779d/r09-public-source/evidence-index.json) لا تدعي أنها تشغيل HTTP فعلي قبل الإصلاح؛ ذلك اختبار طلبات المكون المعزول مقابل العقد. نجح فحص أنواع Web وESLint للملفين المتأثرين. أُعيد ملف الحالات الأربع فقط بعد تعديل تعبير الإتاحة نفسه.

## النطاق

تُنشأ سبع دورات صناعية في PostgreSQL 16 جديد ومعزول: ثلاث PUBLISHED/COMPLETE، ومسودة، ومؤرشفة، ومنشورة غير مكتملة، ومنشورة كاملة تدّعي لغة بلا مرجع canonical محسوم. تُزرع الحالات بأداة إعداد المختبر المعتمدة؛ لا يدعي ذلك ممارسة workflow النشر أو موافقة مسؤول. كل الدورات داخلية مجانية، ولا مزود مؤثر أو بيانات أصلية.

يقرأ الفحص المالك بواسطة دور `post28_app` ويقارن مع API العام المجهول عبر ثلاث صفحات بحجم عنصر واحد؛ يثبت ترتيب معرفات المالك وعددها وعدم تكرارها وتطابق total. يفحص كل رابط منشور وكل حالة محجوبة، وCache-Control، ونتيجة صفر حقيقية لفئة صناعية فارغة. يتضمن fixture نص درس لا يفترض أن يظهر إلا للمسجل، وعلامة داخلية في optionalFields؛ لا يجوز تسريبهما في تفاصيل الدورة العامة أو قائمتها.

يفتح Chromium واجهة التفاصيل العربية لدورة منشورة، ويتحقق من رابط التعلم المبني على owner ID، ثم رابط المسودة الذي يُرفض من API 404. سلوك الواجهة الحالي الرجوع إلى قائمة الدورات دون عرض عنوان المسودة أو بيانات بديلة عنها؛ لا نسمي استجابة مستند SPA التي تعيد 200 استجابة HTTP 404 للواجهة. هذه الدفعة لا تثبت رسالة خطأ مستقلة أو سياسة SEO لذلك الرابط.

## حدود التنفيذ والفحوص

نجح التشغيل الأول `39346685129` على `34894a6` في فحوص API وتفاصيل الدورة المنشورة؛ [أدلته الأصلية وملاحظة المراجعة](../reviews/evidence/post28/34894a6e8727485c09abc8ffc53256f8185c17e7/r09-public-runtime/evidence-index.json) محفوظة. كشف فحص الصورة أن انتظار رابط المسودة انتهى عند إطار القائمة وهي ما تزال تحمل البيانات. لا نعتبر ذلك إثباتًا للقائمة المحملة. أضاف `157debd` انتظار الإجمالي الفعلي والعناوين المسموحة وغياب المحجوب، ثم أضاف المرشح المصحح اختيار native/imported وFREE_STUDY من الواجهة وانتظار استجابات API الفعلية ونتائجها.

أُوقف تشغيل المرشح المتجاوز `157debd` بعد نجاح مختبر R08 وتنظيفه وقبل بدء مختبر الحزم؛ تأكد GET من الحالة completed/cancelled. وأُرسل طلب إيقاف مقيد للمرشح `4244b94` بالشروط نفسها بعد اكتمال مختبره. لم تُقطع قاعدة عاملة، ولم تُسقط بوابة للمرشح الحالي؛ الهدف عدم إكمال فحوص مصدر تجاوزناه. الإيصالات محفوظة مع دليل المصدر.

استُبدل وضع المتصفح في CI بـ`--r09-public` ليمارس الحالات الجديدة؛ لم يُعد مسار الطالب السابق يدويًا. بقيت أوضاع التشخيص السابقة متاحة، واستمرت تبعيات المصدر واسترجاع الحزم، وNode 22/Linux x64، وقاعدة جديدة ودور محدود وTLS والتحقق من SHA والتنظيف. لم يُضف إذن كتابة جديد إلى دور التطبيق. وحدات API/Web/Admin مسترجعة من المصدر نفسه؛ التشغيل الجديد يمارس واجهة Web وAPI العام، ويقرأ readiness لـAdmin، ولا يدعي إعادة ممارسة أفعال إدارية جديدة.

نجح فحص تركيب ملفي MJS المتغيرين، واختبار عقد CI المتأثر فقط: قبول الوضع المحدد مع رفض أمر اعتباطي أو وسيط إضافي أو إسقاط تبعية السلامة. جرد البيئة باقٍ عند 320 اسمًا. لا إعادة بناء كامل محلي ولا إعادة يدوية للفحوص الناجحة غير المتأثرة. تنفذ GitHub بوابات المصدر الإلزامية تلقائيًا عند الدفع؛ لا حارس أو assertion محذوف.
