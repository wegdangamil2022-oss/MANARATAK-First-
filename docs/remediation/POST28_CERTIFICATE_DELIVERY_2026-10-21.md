# تسليم الشهادة الموقعة — إثبات API وحدّ السحب

نجح النطاق المحلي لتسليم PDF وpreview من API المبني على6fa9054 في مختبر PostgreSQL16 جديد بدور محدود ومزود HTTPS صناعي موقّع. مصدر المشغّل 682a7ff9bcab350bf32f025b232f438874d67b97. أُعيد استخدام حزمة API بعد إثبات عدم تغير الكود؛ لم تُعَد فحوص الملكية والانتهاء السابقة أو بناء Web/Admin.

## ما ثبت فعليًا

- أُنشئ مساق ودرس صناعيان وأُكمل الدرس عبر CourseProgressUseCases. استُهلك حدث CourseCompleted المخزن لإصدار شهادة واحدة، ثم أنتج الرسّام القائم PDF وpreview وQR مع إرفاقها عبر عقود الحفظ الحالية.
- جهة الإصدار والقالب الصناعيان النشطان مستبقيان دون تعديل موافقاتهما أو مراجع نسخهما. استُعمل مفتاح HMAC جديد عابر لهذا المختبر؛ ليس مفتاح إنتاج أو اعتمادًا تقنيًا جديدًا، ولم يُثبت صلاحية مفاتيح توقيعات الشهادات التاريخية. صفوف الشهادة الأصلية والتوقيعات المخزنة نفسها لم تتغير.
- طابق الرسّام ملفات الشعار الصناعية المحفوظة ببصماتها. أصول المخرجات عينة ثقة مادية صناعية؛ لا ادعاء برفع/فحص malware/تعقيم EAP جديد.
- تحقق API نفسه من توقيع الشهادة الجديدة وحالتها الفعالة. نُزّل PDF وpreview عبر روابط المزود، وطابقت البايتات والبصمات مخرجات الرسّام. مُنع الطالب الآخر قبل منح الرابط.
- رُفض تجاوز مسار الشهادة باستعمال مسار أصول الطالب العام، لأن أصل الشهادة مملوك بنوع Certificate.
- سُحبت الشهادة عبر أمر مالك الشهادات الداخلي بعقده الحالي داخل المختبر، لا عبر تعديل صف status مباشرة. تحقق عام لاحق أعاد REVOKED وتوقيعًا سليمًا وisValid=false؛ ورُفض منح PDF وpreview جديدين قبل استدعاء المزود. هذه ليست تجربة واجهة الإدارة أو تفويض HTTP لأمر السحب.
- تطابقت صفوف Certificate وIssuer وTemplate وTemplateVersion الأصلية وBinding والحقائق المالية ببصماتها. انتهت الجلسات وأُغلق API والمزود والمختبر.

## نتيجة يجب إبقاؤها مفتوحة: R14-DELIVERY-01

طُلب رابط المزود القديم بعد سحب الشهادة فأعاد **200 ضمن مدته الأصلية**. لذلك نجاح المسارات أعلاه ليس نجاحًا للإبطال الفوري للروابط السابقة. العقد الحالي يمنح bearer capability مؤقتة بحد300 ثانية، وإيقاف المنح الجديدة لا يمحو capability سبق كشفها. لم يُختصر TTL لإخفاء النتيجة ولم يُغير assertion لعرضها كمنع.

الأثر: يمكن لصاحب الرابط القديم مواصلة جلب بايتات الشهادة حتى انتهاء capability. التحقق العام من صحة الشهادة يظل يُظهر سحبها؛ لا يمكن استرجاع ملف نُزّل بالفعل. لا يجوز وصف النظام بأنه يضمن إبطال الرابط الموزع فور السحب.

التوصية التقنية: عند اشتراط سحب فوري للتسليم الخاص، يُستخدم بث خادم موثق يعيد فحص الطالب والشهادة قبل التخزين وبعده، مع نقل مستهلكي Web/Admin بعقد متوافق؛ أو يقدم المزود إثبات fencing للروابط القائمة مرتبطًا بحدث سحب الشهادة. تغيير endpoint وحده أو إخفاؤه من الواجهة لا يغلق المسار المباشر. لم يُثبت أي بروتوكول fencing لذلك لدى مزود فعلي. تبقى مراجعة قبول نافذة TTL أو تنفيذ البث الموثق بوابة إصدار معلنة، ولا نشر ضمن هذه الدفعة.
