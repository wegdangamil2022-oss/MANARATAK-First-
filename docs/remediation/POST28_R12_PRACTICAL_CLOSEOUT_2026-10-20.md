## ما أصبح مثبتًا

1. **API والجلسات والإيصالات:** [البروفة السابقة](POST28_R12_API_REHEARSAL_2026-10-20.md) أثبتت HTTPS وCSRF والجلسة القائمة وإعادة الأمر دون أثر جديد، وحفظ الصفوف المالية والموافقات وBinding والنشر والتدقيق الأصلي، وتوقف الحالي قبل تشغيل السابق. لم تُعد هذه الفحوص الناجحة.
2. **العامل المبني السابق:** اشتغل عامل StudentWorkspace المضمّن في كل حزمة فعلية على PostgreSQL16 جديد بدور تطبيق عادي. عالج الحالي حدث هوية صناعيًا، ثم أعاد السابق تسليم الغلاف الصناعي نفسه مع بقاء إيصال inbox مطابقًا وإصدار workspace دون زيادة. إعادة التسليم محاكاة معلنة بتعديل حالة غلاف الاختبار الصناعي فقط؛ ليست حذفًا لإيصال أو تغييرًا لحدث تاريخي.
3. **إيقاف معالجة نشطة:** أُمسك قفل صف workspace داخل معاملة حقيقية. ثبت أن السابق حجز الحدث وبقي PROCESSING، ثم استقبل معالج SIGTERM الأصلي من خلال IPC محلي لأن Windows لا يوفر نقل إشارة Linux نفسه. لم يخرج قبل تحرير القفل؛ أكمل الحدث وإيصاله مرة واحدة، وأغلق بميزانية الإيقاف وبرمز0. استغرقت مرحلة الإيقاف المرصودة نحو205ms. لم تعمل عمليتا API معًا، وثبت استماعهما على127.0.0.1 فقط.
4. **حدث غير مدعوم:** ظل `IdentityStatusChanged.v2` في PENDING، بعدد محاولات صفر ودون حجز أو إيصال أو أثر. هذا احتفاظ آمن لا نجاح معالجة؛ وجود حدث غير مدعوم شرط يمنع ترقية مستهلك لا يفهمه.
5. **fencing داخل PostgreSQL:** نُفذ مخزن outbox من Git blob السابق بعد مطابقة blob الحالي. بساعة منطقية معلنة لانتهاء الحجز، رُفضت محاولات المالك القديم للتجديد وتسجيل النجاح والفشل، ونجح صاحب token الجديد وحده. لم تُستخدم mocks لقرارات CAS. اكتمل هذا الجزء ثم فشل فحص مصدر الأصول لاحقًا بسبب LF/CRLF؛ لذلك بقي التقرير الكلي لتلك المحاولة failed، وحُفظ نجاح مكوّن fencing منفصلًا ولم يُعد.
6. **عقود الأصول من المصدر المثبت:** فُحصت29 وحدة مصدر أصلية من Git، مع تطابق بصمات السابق والحالي. استخدم الفحص مستودع Prisma فعليًا ودورًا عاديًا وملفًا صناعيًا CONFIDENTIAL/TEMPORARY بانتهاء ثابت بعد180 يومًا ودون Legal Hold. تطابقت بايتات القراءة وبصمتها قبل/بعد، ورُفض المحتوى المحرّف، ونجح عقد grant مؤقت، ثم رُفضت القراءة وطلب grant جديد بعد الحذف المنطقي قبل الاتصال بالمزود. لم تُنشأ Consent أو Binding ولم تُغير الموافقات التاريخية. مزود البايتات صناعي داخل العملية، ورابط grant غير قابل للاستخدام عمدًا؛ لا ادعاء بتنزيل grant أو اختبار صلاحيات HTTP الفعلية عبر API.

## الفحوص والأخطاء التشغيلية

لم تُعد مجموعات R06–R11 أو بناء المشروع أو بروفة API السابقة. أضيفت بروفة العامل المبني وفحص CAS وفحص الأصول المحدد. احتاج المشغل المحلي تصحيح preload الذي لم يصل إلى موضع spawn؛ بقيت عملية الاختبار عند انتهاء مهلة IPC، ثم أُثبتت ملكيتها وأُنهيت وتأكد غيابها وتوقف cluster. احتُفظ بالتقرير الأصلي الذي سجل cleanup غير مكتمل وبإثبات الإغلاق اللاحق، ولم يُستبدل الفشل بنجاح.

في مشغل عقود المصدر كان PATH مقيدًا بمسار Node؛ استُخدم مسار Git مطلق. ثم صُحح availableAt في fixture ليقع قبل وقت الحجز بدل الاعتماد على ساعة الإنشاء اللاحقة. بعد نجاح fencing ظهر فرق LF/CRLF في checkout؛ عولجت مقارنة checkout فقط، مع بقاء مطابقة Git blobs الأصلية بايتًا ببايت. نجح تحميل المصادر دون قاعدة قبل تشغيل الأصول وحدها؛ لم يُعد fencing أو العامل الناجحان. هذه تصحيحات للمختبر وليست ثغرات تطبيق مثبتة.
