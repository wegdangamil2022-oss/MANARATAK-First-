- أُوقفت واجهتا منح رابط الشهادة بإجابة410 بعد التفويض، وأُغلق تجاوز واجهة الأصول العامة باستخدام سجل الاستخدام الموجود. يظل سجل Audit للفشل قائمًا، مع410 واضح بدل500 للحالة المتوقعة. لم يُضف Outbox أو نظام صلاحيات جديد.
- زرا تنزيل الطالب والإدارة يقرآن Blob موثقًا. نجحت معاينة الطالب المرئية وتنزيل PDF من الواجهتين، وطابقت البصمات ملف الرسّام. دخل المشرف عبر MFA فعلي، وفُحصت الصور؛ لا أخطاء صفحة أو استجابات500 في الرحلة الناجحة.
- أُلغيت الشهادة عبر HTTP إداري مخول أثناء انتظار قراءة التخزين؛ رُفض إرسال PDF. رُفض طلب URL الموثق نفسه بعد الإلغاء، قبل قراءة التخزين. سُجل REVOKED مرة واحدة. لم تمنح الرحلة الجديدة أي رابط مزود.

## المحاولات المحفوظة وحدود الأدلة

نجحت طلبات PDF/preview للمالك والإدارة ومنع الطالب الآخر علىe2ff681؛ المحاولة ككل بقيت FAILED بسبب500 لمسار المنع العام. بعد إصلاحه، توقف إثبات المختبر لأن أداته قرأت error بدل code من Problem Details؛ ثم توقف قبل المتصفح بسبب Git غير موجود في PATH المقيد. هذه إخفاقات محفوظة، ولا تُعاد تسميتها PASS.

استُؤنف المختبر الصناعي الأخير بعد إثبات هوية العنقود والبرنامج، وأُعيد استخدام الشهادة ومخرجاتها ومفتاحها العابر وMFA المؤكد دون إعادة إصدار أو تأكيد مصطنع. صُححت أداة الإثبات فقط لتقرأ code وتستخدم مسار Git المطلق. نفذ الاستئناف المتصفح والإلغاء المتزامن والحالات التي لم تُنفذ. ملفات المشغلات المحفوظة تصف الاستئناف النهائي؛ ليست ادعاء باسترجاع نسخ أدوات المحاولات السابقة التي كُتبت فوقها.

جهة الإصدار والقالب والصفوف الأصلية للشهادة وBinding والمال لم تتغير بصماتها. جدول Consent الأصلي فارغ؛ لا ندعي تجربة صف موافقة تاريخي موجود. التوقيع HMAC عابر صناعي جديد، وليس مفتاح إنتاج أو تحققًا من مفاتيح التوقيعات القديمة. أصول الرسّام عينة ثقة مادية صناعية، لا فحص malware/تعقيم EAP جديد.

أُغلقت عمليات API والمزود والمتصفح والعناقيد التابعة للدفعة. أُلغيت جميع جلسات ممثلي المختبر الناجح، بما فيها جلسات المحاولة السابقة فيه. لم تُمس قاعدة خارج المختبر أو Neon أو إنتاج أو migration تاريخية أو main.

## حد الروابط القديمة قبل النشر

الإصلاح يمنع إصدار روابط جديدة لمرفقات الشهادة الخاصة؛ لا يمحو رابط مزود سبق كشفه ولا يستعيد بايتات نُزلت. نتيجة200 القديمة محفوظة في تقرير تسليم الشهادة السابق. لا يوجد ادعاء بإبطال رجعي فوري.

عند تجهيز هدف نشر فعلي:

1. أوقف جميع نسخ وعمّال الإصدار القديم، واحصر القدرات الصادرة فعلًا وآخر إصدار وأقصى expiresAt موثوقًا من المزود.
2. مسار الشهادة السابق طلب300 ثانية، لكن مسار الأصول العام يسمح بطلب3600؛ لا تستخدم300 كحد شامل أو تفترض التزام المزود بالمدة دون دليل.
3. انتظر انتهاء آخر قدرة مثبتة مع حد انحراف الساعة المعتمد، أو أثبت إبطالها لدى المزود. إذا كانت الأعمار غير موثقة فلا يكفي انتظار رقم تخميني.
4. أثبت رفض العينات القديمة قبل فتح التنزيل، وتجنب rollback يعيد إصدار الروابط. لم تُنفذ هنا اتصالات مزود خارجي أو تغيير مفاتيح أو ترقية.

تبقى بوابة الانتقال للروابط القديمة مطلوبة إن وجدت في الهدف الفعلي، وبوابات الإصدار السابقة وNO_GO قائمة. استخدام سجل الاستخدام الحالي لإغلاق منفذ المنح يضيف قراءاته المعتادة على طلبات أصول Certificate الخاصة؛ لم تُقَس أحمال هذا المسار ولا نُعلن قبول أداء شاملًا.
