# R14 — مذكرة قرار إصدار: NO_GO

**التوصية الحالية: NO_GO للإنتاج؛ المسموح هو استكمال العمل المعزول ضمن التفويض القائم.** هذه مذكرة تجهيز قرار حسب الخطة، وليست اعتمادًا مستقلًا أو إغلاقًا رسميًا لـR14. مصدر المراجعة `83e210e0eb9505c875129948bd52171986f458b3`، وآخر إصلاح تنفيذي `cbe2ff2d0e3ba881361fcbe42133af500cd4c331`، والفرع `feat/post28-r07-artifact-preparation`. لا نسبة جاهزية تقديرية.

## الأساس والحدود

أُنجز النطاق العملي لـR00–R13 بمصادره وحدوده الموثقة. R05 إغلاق محلي صناعي بمراجعته الأصلية، وR06–R13 لها استثناءات قبول شاملة باقية. لا يحول جمع هذه الحالات المختبرية إلى قبول إنتاج أو قبول كل CD/العلاقات/مجالات النظام.

CI لإصلاح R11 على `2934821` مكتمل وناجح في مهامه الست. CI آخر إصلاح `cbe2ff2`، التشغيل [39516645007](https://github.com/wegdangamil2022-oss/MANARATAK-First-/actions/runs/39516645007)، كان بخمس مهام ناجحة وLinux جاريًا عند القراءة الأولى لهذه المذكرة؛ النتيجة الدقيقة المحدثة تُحفظ في إيصال الأدلة وJSON عند ورودها. لا يُستخدم نجاح CI بديلًا عن الأدلة والتوقيعات المطلوبة.

تتطلب [سياسة المصدر](../../config/release/source-release-policy.json) فصل المصدر والتشغيل، وأدلة حديثة، وتوقيعًا معتمدًا، ولا تفوض النشر التلقائي. [عقد القبول](../../config/release/runtime-acceptance-contract.json) يحتفظ ببواباته الاثنتي عشرة، ومصفوفة26 مجالًا ومراجعة27 قسمًا. لا أغير هذه العقود لتسهيل GO.

## الأعمال المسموحة محليًا قبل إعادة طلب قرار إصدار

| الترتيب | العمل المحدد | شرط اعتباره مكتملًا |
|---|---|---|
| 1 | رحلة Admin الكاملة: تأليف/مراجعة/نشر/سحب، بأدوار مستقلة وMFA الفعلي | الحزم المبنية والمتصفح والصلاحيات السلبية واختفاء المنشور؛ لا يكفي تفعيل MFA منفصلًا أو دورة API فقط |
| 2 | تسليم شهادة ووثيقة خاصة من API المبني عبر مزود معزول مفوض | ثبوت الهوية وConsent/Binding القائمين، انتهاء grant ورفض الآخر والسحب؛ دون رابط عام بديل أو اختلاق scan/EAP |
| 3 | مسارات العمال المطلوبة للمال والشهادات والاستيراد، مع التكرار والتعطل | أثر واحد وإيصالات محفوظة وتسييج lease؛ لا تعميم لاختبار StudentWorkspace على بقية العمال |
| 4 | بروفة Linux للتراجع في نطاقه المعتمد | artifact pair محددان، SIGTERM وإعدادات routing حقيقية، عدم ظهور روابط متقاعدة وعدم فقد ledger/receipts؛ لا down migration |
| 5 | تجهيز تعريف حجم إطلاق ممثل وحدود الموارد/SLO وقياس pool checkout | حدود تسبق القياس، وdataset ممثل، وقياس pool wait فعلي؛ لا استخدام query round trip بدلًا منه |

هذه قائمة عمل معاييرها واضحة؛ لم تُنفذ عناصرها بهذه المذكرة. يُعاد الفحص الذي يتأثر بالتعديل فقط، وتبقى أدلة النجاح غير المتأثرة بمصادرها، ولا يُكرر build شامل لمجرد توثيق النتيجة.

إن لم يوجد حساب أو ميزانية، يبقى تجهيز البنية الخارجية متوقفًا وحده، وتستمر الأعمال المحلية المستقلة. لا تُشترى موارد أو دومينات ولا يُنشأ اشتراك بهذه المذكرة.

## القرار وسير الاستئناف

تبقى `releaseDecision=NO_GO` و`productionAuthorized=false` و`formalR14Accepted=false`. لا تشغيل promotion حتى بوضع dry-run، ولا تغيير main أو Neon أو إنتاج أو قاعدة قائمة أو migrations تاريخية أو مفاتيح ثقة. لا استثناء صامت لبوابة إلزامية.

نقطة الاستئناف الوظيفية: **رحلة Admin الكاملة مع MFA في مختبر صناعي جديد، بعد تثبيت CI الأخير، مع الحفاظ على إنجازات المراحل السابقة**. يظل النشر محجوبًا إلى استيفاء جدول البوابات الفعلية؛ هذه المذكرة لا تستدعي توقيعًا أو موافقة إضافية لمواصلة العمل المحلي المفوض.
