# Network Measurement

`scripts/verify-idle-bandwidth.js` observes a fixed interval without creating external traffic.

Run two equal-duration samples:

```powershell
node scripts/verify-idle-bandwidth.js --duration 300
node scripts/verify-idle-bandwidth.js --duration 300 --url http://localhost:3000
```

The first is the machine/Codex baseline. Start MANARATAK before the second command. Add `--probe /api/health` only when one explicit localhost health request is wanted.

OS byte counters are aggregate counters for the machine, not per-process attribution. `monitoredHttpRequests` contains only requests generated by this verifier. When OS counters are unavailable the report says `BYTE MEASUREMENT UNAVAILABLE`; it never substitutes zero.

Compare equal windows and keep Codex/browser activity as similar as possible. This tool cannot prove that unobserved browser requests did not occur; browser DevTools or server access logs are still required for request-level runtime evidence.
