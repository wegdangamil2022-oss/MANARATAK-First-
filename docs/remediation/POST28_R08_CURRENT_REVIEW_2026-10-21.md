## ما تحقق فعليًا

- استُرجع أرشيفا Redis والمزود الصناعي من Actions، وتطابقت هوية التشغيل والمصدر وحجم ZIP وبصمة SHA-256 مع metadata المسجلة. تعذر تنزيل HTTP المباشر مرة واحدة؛ نجح مسار موصل GitHub البديل، ولم تُعد مهمة CI.
- Redis فعلي: عمليتان مستقلتان، 24 طلبًا و10 قبول مشترك؛ عزل namespace/revision، رفض الصحة القديمة، ظهور فشل العامل وتوقفه، TTL محدود وصلاحيات ACL مقيدة. رفض الانقطاع، وقبول webhook موقّع مرة واحدة ورفض replay والتلاعب والتوقيت القديم. أزيلت الحاوية المملوكة.
- PostgreSQL 16 صناعي: نجحت حالتان محددتان؛ استعادة استرداد مالي فقد الرد دون استهلاك الموافقة أو القيد مرتين، ومهلة تفويض حقيقية دون إعادة الإرسال أو اعتبار الفاتورة مدفوعة. الدور `post28_app`، وأزيلت القاعدة والشبكة المملوكتان دون لمس قواعد سابقة.
- الاكتشاف وجد أربع حالات مالية؛ شُغلت واحدة في كل استدعاء. يسجل Vitest ثلاث حالات غير مختارة لكل استدعاء. لا تُحسب هذه الحالات نجاحًا ولا يُعلن قبول الملف الكامل 4/4؛ دليل النجاح الحالي **حالتان محددتان فقط**.
