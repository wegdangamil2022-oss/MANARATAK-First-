# الموظفون والهويات والأدوار والصلاحيات — التنفيذ وحالة التفعيل

هذا التسليم ينفذ ترتيب الوظائف الحالية والحواجز الأمنية ذات الأولوية، ويتيح تخزين مسودات Staff والهيكل الوظيفي بعد تطبيق الإضافة المعتمدة على القاعدة الأصلية. **لا يعني اكتمال رحلة التوظيف والدعوة والتفعيل والمغادرة بالكامل.**

## المنفذ

- أربعة مداخل للموظفين: الموظفون، الدعوات والانضمام، الهيكل الوظيفي، التغييرات والمغادرة. دليل الهويات العام يبقى أداة منفصلة داخل المدخل الأول، ولا يحوّل كل Human أو حامل دور إلى موظف.
- خمسة مداخل للصلاحيات: الأدوار والقوالب، تعيينات الوصول، الصلاحيات والسياسات، التحقق والمراجعات، الحوكمة والأمان. إنشاء الدور عند الطلب، مع روابط التبويبات القديمة وتفاصيل الهوية والرجوع بفلاتر الدليل.
- عناوين مدمجة وخط Cairo صريح، اختيار نيلي وأيقونات ذهبية، وبترولي ظاهر في الأزرار. التصنيف الأكاديمي والمالية وخدمات المؤسسات تغيرت ألوان رؤوسها وأزرارها الثانوية فقط؛ ترتيبها محفوظ.
- تغيير الدور أو الإسناد الحساس والسياسات والوصول الطارئ يحتاج موافقة محفوظة يصدرها المعتمد من حسابه. صاحب الطلب ينفذ النسخة المعتمدة لاحقًا. انتهاء الموافقة أو استهلاكها أو تغير الدور أو السياسة أو الهوية يبطل التنفيذ.
- استهلاك الموافقة وفحص النسخة يتمان داخل معاملة الكتابة نفسها مع سجل التدقيق وoutbox. سحب إسناد معتمد يظل ممكنًا من هوية غير نشطة، بشرط تطابق حالتها والنسخة المعتمدتين. إعادة إنشاء الإسناد تبطل موافقة سحبه القديمة.
- التفويض يحتفظ بقيود دور المانح؛ الوصول الطارئ وحده لا يسمح بمنح وصول دائم. تعديل سياسة مستخدمة يتطلب سلطات أصلية غير مقيدة لتلك الصلاحيات لدى المانح، إضافة إلى الاعتماد المستقل.
- مسار الاتصال الإداري يرفض أعلام التوثيق اليدوي للبريد والهاتف. مسار إثبات الملكية يبقى لدى Identity؛ لم نغير حسابًا أو نتجاوز MFA.
- فحص الوصول يعلن وقت الفحص وسياق اتصال المسؤول، ولا يدعي جاهزية جلسة الموظف أو اكتمال MFA فيها.

## Staff: مصدر جاهز للمراجعة وتفعيل مشروط

يوجد مالك مستقل لمسودة العضوية الوظيفية والأقسام والمسميات وأحداث المسودات. الحفظ لا ينشئ Identity ولا يمنح Role ولا يفعل العضوية. الربط بهوية موجودة لا يعد إثبات ملكية أو قبول دعوة.

المصدر يطبق المعاملة المدققة، التحقق من تطابق المسمى والقسم، منع دورات الأقسام وإدارة الذات، نسخ التعديلات، وإلغاء المسودة فقط. لا توجد واجهة حذف سجل موظف أو تعطيل حساب طالب باسم المغادرة. يستخدم هذا النطاق حاليًا إذن **admin:identities:manage** مع مصادقة الإدارة وMFA؛ لا توجد صلاحية مفترضة أو منح تلقائي.

المخطط المعتمد: [20261028000100_staff_draft_organization](../packages/infrastructure/prisma/migrations/20261028000100_staff_draft_organization/migration.sql). طُبق على القاعدة الأصلية بتفويض المستخدم اللاحق في 28 أكتوبر، داخل معاملة واحدة بدور الترحيل القائم. يحتوي أربعة جداول جديدة وقيود المصدر والتواريخ وعضوية مفتوحة واحدة لكل هوية وفهارسها. سُجلت بصمة ملف SQL في سجل Prisma، دون تشغيل ترحيلات أخرى أو نقل بيانات الحسابات والأدوار.

ضُبطت صلاحيات الجداول الجديدة فقط لدور التطبيق: قراءة وإضافة وتعديل الهيكل والمسودات؛ قراءة وإضافة سجل الأحداث دون تعديله. لا حذف أو TRUNCATE أو صلاحية DDL للتطبيق. قورنت بنية الجداول الحالية وبصمات بيانات الهوية والمستخدم والحساب وبيانات الاعتماد والأدوار والإسنادات والسياسات قبل الإضافة وبعدها داخل المعاملة؛ ظلت محفوظة. لا تعبئة أو بيانات تجريبية أو تعديل حساب أو MFA.

قبل قراءة الدليل تفحص الواجهة وجود الجداول وصلاحيات دور القاعدة. غياب التهيئة يعرض حاجزًا صريحًا؛ ليس عداد صفر أو نجاح حفظ وهمي. أعطال الاتصال تختلف عن غياب السجلات.

## استكمال الدعوات والتفعيل والمغادرة

استُكملت الرحلة بحالات استخدام وواجهات فعلية، ثم طُبق ترحيل الجداول الأربعة الإضافية بتفويض المستخدم الصريح مع ترحيل دعم الطلاب. وجود جداول المسودات وحده يظل غير كافٍ؛ تُفحص جاهزية التخزين والصلاحيات وخدمة الرموز قبل فتح الأوامر.

- الدعوة لمدة 48 ساعة، مرتبطة بالعضوية والبريد، ورمزها محفوظ كبصمة فقط. تصل إلى المنشئ لتسليم يدوي آمن؛ لا إرسال خارجي. يفتح صاحب الحساب الرابط ويسجل الدخول ويوثق بريده ويوافق صراحة عبر POST. لا قبول بمجرد الزيارة ولا تغيير حساب أو كلمة مرور أو MFA، ولا تفعيل أو منح دور بمجرد القبول.
- التفعيل والإيقاف والاستئناف والنقل والمغادرة تحتاج طلبًا محفوظًا واعتماد شخص آخر وتنفيذ صاحب الطلب خلال 30 دقيقة. يعاد فحص أهلية الطرفين والنسخة والهوية والهيكل والمهام عند التنفيذ. انتهاء الاعتماد أو استهلاكه أو تغير النسخة يمنع التنفيذ.
- تسليم المهام شرط مانع، مع روابط لأصحاب المراجعات والاستيراد والتدقيق والدعم والمرؤوسين. لا تحويل صامت لمهام أقسام أخرى.
- حاجز وصول إداري مستقل يسري على المداخل الأصلية والقديمة للإدارة وعلى قوائم المسند إليهم. فشل قراءة الحاجز لا يسمح بالمرور. لا تُلغى جلسة الطالب ولا يُعطل حسابه بسبب المغادرة.
- مصدر استحقاق الدور يسجل الإسناد الجديد وتاريخه والعضوية في معاملة التفويض نفسها. لا تنسب إسنادات قديمة للوظيفة. المغادرة تسحب المطابقات المثبتة فقط والوصول الطارئ؛ تبقي الإسنادات الأخرى والحساب وبيانات الاعتماد والمصادقة الثنائية. آخر مسؤول استرداد مؤهل محمي.

## التحقق وحدوده

نجح سابقًا 167 اختبارًا في 31 ملفًا، مع TypeScript وبناء لوحة الإدارة وفحص ESLint دون أخطاء. وبعد تجهيز المخطط نجح 110 اختبارات مرتبطة في 21 ملفًا، وفحص الأنواع والبنية المعدلة دون أخطاء ESLint. لم يُجر فحص CI الشامل أو قبول القاعدة الأصلية بالكتابة.

أضيف [اختبار تخزين PostgreSQL المعزول](../scripts/database/verify-staff-draft-storage.mjs): 12 تحققًا، تشمل استخدام دور التطبيق الفعلي، إنشاء مسودة وهيكل عبر حالات الاستخدام مع Audit وoutbox وأحداث المسودة، إلغاء المسودة، رفض التكرار والمصادر والتواريخ غير الصالحة، صلاحيات سجل الأحداث، والتراجع وإزالة الجداول المعزولة. كشف الاختبار خطأ Prisma عند قراءة نتيجة قفل advisory من نوع void، وصُحح بتحويل النتيجة إلى text مع الاحتفاظ بالقفل نفسه. لا يقبل الاختبار URL قاعدة؛ يشترط مختبر PostgreSQL محليًا مع إثبات العزل.

اختبارات القبول المعزولة تغطي رفض الموافقة المدعاة والمنتهية والمستهلكة، تغير النسخ، الاستهلاك ضمن معاملة الكتابة وفشل التدقيق، قيود التفويض، إثبات ملكية الاتصال، غياب المخطط والصلاحيات، منع حقن منح أدوار في المسودة، بنية الملاحة باللغتين، وتفاعل صندوق الموافقات. الأدلة التشغيلية المحلية تسجل SHA الملفات المقدمة وتطابق أصول البناء وحدود المصادقة.

طُبق ترحيل الجداول الأربعة فقط على القاعدة الأصلية بعد التفويض الصريح. لم تطبق تعبئة أو حذف أو تجارب قبول بالكتابة عليها، ولم تجر معاينة بالصور أو ادعاء تحقق بصري مصادق. استُكملت لاحقًا عقود الدعوات والتفعيل والمغادرة كما أعلاه، واختُبرت في PostgreSQL معزول: 20 تحققًا تشمل التراجع عند فشل التدقيق والحفاظ على وصول الطالب وحماية الاسترداد. لا يدعي ذلك قبولًا تشغيليًا لكل سيناريوهات الخطة الـ120 أو إرسالًا خارجيًا أو فحصًا بصريًا مصادقًا.
