## التطبيق والتحقق

طبق الإغلاق على الأصلية في معاملة Serializable واحدة، مع قفل السجلات والممثل والأدوار والسياسات وإعادة تقييم صلاحيات الاستيراد والاختبارات والبيانات المرجعية. أضيف المرجعان من خلال مستودع البيانات المرجعية المحكوم؛ لكل منهما نسخة تاريخية أولى، دون إدراج مباشر يتجاوز الحوكمة. سجل تدقيق وOutbox للعملية، ودليل تاريخي مستقل لكل اختبار. ترفض العملية رقم مراجعة قديمًا أو تغير الهوية أو إضافة مرجع متزامنة؛ تكرارها يقرأ إيصال الإغلاق ولا يعيد تعديل المالك.

نجح إثبات PostgreSQL محلي على الحالات الثماني، مع تقدم المراجعات وإنشاء النسختين المرجعيتين، والإعادة ورفض المراجعة القديمة، ثم إجبار التراجع وإثبات عودة الأعداد. نجحت اختبارات عرض الحالات متعددة الجهات/الإقليمية ورفض JSON غير مكتمل، وفحص الأنواع وبناء الإدارة. التحقق من الأصلية بعينة أربعة سجلات وفلتر TW؛ لا إعادة فحص عامة للتخصصات أو إعادة استيراد الملفات.
