## التحقق

- 246 اختبارًا في مجموعة الاختبارات نجحت بعد إصلاح الفلتر؛ ثم نجحت ست حالات واجهة متأثرة، ومنها حالة جديدة لأسماء العلاقات العربية. خمسة اختبارات مستقلة لإثبات المصدر ورفض الأدلة المخترعة والتكرار والاستبدال الخاطئ للمراجع نجحت.
- PostgreSQL محلي: سبع عينات تشمل أنواع العلاقات الأربعة، مع حفظ النصوص والحقول الأخرى، وتقدم رقم المراجعة، ورفض المراجعة القديمة، وإعادة بلا تعديل المالك. أُجبر التراجع وأثبتت بصمة الحالة السابقة تطابقها بعده.
- الأصلية، قراءة فقط: تفاصيل **IELTS وCSCA وGPAT** أعادت أسماء المراجع الصحيحة؛ أربع حالات فلترة نجحت: الدولة مع البحث والتصنيف، والجهة مع البحث، والدولة غير المعروفة، والتصنيف المتعارض.
- نجح فحص الأنواع للبنية التحتية وAPI والإدارة، وبناء الإدارة. لا أخطاء ESLint في الملفات المستهدفة؛ التحذيرات القائمة في الملفات القديمة ليست إغلاقًا لجودة المستودع كله. نجح حاجز جودة المصدر والتنظيم.
- التحقق عبر طبقة المستودع وعرض المكونات؛ لم تُدّع مشاهدة جلسة إدارة مصادق عليها أو تجاوز MFA.

تفاصيل الزمالات تبقى بانتظار ملف المالك. لم ينفذ هذا العمل استيرادًا عامًا جديدًا للجامعات أو الدورات أو إعادة فحص شاملة للتخصصات.
