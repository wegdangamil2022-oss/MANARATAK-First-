# W14 Source Remediation Closure — CMS integrity and publishing governance

**Scope:** 10 findings — 6 HIGH, 4 MEDIUM.
**Boundary:** source remediation only. No migration/backfill/runtime mutation was executed.

## Closed findings

- `P16-LOCALE-001` — root content lifecycle is derived from locale states; localized transitions no longer overwrite root truth.
- `P16-NAV-005` — navigation authoring and publishing are separate commands; checker publishes an immutable reviewed hash/version without replacement nodes.
- `P16-ANN-006` — announcement authoring and publishing are separate; checker cannot rewrite content during approval.
- `P16-SCHED-002` — scheduler uses atomic `PROCESSING` claim/lease, `FOR UPDATE SKIP LOCKED`, lease recovery, and target-state idempotent completion.
- `P16-SEO-004` — canonical URL is generated by governed routing and removed from admin authoring contracts.
- `P16-SEO-003` — canonical/slug redirect routing is content-type aware.
- `P16-REDIR-008` — redirect validation traverses the active graph and rejects cycles longer than two edges.
- `P16-NAV-010` — orphan parents, duplicate node IDs and cycles are rejected.
- `P16-BLOCK-009` — block payload validation is recursive and rejects undeclared fields by default.
- `P16-TAG-007` — tag filtering is included in the database predicate before pagination/counting.
