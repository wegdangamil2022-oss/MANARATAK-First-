# P12 — تفعيل حساب المالك وتشغيل الدخول الفعلي محليًا

اكتمل تفعيل حساب التطوير الحقيقي ببريد المالك، ثم نجح الدخول من صفحة الإدارة الفعلية وقراءة الدول عبر API بصلاحيات مستخرجة من قاعدة التطوير. نجح تحديث الصفحة مع استمرار الجلسة، ورفض الزائر غير المسجل، وإبطال الوصول بعد تسجيل الخروج. لا أخطاء JavaScript مسجلة في هذا المسار. هذه نتيجة تشغيل محلي محددة، وليست قبولًا شاملًا للمنصة أو للإنتاج.

مرجع الكود `ef1a4f638c97a70cb65a54896e9e59b3af7049cc`. الهدف الوحيد مشروع Neon المستقل `hidden-smoke-02928871`، فرع `br-sweet-king-b9pem1dg`، قاعدة `neondb`، PostgreSQL 16.15. جرى التشغيل بدور التطبيق المقيد دون ملكية أو DDL أو superuser/CREATEDB/CREATEROLE/BYPASSRLS أو وصول إلى دفتر migrations. لم نوسع صلاحية لحل فحص. [إثبات التفعيل](evidence/IMPORT_REAL_OWNER_ACTIVATION_2026-10-23.json)، [إثبات المتصفح](evidence/IMPORT_REAL_OWNER_BROWSER_2026-10-23.json).

## الهوية والبريد

استُخدم مسار التسجيل الموجود، وتسليم SMTP حقيقي مع تحقق TLS إلى Gmail، ثم الرمز الذي أدخله المالك من الرسالة المستلمة. استهلاك الرمز والتحقق وآثارهما جرى في معاملة واحدة. بعد تحقق البريد ومطابقة كلمة المرور المشفرة استُخدم `ControlledFirstAdminBootstrap` مرة واحدة، مع سجل `FIRST_ADMIN_BOOTSTRAP_ONCE`. نُسب التنفيذ إلى المشغّل المفوض من المالك؛ لا ندعي توقيع مراجع بشري مستقل.

بقيت كلمات المرور ومفاتيح التشغيل خارج Git والدردشة؛ الأسرار المحفوظة محليًا محمية بـWindows DPAPI للحساب الحالي. أزيلت النسخة المشفرة للرمز بعد استهلاكه. Cookies الدخول وrefresh كانت HttpOnly وSameSite=Strict. الاتصال المحلي HTTP على loopback فقط؛ إعداد HTTPS والإصدار العام غير معتمدين بهذه التجربة.

## الحفظ والاستعادة

قبل إجراء الحساب نجح نسخ نطاق auth/roles/audit/outbox واستعادته في مختبر PostgreSQL 16 جديد، مع مطابقة عشرة جداول وشكل الأعمدة ودالة audit والسياسة الفارغة، والتحقق بدور مقيد للقراءة. النسخة الكاملة الجديدة تعثرت بالمهلة؛ ملفها الجزئي ليس نسخة معتمدة. استخدمت الاستعادة مخططًا من النسخة الكاملة المثبتة سابقًا وبيانات النطاق الحديثة، ولا نزعم استعادة حديثة لكل المنصة. [دليل النطاق](evidence/IMPORT_ACCOUNT_RECOVERY_2026-10-23.json). أُوقف مختبر الاستعادة بعد التحقق.

المقارنة المسجلة أثناء تجهيز إجراء الحساب طابقت بصمات 272 جدولًا خارج جداول الإجراء والمراجع المصرح بها، مقابل baseline السابق. [نطاق المقارنة واستثناءاته](evidence/IMPORT_ACCOUNT_PROTECTED_DATA_2026-10-23.json). ليست هذه مقارنة جديدة لكل الجداول بعد كل طلب متصفح. لم تُنقل بيانات الطالب أو الشهادات أو Consent أو Binding إلى fixtures ولم يُنفذ دفع.

## التحقق ونقطة الاستئناف

نجحت سبعة فحوص مستهدفة لبوابة أول مدير باستخدام TSX؛ عولجت محاولة loader غير الصحيحة بإضافة loader المشروع، دون تغيير assertions أو الحواجز. لم تُعد R0–R13 أو مجموعات البناء العامة أو فحوص الاستيراد الناجحة. حفظ الأدلة ومراجعتها لا يثبت نجاح CI لهذا التسليم؛ تُقرأ نتيجته على commit المرفوع.

أُزيل عائق «الحساب الحقيقي مؤجل». بقي قبل استيراد الاختبارات والجامعات على Neon: قراءة الهويات والمراجع الحية، نسخة حديثة واستعادة للنطاق المناسب، وخطة دفعة مختومة ومراجعة المالك وفق العقد. صلاحية حساب الإدارة لا تلغي هذه البوابات. معاينة P11a مستقلة مكتملة بنطاقها في [دفعة المنح الأولى](IMPORT_SCHOLARSHIP_FIRST_PREVIEW_2026-10-23.md). P13 للتأليف والمراجعة والنشر والعرض وزر الاختبار والسحب يبقى مفتوحًا حتى وجود المحتوى المترابط وأدلته. النشر والاستضافة وDNS والخدمات المدفوعة ليست ضمن التنفيذ الحالي.
