## العزل والإعداد

أُنشئ cluster محلي جديد بمعرّف `54bc2513-95b6-4049-8f02-6904551d9b02` على loopback:50614. أثبتت بوابة native lab فراغ الهدف وتطابق SHA وnonce وdatabase OID وserver identity. طُبقت الترحيلات التاريخية الـ111 كما هي عبر post28_tx_migrator غير المرتفع؛ لا db push أو reset أو تعديل migration. لم تُلمس أي قاعدة سابقة أو Neon.

نفذت التجربة كلها بـpost28_app: بلا superuser أو CREATE ROLE/DB أو BYPASSRLS أو ملكية أو DDL أو وصول إلى _prisma_migrations. أعطي SELECT لنماذج Prisma لاحتساب العلاقات، وكتابة لـ16 جدولًا لازمة للتجربة فقط. استخدم migrator لإعداد المخطط والمنح وإدخال عطل الصلاحية، ولم ينفذ سيناريوهات التطبيق.

## ما أثبته التنفيذ

1. تسجيل مستخدم صناعي بعنوان example.test عبر RegisterUserUseCase، وتسليم رمز تحقق مولد فعليًا إلى SMTP محلي، ثم VerifyEmailUseCase الفعلي. رُفض الاستيراد قبل تحقق البريد، ورُفض بعد التحقق حين كانت الصلاحيات غائبة. الدور التجريبي يمنح فقط admin:imports:manage وadmin:international-tests:manage؛ أُسند كـfixture صناعي صريح. لم يُنشأ حساب بشري أو يُستخدم first-admin bootstrap أو تُختلق موافقة مسؤول.
2. معاينة READY للاختبارين على الكتالوج الفارغ. سُحبت INSERT على TransactionalOutboxRecord من التطبيق، وفشل commit وبقيت أعداد الجذور/النسخ/المحتوى/Audit/Outbox كما كانت تمامًا. أُعيدت المنحة بعد العطل.
3. نجح commit: جذران ونسختان و36 كتلة محتوى من TOEFL iBT وIELTS. طابقت source.raw النص الكامل لكل مصدر؛ بقيت النسختان DRAFT وغير عامتين وغير موثقتَي المصدر. حُفظ REPLACE_EXISTING وقرار APPROVE_INITIAL_CREATE، دون تحويل manifest التاريخي.
4. أضاف التطبيق Audit واحدًا وOutbox واحدًا فوق baseline التجربة. نجحت reconcile، وإعادة نفس الطلب أعادت replayed=true وdatabaseWrites=0 مع مطابقة كل الأعداد.
5. رُفضت دفعة إنشاء أولى أخرى بعد امتلاء الكتالوج، حتى بمعرّف changeSet جديد. تغير الهدف بين المعاينة والكتابة له اختبار البوابة السابق ببدائل الذاكرة؛ لا ندعي أن تجربة PostgreSQL هذه أثبتت سباق كاتبين متزامنين.
6. نجح التعويض: ARCHIVED للجذرين وSUPERSEDED للنسختين، مع بقاء الكتل الـ36 والمصدر الخام. زادت Audit/Outbox بواحد لكل منهما، ونجحت reconcile وإعادة التعويض دون كتابة.

أُغلق SMTP بعد التجربة. أُوقف خادم المختبر باستخدام تطابق المسار وpostmaster PID وبصمة موضع الملف التنفيذي، وبقيت الملفات محفوظة دون حذف. لا إعادة للمجموعات العامة أو لفحوص المراحل السابقة؛ هذه أول تجربة PostgreSQL لهذا المسار الجديد.
