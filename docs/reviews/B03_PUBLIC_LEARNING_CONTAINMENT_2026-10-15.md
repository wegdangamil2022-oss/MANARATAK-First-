## ما تغير

- فُصل اختيار شاشة الدورة في `PublicCourseEntry`: لا تدخل `CourseStudyRoomView` إلا مع `dataMode=prototype` وحالة الدراسة التجريبية. قيمة `mn_is_studying_course` القديمة لا تفتحها في api، ولا تُقرأ/تُكتب كحالة دراسة حية. يظل تنبيه prototype الموجود في التطبيق قائمًا.
- CTA الدورات الداخلية، المجانية والمدفوعة، يفتح `/:locale/student/courses/:ownerId` عبر React Router وعقد `courseLearnerPath`. لا يُستنتج المالك من slug أو الاسم أو المزوّد. المالك المفقود والتصنيف غير المعروف لا ينتجان رابط تعلم داخليًا. الدورات الخارجية لا تكتسب تسجيلًا/تقدمًا محليًا.
- `OwnerCourseDetail` يتجاهل callback الدراسة التجريبية في api حتى لو مرره مستهلك بالخطأ. تصنيف بطاقات الدورات في api يعتمد `originType`، واستنتاج المزوّد والرابط الخارجي المصطنع محصوران في prototype.
- صفحة التعلم الفعلية تستخدم عقود API القائمة. 401 يحفظ مسار الدورة المحلي للعودة بعد تسجيل الدخول؛ `COURSE_ENROLLMENT_REQUIRED` وحده يعرض التسجيل. تعطل الخدمة أو تعليق التسجيل أو فقد نسخة المنهج لا يتحول إلى عرض تسجيل جديد. ردود مساحة تعلم قديمة تُهمل بعد تغيير الدورة، كما لا يعيد انتهاء تسجيل معلّق فتح الدورة السابقة.
- لا ينقل الانتقال إلى المسار أي تقدم أو محاولة أو نتيجة أو استحقاق شهادة من النموذج. ما يظهر في صفحة التعلم مصدره استجابة الخادم؛ التسجيل المدفوع يظل خاضعًا لخدمة `CourseProgressUseCases` وبوابة الموافقة المالية الحالية، دون تغيير صلاحياتها.
- `FeaturedScholarships` يعرض فقط السجلات المميزة الواردة من مصدر البيانات، ويختار نفس السجل بمعرفه الدقيق؛ حُذفت بطاقتا CSC/Chevening الثابتتان والمطابقة التقريبية وصورة الاستبدال غير الموثقة. القائمة الفارغة تخفي القسم. **المحوّل الحي الحالي يضع featured=false، لذلك سيبقى هذا القسم مخفيًا في api إلى أن يوفر B08 عقد التمييز الحقيقي؛ لا نمنح السجلات هذا الوصف تخمينًا.**
- `FeaturedMajors` يحتفظ بمدخل تصفح الدرجات، ويخفي جميع الأعداد الثابتة في api. لا يستعمل عدد نتائج الصفحة الأولى كتعداد عالمي. الأعداد القديمة محصورة في prototype المعلن.
- `FeaturedExams` يعرض سجلات الاختبارات المنشورة ذات ownerId الواردة من المصدر، وينقل نفس السجل دون مطابقة أسماء لشعارات ثابتة. لا بطاقات عند فراغ القائمة؛ القائمة الثابتة محصورة في prototype.
- `AIToolsBanner` في api يحتفظ بمدخل دليل الأدوات ويخفي بطاقات القدرات الست التجريبية إلى أن يوفر B08 مصدرًا محكومًا. لا يُستنتج توافر أداة تشغيلية من وجود بطاقة تصميم.
