المصدر الأساسي للمراجعة `main@06c1013cab65ac219f5d1afec934cc4e52f30d9e` بعد دمج الإصلاحات السابقة؛ فرع العمل `fix/relationship-audit-20261022`. لا تغييرات في Prisma أو ملفات migrations ضمن هذه المراجعة.

المرجع المعماري هو Roadmap v6.0، عقود المجالات في `docs/phases/`، و[سجل العلاقات](../remediation/CROSS_PHASE_RELATIONSHIP_CLOSURE_MATRIX.md). [الجرد الكامل](evidence/relationships/2026-10-22/source-relationship-inventory.json) يشمل جميع النماذج والروابط المعلنة وبنود السجل الـ77، وليس عينة مختارة من الجداول.

- 281 نموذجًا.
- 626 حقل علاقة، تشمل الطرف العكسي.
- 313 علاقة مالكة لأعمدة الربط؛ لا تضاعف بعدّ الطرفين.
- 69 علاقة R و8 علاقات تأسيسية X في السجل المعماري.
- لا وجهة نموذج مفقودة في الرسم البنيوي. توليد Prisma Client تم من المصدر دون اتصال بقاعدة وبلا تفويض كتابة.

جرد البنية لا يثبت بمفرده تنفيذ كل قواعد العمل أو عمل الواجهات أو اكتمال قاعدة Neon. استُخدمت أدلة المخطط السابقة المطابقة دون إعادة الترحيلات: `evidence/post28/433e420ec230c4dee9bd6e974329f0f48119e613/r04-r05-practical-review/GREENFIELD_MIGRATION_PARITY.json`. حالة Runtime Pending في السجل محفوظة، ولا تتحول إلى PASS شامل بسبب هذا الجرد.

## النواقص المثبتة والإصلاحات

1. **رابط اختبار صحيح لا يعمل خارج أول صفحة:** `loadPublishedExams` يحمّل 20 عنصرًا، ومعالجات الانتقال كانت تبحث في تلك المصفوفة فقط. أضيفت قراءة canonical محدودة عبر `/public/international-tests/id/:id`، مبنية على `findPublishedById` واللقطة المنشورة ذاتها؛ لا fallback لقراءة الإدارة. رُبطت بها المعالجات الخمسة مع تجاهل الردود القديمة وإظهار التعذر. المسارات بالـslug مستمرة.
2. **المستند/الشرط يعرض نصًا فقط في موضعه:** أضيف زر «عرض الاختبار المرتبط» داخل البند عند وجود ID آمن ومعالج انتقال. النص الذي يذكر TOEFL/IELTS بلا علاقة معتمدة يبقى نصًا؛ لا مطابقة تخمينية.
3. **الدورات عبر اختبار غير منشور أو تصنيف مؤرشف:** شُدد predicate قبل التصفح والعدّ، إلى جانب اعتماد العلاقة وأهلية الدورة. لا تُخفى النتائج بعد pagination بما يفسد العدّ.
4. **اختبار اختياري يظهر تحت «الاختبارات المطلوبة»:** أُخرج `isRequired=false` من الملخص الإلزامي، مع بقاء بند الوثيقة/الأهلية كما هو.
5. **اختفاء بعض المتطلبات بسبب حجب مالكها دون تنبيه:** بقيت قيود الخصوصية والنشر كما هي، وأضيف `hasUnavailableRequirements` كإشارة قراءة مشتقة بلا تخزين جديد. لا تُكشف الهويات أو الحقائق المحجوبة؛ تُعرض رسالة تحيل إلى المصدر الرسمي بدل الإيحاء باكتمال المتطلبات.

العقد الموحد: [Canonical relationships and public navigation](../architecture/PUBLIC_CANONICAL_RELATIONSHIP_NAVIGATION.md).

## ما ينتظر ملف المنح الجديد

تحديث لاحق في اليوم نفسه: استُلم v6.6، واستُبدل المصدر القديم، واكتملت مراجعة خريطة أقسام السجلات الـ947 مع إصلاح تجهيز أدلة المستندات وفصل التخصصات عن البرامج. [قرار المصدر والعودة لتهيئة القاعدة](SCHOLARSHIP_V66_RELATIONSHIP_REVIEW_2026-10-22.md) يحدّد ما أنجز وما يبقى قبل الاستيراد. توجيه المالك الجديد يجيز العودة لتهيئة القاعدة بعد المراجعة والدمج، دون أن يجيز ترقية السجلات المعلّقة أو اختلاق تعيينات canonical. البنود أدناه تحفظ سياق المراجعة الأولى.

- مطابقة الأعمدة والمجموعات والعلاقات على المصدر الجديد قبل تقرير أي نقص بنيوي إضافي.
- عدم مساواة «درجة + تخصص» ببرنامج ممول محدد إلا إذا أثبت المصدر هذه المجموعة.
- متطلبات الاختبارات البديلة، الإعفاءات، الدرجات المختلفة حسب الإصدار/النوع، والحدود المنفصلة للمهارات تحتاج تفسيرًا مثبتًا. عقد المنحة الحالي يملك test ID وحدودًا عامة؛ لا توجد فيه أعمدة نوعية لنسخة/سلم درجة الاختبار مثل عقد قبول البرنامج. إن تطلبها الملف، تُصمم إضافة للعقد وتُراجع كترحيل لاحق، دون تخزين دلالة مضللة الآن.
- الروابط الإضافية والتحسينات البصرية أو التوصيات الآلية قابلة للتأجيل؛ لا تُنشأ توصيات ملزمة من مجرد تشابه نص.

## حالة القاعدة وحدود هذه الدفعة

تأكيد قراءة فقط بعد توجيه الإيقاف: القاعدة الجديدة تحتوي 84 ترحيلًا منتهيًا، وترحيل `20261011114500_cms_bounded_search_indexes` غير منتهٍ، وpg_trgm غير مثبتة، ولا جلسة أخرى نشطة. لا تُعرض جاهزة. لم تُستأنف recovery أو migrations أو seeds أو imports في هذه الدفعة. عملية الاستئناف السابقة لم تُكمل النسخة الاحتياطية أو تثبيت الإضافة أو معالجة سجل الترحيل؛ الأدلة التاريخية محفوظة ولا تُحذف. لا عمل على المشروع القديم أو بيانات طلاب فعلية.

النطاق البرمجي هنا لا يغيّر Prisma أو سلسلة SQL. وصول ملف المنح لا يفتح تفويض كتابة تلقائيًا؛ تُعرض أولًا مطابقة المصدر ونواقصه وخطة التطبيق المحددة.

## التحقق

نجحت 33 حالة مميزة في ثمانية ملفات فحص مركزة خلال هذه الدفعة: API العام 5، محلل الانتقال بالمعرّف 6، محول المنح 5، شروط علاقات الدورات 2، قراءة الاختبار المنشور بالمعرّف 2، عرض متطلبات المنحة 3، حالة المتطلبات المحجوبة 4، وضوابط الخصوصية/الكتابة المجاورة Section11 عدد 6. لا تشمل هذه الأرقام الحالات التي استبعدها مرشح الاختبار أو أي فحص قاعدة حقيقية.

أُعيدت الحالات الثلاث الجديدة لفحص API بعد اكتشاف اعتمادها على نسخة application المولدة القديمة، وبناء التبعية المتأثرة فقط. بقيت assertions وحماية النشر دون إضعاف. ظهرت أخطاء TypeScript بسبب عدم تعريف مفاتيح بنود المتطلبات في client DTO القديم، وعولجت بمواءمة التعريف مع إسقاط API مع الإبقاء على توافق القراءات القديمة؛ اكتمل فحص TypeScript للـdomain/application/infrastructure/API/Web. فحص ESLint للملفات المتأثرة بلا أخطاء، مع تحذيرات موجودة في الملفات الكبيرة لم تُعالج بإلغاء قواعد.

لا إعادة لترحيلات المختبر أو مجموعات R السابقة، ولا تشغيل متصفح فعلي مربوط بقاعدة في هذه الدفعة. جرد Prisma وتوليد العميل وفحوص الوحدة/typecheck تعمل دون اتصال بقاعدة؛ فحص حالة القاعدة المذكور أعلاه كان SELECT فقط. الدليل البنيوي السابق لا يرقّي قاعدة Neon الجزئية إلى قبول. نُص على تعطيل نشر Vercel لهذا الفرع تحديدًا، مع حفظ سياسة main كما وجدناها؛ رفع الكود ليس إذن نشر خارجي.
