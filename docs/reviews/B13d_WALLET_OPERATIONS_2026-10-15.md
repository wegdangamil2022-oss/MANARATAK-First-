# B13d — المحفظة والحجز والفك والالتقاط

خط الأساس: 92e71c316091e18bc3a22c53d8385962d0c0789c. قبول مراجعة مصدر وفحوص محددة؛ لا اعتماد تشغيل مالي.

## التنفيذ والعقد

أضيفت قراءة محفظة محددة بالمرجع مع رصيد يحسبه المالك وقائمة حجوزات من 20 سجلًا (حد أقصى 50) وصفحات وعدد ضمن RepeatableRead. تتطلب GET صلاحية المالية القائمة وترسل no-store؛ لا قوائم غير محدودة ولا رصيد محسوب من العميل.

واجهة المحافظ تعرض الرصيد والحجوزات؛ تبحث عن فاتورة فعلية لتجلب معرفها وإصدارها وعملتها ومستحقها من المالك قبل إرسال الحجز. لا معرفات أو مبالغ مفترضة. بقي شرط إنشاء الحجز من صاحب المحفظة نفسه؛ صلاحية الموظف لا تمنح موافقة نيابة عنه. أُغلق تجاوز هذا الشرط في fallback إعادة قراءة حجز قديم: فحص المالك يسبق إعادة duplicate.

حفظ الحجز وإتمام RELEASE/CAPTURE يستخدمان FinanceCommandRecord لربط الممثل والمفتاح والهدف والنية/الإصدار بالنتيجة في المعاملة نفسها. إتمام الحجز يعيد الاستجابة قبل شرط ACTIVE، ويلزم إصدارًا صحيحًا ويحدث بشرط الإصدار؛ يمنع تغيير RELEASE إلى CAPTURE بنفس المفتاح. شروط الرصيد والعملة والالتزام والحجز المُدار للتحويلات ظلت لدى المالك؛ لم تضاف موافقة مفترضة. الالتقاط يبقى قيدًا جديدًا وتحديث المستحق مع تدقيق/outbox داخل Serializable.

واجهة الأوامر تحفظ path/body/version/key للنفس وتمنع النقر المكرر وتسمح بإعادة محاولة مطابقة؛ تتجاهل الردود المتأخرة بعد تغيير المرجع. إخفاء البيانات القديمة عند فشل القراءة ومنع الاعتماد على سجل يعود لمرجع آخر مدعومان بعقد قارئ مشترك. APIs الكتابة تحت wallet:manage وتلزم الإصدار.

## الفحوص والمتبقي

فحص V8 خفيف واحد لجسم resolveWalletHold ببدائل صريحة: 7/7 PASS (فك مرة واحدة، التقاط وقيد مرة واحدة، غياب/تعارض الإصدار، حجز التحويل الممنوع، action غير صالح، تغيير النية بنفس المفتاح). [الدليل](evidence/b13d-wallet-light-checks-2026-10-15.json). لا يمثل فحص SQL أو typecheck أو UI/HTTP؛ فحص إنشاء الحجز تحت التنافس والرصيد الحقيقي ما زال runtime معلقًا.

بيئة الأوامر منفصلة؛ لم تشغل Vitest أو build أو DB أو مزود ولا أُعيد فحص سابق. يلزم typecheck وUI/HTTP عند استعادة البيئة، ثم PostgreSQL معزول للرصيد/حجزين/receipt/rollback وتجربة صاحب المحفظة والموظف؛ لا تفعيل FINANCE_RUNTIME_APPROVED. التراجع بتعطيل الأوامر الجديدة دون محو حجز أو قيد. التالي عكس القيد.
