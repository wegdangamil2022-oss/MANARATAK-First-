## الإصلاحات في هذه الجولة

- نقل 173 نصًا ثابتًا ومصطلحات picker/usage إلى dictionaries AR/EN في Library/Details/Governance/Upload/Actions/Picker، وتصحيح LTR وتنسيق تاريخ Governance بحسب اللغة. SSR وChromium EN/mobile يثبتان عدم تسرب العربية داخل asset workspace.
- اختبارات serialization القديمة رفضت port 55432؛ أضيف خيار rehearsal صريح بURL ثابت فقط، دون تعديل installer CI أو فتح host remote. أزيل import مكرر، وصححت ثلاثة fixtures CMS بما يتوافق مع `lastModifiedBy` المطلوب؛ assertions الأمنية بقيت كما هي.
- تمت rehearsal لترحيلات reference/restore/archive الثلاثة على الحاوية الجديدة فقط بعد عرض الأوامر، ثم 39 PG cases حقيقية و10k assets benchmark. schema `db push` + guard SQL ليس migration-chain/greenfield rehearsal كاملًا.

## العوائق المتبقية

- لا isolated scanner/sanitizer/object-store/CDN configured fixtures متاحة؛ الأدلة الحالية mocks/contract/local gateway وليست EICAR/EXIF/CDN acceptance. طلب المستخدم يمنع المزودات الحقيقية، فلم نتصل بها.
- uncertain archive/restore operations تبقى blocking؛ لا automatic authoritative provider reconciliation/fencing. target migration installation/legacy request quiescence لم يحدثا.
- editor/public end-to-end كامل، rights/license policy، renditions provider/inventory، وarchitecture decision للregistry تبقى واضحة في الجدول.
