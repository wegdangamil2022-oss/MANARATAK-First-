### أدلة التحقق الأولية

## 3 — المنح الدراسية

الحالة: جاهزية وظيفية ضمن العقد الحالي بعد التصحيح والتحقق أدناه؛ لم يُجرَ اختبار نشر أو حفظ على القاعدة الأصلية.

- الفلاتر والبحث والصفحات تُقرأ من الرابط وتُحفظ عبر React Router دون محو بيانات تاريخ التنقل. تُستبعد القيم غير الصالحة وتُحدّد أطوال البحث، وتعود الصفحة للأولى عند تغيير الفلاتر. أضيف التنقل بين الصفحات إلى عرض البطاقات أيضًا.
- تُلغى قراءات القائمة المتقادمة، ولا تبقى نتائج سابقة عند فشل القراءة. يفصل خطأ الإحصاءات عن خطأ القائمة، ولا يُعرض العدد المفلتر بوصفه إجمالي المنح. تتاح إعادة المحاولة للقائمة ولبرامج العلاقات المرجعية.
- لا تُستبدل بيانات منحة بإقرار حفظ متأخر بعد الانتقال إلى منحة أخرى أو تغيّر نطاق الصلاحيات. لا يُعلن نجاح قرار نشر أو أرشفة قبل إعادة قراءة الحالة المطلوبة؛ وعند تعذر ذلك يمنع تكرار القرار على نسخة قديمة، مع حفظ المسودة عند تعذر التحقق من حفظ المحتوى.
