2. وقت آخر قراءة ناجحة تجاهل قراءات المؤشرات التنفيذية. أصبح يشملها ضمن المصادر المصرح بها.
3. رابط طلبات التقديم اشترط إدارة كتالوج الخدمات مع صلاحية قراءة الطلبات. أصبح يطابق مسار قراءة الطلبات، ويختفي عند سحب الصلاحية.
